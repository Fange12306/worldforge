# 语言演化与历史语言学

> 目的: 让虚构语言携带"历史"——用历史比较法重建祖语,用音变规则派生语系,用借词分层埋考古线索,用词汇统计粗定分化年代,把语言兴衰写成历史事件。
> 前置: 音系篇(04)提供音位清单作为音变的原料;与历史篇(征服/接触期)、地理篇(迁徙/隔离)双向咬合。

## 核心理论

- **历史比较法 = 重建祖语的基本方法**: 比较同源语言中同源词的语音对应,排除偶然相似与借词,归纳规则语音对应,据此逆向重建祖语。核心原则是"差异有序、对应成律"。辅助方法还有内部重建法——仅凭单一语言的交替形态(如元音交替)推断早期形态,适用于无亲属可比的孤语。
- **谱系树 vs 波纹模型,二者互补**: 谱系树把分化画成树干分叉(祖语→语族→语支→语言→方言),分叉即人群分化;波纹模型补充: 创新像波纹从中心扩散,相邻语言共享部分特征——谱系并非干净分叉,而是方言连续体被政治/军事边界切割成"语言"。树状图管"遗传",波纹图管"接触"。
- **音变规律无例外,例外归类推**: 音变是盲目的、机械的、按语音环境无条件进行的;词形统一靠类推修补。"例外"往往只是条件更精细的规律(重音位置、相邻音环境),这是重建工作可检验的公理基础。
- **借词分层 = 语言史的"地层学"**: 不同历史时期、不同来源的借词构成地层——底层(被征服/原住民语言)、上层(征服者语言)、文化层(宗教/科技传播)。借词方向即权力/文化关系。
- **语言联盟 = 无亲缘的趋同**: 地理相邻、不必同源的语言共享一套结构特征(音系/句法);典型如巴尔干联盟(分属数语族却共享后置冠词、属格与格合并、不定式退化)。它暗示长期共处与双语社会。
- **词汇统计粗定年代,但不可精确**: 基于"核心词汇替换率大致恒定"(经验保留率约每千年 86%,即每千年替换约 14%),统计同源核心词比例估算分化年代。该法争议极大,现在只作亲属关系速测工具,不作精确断代。
- **语言死亡是代际传承中断,不是"变没了"**: 儿童不再习得母语、转用强势语言;死亡语言仍可通过文献复活。消亡的常见推手: 帝国标准化政策、战争屠杀、移民转用、教育压制。

## 分化时间估算速查(词汇统计,仅供设定参考)

| 同源核心词保留率 | 约合分化年代 | 设定含义 |
|---|---|---|
| > 80% | < 1000 年 | 近亲方言/兄弟语言,互通度仍高 |
| 60~80% | 1000~2000 年 | 语支级分化,共享大量同源词 |
| 40~60% | 2000~3500 年 | 语族级分化,同源痕迹需细察 |
| < 40% | > 3500 年 | 语系级分化,只能靠规则对应辨认 |

## 语言活力分级(评估虚构语言生死)

| 等级 | 判据 | 世界构建写法 |
|---|---|---|
| 安全 | 代际传承稳定,全领域使用 | 主流语言,无需处理 |
| 易危 | 儿童在家仍学,但公共域被挤压 | 少数族裔语,家庭域存活 |
| 明确濒危 | 儿童不再习得,只剩老人说 | 老人语,主角"最后一说者"素材 |
| 严重濒危 | 使用者极少且分散 | 仅仪式/口传残留 |
| 极危 | 仅个位数使用者 | 抢救性记录剧情 |
| 灭绝 | 无母语者,但文献/录音尚存 | 可复活: 词典编纂、语言巢 |

## 机制与案例(可迁移的设定模板)

- **链式音变(经典模板)**: 一组系统性移位,如"清塞音→清擦音、浊塞音→清塞音、送气浊塞音→浊塞音"三连环(例: 拉丁语 pater↔英语 father 的 p→f)。设计女儿语时照此造 1~3 条链式规则,一支语言即可与祖语拉开"听感距离"。
- **条件音变("例外"的真相)**: 同一条规则按重音位置/相邻音分化出不同结果(如清擦音在非重音前浊化)。这正是"留几条不规则形式"的正当来源: 表面不规则,实为条件更精细的规律。
- **重建预测考古证实(最强叙事)**: 纯靠内部推理假设祖语存在某类已消失音位,后由出土文献印证。世界内可复刻: 虚构学者重建出祖语词汇,恰好被遗迹铭文证实——"重建可以预测并等待证实"是历史语言学最有戏剧性的情节。
- **借词锁定时代**: 若语言 A 保留了语言 B 已发生音变前的形式,则借入必早于该音变——借词像化石一样给历史事件定下限。
- **语言复兴案例(正面模板)**: 断代语言经一人之力复兴为国语;社区学校"语言巢"幼儿沉浸教育逆转衰退;反面是持续萎缩的语言。可设定"祖语以仪式/古典语身份存续"(类似拉丁语、梵语),与日常口语形成雅俗分层。
- **语系起源之争(设定素材)**: 同一语系的起源可有"草原骑马说"与"农业扩散说"之争,数据不同结论不同——世界内可让学派对掐,成为学术线/派系斗争。

## 构建操作

1. 先画一棵语系树并让它"可见": 设定 1~2 个祖语,按世代或世纪画分叉树;为各分支设计共享同源核心词(水/火/母亲/石头等各 20~50 个),让读者一眼看出"这两国语言是远亲";
2. 为每支语言写"音变规则手册": 如祖语某音在 A 语保留、B 语变擦音、C 语变塞擦音(条件分述);故意留几条不规则形式用类推或借词解释——这层"脏数据"正是真实感来源,也可做成世界内语言学家的研究谜题;
3. 用借词分层做考古: 为每段历史事件(征服、贸易、宗教传播、科技引进)设计一个借词层,各层词汇领域不同(征服层=军事与食物、宗教层=仪式术语);让世界内学者能通过词汇地层"挖掘"出被遗忘的王朝;
4. 设置语言联盟制造"伪亲属": 让几个不同语族的邻国共享结构特征(后置冠词、声调、量词、复合动词),使世界内语言学家误判其同源——可安排"被证伪的谱系"学术事件;
5. 把语言兴衰写成历史事件: 设定若干濒危/死亡语言(帝国标准化政策压制、战争屠杀、移民转用),再写一两场复兴运动(儿童沉浸式语言巢、词典编纂、文献复活);
6. 为世界添加"语言年代学争议": 虚构学者用核心词表估算分化年代但结果互相矛盾(呼应真实学界对替换率恒定假设的批评),成为派系斗争或剧情线索;也可让重建祖语词汇"恰好"被遗迹证实,复刻"重建预测考古"的戏剧性;
7. 用方言连续体补充谱系树: 在平原地区画"渐变色带"(相邻村庄语言互懂、两端不通),在山地画碎裂飞地,再让政治边界把连续体切成"语言"——地图与语言史同步产出。

## 检查点/清单

- [ ] 语系树已画: 祖语→语族→语言分叉清晰,可追溯?
- [ ] 每支语言有 2~4 条音变规则,且条件(语音环境)写明?
- [ ] 有不规则形式,且每个都有类推/借词/条件音变解释?
- [ ] 同源核心词 20~50 个/支,共享可感知的同源痕迹?
- [ ] 借词分层与历史事件一一对应,借词方向=权力关系?
- [ ] 语言联盟已设定,且与长期共处/双语社会叙事配套?
- [ ] 濒危/死亡/复兴语言已写入历史时间轴?
- [ ] 方言连续体与地理(平原趋同/山区碎裂)一致?
- [ ] 无"全员同步分化"——各支分化年代有差异(用词汇统计粗定)?
- [ ] 语言史与历史篇的征服/接触/迁徙事件无矛盾?
