# 种族谱系与演化

> 目的: 把种族放进演化树, 用"谱系四模式"组织种族关系, 用适应辐射与地理隔离解释多样性, 并把谱系表做成自带政治含义的意识形态文件。
> 前置: 输入地理屏障(山脉/海/沙漠/魔法裂隙)与生态空缺(大灭绝/魔潮之后); 输出种族关系(混血可行性/冲突温度)与神话史。

## 核心理论

- **全部物种是一棵演化树上的分支**: 任何两个类群共享一个最近的共同祖先, 分叉节点即成种事件。类群必须是"单系"(一个祖先及其全部后代)而非按形态相似拼凑; 建树依据是共有新特征。"种族"应被理解为树上的分支而非并列的盒子——半精灵、混血种在谱系上的位置因此变得可解、可争议。
- **种族谱系的四种叙事模式**(把生物学模式转译为谱系学范畴):
  | 模式 | 生物学地基 | 叙事含义 |
  |---|---|---|
  | 同源分化 | 共同祖先适应辐射 | 共享深层血统, 可育混血的前提 |
  | 异源独立 | 不同源头趋同演化 | 形态相似却来源迥异(袋狼似狼而无关) |
  | 收养追认 | 谱系的灵活运用 | 养子/征服者/神话英雄被"写入"家谱 |
  | 堕变造物 | 神话事件而非自然成种 | 神/术法造出, 或高等种族堕落扭曲而成 |
- **适应辐射需要三条件**: ①祖先进入开放的生态位空间; ②环境梯度(群岛/山脉/湖盆)提供隔离; ③强烈的分化选择。一个祖先种在生态空缺中快速分化出多种生态形态, 形态与生态位一一对应。
- **地理隔离与物种形成**: 种群被地理屏障切断→两地独立演化(突变/遗传漂变/不同选择压力)→积累生殖隔离(合子前: 求偶行为/繁殖季节/器官不匹配; 合子后: 杂种不育/杂种衰败)→即使屏障消失也不再融合。同域/邻域成种较少见, 通常依赖生态位分化与选型交配。
- **退化与返祖**: 退化指功能或结构的简化(洞穴生物眼与色素退化、鲸类骨盆后肢残留)。**复杂结构一旦丢失, 演化上几乎不会原样重现**(不可逆法则); 但功能/生理层面可被"重新发明"。返祖则是个体偶发重现久远祖先特征(鲸偶现后肢芽), 说明祖先状态仍潜伏于基因组, 可被重新表达。
- **谱系即神话史**: 家谱/谱系表从来不是中性记录, 而是世界观大纲与权力文本——王室家谱通过追溯神圣或遥远的祖先来合法化统治; 谱系可被修订、追认、嫁接、抹除。**谁被列入、谁被抹去、谁被追认, 本身就是叙事**。
- **分化时间用世代数而非绝对年份标定**: 分子层面的随机漂变为主时, 树的分叉时间由"世代数"决定——对长寿种与短寿种, 同一绝对年代跨度对应截然不同的世代数; 标注分化时间须写明"距今 X 代/纪元", 否则长寿种与短寿种的谱系刻度无法互比。

## 成种与分化的操作模板

- **异域成种五步**(可直接作种族分化模板): ①祖先种扩张+地理屏障出现; ②隔离种群漂变与局部适应; ③合子前隔离先形成(行为/季节/形态); ④合子后隔离巩固; ⑤二次接触时或融合, 或经强化彻底分化。
- **隔离程度决定"种族关系"温度**: 长期隔离→生殖隔离(混血不育或无法交配); 近期隔离→混血可行但成社会禁忌; 相邻共存→靠选型交配/生态隔离(栖息地/作息/择偶标准)维持差异。
- **成种进行时的活标本**: 不同"种"之间仍会杂交、生殖隔离尚未完成——环境骤变(大旱/丰水)会让不同形态的个体存活率反转, 选择效应数代可见。这是"种族边界模糊期"的最佳模板。
- **谱系断裂**: 大规模灭绝(疾病/栖息地破坏/灾变)抹去大半分支——"古籍载四十种龙, 今存五种"式的设定由此获得自然解释。

## 构建操作

1. 先画演化树, 再写种族史: 为每个种族标注共同祖先是谁、分化时间(以"纪元/代际"锚定)、与邻族是姊妹类群还是远亲趋同; 混血可行性由树拓扑决定——只有同源且生殖隔离不完整的种族间才有可育混血;
2. 用适应辐射生成同源种族群: 要"精灵有森林/沙漠/深海/高山诸裔", 就复制标准配方——一个祖先种+一组环境梯度+各自特化特征(耳形/肤色/夜视/呼吸), 特征直接对应生态位而非纯装饰; 并说明辐射前提: 这些生态位为何空缺(大灭绝/魔潮之后);
3. 用地理隔离控制"种族关系"的温度: 地图上的屏障(山脉/海/沙漠/魔法裂隙)决定分化程度; 让"种族冲突"获得演化层面的解释力;
4. 把退化与返祖写成机制而非设定: 远古种族衰落=功能简化+不可逆法则的不可逆(失去的力量无法原样找回, 只能趋近替代), 制造悲怆; 返祖个体(重现祖先巨角/第二对眼/远古记忆)可作主角、先知或诅咒——"血脉觉醒"=休眠基因被重新表达, 而非常识性"变强";
5. 让谱系表自带政治性: 绘制神族/王族/种族族谱时刻意植入——被追认的收养祖先(合法性嫁接)、被抹除的旁支(清洗)、神话祖先与考古祖先的错位(正典史书≠真实历史); 把"家谱文书"做成可伪造、可焚毁的剧情道具;
6. 主动使用异源独立与收养追认, 打破"万物同源"的平庸: 允许两族形态相似却来源迥异(趋同), 允许一个种族在政治上"收养"异族英雄为王(追认), 形成"生物学谱系"与"政治谱系"双轨叙事;
7. 给演化树配"地层": 化石、圣遗物、古文献按纪元分层, 让读者能推断"古籍中的上古巨兽"其实是某共同祖先的化石证据; 用谱系断裂解释"为何今存五种龙而古籍载四十种"。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 所有种族"从同一人形祖先演化"却无分化机制与时间 | 给共同祖先+分化时间+隔离机制 |
| 混血规则全有或全无 | 服从生殖隔离的梯度(屏障时长/隔离类型) |
| 退化写成可逆增强器 | 复杂结构不可逆, 只能趋近替代或功能重发明 |
| 家谱仅作装饰 | 谱系表自带矛盾、缺口与政治含义 |
| 种族关系无演化解释 | 用地理隔离程度定混血可行性与冲突温度 |
| 特征与生态位脱钩 | 辐射分支的特化特征直接对应生态位 |
| 万物同源无例外 | 用异源独立(趋同)与收养追认制造双轨张力 |

## 检查点/清单

- [ ] 每个种族在演化树上有位置(共同祖先/分化时间/邻族关系)?
- [ ] 谱系四模式(同源/异源/收养/堕变)均有使用?
- [ ] 同源种族群的辐射前提(生态位为何空缺)已说明?
- [ ] 混血可行性由生殖隔离梯度决定而非全有全无?
- [ ] 退化遵循不可逆法则, 返祖=休眠基因重新表达?
- [ ] 谱系表有政治性(追认/抹除/正典与史实错位)?
- [ ] 演化树配有地层(化石/圣遗物/古文献分层)?
- [ ] 谱系断裂解释了"古籍多而现存少"的设定?
