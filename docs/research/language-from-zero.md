# 第一部分: 执行流程

## 第 0 步: 定位与总流程——先定语言角色, 再谈造语

**[输入]** 文明档案(各族/政体/宗教/社会分层)+ 历史篇大事年表(迁徙/征服/贸易事件)+ 地理篇地图(山脉/海洋/商路/平原)+ 法则篇魔法规则(真名/施法语言/神圣文字)+ 既有命名素材(人名/地名/咒语残片)。

**[操作]**
1. **写"语言角色清单"**: 列出每门语言的名称/级别/使用者/功能(日常/官方/宗教/魔法), 按叙事可见度分配工作量, 严禁"每族都做完整语言"(109: 命名级/完整级/实验级三类工作量差一到两个数量级, 先定角色再动手)。
2. **语言是分层系统不是单词表**: 自底向上构建 音系→形态→句法→词汇, 任何一层缺失都会在命名与文本中露馅; 音系先行, 人名/地名/咒语/借词/文字一律从音位表内生成。
3. **建谱系树与语言史时间轴草稿**: 设计 1-2 个祖语→声明 2-4 条音变规则(仿格林定律)→推女儿语; 每支语言标注"诞生时代/主要音变/借用来源"; 用词汇统计学粗定分化年代(核心词约 14%/千年替换)。
4. **画语言地图**: 语族分布与山脉/海/迁徙/征服史一致; 平原=方言连续体, 山区=碎裂语言带; 大河名用最古层, 城镇名用征服层; 商路与海岸=趋同带(地理语言学)。
5. **为魔法/神圣语言设"双言制"接口**: 高变体(宗教/法律/魔法)与低变体(日常口语)并存并功能分工; 用"帝国古文字不变、口语已漂移"解释咒语/真名/仪式的来源——祭司念古语、民众说土语(文字滞后机制)。
6. **建"语言档案"模板(八件套)**: 音系表(IPA)/构词纲要/句法纲要/核心词汇/文字系统/样例文本(莱比锡标注+可回译)/谱系树/语言地图, 先为旗舰语言建样板, 再推广。
7. **跑检查点清单**: 每语言有音系文档? 命名只用本语言音系? 谱系可追溯? 地图与迁徙一致? 至少一段带标注文本? 魔法语与日常语接口明确? 无跨语言串味?

**[决策规则]**
- 语言是活的: 不存在完全规则的自然语言, "过度规则"本身就是错误信号, 规则与例外要成对出现(Peterson 有机性);
- 音系先行: 音位清单决定语言"长什么样", 是其他一切模块的约束源;
- 语言史 = 历史语言学: 分化(谱系树)与趋同(波浪模型/语言联盟)是两条并行的演化轨道;
- 文字是独立于语音的平行系统: 正字法深度(浅/深)决定"拼写与发音脱节"这一神圣语机制的成因;
- 语言即社会分层: 双言制(高变体/低变体)是"魔法语言 vs 日常语言"、"祭司古语 vs 民众土语"的学术原型(Ferguson)。

**[输出产物]** `语言角色清单`(分级/使用者/功能)+ `谱系树草稿与语言史时间轴` + `语言地图` + `双言接口说明` + `语言档案模板`(八件套)+ `检查点清单`。

**[检查点]** 角色分级齐备且工作量与叙事可见度匹配; 音系先于其他模块; 谱系与地理/迁徙/征服史互证; 双言接口可解释所有咒语/真名来源; 旗舰语言档案八件套齐备; 无跨语言混用。

## 第 1 步: 语言类型学与语言演化——先定骨架, 再写历史

**[输入]** 第 0 步角色清单 + 文明篇(社会结构/宗教/贸易网络)+ 历史篇(征服/迁徙/贸易事件)+ 地理篇语言地图草稿。

**[操作]**
1. **定"类型学骨架"**: 选基本语序(SOV/SVO/VSO 等), 按 Greenberg 共性 2-4 与 Dryer 相关对自动推导介词类型/属格位置/关系从句位置/副词位置/疑问词位置, 形成内部一致的"类型包"; 刻意违反相关对(如德语式框架结构)必须写历史漂移/语言接触解释。
2. **用 WALS 做"8-12 特征配方"**: 从语序/格标记/名词类/动词一致/证据性/声调/复辅音/疑问策略各选一项, 逐对检查蕴含关系, 排除统计互斥组合("无格标记+完全自由语序""SOV+前置词"), 保证语言统计意义上"像真的"。
3. **特色机制只取 1-2 个并绑定文化动机**: 分裂作格需定分裂维度(人称层级/时体/生命度, Silverstein 施事层级); 证据性需定义务性(每句强制?)与权威语义(谁有资格用亲历系→可映射祭司/贵族话语权); 名词类需定语义核心+"任意延伸"边缘(Dyirbal 四类模板)。
4. **建谱系树并让"同源异貌"可见**: 为各分支设计共享同源核心词(水/火/母亲/石头 20-50 个), 用 2-4 条音变规则推导; 故意留几条不规则形式用类推或借词解释——这层"脏数据"正是真实感来源, 也可做世界内语言学谜题。
5. **用借词分层做考古**: 为每段历史事件(征服/贸易/宗教传播)设计一个借词层, 各层词汇域不同(征服层=军事食物/宗教层=仪式术语); 借词方向即权力关系; 借词能锁定借入时代(保留借出语音变前形式=借入必早于该音变)。
6. **设 1-2 个语言联盟制造"伪亲属"**: 让不同语族邻国共享结构特征(后置冠词/声调/量词), 使世界内语言学家误判同源——可安排"被证伪的谱系"学术事件; 语言联盟也暗示长期共处与双语社会。
7. **把语言兴衰写成历史事件**: 设濒危/死亡语言(帝国标准化/战争屠杀/移民转用), 写复兴运动(语言巢/词典编纂/文献复活, 参考希伯来语与毛利语); 让祖语以仪式/古典语身份存续(拉丁语/梵语模式), 与日常口语形成雅俗分层。
8. **为世界添加"语言年代学争议"**: 虚构学者用核心词表估算分化年代但结果互相矛盾, 成为派系斗争或剧情线索; 也可让重建出的祖语词汇"恰好"在遗迹中被发现, 重现索绪尔喉音理论的戏剧性验证。

**[决策规则]**
- 类型学以共性为目标、以差异为材料(Comrie); "若语言有 X 则必有/常有 Y"的蕴含共性是配方检查的标尺;
- 语序不是独立参数, 而是 VO/OV 两大阵营的共变(Dryer 分支方向理论);
- 特色机制是"世界观"的语法物化: 作格适合结果导向文明, 多一致/多式综合适合仪式语(复杂度分配给过去高地位语言);
- 音变规律无例外, 例外可由类推解释(新语法学派)——音变是盲目的、按语音环境机械进行的;
- 语言死亡是代际传承中断而非"变没了"; 复兴须自下而上逐级爬(GIDS)。

**[输出产物]** `类型学配方表`(每语言: 语序包/特征清单/WALS 依据)+ `谱系树`(祖语/音变规则手册/同源核心词)+ `借词分层地层表` + `语言联盟档案` + `语言兴衰年表`(濒危/死亡/复兴)+ `语言年代学争议文档`。

**[检查点]** 语序包内部一致(相关对无冲突); 配方逐对过蕴含检查; 特色机制 ≤2 且有文化动机与触发条件; 每支语言有音变规则手册; 借词层与历史事件一一对应; 至少一个语言联盟; 至少一条濒危-复兴叙事线。

## 第 2 步: 音系与书写系统——音系定气质, 文字定权力

**[输入]** 类型学配方 + 文明篇(宗教/识字率/媒介)+ 历史篇(正字法事件)+ 地理篇(书写材料: 泥板/竹简/石碑/纸草/贝叶)。

**[操作]**
1. **定"听觉气质"再填表**: 飘渺族=纯 CV+五元音+无清浊对立+几乎无辅音丛; 重权族=大辅音库(挤喉音/清浊满格)+闭音节为主+低调嘎裂声; 航海商族=音节简单+元音对立丰富(便于远距离喊话)。用"对称矩阵+1-2 空洞"落表, 空洞即传说("古语 /g/ 已亡, 借词仍带 /g/")。
2. **音位总数控制在自然范围**(11-141, 常见中位数 25-35; 辅音 20-40+元音 5-10, UPSID/Maddieson); 奇异音段(吸气音/超复杂复辅音)只出现在地理文化可解释的角落, 配"孤儿音"来源, 避免"全球通用奇音"。
3. **设计音节结构与韵律**: 纯 CV(波利尼西亚式)到重辅音丛(格鲁吉亚式六连辅音); 设定 2-3 组"允许/禁止"配列与同化规则; 音节重量(长元音/闭音节=重)与重音/声调联动; 可做"拍"语言(日语式 mora)。
4. **声调设计(2-6 调)并写"出生证明"**: 每调注明声调发生史——声母清浊对立丢失→高低调分裂; 韵尾 -ʔ 丢失→升调、-h 丢失→降调(越南语三阶段); 前缀丢失; 定 1-2 条变调规则(普通话 T3+T3→T2+T3; 闽南语"除末音节全变"连锁变调); 低调伴嘎裂声=威严质感。
5. **按"音系→文字"推导书写类型**(Daniels & Bright 六类型): 纯 CV→音节文字/abugida; 重辅音丛→字母; 辅音词根型→abjad; 单音节孤立语→语素文字; 特征文字(谚文式)="理性王权为民造字"叙事——避免"CV 语言配 abjad"的违和。
6. **写"文字演化编年史"四阶段**: 象形(图画记事)→假借(同音表音, 歧义危机)→形声(加义符/限定符消歧)→楷化(统一正字/笔画简省); 每阶段配一个历史事件并留物质遗迹(碑铭用古体、法典用新体); 字母"单次起源、多次传播", 个人创制(谚文/切罗基文)是造字英雄叙事模板。
7. **用文字分层塑造社会结构**: "神圣古体+世俗简体"双轨(埃及三体/日语三系统): 祭司/贵族垄断语素古体(神秘排他), 民间流行简化音节字(开放通俗)——直接决定识字率/书籍形态/教育/权力分配。
8. **媒介绑定材料与字体**: 泥板(楔形/笔画刚硬)、竹简(直排)、纸莎草(草书化)、石碑(庄严正体); 碑铭用古正体、私信用连笔草体; 留 5% 历史残留(同音字/多音字)与一场"正字法改革之争"。

**[决策规则]**
- 标记性: 无标记音(p t k/m n/i a u)跨语言最常见, 有标记音少见、习得晚、易在历史中失落——"奇音"应少而精;
- 空洞是历史音变的化石, 是给世界造史的天然抓手;
- "象形→表音"是文字演化的总趋势, 但单线论已被否定(辅音文字先于字母即反例);
- 字符数趋向经济、持续表音化、歧义驱动改革(Fortuny);
- 文字是"言语行为固化进物质"的第一步——契约/碑铭/护符让施为脱离说话者的在场而持久生效(为魔法语言铺垫)。

**[输出产物]** `音位表`(每语言: 辅音/元音/空洞/音系经济性)+ `音节结构与配列规则` + `声调档案`(调值/出生证明/变调规则)+ `文字系统卡`(六类型之一+正字法-音系转写规则)+ `文字演化编年史`(四阶段+事件+物质遗迹)+ `文字分层与识字率地图`。

**[检查点]** 音位表在自然范围且对称+空洞; 奇音有来源解释; 每调有出生证明且变调规则可操作; 文字类型与音系匹配; 四阶段各有历史事件与物质遗迹; 神圣/世俗双轨与识字率、权力结构互证。

## 第 3 步: 词汇与语法——词分三层, 语法只取签名

**[输入]** 音系表 + 类型学配方 + 文明篇(农业/战争/航海/宗教语义场)+ 历史篇(接触期)+ 经济篇(贸易/税收词汇)。

**[操作]**
1. **词汇三层扩展**: ①Swadesh 100(或 207/Leipzig-Jakarta)核心词全自创、形态尽量简单、高频词允许不规则; ②20-30 个词根辐射词汇家族, 定 10-15 个能产词缀+派生规则; ③借词按文明接触史分层, 每层配一套音系适配规则(音段替换/增音/删音/重音规则化)。
2. **语义场按"演化阶梯"扩展**: 色彩词按 Berlin-Kay 等级序列(黑/白→红→黄/绿/蓝)逐级增加而非随机堆叠; 用隐喻(身体部位→空间/抽象)、转喻(容器→内容/工具→职业)、语义漂移(变宽/变窄)扩展; 每新增一词记录"词源+构词路径", 汇成词源词典。
3. **选"语法签名"1-2 项深度做**: 作格(定分裂维度与"受动者中心"世界观)/名词类(定语义核心+任意延伸边缘)/证据性(定义务性与权威语义)/自由语序(配套话题/焦点标记与语用规则); 其余语法用典型类型, 防特征堆砌导致不自然。
4. **语序与格系统联动**: 主序定后按谐和原则推副序(SOV→后置词+属格前置); 自由语序必须说明格系统如何分担语义角色(格弱化常与语序固定化同步, 英语史模式); 两者都强是罕见配置。
5. **用"演变脚本"生成不规则**: 写 3-5 条历史音变规则(元音链移/词尾辅音脱落), 手工套用到高频词, 得到有词源依据的不规则动词/复数/属格, 而非随机乱造(高频词更易磨损、更易保留不规则, Bybee)。
6. **借词层写入世界史**: 每层借词对应一个文明接触期, 借词方向即权力/文化关系; 区分征服层/宗教层/科技层词汇域(参照中世纪英语的法语层); 核心词几乎不被替换是判断借词的线索。
7. **控制同音歧义密度**: 每百词制造 1-3 个同音/多义词增强自然感, 但保证语序/助词/话题标记等消歧手段存在; 神名/禁忌词触发同音回避(taboo avoidance)作叙事钩子。
8. **产出三份配套文档**: 音系规则手册/构词词缀手册/词源与借词词典, 保证后续创作中词汇与语法高度一致。

**[决策规则]**
- 核心词稳定性梯度: 人称代词/身体部位/亲属/数字 1-2 最稳, 文化器物与低频词最易替换(词表现在只作"采样器"不断代);
- 派生造新词位, 屈折不造新词; 能产词缀与化石词缀并存是自然语言常态;
- 自然 vs 人工的平衡: 人造语言天然过度规则, 不规则必须有历史"来源"(原始形式+音变+形态合并);
- 借词被强制音系适配, 也可故意保留"外来层"发音作社会/文体标记;
- 借词方向必须由历史接触事件解释(命名-语言-文化一致性原理)。

**[输出产物]** `核心词表`(100 词+词根词缀表)+ `语义场扩展清单`(词源词典)+ `语法签名规则页`(1-2 项完整规则)+ `演变脚本`(音变规则+不规则词表)+ `借词分层词典`(来源/年代/音系适配)+ `同音歧义登记表`。

**[检查点]** 核心词全自创且高频词有"脏数据"; 词根词缀可自由造新词; 语法签名 ≤2 且规则完整可回译; 不规则词有演变脚本出处; 借词层与历史事件对应; 歧义密度可控且有消歧手段。

## 第 4 步: conlang 类型与实践——先定层级, 再谈完整

**[输入]** 前几步的语言骨架 + 叙事需求(哪些语言出现对白/只出现名字/只出现短句)+ 预算(作者时间/团队规模)。

**[操作]**
1. **按三分法对每门语言定性**(目标即定义): auxlang(世界内通用语, 标准=易学/中性)/engelang(逻辑/律法语言, 标准=规则一致/无歧义)/artlang(艺术语言, 标准=像活语言/契合文化气质); 世界构建 90% 是 artlang, 但通用语可借 auxlang 思维(简化+中性)。
2. **按"可见度"定层级**: 只用于地名/人名=命名语言(音系+正字法+150-300 词, 无语法, 工作量以天计); 角色要说对白=语法草图(基本形态句法)或完整语言(音系+形态句法+词汇+历时演变, 以月-年计, Dothraki 全职约一年); 避免过度投入。
3. **采用"历时语言工程"法**(Tolkien): 先设原始语, 再按音变规则分裂出多支(昆雅/辛达林模式); 语言家族树与各族迁徙史一一对应, 语言史即世界观史; 亲缘/敌对民族共享可察觉的同源痕迹。
4. **音系即气质+可表演性约束**(Frommer): 尚武族用塞音/小舌音(克林贡), 优雅族用开元音/流音(昆雅); 保留 1-2 个"怪音位"制造异质感, 但必须保证读者/演员能发音。
5. **语法只建"主题相关"范畴**: 突出 2-3 个体现文化核心的范畴(荣誉敬语/证据性/不可让渡领属); 选一个异于英语的语序(VSO/OVS)并贯彻到底; 克林贡 OVS+作格=刻意陌生化, Láadan 证据性=假说驱动, Na'vi 名词类前缀+证据性=特色语法示范。
6. **先定规则再写对白**: 正文每句都要能回译为自建语法; 维护"词典+词族+构词法"文档(含借词与词源), 版本化管理, 杜绝临场发明导致前后矛盾。
7. **注入"不完美"**: 造不规则动词/历史借词/文白分层(口语 vs 古语/宗教语); 让一门古语充当"世界的拉丁语"(高瓦语模式), 近零成本提升世界深度。
8. **使用即检验**: 定期用自建语言写句子/编谚语暴露设计漏洞; 发布到社群(LCS/r/conlangs)获取反馈, 让语言在"被使用"中自然演变(Peterson 流程)。

**[决策规则]**
- 造语的成败不在设计而在社群生态——两百年 auxlang 方案只有 Esperanto 存活(Okrent), 世界内通用语要给出"使用者网络";
- artlang 的核心是自然主义(naturalism): 语言是历史产物, 携带不规则/借词/音变痕迹, 可被考古(Tolkien "philological" 式爱好);
- engelang 两支脉(17 世纪哲学语言/20 世纪逻辑语言)适合"神谕/预言/律法语言"设定;
- 命名语言与完整语言工作量差一到两个数量级——先定角色再动手;
- 语言先于故事: 故事从语言中生长出来, 语言是世界构建的引擎而非装饰(Tolkien)。

**[输出产物]** `语言类型宣言`(每语言: auxlang/engelang/artlang 定性+验收标准)+ `工作量分级表`(命名级/草图级/完整级)+ `历时演变档案`(原始语+音变规则+语支树)+ `语法范畴清单`(主题相关范畴)+ `词典与构词文档`(版本管理)+ `使用检验记录`。

**[检查点]** 每语言三分法定性明确; 层级与叙事可见度匹配(无过度投入); 语支树与迁徙史互证; 怪音位可发音; 语法范畴体现文化核心; 对白可回译; 有"不完美"注入; 使用检验有记录。

## 第 5 步: 命名体系与地名学——名字即世界观

**[输入]** 各语言音系与词根库 + 文明篇(宗教/社会分层/等级制度)+ 历史篇(征服/改名事件)+ 地理篇(水文/山脉/聚落)。

**[操作]**
1. **做 2-3 层语言地层表**: 古语层(底层, 被征服/被同化民族残留)/征服层(上层, 占领者语言)/纪念层(政权刻意书写: 圣徒名/帝王名/革命名)三套地名词根; 规定大河与山脉只用古层、城镇用征服层、行政区与皇宫用纪念层——读者从地名读出"谁先来、谁后到"。
2. **按耐久性梯度分配**(Bright): 大河名>山名>聚落名>细碎地名; 河流必须是最古层的保存者(泰晤士河前凯尔特层案例); 设"现代人叫的'永河'其实是古语'水'的误读", 用语言化石制造考古式悬念。
3. **给每文化写姓名模板卡**(Wilson): 结构式(本名+父名(性数变化)+氏族名+称号)+父名/母名后缀系统(-son/-dóttir 式变体); 贵族/平民/奴隶/外来者名制差异——姓名结构直接呈现社会分层, 比旁白更省笔墨。
4. **按 Stewart 十类建"地名词根库"**: 描述地形/所有性(人名族群)/事件性/纪念性/溢美性/民间词源/人造名/移用名("新X")/误植名, 生成地名时按分类抽样, 保证类型分布均匀且风格自洽。
5. **让命名规则绑定文化价值观**: 宗教文化→神名嵌入(为每位神设计名字词素, Michael/-el 模式); 清教徒式→美德名; 尚武文化→战功称号(西庇阿·阿非利加努斯); 怕鬼文化→护符贱名与真名禁忌——用命名规则代替设定文本。
6. **设计一场"改名事件"并保留旧名残迹**: 征服/革命/改宗后官方改名清单+旧名三种存活方式(诗歌与仪式用语/老人与流亡者口音/民间词源化新语义); 民间词源机制链=语音同化→语义附会→传说回填(把冲突历史"软化成自然")。
7. **建"命名词典"并严格复用**: 按语言/性别/阶级/时代分表的词表+词根词缀+组合规则, 每生成新名先查库; 同一语言内严禁混入另一语言音系——跨语言混用是最常见返工源。
8. **地名反推被抹去的民族**: 设已灭亡民族, 其语言只活在河名/山名/民间传说中; 用地名层累式叠压(凯尔特-罗马-盎格鲁-丹麦-诺曼)做历史断层叙事。

**[决策规则]**
- 专名是"语言化石": 一旦凝固字面义消隐, 但作为音义单位存活并承载记忆——专名学是历史语言学最可靠的材料来源;
- 底层词汇集中在水文名中(最耐久、最难被替换); 征服层叠压在聚落名上;
- 姓名结构本质是社会制度的音系化(父名制=无阶层氏族社会; 罗马 tria nomina=公民等级编码);
- 改名从不彻底: 旧名残留在仪式/诗歌/方言/家族记忆中, 或被民间词源重新收编("改名即改写历史", damnatio memoriae);
- 名字即世界观: 神名嵌入/美德名/战功名/护符名, 命名即祝祷。

**[输出产物]** `语言地层表`(古/征服/纪念三层+词根库)+ `耐久性梯度分配表`(河/山/聚落/细碎地名)+ `姓名模板卡集`(每文化: 结构式/后缀系统/阶层差异)+ `地名词根分类库`(Stewart 十类)+ `改名事件档案`(官方清单+旧名三残迹)+ `命名词典`(版本化)+ `地名考古线索表`。

**[检查点]** 三层地名词根齐备且分配规则明确; 大河名用最古层; 每文化姓名模板卡可生成新名; 词根库覆盖十类; 改名事件有旧名残迹; 命名词典跨作品复用; 无跨语言混用; 至少一个"地名反推灭亡民族"悬念。

## 第 6 步: 语言社会与语言政策——域表定权力, 政策分取向

**[输入]** 语言档案 + 文明篇(政体/宗教/教育/社会分层)+ 经济篇(贸易网络/税收)+ 历史篇(标准化/文字改革事件)。

**[操作]**
1. **为每种语言/变体做"域表"**(Fishman): 宗教/法律/教育/家庭/市场/政府各域绑定默认变体; 写明哪些场合"绝对禁用"哪种话——双言社会最便宜的仪式感与权力感来源。
2. **画方言连续体与等语线**: 沿山脉/河流/古国边界布置渐变音变(r 化/元音央化), 相邻村庄"听得懂但口音怪"; 政治边界把连续体一刀切成"语言"; 地图上标方言岛。
3. **设计"语言/方言"政治裁决**(Kloss): Abstand(靠天然距离成立)vs Ausbau(靠标准化工程成立); 用 Max Weinreich 名言("语言=拥有陆军和海军的方言")让民族为自己的话正名; 写"被证伪的谱系"与"被降格的方言"。
4. **设定双言/多言制**: Ferguson 双言(高变体 H=宗教/法律/书面, 低变体 L=家庭/日常, H 无人当母语习得、靠学校、语法更复杂); Fishman 扩展四格(双言×双语); Platt 多言制(多 H 多 L 按族群与域分配, 新加坡模式)。
5. **用显/隐性声望刻画角色**(Labov): 贵族说标准语, 下层用土话, 中间阶层正式场合"过度纠正"、私下"降格"; 语体移动暴露社会野心或乡愁; 女性既守标准又领跑新音变(性别悖论); 语码转换=身份宣言(Le Page "身份即行为")。
6. **写语言政策三分法**(地位/本体/习得规划)并选意识形态取向(Ruíz 三取向): 同化帝国=语言是问题(禁语令/文字改革/语言屠杀); 权利联盟=语言是权利(官方化/保护); 资源城邦=语言是资源(通译/多语商业)。
7. **按 Haugen 标准化四步写"标准语工程"**: 选标准(选谁当基准=选谁掌权)→编典(词典/语法书, 仿法兰西学术院 59 年成典)→功能精化(扩展至科技/法律新领域)→接受(学校/法庭/媒体强制普及); 写"改革派 vs 守旧派"的词典之战。
8. **为少数语言排 GIDS 死亡倒计时并写复兴**: 八级量表定位(仅剩老人→家庭代际(关键临界点)→学校→职场→官方), 死因(禁语令/城市化/通婚/识字教育), 复兴工具箱(语言巢/浸入学校/成人"新说话人"/正字法与语料建设/媒体立法), 参考希伯来语/毛利语/威尔士语。
9. **语码转换即剧情**: 谈判中角色从 H 切 L 表示翻脸/拉拢/暴露出身; "谁先开口说哪种话"成为宫廷礼仪与外交信号; 混血/移民角色在族裔语与通用语间撕裂("会说不会写 H"的学者、"只会读不会说"的祭司都是阶层细节)。

**[决策规则]**
- 语言变异是"有序异质": 同一变量随阶层与语体系统变化(Labov);
- 双言制可稳定数百年: 功能专门化/声望/文学传统/语法复杂/词汇成对互补/音系两套;
- 语言不因其优越而扩张, 而因其载体渠道(军事行政/圣典/贸易/科技/教育/流行文化)(Ostler);
- 国语建构=民族国家工程核心: 谁的语言成为国语, 谁定义"谁属于这个国家"(Anderson); 印刷资本主义塑造想象的共同体;
- 语言政策可统一帝国, 也可撕裂国家(印度反印地语运动/孟加拉语言运动);
- 语言死亡是使用领域逐层被剥夺的梯度过程; 逆转须从最底层(家庭代际传递)往上修(GIDS)。

**[输出产物]** `域表矩阵`(每变体×场合)+ `方言连续体与等语线图` + `语言政治裁决档案`(Abstand/Ausbau 判定)+ `双言/多言制度表` + `声望-阶层角色卡` + `语言政策书`(三分法+意识形态取向+管理机构)+ `标准化四步年表` + `GIDS 濒危档案与复兴计划` + `语码转换场景库`。

**[检查点]** 每变体域表齐备且有关键禁用场合; 连续体与地理/政治边界互证; 裁决冲突有剧情; H/L 分工即社会制度地图; 声望差异落到具体角色; 政策取向与政体匹配; 四步各有事件; 濒危语言有 GIDS 级数与复兴路径; 语码转换是剧情非装饰。

## 第 7 步: 魔法语言/翻译/多语生态与一致性总检——言语成行, 翻译成戏, 生态成图

**[输入]** 前六步全部产物 + 法则篇魔法规则(施法语言/真名/代价)+ 军事篇(外交/战俘审讯)+ 经济篇(贸易网络)+ 历史篇(接触事件)。

**[操作]**
1. **建"双层语言系统"**: 日常语与魔法语分立, 明确差异机制——魔法语否定索绪尔任意性(词与物因果绑定, 故不能说谎/不能乱说), 日常语因规避真名而存在; 规定学魔法语门槛(须知真名/先立誓/发声书写有生理代价), "会两种语言"=身份标志。
2. **把言语行为五分类映射为法术系**(Searle): 宣告类=即发咒(命名/封禁/宣判); 承诺类=契约/誓约魔法(违约有实体化惩罚); 指令类=驱役御使咒; 表达类=祝福/诅咒(祝祷系); 断言类=预言与真实视域(语言诚实性保证预言可信); 每类独立代价与反制。
3. **设计"真名系统"**: 万物(或灵脉节点)有真名, 知其真名者得其支配权(Le Guin 地海); 名字分层(真名/日用名/绰号/头衔); 命名仪式(成年赐名/龙与骑士互名)是剧情节点; 主线三幕=藏名(隐瞒与误认)→寻名(考古/审讯/语言学逆向工程)→用名(制敌/救赎/自我认同)。
4. **给"诚实语言"留漏洞**: 不能说谎≠不能骗(省略/隐喻/反讽/转述/断章取义/字面主义履约"我说过会来, 没说何时")——契约博弈/文字陷阱/法庭式斗法剧情; 誓言律令的字面主义是经典漏洞。
5. **把避讳做成世界张力**: "不可说之名"(神名/国王名/亡灵名), 说出即触发后果(定位/召来/诅咒); 沉默成为战术(匿名=自由, 被指名=被绑定); 参考中国名讳/埃及抹名即杀/伏地魔 Taboo 三机制组合。
6. **符文=固化的言语行为**: 定刻写成本(材料稀缺/一笔不可错/刻错反噬/需注入能量)、读写规则(朗读铭文=触发施为/反向刻写=解除/涂改=篡改契约); 由此产生考古解密/伪造文书/破坏封印故事线; 可结合卡巴拉字母创世与奥丁窃符的"知识即献祭"母题。
7. **绘"词汇缺口地图"**(翻译): 为两文明各列 3-5 个单义文化词(无"债务/明天/私人财产"对应词), 缺口出现在世界观要害(时间/所有权/忠诚)而非鸡毛蒜皮; 误解等级链=词汇级假朋友→语用级禁忌失礼→世界观级冲突(条约期限/领土归属/婚姻契约最适合埋"文明级误解")。
8. **让译员成为核心人物**: 通译是信息唯一阀门, 可增删/润色/故意误译; 围绕"译员忠诚于谁"制造张力; 安排翻译外交场景(谈判/献书/宣誓/和亲/战俘审讯), 让一方发展出"多译员互证"或"禁通译"体制。
9. **画多语生态图**: 多语三类型(并行/分层/语码混合); 贸易通用语=lexifier 强势语言+皮钦简化(固定语序/取消屈折/动词不定式化/词汇减半/语音简化); 港口三代演化时间线(接触代皮钦→下一代母语化变克里奥尔→国家独立升格官方语); 语言孤岛(隔离社群语言保守, Trudgill); 语言-生物多样性并行(雨林/群岛/山区=双热点)。
10. **跑"语言档案八件套"总检**(121): 音系表/构词纲要/句法纲要/核心词汇/文字系统/样例文本(莱比锡标注+可回译)/谱系树/语言地图; 每项过可验证性关卡——正字法↔音系 100% 对应、文本可逐词回译、谱系树与地图吻合、借词带来源与年代、每个词条可追溯首现出处。
11. **反现代主义自检**: 一锅语言(互不兼容特征堆叠)? 过度规则(无例外无不规则)? 无时间轴(语言千年不变, 古典语与现代语不分)? 跨语言混用(英语词尾硬安/异语言碎片乱拼)?

**[决策规则]**
- 魔法语言的本质是把施为句的"言出法随"推至极端: 言语与世界之间的缝隙被取消(Austin);
- 施为要生效须满足恰当条件(说话者有权威/程序正当/内心真诚/情境匹配)——法术失败即恰当条件不满足, 也是法术反制的设计依据;
- 真名=本质=权力: 词与物因果绑定, 名是秩序的开端也是权力的载体(老子"道与名"、地海);
- 语言相对论取弱式: 语言影响认知而非决定——差异可被过度解释成伪科学(Hopi 时间案教训);
- 不可译性是剧情发动机: 忠实与可读不可兼得("Traduttore, traditore"), 翻译即改写与再创作(Lefevere);
- 皮钦/克里奥尔是特定生态下的正常演化而非"异常畸形"(Mufwene);
- 任何产出物必须可验证: 可回译/可溯源——语言是系统不是标签集(命名-语言-文化三位一体)。

**[输出产物]** `双层语言系统图` + `言语行为-法术映射表` + `真名档案`(分层/仪式/寻名三幕)+ `诚实语言漏洞清单` + `避讳与禁忌词表` + `符文固化规则` + `词汇缺口地图与误解链` + `译员人物卡与外交场景库` + `多语生态图`(三类型/通用语/孤岛/濒危)+ `语言档案总检报告` + `反现代主义自检表`。

**[检查点]** 双层语言差异机制明确且魔法语门槛成系统; 五分类映射每类有代价与反制; 真名分层与寻名三幕齐备; 诚实语言有漏洞可钻; 避讳有后果与战术; 符文有刻写成本与篡改规则; 词汇缺口在世界观要害; 译员有忠诚张力; 多语生态三类型落地; 八件套总检全过; 无跨语言串味与时间轴断裂。

## 第 0 步: 米拉斯语言定位书

- **语言角色清单**(工作量分级): 灵纹语(灵枢城, **完整级**——声调+表意文字+双言双变体, 世界语言旗舰); 古灵纹语(灵枢城高变体, 完整级内嵌——宗教/法律/咒语专用); 市井灵纹语(灵枢城低变体, 完整级内嵌——日常口语, 混入潮邦借词); 潮邦语(潮邦, **草图级**——音节文字+航海词汇域, 航海记录); 雾裔语(雾盐邦, **命名级**——音系+百词+地名残留, 无声调鼻音丰富); 风语草原语(风语游牧, 命名级+方言连续体——草原历法口传); 北境遗民语(濒危命名级——灵纹方言改写教义=革命行为); 缝合地峡通用语(世界内 **auxlang**——贸易皮钦, 多语港市)。
- **双言接口**: 灵枢城=高变体(古灵纹语: 宗教/法律/法典/咒语)vs 低变体(市井灵纹语: 市集/家庭/民歌)——咒语与真名全部来自高变体古音层, 无人把古灵纹语当母语习得, 靠祭司学院(文字滞后机制: 灵纹文字冻结、市井口语已漂移→祭司念古音、民众按今音读圣典)。
- **语言史时间轴**: 古灵纹语(前灵权时代, 祭司口传秘语+原始刻符)→灵纹语(800 年前灵权革命, 起义祭司把灵纹"下放"为可书写工程文字, 标准化神圣语)→市井灵纹语(灵晶时代 500 年前起, 口语元音链移+潮邦借词渗入)。
- **自检**: 无跨语言混用(灵枢城人名禁用潮邦音节, 反之亦然); 谱系与迁徙史一致(火链群岛=流亡灵纹师的古灵纹语方言岛); 魔法语(古灵纹语/灵纹文字)与日常语接口明确=双言制本身。

## 第 1 步: 米拉斯类型学与演化

- **类型学配方**: 灵纹语=孤立语+语素文字+4 声调, SOV+后置词+属格前置(谐和包, 祭司文言语序保守古旧); 潮邦语=黏着语+音节文字, VSO+前置词+名词-属格(航海民族的口语效率); 雾裔语=孤立语+无声调+鼻音丰富, 无格标记故语序僵化。三者两两互不可懂(Abstand 成立)。
- **语系谱系**: 灵纹语系(古灵纹语→灵纹语/市井灵纹语/火链方言——三次灵脉战争强制扩散的"残缺灵纹"仿制品, 北境得降级版); 潮邦语系(潮邦语+港市克里奥尔); 雾裔语=孤立语(避难地形白雾荒漠/盐角)。**缝合地峡语言联盟**: 无亲缘的灵纹语/潮邦语/雾裔语共享量词+后置词+语素简化→世界内语言学家误判同源→"被证伪的谱系"学术事件(云顶寺学者翻案)。
- **借词分层考古**: 灵纹语三层——底层(前灵权部族语, 只存于龙骨山脉山名/灵脉节点名)、上层(灵纹语, 征服与宗教词域)、文化层(潮邦航海/贸易词=灵晶时代借入, 云顶寺冥想/草本词)。借词锁定时代: 潮邦语"灵纹"借词保留楷化前古音→证明借入早于 500 年前楷化。
- **音变规则手册**: 古灵纹语 *k → 灵纹语 /k/、市井灵纹语 /h/(口语漂移)、火链方言 /tʃ/(条件分述); 市井灵纹语"元音链移"(仿大元音转移)而文字冻结→拼读脱节=神圣语机制。
- **语言年代学争议**: 灵枢城祭司估算灵纹语与潮邦语分化 3000 年前, 潮邦学者估算 800 年前(核心词被借词污染)→两派学统之争=剧情线索。

## 第 2 步: 米拉斯音系与书写系统

- **灵纹语声调设计**: 4 调(高平/中平/低降/升), 调型高低相间有"几何感"; **声调出生证明**——第 4 调(升)来自古灵纹语 -ʔ 尾脱落, 第 3 调(低降)来自浊声母清化+低调伴嘎裂声=祭司威严音; **变调规则**: ①血月变调——血月爆发年祭仪诵经触发"低降+低降→高平+低降"(41 年一遇, 民间日常不触发, 只有祭司念对才有效=与血月法则联动); ②灵脉变调——灵脉亲和度等级决定发音域: 高阶亲和者能发"灵脉共振调"(调值随节点能量微变), 低阶者发不出→称号可听辨(灵脉亲和度等级的语言物化)。
- **灵纹文字演化史四阶段**(与灵权革命对应): ①象形(前灵权时代: 祭司刻符记事, 龙骨山脉碑铭遗存, 灵纹是口传秘语+少量刻符); ②假借(灵权革命前夜: 同音假借表音扩散, 歧义危机——"火"与"血"同音误读引发祭祀事故, 祭司借机强化解释权); ③形声(800 年前灵权革命=灵纹文字化轴心: 起义祭司把灵纹下放为可书写工程文字, 加义符"灵脉部/血月部/灵魂部"限定消歧, 灵纹=可书写可施法, 第一 GPT 的文字基础); ④楷化(灵晶时代 500 年前: 学院标准化正字,《灵纹法典》成书, 笔画简省)。当代文字政治: 印刷灵纹法典被禁=祭司垄断注释权的革命媒介。
- **文字分层**: 灵枢城=神圣古体(灵纹语素文字, 祭司垄断, 识字成本高→精英垄断)+市井简体(民间简化灵纹/音节化草书, 商贩记账); 潮邦语=音节文字(门槛低, 水手写航海日志/情歌/商册); 雾裔语无文字(口传, 鼻音韵母歌谣记忆法, 白雾荒漠商队靠歌谣传盐路知识)。
- **识字率**: 全大陆约 4%(灵枢城祭司/书吏/潮邦商人, 风语游牧近零); 俗语灵纹译本=地下违禁品(潮邦书商走私, 翻译即权力)。

## 第 3 步: 米拉斯词汇与语法

- **词汇三层**: 核心词(灵纹语 100 词自创,"水/火/风/土/灵/血月"高频词不规则——"施法"动词强变化); 词根词族(灵脉词根辐射 20 词家族: 灵脉-纹-法阵-晶-井-税-术士-亲和); 借词层(潮邦航海词/云顶寺冥想词/北境古语词, 各配音系适配: 潮邦借词增音填音节, 云顶寺借词保留长元音)。
- **语法签名**(各取 1-2 项, 绑定文化): 灵纹语=**证据性**(祭司诵经每句强制标"亲历/神谕/转述"三系——"神谕系"只有大祭司有权用=话语权物化; 法官断案"转述"系证词不被采信=法律效力与语法绑定); 潮邦语=**名词类**(航海文明: 人类类/船具类/风暴类, "风暴类"前缀触发禁忌变音=水手讳言); 雾裔语=鼻音同化+雾中传声的语音经济(远距离喊话靠鼻音共振)。
- **禁忌词域与同音歧义**: 民间避说"枯竭"直称(用"潮退"委婉, 血月枯竭年禁忌强化); 灵纹语"灵晶"与"圣石"同音多义=潮邦商人利用合同歧义(灵晶经济纠纷剧情引擎); 神名/真名词域触发同音回避。

## 第 4 步: 米拉斯 conlang 实践

- **定性**: 灵纹语=artlang 完整级(声调+语素文字+双言双变体+历时演变, 世界语言旗舰); 潮邦语=artlang 草图级(音节文字+名词类+航海词汇域); 雾裔语=artlang 命名级(音系+百词+地名残留); 缝合地峡通用语=世界内 auxlang(皮钦: 易学/中性, 港市商业); 灵纹文字=conscript(四阶段历时演化+碑铭/法典/草书字体分层)。
- **历时语言工程**: 古灵纹语=原始语, 分裂出灵纹语/市井灵纹语/火链方言(三次灵脉战争扩散+去语境化——北境仿制品是"残缺灵纹"), 语支树与各族迁徙史一一对应; 语言史即世界观史(托尔金式)。
- **可表演性约束**: 灵纹语 4 调与喉音均为可发音音位; 雾裔语鼻音丰富(靠雾水呼吸者生理特化, 符合"陌生但可发"约束); 咒语音系=古灵纹语古音层, 不与现代音混淆。
- **不完美注入**: 灵纹语高频"施法/献祭"动词强变化(演变脚本: 古灵纹语词尾辅音脱落+类推修补); 市井灵纹语混入潮邦借词("船""盐""港"用潮邦词=低变体特征, 高变体禁用); 文白分层=高变体古灵纹语 vs 低变体市井语。

## 第 5 步: 米拉斯命名体系与地名学

- **地名分层表**(三层+耐久度分配):
  - **古灵纹层**(最古, 大河名/山名/灵脉节点名): 龙骨山脉(古灵纹语"龙骨"=灵脉之脊, 词源已晦, 只有祭司注疏可解); 苍原高原; 灵脉节点名全部为古灵纹语(真名系统基础)。
  - **雾裔底层残留**(雾裔被同化后语言只剩地名): 盐角(雾裔语"盐"词根, 雾盐邦祖地); 白雾荒漠(雾裔语"雾"根, 商队仍用雾裔语歌谣称之)。
  - **征服改名层**(灵权革命/灵脉战争改名): 缝合地峡(800 年前灵权革命后由古部族语"裂口"改名, 旧名仍活在老人与流亡者口音、灵纹法典古注中); 灵枢城(灵权革命后由"古祭司城"改名); 火链群岛(火山带描述名+流亡灵纹师纪念层叠压)。
  - **民间词源**: "风语草原"=游牧自称被灵枢城书吏按灵纹语重新解释("风之声"); 传说回填为地名提供合法性叙事。
- **人名模板**: 灵枢城=灵脉圣名(神名嵌入: 灵脉圣名词素+血月神名词素)+称号(灵脉亲和度等级: "一阶亲和者/三阶引灵者", 称号随等级晋升改换); 潮邦=本名+父名(-son/-dóttir 式变体)+船名(航海氏族, 无固定家姓); 雾裔=鼻音名+护符贱名(避讳: 真名隐藏, 敌人得知真名即可加害)。
- **改名事件档案**: 灵权革命=灵枢城官方改名清单(宫廷/神殿名), 旧名三残迹——灵纹法典古注/流亡祭司口音/民间词源化新语义; 改名即改写历史(damnatio memoriae 式: 被除名第一王朝之名见第 7 步)。
- **命名词典**: 灵纹语/潮邦语/雾裔语三卷, 按性别/阶级/时代分表, 每生成新名先查库; 严禁跨语言混用(灵枢城人名混入潮邦音节=社会性破绽, 可作间谍暴露梗)。

## 第 6 步: 米拉斯语言社会与政策

- **双言社会**: 灵枢城=高变体(古灵纹语: 宗教/法律/法典/咒语, 祭司垄断解释权)vs 低变体(市井灵纹语: 市集/家庭/民歌); 特征全表对应 Ferguson——功能专门化/高变体有文学传统(灵纹法典)/无人当母语习得(靠祭司学院)/词汇成对互补(高"献祭"vs 低"交税")/音系两套(高变体保留古音)。
- **域表矩阵**: 法庭=古灵纹语(禁市井语, 违者藐视); 市场=市井灵纹语+潮邦语; 潮邦港口=多语域表(行政=潮邦语, 宗教=灵纹语借词层, 家庭=各族母语, 码头=缝合地峡通用语); 云顶寺=静默戒律+古灵纹语诵经(禁口语)。
- **方言连续体**: 风语草原=从灵枢城边缘到草原的连续体(元音央化渐变, 相邻部落互懂、两端互不懂); 灵枢城-草原政治边界把连续体切成"语言"; 北境=方言岛(隔离保守古层)。
- **语言政策**: 灵枢城=**同化型**(语言=问题: 禁俗语灵纹译本、灵纹法典禁书目录、印刷灵纹法典被禁、缉书人, 祭司=分配性联盟); 潮邦=**资源型**(语言=资源: 通译所、多语记账、语言配额=商路外交筹码, 港市通用语受官方鼓励); 云顶寺/北境=**权利型**(北境遗民用灵纹方言重写教义=路德译经式革命行为)。
- **声望与角色**: 灵枢城中间阶层(书吏)正式场合过度纠正古灵纹语、私下降格市井语(过度纠正=社会流动焦虑的语言指纹); 潮邦商人谈判先潮邦语、中途切通用语=表态(有标记语码转换)。
- **GIDS 濒危与复兴**: 雾裔语(仅盐角老人+白雾荒漠商队, 约 GIDS 6 级——家庭代际临界点, 死因=灵权革命同化+通婚+城市化); 复兴线=云顶寺藏经阁记录雾裔歌谣+盐角"语言巢"(祖孙沉浸, 毛利语模式)——"最后一位雾裔母语者之死"是高张力情节。
- **标准化工程**: 灵权革命后祭司编《灵纹法典》(仿法兰西学术院 59 年成典式工程, 楷化正字=本体规划); 潮邦编《港册》规范音节拼写与商册格式(功能精化); 两次"词典之战"=改革派(学院)vs 守旧派(刻印师行会)。

## 第 7 步: 米拉斯魔法语言/翻译/生态与一致性总检

- **双层语言系统**: 日常=市井灵纹语/潮邦语; 魔法=古灵纹语(高变体)+灵纹文字——**灵纹文字本身即咒语**(宣告类施为固化进物质: 契约/碑铭/护符让施为脱离在场而持久生效); 索绪尔任意性被否定: 灵纹词与灵脉现象因果绑定, 故咒语不能说错(错音/错笔=反噬), 施为须满足恰当条件(大祭司权威+仪式程序+血月时机)。
- **真名系统**: 灵脉真名=古灵纹语(节点真名=掌控灵脉节点), 大祭司垄断"节点真名册"; 寻名三幕——藏名(祭司隐真名用称号, 真名=弱点也是钥匙)→寻名(潮邦学者考据古灵纹语+考古龙骨山脉碑铭=语言学逆向工程)→用名(用节点真名控制/封印/夺权, "得知敌人真名"与"敌人得知我真名"对称高潮)。
- **禁忌音节**: 被除名第一王朝之名=不可说(说出=定位信标+唤回被封印之物, 伏地魔 Taboo 式; 灵权革命时除名=政治性抹名, damnatio memoriae); 死者名避讳(北境亡灵信仰: 提名=召魂); 沉默=战术(流亡灵纹师匿名=自由)。
- **灵纹契约**: 契约/誓约/碑铭=固化的施为句; 刻写成本(灵纹一笔不可错, 刻错反噬; 需注入灵脉能量), 反向刻写=解除, 涂改=篡改契约(经济纠纷/伪造文书剧情); 禁咒公约=字面主义博弈场。
- **诚实语言漏洞**: 灵纹誓约不能说谎但可字面主义履约("我保证不进攻灵枢城"≠"不进攻灵枢城属邦"); 三次灵脉战争的和约全部埋文字陷阱=外交斗法史。
- **翻译误解链**(灵枢城 vs 潮邦概念差异): ①"税"——灵枢城"灵脉税"=再分配义务/献祭(神权语义), 潮邦"关税"=契约性收费(市场语义)→条约"免灵脉税"条款被潮邦误读为财政豁免、被灵枢城解读为放弃神权义务→和约破裂危机; ②"灵晶"——灵枢城=圣石/电池(花掉=消耗), 潮邦=货币/商品(花掉=流通)→潮邦商人囤积灵晶被灵枢城视为渎神; ③时间——灵枢城=血月 41 年纪元("血月纪"), 潮邦=航海年历→条约期限换算分歧。译员=潮邦通译(信息唯一阀门, 故意误译"灵脉税"条款=外交事故, 之后双方发展"多译员互证"体制)。
- **多语生态**: 缝合地峡=多语港市带(皮钦通用语: 潮邦语词汇+灵纹语借词+雾裔语鼻音词, 固定语序/动词不定式化/词汇数百词); 三代演化=接触代皮钦→港市克里奥尔→灵晶时代升格商路官方语(斯瓦希里语轨迹); 语言孤岛=火链群岛(流亡灵纹师古灵纹语方言岛, 保守古层+火山词汇渗透); 语言-生态并行: 白雾荒漠/北寒原=雾裔语与特有物种(雾蜂/寒原苔)双热点,"每砍一片森林带走一种语言"式主题意象。
- **一致性总检(八件套抽查)**: 灵纹语档案齐备(4 调/语素文字/证据性/双言/样例文本可回译); 灵纹文字四阶段与灵权革命/灵晶时代时间线吻合(楷化不早于 800 年前, 印刷被禁不早于《灵纹法典》成书); 真名/禁忌音节全部为古灵纹语且与音系一致; 借词带来源年代(潮邦航海词=灵晶时代借入, 早于楷化音变); 市井灵纹语例句可回译; 无跨语言串味(灵枢城人名禁用潮邦音节); 与法则/技术/历史/军事/经济各篇衔接——灵纹=第一 GPT 文字化(技术篇)、灵脉真名=节点掌控(法则篇)、禁咒公约=字面主义博弈(军事篇)、灵晶同音歧义=经济纠纷(经济篇)、血月变调=41 年节拍器(历史篇)。

# 第三部分: 一致性总检清单(语言篇)

**基础层**(第 0 步):
- [ ] 语言角色清单齐备: 每语言有名称/级别(命名级/草图级/完整级)/使用者/功能, 工作量与叙事可见度匹配;
- [ ] 语言档案八件套模板已建: 音系/构词/句法/核心词汇/文字/样例文本(莱比锡标注)/谱系树/语言地图;
- [ ] 音系先行: 所有命名/文本/借词/咒语在音位表内生成, 无跨语言混用(同一文明不混入另一语系词汇);
- [ ] 谱系树与语言史时间轴可追溯, 与迁徙/征服/贸易史互证;
- [ ] 语言地图与地理联动: 平原=方言连续体, 山区/群岛=碎裂语言带, 大河名用最古层;
- [ ] 魔法语与日常语接口明确(双言制/古语层/借词层), 咒语/真名来源有据;
- [ ] 每语言至少一段带标注样例文本, 可回译验证。

**构建层**(第 1-3 步):
- [ ] 类型学"8-12 特征配方"逐对过蕴含检查, 无统计互斥组合("无格标记+完全自由语序""SOV+前置词");
- [ ] 语序包内部谐和(Greenberg 共性 2-4/Dryer 相关对), 违反相关对有历史漂移解释;
- [ ] 特色机制 ≤2 且绑定文化动机与触发条件(分裂作格的分裂维度/证据性的义务性与权威语义/名词类的语义核心+任意边缘);
- [ ] 谱系树各分支有音变规则手册(2-4 条规则+类推修补), 同源核心词可见;
- [ ] 借词分层与历史事件一一对应(征服层/宗教层/科技层词汇域不同), 借词方向即权力关系;
- [ ] 至少一个语言联盟(无亲缘共享结构特征, 含"被证伪的谱系"悬念);
- [ ] 每调有"出生证明"(声调发生史: -ʔ/-h 脱落/浊声母清化)与 1-2 条变调规则;
- [ ] 文字类型与音系匹配(纯 CV→音节文字/abugida, 单音节孤立语→语素文字), 无"CV 配 abjad"违和;
- [ ] 文字四阶段编年史(象形→假借→形声→楷化)各有历史事件与物质遗迹;
- [ ] 神圣古体/世俗简体双轨与识字率、权力结构互证;
- [ ] 词汇三层齐备(核心词自创/词根词族能产/借词带音系适配), 高频词有"脏数据";
- [ ] 语法签名规则页完整可回译; 不规则词有演变脚本出处; 同音歧义密度可控且有消歧手段。

**命名层**(第 5 步):
- [ ] 语言地层表 2-3 层齐备(古语层/征服层/纪念层), 分配规则明确(河山=古层, 城镇=征服层, 政区=纪念层);
- [ ] 耐久性梯度落地: 大河名>山名>聚落名>细碎地名, 河流保存最古层;
- [ ] 每文化姓名模板卡可生成新名(结构式/后缀系统/阶层差异);
- [ ] 地名词根库覆盖 Stewart 十类, 生成时分类抽样风格自洽;
- [ ] 命名规则绑定文化价值观(神名嵌入/美德名/战功名/护符贱名);
- [ ] 改名事件有官方清单+旧名三残迹(仪式诗歌/老人口音/民间词源);
- [ ] 命名词典版本化复用, 无跨语言混用;
- [ ] 至少一个"地名反推被抹去民族"的考古悬念。

**社会层**(第 6 步):
- [ ] 每变体域表矩阵齐备(宗教/法律/教育/家庭/市场/政府), 有关键禁用场合;
- [ ] 方言连续体与等语线已画, 政治边界切割有"语言/方言"裁决冲突(Abstand/Ausbau);
- [ ] 双言/多言制度明确: H/L 分工即社会制度地图, H 无人当母语习得靠学校;
- [ ] 显/隐性声望落到具体角色(过度纠正/语体移动/性别悖论);
- [ ] 语言政策三分法(地位/本体/习得)+ 意识形态取向(问题/权利/资源)与政体匹配;
- [ ] 标准化四步各有事件(选标准=选谁掌权/编典/功能精化/接受);
- [ ] 濒危语言有 GIDS 级数与死因, 复兴路径自下而上(语言巢→学校→媒体→行政);
- [ ] 语码转换是剧情非装饰(翻脸/拉拢/身份暴露/外交信号)。

**超自然层**(第 7 步):
- [ ] 双层语言系统分立, 魔法语否定任意性(词物绑定, 不能说谎), 门槛(真名/立誓/生理代价)成系统;
- [ ] 言语行为五分类映射法术系, 每类有独立代价与反制;
- [ ] 真名系统有分层(真名/日用名/绰号/头衔)+寻名三幕(藏名/寻名/用名);
- [ ] 诚实语言留漏洞(省略/隐喻/字面主义履约), 契约博弈可推演;
- [ ] 避讳有后果(定位/召来/诅咒)与战术(沉默=匿名自由), 禁忌词表齐备;
- [ ] 符文固化规则完整(刻写成本/反向刻写=解除/涂改=篡改), 考古/伪造剧情可展开;
- [ ] 词汇缺口地图落在世界观要害(时间/所有权/忠诚), 误解等级链(词汇/语用/世界观)可升级;
- [ ] 译员是核心人物(信息阀门/忠诚张力/多译员互证或禁通译体制);
- [ ] 多语生态三类型落地, 贸易通用语有 lexifier 与简化规则, 港口三代演化时间线可写;
- [ ] 语言档案八件套总检通过: 正字法↔音系 100% 对应、文本可回译、谱系与地图吻合、借词带来源年代、词条可溯源;
- [ ] 反现代主义自检通过: 无一锅语言/无过度规则/无千年不变的时间轴/无跨语言混用;
- [ ] 与法则/地理/文明/历史/经济/军事/技术各篇衔接(魔法语言↔法则, 地名↔地理, 双言↔文明, 语言史↔历史, 借词↔经济贸易, 禁咒字面主义↔军事公约, 文字化↔技术 GPT)。
