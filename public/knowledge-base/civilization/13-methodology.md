# 文明设计方法论

> 文明生命周期模板、参数化推导链、主题契合、一致性检查——从 0 到 1 构建虚构文明的操作方法。

## 文明生命周期模板

**伊本·赫勒敦王朝四阶段**(asabiyyah 群体凝聚力): 征服立业→巩固权力→安逸奢侈→涣散衰亡, 约三代人(~120年)一个周期。机制: "沙漠/边缘地带"的质朴团结被"城市/中心地带"的安逸奢侈腐蚀; 旧集团团结耗尽时, 新边缘集团取而代之。

**汤因比挑战—应战**: 文明生于"适度艰难"的压力与回应; 成长依赖"创造性的少数人"; 衰落始于少数人僵化为统治集团、多数人沦为"内部无产者"; 循环不是宿命, 应战成功即可延续或转型("退隐与复出")。

**斯宾格勒阶段对照**: 文明≈千年寿命; "文化"(创造力前段)vs"文明"(僵化末段: 城市化/大众化/凯撒主义)。

**构建用法**: 标注每个文明当前处于"起源→成长→巅峰→衰落→转型"哪一阶段, 写出该阶段固有张力(巅峰期"奢侈侵蚀团结"/衰落期"边缘集团崛起"); 只画故事时间窗内的, 其余写"年代史"备查。

## 参数化推导链(核心工具)

沿"**地理→气候→资源→人口→政体→文化→扩张方向**"做单向可验证推导, 而非拼贴设定:

- 纬度/地形/水文 → 气候;
- 气候与土壤 → 人口承载力与剩余产品;
- 剩余 → 分工与阶层分化;
- 稀缺资源(水/金属/香料/航路)与分工 → 政体形态与权力组织;
- 生计方式与政体 → 宗教/伦理/时间观/性别角色等文化;
- 文化 → 反向决定扩张方向(资源富集区/贸易线路/"应战"压力源)。

**铁律: 每个下游设定都必须能被上游参数推导并解释。** 两文明差异应源于链条上游(地理/气候/资源)的差异, 而非凭空的文化设定。

**验证法**: 用模型反推世界——布里斯托气候学家模拟《沙丘》Arrakis 检验"水经济"文明可行性(蒸馏服/水作货币/Fremen 文化皆从"水稀缺"单一参数推导)。对资源—人口—气候可量化环节, 参考真实数据确认文明"活得了"。

## 主题契合而非套模板

- 世界是"为故事服务的舞台", 不是设定清单;
- **深度优先于密度**: 先深化已有的, 再添加新的;
- 警惕**世界构建病**(无限扩充设定导致瘫痪);
- **冰山法则**: 只显露与情节/角色相关的部分;
- **抽象金字塔**: 以具体感官细节锚定读者(如《沙丘》香料的微光、《迷雾之子》燃烧金属后的金属味);
- 先定主题/核心前提("如果黑暗君主赢了会怎样?"), 一切文明设定都是它的实例化, 否则删除。

## 一致性检查清单(逐项自问)

1. **时间线**: 事件日期/代际与人口、技术演进速度是否匹配?
2. **规模**: 都城人口、军队规模是否超出农业/资源承载力(参考真实前工业社会数据)?
3. **经济**: 货币/税收/贸易线路自洽吗? 稀缺资源是否被文化(禁忌/价值观)如实反映?
4. **政体**: 权力如何获得、传承、被制衡? 官僚与军事集团关系?
5. **技术—社会匹配**: 技术是否与社会结构互为因果(印刷术→宗教改革式连锁)?
6. **语言与命名**: 命名规则是否反映历史层次(古语残留/外来词)?
7. **例外登记**: 每条"设定外便利"都必须有代价或解释。

## 经典机制速查(让文明"活"的引擎)

| 机制 | 内容 | 用法 |
|---|---|---|
| 挑战—应战 | 适度艰难催生应战型社会 | 设压力源+回应方式+失败路径 |
| asabiyyah 周期 | 团结→安逸→涣散→被取代 | 解释边疆蛮族取代老帝国 |
| 创造少数→统治少数 | 精英寄生化、大众脱钩 | 政治史主线 |
| 复杂度预算 | 治理成本曲线, 收益递减→简化 | 让崩溃成为合理选择 |
| 精英过度生产 | 职位供给不足→内斗→瘫痪 | 百年周期节奏 |
| 合法性公式 | 神授/天命/公民美德+仪式 | 公式动摇=危机 |
| 连续性/突破性 | 礼仪延续 vs 断裂革新 | 两种不同的兴衰模式 |

## 构建操作

1. 先定主题/核心前提, 再定文明;
2. 用生命周期给文明定位(只画故事时间窗内的阶段);
3. 跑一遍参数推导链并留档(每层记录"由什么推出、受什么限制");
4. 用经典机制制造合理意外;
5. 一致性检查清单逐项自问;
6. 用模拟/模型验证关键链条;
7. 避免世界构建病: 只深化与故事直接相关的 3~5 个设定簇, 其余用冰山法则留白。
