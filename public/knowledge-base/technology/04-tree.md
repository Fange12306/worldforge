# 技术树设计与时代分期

> 目的: 把技术体系建成一棵自洽、可校验、能驱动剧情的技术树——从现象库自底向上生成节点,用能量/信息/组织三维划时代,设计瓶颈、死胡同、冗余路径与后发跳越。
> 前置: 01-overview 的现象库与 DAG 骨架;与 05-energy(能量维度)、07-diffusion(窗口期)配套。

## 核心理论/机制要点

### 1. 现象库→技术树构建法(自底向上的组合进化)

- 先为世界建立"现象库"(物理/化学/生物/社会现象清单: 燃烧、电解、音速、光合、货币信任),再通过组合操作生成技术节点——`技术 = 现象 + 已有技术的组合`。
- 技术树自底向上生成且内部一致,而非从效果倒推导致的凭空节点;任何无法回溯到现象库的节点都要删除或补设定,这是世界自洽性的硬校验。

### 2. 能量—信息—组织三维分期

| 维度 | 载体跃迁 | 世界构建用法 |
|---|---|---|
| 能量 | 人力/畜力→蒸汽/机械→电力→核能 | 每时代定能量来源与峰值输出功率 |
| 信息 | 语言/口传→文字/印刷→电报电话→计算机/互联网 | 每时代定信息存储与传递方式 |
| 组织 | 部落→帝国→民族国家/科层公司→跨国/网络协同 | 每时代定组织形态与制度节点 |

- 通用技术(GPT)= 应用面广 + 可持续改进 + 催生互补创新(蒸汽机、电力、信息科技),即"时代门槛"。
- **时代门槛 = 通用技术完成扩散并改写基础设施与组织形态的时刻,而非发明瞬间**;门槛时刻常是三维同步跃迁(通用技术+基础设施+组织范式整体换代)。

### 3. 路径依赖与技术锁定

- 小历史事件 + 递增报酬 → 次优技术被锁定;锁定来源: 沉没成本、网络外部性、学习效应、制度适配。
- 这解释了"领先文明为何死守旧范式"与"死胡同技术为何迟迟不淘汰";也意味着技术史可有"浪费与错路"。

### 4. 后发跳越与机会窗口

- 新技术出现时,领先者因旧技术生产率高、沉没成本大而拒绝换代,后发者因无旧包袱直接采用新技术,实现领导权更替。
- 范式转换期即后发者的"机会窗口"——跳越不是奇迹,而是发生在技术-经济范式更替的特定窗口期;窗口关闭(标准锁定、路线固化)后,追赶者被锁死在旧轨道。

### 5. 树的图论机制与双轨

- 科技树是 DAG(有向无环图): 节点=技术,边=前置依赖;拓扑排序保证无环,层数=时代数,关键路径决定"时代最短通关时间"。
- 双轨: 技术树(科学与生产)+ 制度树(组织与制度,如 法典→国家劳动力→军工传统);制度节点往往比技术节点更深刻地改变世界——电报改变商业,但让电报发挥威力的是"标准时间+公司组织"。
- 目标导向学习: 完成特定行为可加速对应研究(如"用投石车摧毁单位"半价加速攻城科技),使"研究什么"与"做了什么"互相引导;时代更替时重置旧加成,模拟范式更替的强制机制。

### 6. 死胡同、冗余路径与反直觉代价

- **死胡同**: 看似强大但无后续的技术(机械式电视、飞艇、格式战败者);**冗余路径**: 多个并存方案最终收敛于局部最优(铁路vs运河、坩埚钢vs转炉钢)。
- **反直觉代价**: 效率提升未必缓解资源压力,反而可能扩大总消耗(瓶颈突破→新瓶颈;解决煤炭瓶颈却创造石油地缘政治)——时代推进要带代价与冲突。

## 构建操作

1. 先建现象库,再组合生成技术树: 写下该世界的现象清单(物理法则/魔法规则/物种特性/社会制度),每个节点标注"由哪些现象+哪些既有技术组合而来",无法回溯的节点删除或补设定;
2. 用三维门槛划时代: 每个时代用三个标志节点定义——能量(驯化挽畜/蒸汽机/聚变堆)、信息(文字/印刷/量子通讯)、组织(城邦法典/科层官僚/跨国行会);时代更替须三维联动或有合理解释,只有一维突破的要写成张力而非漏洞;
3. 给关键节点设瓶颈,给末端节点设死胡同: 时代门槛技术应有"多重前置+稀缺资源+组织条件"(印刷术=造纸+活字+油墨+识字市场);同时安排 2~3 个死胡同技术,让世界有真实历史那种"浪费与错路";
4. 保证冗余路径,避免单一最优线: 每个重要能力(炼钢/远航/远程通讯)至少给两条可到达路径,使不同文明/种族走不同分支;用"环境适配性"制造差异(沙漠文明走水利分支,海洋文明走造船分支);
5. 设计锁定与跳越的戏剧机制: 为领先文明写"沉没成本+制度惯性"(路径依赖),为后发文明写"范式窗口期"(新技术刚出现、旧技术未锁定的一两代人之内);两个文明的故事张力 = 领先者守旧 vs 后发者跳越,或后发者跳越失败陷入"半新不旧"中间态;可用"时代更替重置"作叙事节拍,旧王朝的技术优势在范式转换时清零;
6. 技术与制度双树并置: 参照市政树为世界同时绘制"技术树"与"制度树"(组织维度),制度树节点(有限责任/专利法/标准时区)往往比技术节点更深刻地改变世界;
7. 校验前置链的一致性: 检查每个节点的前置是否覆盖物理+社会两个层面——"有电报但无电池/绝缘/标准化"、"有火枪但无冶金/火药配比/军制改革"都是常见硬伤;拓扑排序式检查(每个节点有完整入边)是最廉价的自洽性审计;
8. 用反直觉设计增加深度: 突破瓶颈技术后世界未必更轻松——效率提升反而扩大资源消耗或引发新瓶颈,让时代推进带上代价与冲突。

## 检查点/清单

- [ ] 现象库存在,且每个技术节点可回溯"现象+既有技术"组合来源?
- [ ] 技术树为 DAG,拓扑排序无环,层数=时代数?
- [ ] 每个时代由能量/信息/组织三维标志节点定义?
- [ ] 时代门槛技术有瓶颈(多重前置+稀缺资源+组织条件)?
- [ ] 至少 2 个死胡同技术与若干冗余路径,无"唯一解"?
- [ ] 领先/后发文明各有锁定与窗口期的戏剧设计?
- [ ] 制度树(组织维度)与技术树并置,制度节点有独立演化?
- [ ] 前置链覆盖物理+社会两层,无"有技术无配套"硬伤?
- [ ] 突破性技术附带代价(资源/地缘/新瓶颈)?
