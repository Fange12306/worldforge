# 军事体系: 从0到1构建虚构世界的军事 — 完整研究手册

> **目的**: 给定世界的地理底图、政体人口、财政能力与技术/法则状态, 按本手册从"定位与总流程"出发, 依次完成军事社会学与军队构成、战争伦理与军事文化、兵种与后勤、训练与军事革命/雇佣军、战略与地缘政治、战争形态演化与非常规战、魔法战争与一致性总检八个环节, 构建自洽、可推演、可叙事的虚构世界军事体系。
> **范围**: 战争与政治的关系(克劳塞维茨三位一体)、军事社会学(MPR/暴力垄断/兵制光谱/政变)、战争伦理(正义战争论/骑士与武士道/荣誉经济)、兵种经济学与后勤决定论、训练与军事革命论、雇佣军与私有武力、战略理论与地缘政治、战争形态演化史与非常规/不对称战争、魔法战争形态学与一致性总检(与地理/文明/历史/经济/法则篇衔接)。
> **用法**: 每步含 [输入] → [操作] → [决策规则] → [输出产物] → [检查点]。13 个主题的详细研究笔记见 `docs/research/notes/`(83-95, 前缀 military-)。
> **贯穿示例**: 内嵌示例世界「米拉斯」军事篇——灵枢城神权城邦(灵术师兵团+雇佣军)× 潮邦航海共和国(海军+武装商船)× 风语游牧(轻骑兵)三套军事体系并存, 41 年血月周期作为战争节拍器, 灵脉施法成本与传送门垄断作为超自然军事锚点。

# 第一部分: 执行流程

## 第 0 步: 定位与总流程——军队最后写, 先立三个账本

**[输入]** 地理资源底图(粮食产区/地形/河流/交通/灵脉等特殊资源)+ 文明档案(政体/人口/宗教/技术)+ 经济篇财政档案(税基/货币/借贷/军饷形态)。

**[操作]**
1. **定理论立场**: 默认采用**克劳塞维茨三支柱**——战争是"政治通过另一种手段的延续", 军事系统是政体的输出端而非独立模块; 先有战争目的(政治目标), 才有军队编制与作战样式。为每个政权写一句"战争目的声明"(复仇/圣战/收复失地/生存/商路控制)。
2. **固定依赖顺序**: 地理/气候 → 政体与人口(剩余产品率、动员合法性)→ 财政(税基、货币、实物/现金军饷)→ 技术/法则(冶金、火药、魔法普及率与等级)→ **最后**才推导兵种构成、编制与战役。前序模块定稿后不得被后序反向推翻; 军队档案记录依赖链反向引用("此军团依赖灵脉税, 枯竭则瓦解")。
3. **建三个账本**(与军事-财政国家 Brewer 论对应): ①人口账——军队规模 ≤ 人口 × 可动员率(前工业常备军约 0.5-2%, 战时动员 5-10%, 总力战 10-15% 为社会崩溃级); ②财政账——军费 ≤ 财政总收入 × 可承受比例(和平 20-40%, 战时 60-80%, 罗马因职能单一可至 70-80%); ③后勤账——战役半径 ≤ 补给手段的日行距离与补给线安全长度。三个公式强制校准, 任一失衡即需回调。
4. **用牙尾比 (tooth-to-tail) 连接技术模块**: 每名战斗兵员配多少支援(拿破仑时代约 1:1-1:2, 现代技术密集军队可至 1:3 以下)——技术越先进后勤尾巴越重; 魔法兵种应类比"战略空军": 数量极少、造价极高、需专属补给链(法器维修、稀有素材、后勤保障团)。
5. **跑"反现代主义"自检表**: 无人口/财政依据的百万大军? 穷国养得起豪华常备军? 跨沙漠远征无人饿死? 士兵凭空产生无社会来源? 兵器数百年不演进? 战争目的不明("为了打而打")? 每项都是高危错误。
6. **按叙事深度定档案粒度**: 军事若只是背景, 三账自洽即可; 若军事是主线(战役/战略/军事政变), 下钻到指挥决策、训练成本、伤亡替换率与士气(摩擦的叙事化)。

**[决策规则]**
- 军事系统 = 政体的输出端, 不是独立模块(克劳塞维茨);
- "战争制造国家, 国家制造战争"(Tilly)——你设定的战争形态直接决定政体、财政与社会结构;
- 财政能力 = 军队规模的天花板; 后勤算术 = 战略意图的硬约束(van Creveld);
- 军队的社会来源即社会分层图: 骑士↔采邑、常备军↔官僚财政、雇佣军↔货币经济;
- 史诗感来自稀缺与代价(5 万常备军"因为这个王国财政只养得起这么多"就是故事), 而非"加零"。

**[输出产物]** `军事定位书`(理论立场 + 依赖链 + 三账本 + 三个公式的校准结果 + 每政权战争目的声明 + 自检表)。

**[检查点]** 依赖顺序无循环; 三个公式全部通过或已给出机制理由; 每政权有明确战争目的; 魔法/灵术兵种已完成后勤映射三问(燃料何来/谁维护训练/断供后果)。

## 第 1 步: 军事社会学与军队构成——先定财政底座, 再选兵制

**[输入]** 军事定位书 + 经济篇财政档案(税收货币化程度/信贷/行政统计能力)+ 社会分层资料(文明篇)。

**[操作]**
1. **用"军事劳动组织决策表"选兵制**(Zürcher 框架): 四项指标——税收货币化程度(实物税还是白银/金币)、有无信贷与银行、行政统计能力(能否造兵册)、人口密度与人均财富——决定政权落在**民兵/征召/常备/雇佣**光谱的哪一格: 实物税经济只能撑民兵与封建征召, 现金财政才能养常备军与雇佣兵(明代卫所转募兵即此逻辑)。
2. **用 MPR 反向设计社会气质**(Andreski): 高 MPR(全民皆兵)社会给出平等主义制度——公民大会、战利品共享、成人礼=持枪权, "参战权=政治权"即主线冲突; 低 MPR 武士帝国给出贵族等级、农民缴税供养、军人司法豁免, "被剥夺武装的下层"即潜在革命力量。
3. **用"暴力垄断+合法性"三角搭建政权骨架**(韦伯): 每政权回答三问——谁有权合法杀人?(垄断者); 依据何种合法性?(传统神授/魅力战神/法理法典); 军队向谁宣誓效忠? 合法性类型决定效忠对象, 合法性危机点(王权衰微/领袖死亡/法典失信)即暴力垄断裂开处, 在那里安排军阀、私兵、教团武装登场。
4. **用 Malešević 三要素区分"尚武"与"强军"**: 全民武装部落 = 高参与率+低官僚化+意识形态驱动(暴力分散、烈度低、受荣誉规则约束); 帝国常备军 = 低参与率+高官僚化(军需署/驿站/兵册)+强叙事(暴力集中、烈度惊人、依赖后勤)——两者是不同物种, 战斗方式与节奏截然不同。
5. **为每政权建"政变风险模型"**: 政变倾向 ≈ 军人特权密度 + 组织自主性 + 财政脆弱 + 外部威胁感; 然后配稳定器(宪法化军队中立/军官养老金与经商特权/将领王室联姻/军队祭祀神谕绑定), 稳定器失效即政变剧情引爆点(Finer/Nordlinger)。
6. **雇佣兵城邦落地**(瑞士模式): 条件链——人口过剩+山地贫瘠+无资源+尚武传统 → 输出军事劳动换年金与安全; 组织用"佣兵行会/承包连队"; 内置叙事冲突——佣金腐蚀公民德性(马基雅维利)、最强队长篡位(斯福尔扎)、雇主欠饷叛乱。
7. **用"军民距离"制造世界观张力**: 驻防位置(城内=监视 vs 城外=隔离)、军官特权范围、晋升标准(血统 vs 战功测试)——决定民众眼中军队是守护者还是占领者。

**[决策规则]**
- 兵制不是"选制度", 而是军事劳动力市场在财政-行政条件下的均衡解(Zürcher);
- MPR 与社会分层成反比, "尚武民风"常与"平等主义"同现(Andreski);
- 国家 = 对合法暴力垄断的**主张**, 须被承认才成立(韦伯);
- 雇佣军把"谁当兵"与"谁统治"分离——风险是忠诚与篡位。

**[输出产物]** `军队构成档案`(每政权: 兵制光谱定位 + MPR 值 + 合法性类型与效忠对象 + 政变风险与稳定器 + 军民距离设定)。

**[检查点]** 兵制与财政货币形态互洽; MPR 与社会制度互证; 三问(垄断者/合法性/效忠对象)全答; 政变风险有明确触发器; 雇佣军供给方条件链成立。

## 第 2 步: 战争伦理与军事文化——给暴力装上"说法"与"仪式"

**[输入]** 军队构成档案 + 宗教/信仰设定(文明篇、法则篇)+ 社会等级与荣誉观。

**[操作]**
1. **给国家写一部成文"开战正义法"**(正义战争论): 明定谁有宣战权(皇帝/议会/祭司神谕?)、正当理由清单(自卫/纠正冤屈/恢复和平/圣战)、正当意图与最后手段条款; 再写交战正义二原则(区分战斗员/非战斗员、相称性)与战后正义(和约与问责)。刻意设计"法典与实态落差"——战争贩子如何伪造或滥用正当理由, 这是天然剧情引擎。
2. **构建荣誉经济**: 定义荣誉的获得/剥夺机制(公开羞辱→决斗挑战→满足或死亡)、仲裁机构(荣誉法庭/长老会/祭司)、拒绝挑战的代价(社会性死亡); 让荣誉与金钱、婚姻、官职挂钩, 形成可交易的"荣誉货币"(基尔南: 决斗是贵族维持排他身份的工具)。
3. **宗教与战争深度咬合**: 设计战神系谱、战死者彼岸(对应瓦尔哈拉——"唯战死可得永生"), 让士兵真心相信"战死是进天堂的门票"; 加葬仪与曝尸禁忌(希腊: 败方尸体不得收葬是最大侮辱)、战前占卜(罗马 auspicia)、神圣休战日(上帝休战 989 年起: 礼拜日/斋期禁战)。
4. **写清俘虏–赎金经济**: 按军衔定价的赎金表、投降礼节、担保制度、违约后果(阿金库尔 1415 处决战俘是经典违约); "贵族赎金贵、步兵贱"的分层自动产出道德张力与冲突事件。
5. **设计晋升的三种货币(战功/出身/金钱)及其冲突**: 罗马"战功升士兵、出身升军官"二元结构、英国军职购买制(1683-1871)、拿破仑"每个士兵背包里都有一根元帅杖"、武士家格 vs 战国下克上——每组都可转化为人物动机与派系斗争。
6. **给战争仪式写"准入规则"**: 谁配凯旋/献捷(外敌标准、杀敌门槛, 罗马需单役杀敌五千+元老院批准)、战利品分配比例与争议(士兵哗变/将领贪墨)、被俘军旗的羞辱价值(军团鹰旗崇拜)——仪式即权力展演(比尔德《罗马凯旋式》)。
7. **为每条军法典配"例外条款"与双效式辩护**: 伦理体系从不杜绝暴行, 而是为暴行提供语言与台阶(双效原则: 平民伤亡只要"非蓄意附带效应"即可免责; 沃尔泽"最高紧急状态"可临时破禁)——承认这一点, 虚构军事文化才真实可信。

**[决策规则]**
- 正义战争论三段(jus ad bellum / in bello / post bellum)齐备, 才有"合法暴力"的伦理底座(奥古斯丁→阿奎那→沃尔泽);
- 骑士荣誉向外求证(他者授予), 武士荣誉向内自证(同侪评价)——两套伦理产生两种冲突写法;
- 法典越严, 违反越普遍——"落差"即叙事空间;
- 俘虏经济本质是市场理性("仁慈"是定价的产物), 三十年战争式常备军会碾碎它。

**[输出产物]** `战争法文本`(开战/交战/战后三编)+ `荣誉经济规则`(获得/剥夺/仲裁/代价)+ `战争仪式档案`(凯旋准入/战利品分配/彼岸信仰/休战历)。

**[检查点]** 宣战权归属明确且可被滥用; 荣誉获得与剥夺有闭环机制; 战神信仰与战死者彼岸已写(或与灵魂法则衔接); 赎金表按身份分层; 晋升三货币冲突有实例; 仪式有准入资格与分配争议。

## 第 3 步: 兵种体系与后勤——每支军队都是一张资产负债表

**[输入]** 军队构成档案 + 地理篇地形/牧地/矿脉/水道 + 法则篇魔法资源分布(灵脉/法力节点)。

**[操作]**
1. **为每个兵种建立"资源资产负债表"**(兵种经济学第一原理: 兵种是国家能力的物化): 注明资本密集度、训练周期、补给类型(谷物/草料/火药/木材/铁/灵晶)、战略瓶颈资源(马种、硝石、船材、良弓木)。把瓶颈资源设为世界地理与外交焦点——缺马的国家用贸易(茶马互市式)、缺硝石的国家发动战争——资源线即剧情线。
2. **设计"兵种—政体—地形"匹配矩阵**: 草原汗国=骑兵+全民皆兵+随军畜群自给; 海洋城邦=海军+贸易税+雇佣水手+商人寡头; 农耕帝国=步兵+常备军+户籍粮秣制度; 封建王国=贵族重装骑兵+封地征召义务——读者可从军队结构反推政体。
3. **编制数字必须"算得清账"**: 设什(10)→队(50-100)→旗/百人队→千户/团→军团(5000-6000)的十进制结构, 规定每级自带粮草日数、指挥跨度(5-10)与荣誉名号; 财政紧张时读者应能"看出"哪一级会被裁撤(罗马百人队约 80→大队约 480→军团 10 大队; 明代 10 人小旗→112 人百户→1120 千户→5600 卫)。
4. **画"补给半径"地图约束战争**(van Creveld): 建"每日消耗表"——每兵约 1 kg 粮+3 升水, 每马 10 kg 以上草料(骑兵饲料常超人粮, 这是"骑兵贵"的真因); 水运约为陆运 1/10-1/20(戴克里先敕令: 陆运 200 英里小麦价翻倍, 海运跨地中海仅涨 1/3); 陆运超 3-5 日行程牲畜自耗吞掉载重。据此画各军"可及半径": 哪些战争打得成、哪些注定失败。
5. **用"杂志系统 vs 以战养战"区分政权性格**(Louvois vs 华伦斯坦): 富裕帝国用仓库系统(守强、机动慢、怕断粮), 游牧/蛮族用征粮(机动快、怕焦土坚壁清野); 互相克制形成军备竞赛, 也决定占领区民众的敌我态度(征粮者失民心→补给更难的恶性循环)。
6. **把补给线做成冲突引擎**: 袭击辎重队、封锁渡口、山口伏击是真实战略动作; 设计"纵深防御"(故意放敌深入再断粮道); 正面对峙+后勤绞杀双线并行(1812 拿破仑: 随身仅 4 日饼干, 征粮在俄国焦土下失效, 60 万大军生还不足 3 万)。
7. **围城剧本公式**: 写下守方存粮天数(人口×日均消耗)、水源(断水 3 日致命)、攻方补给线长度与季节; 用节拍推进——定量减半→吃马→吃皮革→骚乱→投降/突围, 或攻方瘟疫断粮→解围军到达(维也纳之围 1683、列宁格勒"生命之路")。
8. **军饷 = 忠诚开关与政权定义器**: 明确军队经费来源(税收/战利品/雇佣金/贡赋); 用"拖欠军饷→哗变/劫掠→民心尽失"作转折点; "谁付钱"直接展示政体性质。
9. **魔法后勤必须设上限并展示瓶颈转移**(关键接口): 给传送门定吞吐量/维护者/能耗, 储物袋定容量与稀有度, 造粮术定次数; 撤掉食物瓶颈后立刻引入新瓶颈(军饷/弹药铸造/马匹饲料/医疗/士气/指挥带宽), 并让传送法阵成为敌方特种部队首要破坏目标——魔法不是解除后勤, 而是把后勤变成新的战场。

**[决策规则]**
- 骑兵成本在"马"而非"人": 战马驯养 3-5 年、年维护数倍于步兵军饷——马政即国政(北宋缺马案例);
- 火器的革命性不在杀伤而在"训练时间的民主化"(长弓十年 vs 火器数周);
- 补给距离与消耗率是幂律关系——越深入敌方, 单位路程消耗越高;
- 机动速度的上限是补给速度, 而非行军速度(van Creveld);
- 围城多数结局不是破城而是"饿降"或"饿退"——围城是双方补给能力的对赌。

**[输出产物]** `兵种资产负债表`(每兵种: 成本结构/训练周期/瓶颈资源)+ `编制表`(全链数字+每级自带粮草日数)+ `补给半径地图`(水运/陆运/草料线/传送吞吐)+ `每日消耗表` + `围城计时器`。

**[检查点]** 每兵种有瓶颈资源且其地理分布造成外交焦点; 兵种-政体-地形匹配律成立; 编制数字与经济含义挂钩; 每场战役可通过"距离-补给"检查点; 魔法后勤有上限且瓶颈转移已设计; 军饷来源与政体互洽。

## 第 4 步: 训练、军事革命与雇佣军——把改革写成世界断层线

**[输入]** 兵种资产负债表 + 技术/法则状态 + 历史篇大事年表(为革命时刻定位)+ 财政档案(现金财政/信贷)。

**[操作]**
1. **设计"军事革命时刻"作为世界断层线**(Roberts/Parker/Rogers): 选择一项创新(齐射操练、膛线、棱堡、灵术体系、征兵制)作为历史分水岭, 明确革命前/后军队差异(编制、训练周期、成本、兵源); 按罗杰斯"断续均衡"传播——创新先在一国爆发, 邻国不模仿就在战场被淘汰, 制造"不得不回应"的连锁扩散; 让改革从军事外溢到社会(操练→工厂流水线→学校→钟表时间观, McNeill "命令技术")。
2. **训练制度三参数建模**: 训练周期(数周/数年/终生)、训练载体(行会/寺院/国家学院/骑士团)、训练成本(占用劳力/财政/地位)。长弓十年 vs 火器数周的选择直接决定兵源结构: 精英小规模→贵族共和倾向; 大众大规模→集权国家倾向——兵种结构是政体结构的"底层代码"。
3. **用服从动机矩阵塑造军队性格**: 恐惧(军法连坐)/荣誉(军官阶层)/薪酬(雇佣军)/意识形态(宗教民族)四维配比。深度纪律战术(齐射/方阵)只能由恐惧+荣誉支撑; 革命军可用意识形态动员替代操练(短期强、长期崩, 法国大革命→levée en masse→后期回归专业化——训练与动员的钟摆); 雇佣军只有薪酬→忠诚脆弱、掠夺成性。
4. **用 Tilly 机制决定国家形态**: 设定世界"战争频率"变量——连年战争地区出现财政-军事国家(官僚税收+国债+代议制, 或专制直接征收); 和平地区保持封建/城邦制; 设计一场"三十年战争式"总冲突作为国家形态分水岭, 战前战后地图政体分布截然不同(三十年战争后雇佣军市场失控→各国转向常备军与官僚军需)。
5. **兵种替代写"系统经济学"而非数值碾压**: 让某种武器看似更强却被淘汰(长弓 vs 火器), 理由是训练体系、补充率、国家财政、政治成本的全系统账; 这天然产生旧精英兵种没落与反抗的剧情(武士荣誉对抗火器"不名誉")。
6. **设定"暴力市场化"时代与"去私有化"事件**(Thomson): 世界先存在"合法暴力可买卖"阶段(佣兵团/私掠团/军事承包商公开运营), 再设定一部"国家垄断武力"的划时代法令(类比法国 1793 法令/美国 1794《中立法案》/英国 1819《外国人征兵法》): 谁被定义成"非法暴力"、谁被收编为"国家军队", 引爆政变、内战与佣兵大迁徙——宏大剧情引擎。
7. **用契约细节构建佣兵团文化**(Zürcher/Redlich/Parrott): 每份契约写明兵力、军饷(按"枪"计)、期限、装备自备、战利品分成与违约条款; 佣兵团是"公司"——纹章、招募站、后勤商、军需官、品牌信誉; 委托-代理承诺问题配缓解机制(人质/定金/年金/封地/效忠宣誓/分期付款/编入贵族体系)。
8. **把兵变写成"集体谈判"而非叛乱**(Parker 佛兰德斯军团研究): 欠饷→士兵选举代表→占领要塞→谈判(补饷+赦免)→复工或转投他人; "支付节奏"是雇主决策的核心变量; 兵变期间佣兵团进入"自治共和国"状态(选举/军法/议事会, 色诺芬万人远征军模板)。
9. **铺开"武装商船–私掠者–海盗"合法性光谱**: 委任状、战利品法庭、捕获分红、保险市场构成海上经济(1812 战争约 500 艘私掠船捕获约 1300 艘英船); "合法私掠"与"海盗"的边界由文书与法庭认定, 可被政治操纵; 设计一场"废除私掠"运动(类比 1856《巴黎宣言》)逼旧船队转型为海盗或国家海军。

**[决策规则]**
- 军事革命是"技术 → 攻防成本反转 → 军费膨胀 → 政体重塑"的连锁, 每项革新都在这条链上落位;
- 决定兵种淘汰的是"系统"而非武器本身(Rogers);
- 暴力去私有化是**权威之争**而非效率考量——驱逐私人武力是为了让"谁能合法杀人"只有一个答案(Thomson);
- 佣兵首领的两难: 无能必败、能干必篡(马基雅维利)——"篡位"是雇佣军的结构性可能;
- 反佣兵是一支道德规范而非经济事实(Percy), 它划出"士兵"与"杀手"的边界。

**[输出产物]** `军事革命时间线`(革命时刻+前后对照+扩散链)+ `训练制度表`(三参数+兵源结构)+ `服从动机矩阵`(每军团四维配比)+ `佣兵市场档案`(契约模板/兵变流程/私掠委任状/去私有化法令)。

**[检查点]** 每次革命时刻完成三问(改变攻防成本? 谁能负担? 谁上升谁被淘汰?); 训练制度与政体倾向互证; 服从动机与战术要求匹配(齐射需深度纪律); 去私有化事件有明确时间与后果; 佣兵契约可执行可违约; 私掠合法性光谱完整。

## 第 5 步: 战略理论与地缘政治——画世界棋局, 找重心与咽喉

**[输入]** 军事革命时间线 + 地理篇地形/水系/山口/海峡 + 文明篇政权关系 + 历史篇联盟与战争记录。

**[操作]**
1. **为每个阵营画"三位一体"指标**(克劳塞维茨): 政府(官僚/贵族/教权)、军队(组织与士气)、人民(激情与承受力)三维评分——军队崩溃后人民意志可支撑游击与起义(1812), 民意崩盘可令强军败于内乱。
2. **定义世界的战争逻辑**: 战争是政治工具、宗教圣战还是生存本能? 据此设定升级/降级规则、宣战与和约机制、禁忌武器(威慑→不战而屈人之兵, 孙子"上兵伐谋"); 让"为什么没有全面战争"成为世界观自洽点。
3. **用"重心"与"攻防悖论"驱动剧情**: 给每个国家明确重心(兵力集群/首都/补给中枢/民心/联盟), 战役围绕攻防重心展开(1812 莫斯科是重心误判——俄国重心是军队与抵抗意志); 防御是较强的战争形式、进攻持有积极目的——设防御工事与地形优势(山口/要塞/结界), 使进攻方必须集中、快速、冒险, 天然产生"豪赌"与"守城逆转"故事。
4. **用三层体系规划战役剧情**(Svechin/Triandafillov): 先定战略目标(政治目的), 再设计战役计划(阶段/兵力/补给线/内线外线), 最后落到 2-5 场战术遭遇战; "赢了会战、输了战争"(重心未取)是悲剧与反转来源; 三种形态按时代选用——决战(坎尼模式)/消耗(德尔布吕克 Ermattungsstrategie)/机动(利德尔·哈特间接路线)。
5. **给军师角色"算与算不准"的双重空间**: 军师强在庙算(五事七计式评估/情报/示形动敌)与内线调度(约米尼: 位于两敌之间时借短内线逐一击破); 但摩擦与战争迷雾保证任何计划都会被意外打乱——其价值在"混乱中重新决策"而非全知; 可让不同军师信奉决战/消耗/机动不同学派, 形成路线之争。
6. **先画"世界棋局"再画国界**(地缘政治三论): 标出 ①心脏地带——难以入侵的内陆草原/沙漠/冰原核心, 拥有战略纵深(麦金德: 谁统治心脏地带谁控制世界岛); ②边缘地带——沿海弧形文明带, 人口财富密集, 海陆两权碰撞的"接缝带"(斯皮克曼: 谁控制边缘地带谁统治欧亚); ③海权帝国——岛国或半岛霸主(马汉海权六要素: 地理位置/自然结构/领土/人口/国民性格/政府政策); ④大陆腹地强权。主线冲突沿边缘地带展开。
7. **设计 3-5 个咽喉点并赋予"卡口属性"**: 为每个咽喉点(山口/海峡/运河/地峡/唯一通道/传送门)写明: 谁控制、卡住什么(贸易/军队/魔力供给)、绕行成本、封锁后果; 刻意让一个弱国/城邦把守咽喉, 形成"小国钳制大国"的不对称杠杆(新加坡-马六甲、伊朗-霍尔木兹模板)——现成剧情引擎。
8. **用"威胁感知四要素"推演结盟**(Walt): 威胁 = 综合实力 × 地理邻近性 × 感知到的进攻性意图 × 攻防能力; 推导谁制衡/谁追随/谁推卸责任(沃尔兹: 制衡是结构常态, 追随是罕见例外); 务必让"被制衡者≠实力最强者"; 用"某国意图感知突变"(狂人登基/突然军事化)触发体系重组。
9. **至少设计一个缓冲国并写明"大国为何不吞并它"**: 给缓冲国生存策略(中立化条约/两头讨好/以宗教商会宗族纽带自保), 写两国相互猜忌、维持其存在的理性——吞并即让对手兵临城下(阿富汗大博弈/蒙古第三邻国模板); 缓冲国命运可作悲剧与反转的叙事支点。
10. **战略资源分布 = 冲突线地图**: 为煤铁(工业带)/盐淡水(古代税源)/马匹魔兽(战争机器)/魔法节点灵脉(能源外交)各画分布图; 让最富资源区落在势力边界附近, 制造"资源换安全"与"资源诅咒"(暴利腐化政治、引来外部干预)国家。
11. **用"骑海矛盾"塑造大国性格**(陆海复合型两难): 同时有漫长海岸线与大陆腹地的国家(法国/俄罗斯/明清模板)面临海防派 vs 陆防派之争, 最怕两线作战; 海权国写商船队+海外基地+海军传统, 陆权国写战略纵深+骑兵/铁路/要塞体系; "要不要出海口"成为宫廷辩论与政变的永恒主题。

**[决策规则]**
- 战略目标服从政治目的, 一切战争必须回答"为何而战、打到什么程度为止"(克劳塞维茨);
- 重心 = 敌人力量与抵抗的源头, 战略应指向重心而非边缘(克氏);
- 结盟跟着威胁走, 不跟着实力走(威廉二世造舰队→英国转向法俄协约);
- 咽喉点 = 垄断性 + 脆弱性 + 不对称杠杆 + 过路费/封锁收益;
- 缓冲国是"绝缘层": 大国不吞并它是理性计算而非仁慈。

**[输出产物]** `世界棋局图`(心脏地带/边缘地带/海权国/陆权国标注)+ `咽喉点档案`(每个: 控制者/卡住什么/绕行成本/封锁后果)+ `威胁感知与联盟推演表` + `缓冲国档案` + `战略资源-冲突线地图` + `每政权重心表`。

**[检查点]** 每政权重心明确且战役围绕重心; 咽喉点 ≥3 个且卡口属性完整; 结盟可由威胁四要素解释(非随意的"宿敌"); 缓冲国生存策略与大国克制理性成立; 资源分布产生真实冲突线; 陆海复合型国家有两线作战恐惧。

## 第 6 步: 战争形态演化与非常规战——装有限↔总体温度计, 给弱者胜利机制

**[输入]** 军事革命时间线 + 世界棋局图 + 历史篇王朝周期 + 地理篇复杂地形(山地/丛林/城市/沙漠)。

**[操作]**
1. **制作"战争分期表"**(战争形态 = 动员方式 × 资源模式 × 技术基础 × 战争目的 × 规模节奏): 为世界定义 5-7 个时代, 每格固定五字段——动员方式(部族征召/公民兵/采邑骑士/常备军/总动员)、资源模式(战利品→义务→税收→国债)、军队规模数量级(百/千/万/十万)、战役节奏(日决/季战/年战/持续数年)、目的(掠夺/征服/意识形态/生存/不升级); 表格本身就是世界观大纲。
2. **为每个形态转换设计"战争革命时刻"**: 指定一个发明(棱堡/排枪/铁路总动员/核裂变/灵术体系)并推演三问——它如何改变攻防成本? 谁能负担新战争? 谁的权力因此上升/谁被淘汰? 答案即该时代的政治重构(修昔底德: 战争动因=恐惧、荣誉、利益)。
3. **给世界装"有限↔总体"温度计**(克劳塞维茨 vs 鲁登道夫): 明确是什么机制让战争保持有限(神圣休战/骑士荣誉规则/季节农时/核威慑/经济互赖/公约), 再设计一个"打破约束"的事件(技术让破约成本下降/狂人执政)触发总体化——三十年战争(中欧人口损失约三分之一)与一战皆此逻辑; 核时代则反向: MAD 下用可控小战争替代不可控大战争(Kahn 升级阶梯/Osgood 有限战争)。
4. **让国家制度显式地由战争催生**(Tilly): 每国税收/官僚/征兵/测绘/国债都应在战争史中找到成因; 用"战争→开支→汲取→民变/革命→新制度"循环为王朝更替提供经济因果; 用战争副产品填充日常细节(技术外溢/退伍安置/战争债/阵亡纪念/战史官修叙事)。
5. **给双方定义不同的"胜利货币"**(非常规战第一课): 强者按歼灭与领土结算, 弱者按时间、生存与合法性结算; 结局不必是弱者"打赢", 而是强者先失去继续的意志(越南模式: 军事上没输, 国内政治输了; Arreguín-Toft: 弱者用间接战略获胜概率约为正面硬抗的 4 倍)。
6. **用三阶段论搭起义弧线**(毛泽东): 战略防御(潜伏恐怖/城市地下)→战略相持(根据地/政权"治安恶化")→战略反攻(正面决战或政治谈判); 每阶段切换地形(城市→山地丛林→首都)与战术(暗杀→伏击袭扰→正规作战); 十六字诀"敌进我退, 敌驻我扰, 敌疲我打, 敌退我追"作机动总则; 人民战争"鱼入水"——情报/兵源/补给来自民众, 敌人无法区分战斗员与平民。
7. **设计 COIN 对抗时把平民做成显式"争夺曲线"**(Galula/FM 3-24): 人群分 20% 积极少数+80% 中立多数, 目标是争取中立者; 四步法(消灭武装→切断其与民众联系→赢得民心→建立正规军警); 兵力比约 10:1 起; 政治占 80%、军事占 20%; 每次过度镇压(屠杀/强制搬迁/酷刑)使曲线向叛乱者倾斜——反叛乱悖论: 重火力→平民伤亡→民众倒戈(阿尔及尔: 军事胜利、政治破产)。
8. **平行于军事的信息战线**(Lasswell/认知战/反射控制): 为冲突设计完整宣传体系——口号/战地记者叙事/假消息/纪念仪式; 设计"春节攻势式"转折: 军事惨败被包装成战略胜利, 动摇帝国国内舆论并触发撤军; 反派可用混合战争手段(Hoffman: 常规军+游击队+犯罪网络+信息战+经济手段混用, 模糊战争/和平、战斗员/平民界限)。
9. **地形即角色**: 为抵抗组织选一种主导地形并推导全部战术后果——丛林(点状遭遇/疾病/走私补给线)、山地(隘口伏击/部族网络/补给脆弱)、城市(地下道/巷战/人质, 格罗兹尼装甲纵队覆灭); 复杂地形是"技术抵消器"——弱势方借地形稀释强者火力, 把战争拉回近距离、低技术、拼意志的形态。
10. **弱者制胜五机制全部落位**(Arreguín-Toft/Mack/Merom): ①时间不对称(叛乱者以生存为目标、时间充裕; 政府受选举/财政/舆论约束耗不起); ②意志不对称(民主国家"身体敏感", 平民伤亡引发反战); ③成本转嫁(把冲突成本导向平民制造政治压力); ④合法性争夺(将"镇压"改写为"解放", 争取外援); ⑤扩散防御义务(攻击对手必须保护的大片区域, 摊薄其资源)。再配"挑衅—过度反应"循环(恐怖暴力是沟通性暴力, 观众是舆论与政府)与双时钟(叛乱者无限耐心 vs 帝国倒计时)。

**[决策规则]**
- 形态转换改写"谁有权打仗、代价谁承担、社会权力结构"三件事——每次转换都是时代剧变引擎;
- 有限战争是历史常态, 总体化是需要条件才能接近的极端(克氏);
- 战争是概率与偶然性的领域——指挥官不是全知者, 摩擦即故事;
- 人民战争/游击战是"以时间换空间", 前提是民众支持度曲线不倒向对方;
- 反叛乱的技术效率与政治反噬并存——"技术有效、政治破产"是常见结局。

**[输出产物]** `战争分期表`(5-7 时代 × 五字段)+ `总体化触发器档案`(有限机制清单+破约事件)+ `起义弧线`(三阶段+地形切换+战术升级)+ `民众争夺曲线` + `信息战线档案`(宣传体系/转折事件)+ `弱者胜利机制表`(五机制×应用对象)。

**[检查点]** 分期表每格五字段齐备; 每次革命时刻三问已答; 有限机制与总体化触发器成对出现; 弱者胜利按机制而非奇迹; 民众争夺曲线有显式事件驱动; 信息战与军事线并行且能翻转结局。

## 第 7 步: 魔法战争与一致性总检——稀缺性定军力, 公约定世界结构

**[输入]** 前六步全部产物 + 法则篇魔法规则(施法成本/能量源/传送限制/灵脉法则)+ 历史篇大事年表。

**[操作]**
1. **给每个法术做"军事职能+稀缺性预算"卡**(法术-武器形态学映射): 判断法术的军事价值看其承担的军事职能而非特效——禁咒→核武器(战略杀伤/威慑)、结界→要塞(防护/拒止)、传送→战略机动(兵力投送/纵深穿插)、召唤→征兵替代(改变人力成本曲线)、预言→情报(侦察/预警/C2); 设计时自问"这法术在现代军队里归哪个军种管?", 答案即其兵种学。
2. **用稀缺性而非威力限制魔法军力**: 稀缺性四维——人才供给(天生禀赋 vs 可训练)、时间(施法/准备周期)、资源(材料/祭品/寿命)、集中度(可否并发施法); 威力决定单发效果, 稀缺性决定可用次数、部署密度与战略价值——一条清晰的 mana 经济学胜过十行威力数值(Sanderson 第一定律: 用限制而非设定书约束魔法)。
3. **定义 5 级升级阶梯并逐级命名**(Kahn 44 级阶梯缩编): 常规战→战术魔法→战略魔法→禁咒→末日魔法; 每级给一个可辨识的"跨级信号"(打破哪条禁忌=进入下一级); 角色与读者都能据此判断"战争升级了"; 每一级之内存在自己的有限战争逻辑, 跨级才是质变。
4. **"为何不先用禁咒"的答案全部落在机制上**(Schelling): 二次打击使报复不可避免(威慑三要件: 能力/可信度/传递; MAD 前提=无法被先发制人解除的报复手段——分散潜伏施法者/自动触发结界/埋藏诅咒); 目标不匹配(要领土与臣民而非焦土, 禁咒无法完成占领统治); 反噬双输(魔力枯竭/生态灾难/自我毁灭——自我约束四机制: 威慑/MAD/公约/反噬); 道德禁忌只作表层理由。
5. **让末日魔法成为"国家财产"并设计不扩散三重门槛**: 仅 2-3 个大国掌握, 靠技术门槛(知识保密/师承断绝)+原料门槛(禁咒材料产地垄断)+监督门槛(国际督察团)维持; "一个新兴国家试图挤进核俱乐部"是现成政治主线; 公约照抄军控结构(NPT/CWC: 禁止清单+可验证性+违约制裁, 缺验证则成废纸; 核查漏洞/退出条款即剧情引擎)。
6. **为法师军团的组织选择配代价**(三形态): 独立军团=集中训练、战力强但政治风险高(架空王室); 配属参谋=分散融入常规军、防军事政变(普鲁士总参谋部模板); 自由职业=类比雇佣军/PMC, 灵活但引入忠诚、战后遣散、私掠魔法问题; **学院认证**=军官学校+行会双重垄断(控制知识/执业许可/定价)。
7. **设计反制螺旋作为历史引擎**: 禁咒出现→反禁咒结界→破界咒→结界克星…每轮反制成为新技术节点, 用这条军备竞赛史串起世界千年史, 也自然解释"旧禁咒为何失效"; 反魔法本质是电子战类比(干扰/压制/欺骗: 反咒/抗性附魔/无效化/反魔法力场/法术侦测+非法术手段: 分散部署/遮蔽诱饵/预言预警)。
8. **保留克劳塞维茨式摩擦**: 施法者会疲劳、误判、士气崩溃; 传送受情报限制、预言受反预言干扰、结界有维修成本——避免"法术=按钮"的扁平设定; 超自然重写战争规则要逐环节推演(生产/机动/侦察/防护/后勤/指挥/杀伤)而非"魔法=火炮"式贴皮(《沙丘》范本: 屏蔽场使远程失效、近战回归, 原子武器被公约禁止——超自然重写了战争形态而非叠加特效); 追问"谁垄断、谁付钱、谁受害"(法师公会垄断治疗术即垄断兵源)。
9. **先建军事档案表再写作**(《武经总要》《纪效新书》条目结构): 编制表/军种划分/兵源制度/军官来源与晋升/军饷福利与退役/装备与产能/训练操典/后勤体系/情报体系/交通线与要塞/军法与战争法/军事财政来源/军事科技树/战史与决策链——14 项清单, 所有数字可查可对账。
10. **为每次战争写"成本清单"并让战后社会进入叙事**: 人力/财政/政治/道德/时间五项代价, 胜利必须勾掉至少三项("完美胜利"是叙事毒药); 战后写复员失业/战债/胜者内讧/战败国复仇记忆/纪念碑与记忆政治("士兵心"=古代 PTSD); 战役结构按"动员铺垫→小规模接触→决战(围绕重心)→战后清算"四段推进。

**[决策规则]**
- 稀缺性决定军力上限, 威力决定单发效果——先写稀缺预算再写威力数字;
- 升级阶梯的价值在门槛定义与可辨识信号, 不在层级多少;
- 禁咒不是"更强"而是更贵、更慢、更不可控、不可逆、目标不匹配——"用了就完蛋"要能让读者自行推出;
- 扩散门槛的高低比威力大小更决定世界政治结构——不扩散即地缘政治;
- 一致性三式互证: 人口×动员率=军队上限, 财政×军费占比=军费, 军费÷人均成本=军队规模; 战役距离 vs 补给手段 vs 行军时间表自洽; 多场战争对人口财政的累积效应(连年征战仍繁荣=矛盾)。

**[输出产物]** `法术军事卡`(每法术: 军事职能+稀缺四维预算+反制手段)+ `升级阶梯表`(5 级+跨级信号)+ `禁咒公约文本`(清单/封存登记/督察/制裁)+ `法师军团组织档案`(三形态+代价)+ `军事档案 14 表` + `一致性总检报告`。

**[检查点]** 每法术完成职能映射与稀缺预算; 5 级阶梯有命名与跨级信号; 威慑三要件与二次打击成立; 公约有验证机制与失灵时刻; 法师组织选择配了明确代价; 反制螺旋串起历史; 摩擦未消失; 14 项军事档案齐备; 一致性总检清单(见第三部分)全部通过。

# 第二部分: 贯穿示例(米拉斯军事篇)

> 法则篇: 灵脉法则(能量沿板块缝合线)/血月法则(41 年周期=灵脉爆发-枯竭节拍器)/灵魂法则(战死者彼岸)。
> 地理篇: 龙骨山脉(灵脉主带)/苍原高原(灵脉第二富集区)/丰饶平原(灵稻产区)/风语草原/白雾荒漠(雾盐湖)/北寒原/火链群岛/缝合地峡(南北唯一陆桥)。
> 文明篇: 灵枢城(神权城邦, 祭司-灵脉解释权)/潮邦(商人寡头航海共和国)/云顶寺(隐修)/风语游牧/雾盐邦(沙漠商路城邦)/北境遗民; 历史: 41 年血月周期=历史节拍器, 800 年前灵权革命=轴心时刻, 三次灵脉战争。
> 经济篇(衔接): 灵枢城再分配(灵脉税)/潮邦市场(关税+商人借款)/风语互惠/盐本位银锭/灵晶(高端魔法结算+施法燃料, 花掉=消耗)/灵脉施法有成本。

## 第 0 步: 米拉斯军事定位书

- **立场**: 战争 = 灵脉政治权的延续。灵枢城战争目的=护持灵脉解释权与灵稻贡赋(圣战性质); 潮邦=商路与关税自由(经济战争); 风语游牧=草场与南下生存(生存战争); 雾盐邦=盐路安全; 北境遗民=生存与复仇。800 年前灵权革命是轴心时刻: 灵术从祭祀走向战争, 灵枢城以此夺权——**灵术军事革命重塑了米拉斯所有政体**。
- **依赖链**: 龙骨山脉灵脉+雾盐湖盐+丰饶平原灵稻 → 人口与剩余(灵枢城约 25-30%)→ 财政(灵脉税/灵稻贡赋/盐税分成/潮邦关税)→ 灵术(灵晶燃料+灵脉亲和人才)→ 兵种(灵术师兵团/海军/轻骑兵)。反向引用: "灵术师兵团依赖灵脉学院人才与灵晶燃料, 血月枯竭年即战力折损年"。
- **三账本**: 人口账——灵枢城总人口约 40 万, 常备军约 5 千(1.25%, 含灵术师兵团 300 人与雇佣军 2 千), 战时动员极限 5%; 潮邦舰队水手+陆战队约 8 千(海权国军费靠关税, 常备军比例低于陆权国); 财政账——灵枢城和平期军费约占灵脉税+贡赋的 35%, 战时 70%; 潮邦靠商人议会借款与国债(盐税专款抵押)扩军; 后勤账——传送门 3 座(全在灵枢城控制下), 吞吐量每日约 50 吨, 银海海运=1, 缝合地峡陆运≈15, 龙骨翻山 20+。
- **牙尾比**: 灵术师兵团 1:4(每名灵术师配 4 名侍从/护卫/灵晶搬运工——魔法兵种=战略空军, 造价极高); 潮邦海军 1:2(船匠/水手/补给); 风语游牧 1:0.5(全民皆兵, 畜群自带后勤)。
- **自检**: 百万大军? 无——全大陆合计常备军不超过 3 万; 跨沙漠远征? 有——白雾荒漠商路有绿洲链+灵晶净化水; 武器静止? 无——三次灵脉战争各有形态跃迁; 战争目的不明? 无——六政权各有战争目的声明。

## 第 1 步: 米拉斯军队构成

- **灵枢城=低 MPR 神权武士集团**(Andreski): 暴力垄断=大祭司(灵脉神谕授予); 合法性=传统神授(灵脉神权)+魅力(大祭司个人卡里斯玛); 效忠对象=祭司阶层而非国家。构成: ①灵术师兵团(300 人, 稀缺→编制小+待遇极高——灵脉学院毕业生, 类比战略空军); ②祭司卫队(圣所卫兵, 血统+忠诚选拔); ③**雇佣军 2 千**(现金财政买来的暴力——灵枢城税基 25-30% 足够支付, 但雇佣军忠诚是软肋); ④灵稻民兵(农闲训练, 守城用)。
- **潮邦=法理型海权国**: 合法性=商人议会法典; 军队效忠宪法与议会; 构成=常备海军(战船约 60 艘)+武装商船(战时征用, 商船装弩炮=私掠预备队)+水手民兵; 海军将领与商人寡头联姻——"海军=商业—军事复合体"(McNeill)。
- **风语游牧=高 MPR 全民皆兵**: 每个成年男性=轻骑兵(3-5 匹马轮换), 魅力型+传统型合法性(可汗+部落长老); 参战权=政治权(部落大会), 战利品共享→平等主义气质; 骑兵比较优势来自草原牧地(马政即国政——中原式农耕化挤占牧地的困境不存在)。
- **雾盐邦=商队武装+盐路税卡民兵**: 低 MPR 但渗透型(税卡即兵站); 雇骆驼雇佣兵护商队; 盐路咽喉=其战略资产。
- **北境遗民=高 MPR 魔法抵抗者**: 全民皆兵(含妇女老人)+灵脉残术士; 平等主义氏族; 暴力垄断主张被灵枢城否认→"非法武装"身份即其合法性叙事起点。
- **政变风险模型**: 灵枢城雇佣军队长(手握重兵、受神权猜忌)——稳定器=军饷年付+人质+封"护法将军"头衔收编; 潮邦海军提督(舰队即权力)——稳定器=议会拨款权+将领议会席位; 云顶寺=完全中立(武装最弱, 无人忌惮)。

## 第 2 步: 米拉斯战争伦理与军事文化

- **灵碑战争法**(三段): 开战正义——宣战权=灵枢城大祭司神谕/潮邦议会 2/3 多数/风语部落大会; 正当理由清单(灵脉亵渎/贡赋违约/商路劫掠/圣战); 交战正义——区分原则(灵脉圣所、灵稻仓、盐湖、传送门列"不可攻击物")+相称原则; 战后正义——和约+战犯问责+赎金结算。**法典与实态落差**: 灵枢城以"圣战"名义动员雇佣军劫掠北境, 祭司伪造神谕→天然剧情引擎。
- **荣誉经济**: 风语游牧=战功计荣誉(斩敌数/夺旗), 拒绝单挑=社会性死亡; 灵枢城军官=祭司血统出身 vs 雇佣军队长战功 vs 商人买衔(晋升三货币冲突: 灵术师学院出身碾压战功, 雇佣军队长永远进不了将官团); 潮邦=海战功勋(捕获敌船=股份分红, 荣誉与金钱同构)。
- **战神信仰与战死者彼岸**(灵魂法则衔接): 灵教教义——战死者灵魂入"灵脉回响"(对应瓦尔哈拉), 唯战死得永生; 病死/老死为"草垫之死"(耻); 血月大祭前祭司为出征军举行"灵祭"(战前占卜对应罗马 auspicia); 北境遗民反用此教义: 他们信"灵脉回响被灵枢城篡改", 战死=对灵枢城的灵魂复仇。
- **俘虏–赎金经济**: 灵术师俘虏按品级定价(高阶灵术师=天价, 潮邦以灵晶赎); 雇佣兵无赎金价值常被屠(阿金库尔式违约案例: 灵枢城处决风语战俘引发草原大仇); 潮邦水手按船只股份赎。
- **仪式准入**: 灵枢城凯旋式——须对外敌(非内战)取胜+祭司核准; 凯旋游行展示禁咒战利品; 军团旗(灵脉旗)被夺=奇耻(雾盐邦曾夺灵枢城旗, 成为百年世仇记忆); 血月大祭=神圣休战期(上帝休战模板: 大祭前后各 7 日禁战——谁先破戒谁承担神罚叙事)。

## 第 3 步: 米拉斯兵种与后勤

- **兵种资产负债表**: 灵术师兵团=人力资本密集(灵脉亲和+学院训练 10 年)+灵晶燃料(战略瓶颈资源, 血月枯竭年产能近零); 潮邦战船=资本密集之王(龙骨山脉船材+船坞+水手, 靠关税与商人借款融资); 风语轻骑兵=土地(牧地)密集+马政(每兵 3-5 马, 草料自随畜群); 灵枢城步兵=灵稻贡赋供养(粮秣型); 雾盐邦骆驼军团=盐路特种(白雾荒漠补给链)。
- **编制**: 灵枢城——什(10)→队(100)→旗(500)→师团(灵术师兵团 300 人+侍从 1200 人, 非十进制因稀缺); 潮邦——船(60 水手)→分舰队(10 船)→舰队(60 船); 风语——帐(10 骑)→千骑(可汗亲卫)。每级自带粮草日数写明(灵枢城步兵 7 日, 风语游牧 30 日+畜群)。
- **后勤=战争咽喉**: **传送门极少且被灵枢城垄断控制**——3 座传送门(灵枢城/缝合地峡/龙骨山口), 每日吞吐约 50 吨; 灵枢城=唯一"瞬间投送"能力持有者, 这是它制衡潮邦海权的战略王牌; 灵脉补给线(灵脉节点-法阵驿站-前线)是灵枢城远征的**生命线**——断灵脉补给=灵术师团失去燃料与通讯; 潮邦的对应物=银海航道与补给港链; 风语游牧的对应物=畜群(移动粮仓)。
- **每日消耗表**: 灵枢城步兵 1 kg 灵稻/日+3 升水; 战马 12 kg 草料(风语马矮小耐寒, 耗料少=游牧机动优势); 灵术师兵团额外消耗灵晶(每名每日 0.5 枚=潮邦工人三月工资)→ **灵术师兵团只能打"短促决定性战争"**, 打不了消耗战——这是米拉斯战略的底层约束。
- **杂志 vs 征粮**: 灵枢城=杂志系统(沿龙骨山脉设灵稻仓+灵晶库, 守强机动慢); 风语游牧=以战养战(畜群+劫掠, 机动快, 怕坚壁清野——灵枢城"烧草场"战术专克); 潮邦=海上杂志(补给港链)。
- **围城剧本**: 灵枢城围城战=断灵稻漕运(苍河-泪湖漕运线=首都生命线, 北京模式); 守方存粮=人口 40 万×日均 1 kg=粮仓 4 个月; 围城第 N 天定量减半→吃马→开仓平粜→投降/解围; 缝合地峡要塞=灵枢城与潮邦的攻防对赌点。
- **军饷=忠诚开关**: 灵枢城雇佣军欠饷→哗变→占领缝合地峡税卡谈判(兵变集体谈判模板)→祭司补饷+处决首恶分化; 潮邦水手欠饷→私掠化(武装商船转盗)→潮邦议会紧急拨款。
- **魔法后勤瓶颈转移**: 传送门解决"距离"但吞吐有限→谁控制传送门谁控制战略投送节奏; 灵晶燃料成为新"弹药"→灵脉补给线=战场; 传送法阵=敌方特种部队首要破坏目标(北境遗民曾炸毁龙骨山口法阵, 灵枢城远征被迫改道多走 20 天——一次真实的"切断补给线"事件)。

## 第 4 步: 米拉斯训练、军事革命与雇佣军

- **训练制度三参数**: 灵术师=十年训练(灵脉学院, 国家学院载体, 成本极高→稀缺→精英小规模); 风语骑射=终身训练(草原文化, 自幼骑射); 灵枢城步兵=数月(灵稻民兵); 潮邦水手=数年(航海学徒+船艺行会)。灵术师精英化→灵枢城贵族化倾向; 若灵术普及(量产卷轴化)→集权国家倾向——**灵权革命的本质正是灵术从"精英垄断"走向"祭司国家垄断"**。
- **军事革命时刻=800 年前灵权革命**: 灵术从祭祀法术跃迁为战争法术(攻防成本反转: 旧贵族骑士的刀剑在结界与禁咒前失效)→战争昂贵化(只有灵脉富集区负担得起)→灵枢城崛起、旧封建领主被淘汰→政体重塑(神权城邦取代世袭王侯)。罗杰斯断续均衡: 此后 700 年战争形态相对停滞(结界-破界咒循环), 直到第一次灵脉战争打破均衡。
- **服从动机矩阵**: 灵枢城灵术师团=荣誉(学院出身)+意识形态(灵教圣战)为主, 恐惧为辅; 雇佣军=纯薪酬(忠诚脆弱、掠夺成性、战时抢掠灵稻仓); 风语游牧=荣誉+意识形态(部落/血月信仰); 潮邦水手=薪酬+荣誉(分红+海战功勋)。
- **暴力市场化与去私有化**: 灵权革命前=佣兵团公开运营时代(火链群岛佣兵、北境雪狼团); 灵权革命后灵枢城颁布《武力收归令》(类比 1794 中立法案): 除灵枢城与潮邦议会外, 任何团体拥有百人以上武装="非法私兵"→雾盐邦商团、北境氏族被定罪→"非法武装"身份成为后续一切冲突的引信。
- **佣兵契约细节**(潮邦-火链群岛契约范本): 兵力 500 长矛手、军饷按月付灵晶+战利品三成、装备自备、禁劫掠灵稻仓(违约罚双倍)、期限一季; 人质=团长之子在潮邦港为质; 欠饷条款=兵变合法化通道。
- **武装商船–私掠者–海盗光谱**(潮邦): 潮邦武装商船持议会委任状私掠灵枢城商船(捕获物经潮邦海事法庭判定后按股份分红); 被吊销委任状的船队=海盗(格劳秀斯"全人类之敌"教义被灵教引用于此); 拟设《银海航行令》废除私掠(巴黎宣言模板)→旧私掠船队转型海盗或并入海军——潮邦内政冲突线。

## 第 5 步: 米拉斯战略与地缘政治

- **世界棋局**: 心脏地带=苍原高原(灵脉第二富集区)+龙骨山脉(陆权纵深, 灵枢城所在地, 海权不可达); 边缘地带=沿海弧形带(潮邦/雾盐邦/丰饶平原, 人口财富密集, 海陆两权碰撞的接缝带); 海权国=潮邦(银海, 马汉六要素: 扼银海航路/天然良港/经商国民性/议会支持海权政策); 陆权国=灵枢城(战略纵深+灵脉要塞体系)。主线冲突沿缝合地峡-丰饶平原这条"边缘地带"展开。
- **咽喉点档案**(3-5 个): ①缝合地峡——南北唯一陆桥, 灵枢城把守(君士坦丁堡+马六甲模板), 卡住南北贸易/军队调动/万兽走廊, 绕行=绕火链群岛+北寒原(成本 3 倍+季节风险), 封锁后果=南北经济断裂; ②龙骨山脉山口——灵枢城设关, 卡住潮邦通往苍原高原灵脉的陆路; ③火链群岛航道——潮邦独家航路(香料+奇珍), 卡住灵枢城禁运线; ④白雾荒漠绿洲通道——雾盐邦把守, 卡住盐粮商路, 小国钳制大国的杠杆; ⑤传送门 3 座——灵枢城垄断的"超自然咽喉", 卡住战略投送速度。
- **威胁感知与联盟推演**(Walt 四要素): 灵枢城=综合实力最强+进攻意图(圣战扩张)+灵术攻防优势→被制衡者; 潮邦+风语游牧+雾盐邦结"银海-草原同盟"制衡灵枢城(潮邦出钱/风语出骑兵/雾盐出盐路通道); 威胁感知突变案例: 灵枢城大祭司宣称"收复北境圣域"→邻近+进攻意图上升→北境遗民被同盟收编为代理。
- **缓冲国**: 雾盐邦=灵枢城与潮邦之间的缓冲(盐=资源换安全: 向双方供盐+两边收过路费); 云顶寺=中立隐修缓冲带(苍原高原边缘, 双方都不吞并——吞并即让对手兵临灵脉第二富集区); 北境遗民=灵枢城与"未知极北"之间的缓冲。**大国不吞并的理性**: 潮邦吞雾盐邦→灵枢城兵临盐路; 灵枢城吞云顶寺→潮邦舰队直达苍原。
- **重心表**: 灵枢城重心=灵脉圣所+灵术师团(补给中枢=灵脉补给线); 潮邦重心=舰队+关税收入(补给中枢=补给港链); 风语重心=牧群+可汗(击其牧群=断其根本); 北境重心=氏族民心+残存灵脉节点。战役围绕攻防重心展开: 潮邦若取缝合地峡=断灵枢城南北连通(重心打击), 灵枢城若断潮邦补给港=海军瘫痪。
- **骑海矛盾**: 灵枢城=陆权神权(无出海口, "要不要打通银海出海口"是祭司议会永恒议题); 雾盐邦=陆海复合型(商路+盐湖, 海防派 vs 陆防派之争, 最怕两线作战); 潮邦=纯海权(无大陆腹地, 扩张方向=火链群岛)。

## 第 6 步: 米拉斯战争形态演化与非常规战

- **战争分期表**(五时代×五字段):
  1. **前灵权时代(部族冲突)**: 血缘动员/战利品荣誉经济/百千人规模/季节间歇/掠夺复仇——北境氏族、草原部落战争;
  2. **灵术军事革命(800 年前, 轴心时刻)**: 灵术师团+结界/灵脉税财政/万人规模/季战/夺权与建国——灵权革命;
  3. **三次灵脉战争(帝国征服期)**: 常备军+传送门后勤/灵晶国债/数万规模/年战/控制灵脉与商路——详见升级阶梯;
  4. **血月爆发(周期性总体化)**: 血月法则驱动, 灵脉爆发年=战争总体化窗口(全境动员/灵术火力全开), 枯竭年=打不起仗(自动降级);
  5. **禁咒公约时代(威慑平衡)**: 灵脉枯竭术=禁咒, MAD+公约→代理人战争(北境代理/风语代理)与有限战争成为常态。
- **三次灵脉战争=战争形态演化示例**: 第一次=灵术师团决战(决战形态: 双方主力灵术师团会战, 坎尼式围歼战术); 第二次=传送门后勤革命(灵枢城以传送门+围城战拖垮潮邦, 围城与消耗形态); 第三次=全域消耗+禁咒雏形(双方以灵脉枯竭术威胁而未用→签订禁咒公约, 威慑形态诞生)——每次战争都改写"谁有权打仗、代价谁承担、权力结构"。
- **有限↔总体温度计**: 有限机制=血月休战/骑士式荣誉规则(雇佣军契约)/灵晶成本(打不起)/禁咒公约; 总体化触发器=血月爆发年(灵脉活跃, 灵术成本骤降→全面战争门槛消失)+大祭司"圣战"动员令。三十年战争式案例: 第二次灵脉战争中期血月爆发叠加→中大陆人口损失近三成。
- **非常规战**: ①**北境遗民=山地游击+魔法抵抗**: 三阶段弧线——潜伏(雪洞据点/灵术暗杀)→相持(根据地=北寒原冰洞网络, 灵脉游击队"鱼入水", 民众即情报网)→反攻(炸毁灵脉补给线/山口法阵); 十六字诀本土版"敌进我退入雪原, 敌驻我扰于冰夜"; ②**雾盐邦=沙漠商路游击**: 盐路袭扰+绿洲伏击+走私线补给, 复杂地形(沙暴/绿洲间距)稀释灵枢城火力; ③**风语游牧=机动游击**: 敌进我退(退入草原纵深), 以空间换时间, 断粮道(烧灵稻仓)为主战法。
- **信息战线**: 灵枢城=神谕叙事("灵脉不悦"解释失败/胜利皆为神意); 潮邦=商人新闻(战报+汇率情报); 血月预言=信息战武器(大祭司宣布"血月爆发年=天命决战年"动员信众); 北境=殉道者叙事(被处决游击队员→纪念仪式→"灵枢城是篡改灵脉的伪教"认知战); 设计"春节攻势式"转折: 北境某次"大捷"实为惨败, 但经流言网络包装为战略胜利, 动摇灵枢城信众士气。
- **弱者胜利机制**(北境遗民): 时间不对称(41 年血月周期+代际复仇使命 vs 灵枢城每代祭司的短期合法性); 意志不对称(北境平民伤亡→灵枢城信众反战情绪); 成本转嫁(把战争成本导向灵枢城商路→商人议会施压); 合法性争夺(在潮邦舆论场把"镇压"改写为"灵脉圣战侵略"); 扩散防御义务(北寒原广袤+冰原地形→灵枢城驻军摊薄)。**挑衅—过度反应循环**: 北境游击队袭击灵稻仓→灵枢城处决人质→中立氏族倒向北境。

## 第 7 步: 米拉斯魔法战争与一致性总检

- **法术-武器形态学映射**: 禁咒=**灵脉枯竭术**(核武器: 抽干一片区域的灵脉, 战略杀伤+威慑——类比核弹+生态武器); 结界=灵脉结界(要塞: 龙骨山脉结界墙); 传送=传送门(战略机动: 灵枢城垄断); 召唤=灵脉造物傀儡(征兵替代: 改变人力成本曲线, 但耗灵晶=烧钱); 预言=灵兆占卜(情报: 越重要越模糊, 反预言/自证悖论)。
- **稀缺性四维**(灵术师兵团): 人才=灵脉亲和天赋+学院十年(长期供给缓增, 精英过剩=革命压力源之一); 时间=高阶灵术需数日仪式(无法快速反应); 资源=灵晶燃料(血月枯竭年供给近垂直); 集中度=血月爆发年灵脉活跃, 可并发施法(总体化窗口)。
- **升级阶梯 5 级**(命名+跨级信号): ①常规战(冷兵器/弓弩/火油); ②禁忌灵术(对平民施法/动用亡者术=跨级信号); ③战略灵术(攻城禁咒/大范围结界); ④**血月爆发**(血月年灵脉失控级法术, 跨级信号=大祭司举行"血月灵祭"); ⑤**封印咒(末日级)**——抽干大陆灵脉的终极咒式, 任何势力使用=世界灵脉崩溃。逐级门槛由灵碑法典明文(禁咒公约)。
- **禁咒=灵脉枯竭术→禁咒公约**(NPT 式): 禁止清单(灵脉枯竭术/封印咒)、材料封存登记(禁咒材料产地=龙骨山脉深脉+苍原灵脉节点, 灵枢城垄断)、国际督察(潮邦/云顶寺/雾盐邦联合督察团, 灵枢城勉强接受)、违约制裁(同盟集体断交+禁运); **固有漏洞=剧情引擎**: 核查欺骗(灵枢城在深脉秘密试验)、退出条款(血月爆发年违约诱惑)。
- **威慑与 MAD**: 灵枢城的二次打击=埋藏式灵脉咒印(被先发制人摧毁后仍自动触发, 对应核三位一体); 潮邦的二次打击=海基灵术舰(分散潜伏); 云顶寺=被动威慑(中立即"不在棋局上"); 灵枢城威慑可信度靠"大祭司与圣所共存亡"的公开宣称(Schelling 拴住的狗)。
- **自我约束四机制**: 威慑(怕报复)/MAD(双方同毁)/公约(禁咒清单+督察)/反噬(灵脉枯竭=世界生态与灵魂法则崩溃, 施法者自身魔力损伤+寿命代价——终极兜底)。
- **法师军团组织三形态**: 灵枢城=独立军团(灵术师兵团, 战力强但"架空祭司王室"风险——高阶灵术师团是潜在政变主体); 配属参谋(灵术师配属各军做战术支援, 防政变); 云顶寺=自由职业(不受管制第二供给源, 向各方出售灵术服务——"私掠魔法"问题: 云顶寺叛逃灵术师组建佣兵团)。
- **反魔法与反制螺旋**: 灵脉屏蔽阵(反结界)→破界咒→结界克星(灵脉共鸣器)…千年反制史=米拉斯技术史骨架; 反魔法非法术手段=分散部署(压低禁咒收益)+遮蔽诱饵(灵晶假目标)+灵兆预警; 北境遗民无灵术但用"灵脉干扰术"(污染节点)抵消灵枢城优势——**复杂地形+反灵术=技术抵消器**。
- **总检十项**(对照第三部分): 全部通过——人口/财政/后勤三式互证; 战役距离与补给手段(传送门吞吐/海运/草料线)自洽; 军事技术与政体匹配(灵术师团↔神权财政); 战争规模与政治目的匹配(有限战 vs 血月总体化); 战斗结果与战后统计一致; 灵术规则统一(施法成本/灵晶/血月周期); 多场战争对人口财政的累积效应已核算(第二次灵脉战争减员三成后 41 年恢复期); 角色认知时序(谁知道禁咒真相、何时知道)已设计; 军事文化与灵碑战争法前后一致; 编制数与损失数全书可对账。

# 第三部分: 一致性总检清单(军事篇)

**基础层**(第 0 步):
- [ ] 依赖链无循环(地理→政体人口→财政→技术/法则→军队), 反向引用已记录;
- [ ] 人口账通过: 军队规模 ≤ 人口 × 动员率(常备 0.5-2%, 战时 5-10%, 总力战 10-15% 为社会崩溃级);
- [ ] 财政账通过: 军费 ≤ 财政 × 可承受比例(和平 20-40%, 战时 60-80%);
- [ ] 后勤账通过: 战役半径 ≤ 补给距离, 每日消耗表(兵 1kg 粮/马 10kg 草料)可算;
- [ ] 每政权有战争目的声明(政治延续); 牙尾比与技术水平匹配(技术越先进尾巴越重);
- [ ] 反现代主义自检通过(无凭空百万大军/无饿不死的远征/无无来源的士兵/无数百年静止兵器)。

**组织层**(第 1-2 步):
- [ ] 兵制光谱定位与财政货币形态互洽(实物税→民兵/征召, 现金→常备/雇佣);
- [ ] MPR 值与社会制度互证(高 MPR→平等主义, 低 MPR→等级+军人特权);
- [ ] 暴力垄断三问全答: 谁合法杀人/何种合法性/军队效忠谁;
- [ ] 政变风险模型(动机-机会-态度)与稳定器成对设计, 有明确触发器;
- [ ] 雇佣军供给方条件链成立(人口压力+尚武传统+承包组织);
- [ ] 开战/交战/战后三编战争法齐备, 宣战权归属明确且可被滥用;
- [ ] 荣誉经济闭环(获得/剥夺/仲裁/代价); 战死者彼岸与灵魂/宗教设定衔接;
- [ ] 俘虏-赎金表按身份分层; 晋升三货币(战功/出身/金钱)冲突有实例;
- [ ] 战争仪式有准入资格(凯旋/献捷)与分配争议(战利品/军旗)。

**后勤层**(第 3 步):
- [ ] 每兵种有资产负债表(成本结构/训练周期/补给类型/瓶颈资源), 瓶颈资源有地理分布与外交焦点;
- [ ] 兵种-政体-地形匹配律成立(读者可从军队结构反推政体);
- [ ] 编制数字与经济含义挂钩(每级自带粮草日数/指挥跨度 5-10/荣誉名号);
- [ ] 补给半径地图画出(水运 1 vs 陆运 10-20; 杂志系统 vs 以战养战已分派给政权);
- [ ] 围城计时器可用(守方存粮天数×日均消耗/水源/攻方补给线长度与季节);
- [ ] 军饷来源与政体互洽("谁付钱"=政权定义器), 欠饷-哗变链完整;
- [ ] 魔法后勤有上限(传送吞吐/储物袋容量/造粮次数)且瓶颈转移已设计; 传送法阵=高价值目标。

**战略层**(第 4-6 步):
- [ ] 军事革命时刻有明确时间与前后对照(编制/训练周期/成本/兵源), 三问已答(攻防成本/谁能负担/谁上升谁淘汰);
- [ ] 训练三参数(周期/载体/成本)与兵源结构、政体倾向互证;
- [ ] 服从动机矩阵(恐惧/荣誉/薪酬/意识形态)与战术纪律要求匹配;
- [ ] 暴力去私有化事件(法令/时间/后果)已设定; 佣兵契约与兵变流程(集体谈判)可执行;
- [ ] 私掠合法性光谱完整(委任状/战利品法庭/分红/废除运动);
- [ ] 每政权重心明确, 战役围绕攻防重心; 攻防悖论有地形/工事支撑;
- [ ] 世界棋局已画(心脏地带/边缘地带/海权国/陆权国); 咽喉点 ≥3 个且卡口属性完整(控制者/卡住什么/绕行成本/封锁后果);
- [ ] 结盟可由威胁感知四要素解释; 缓冲国生存策略与大国克制理性成立;
- [ ] 战争分期表(5-7 时代×五字段)齐备; 有限机制与总体化触发器成对;
- [ ] 弱者胜利按机制(时间/意志/成本/合法性/扩散义务)而非奇迹; 民众争夺曲线有事件驱动;
- [ ] 信息战线与军事线并行, 存在"惨败包装为胜利"式转折能力。

**超自然层**(第 7 步):
- [ ] 每法术完成军事职能映射(禁咒→核/结界→要塞/传送→机动/召唤→征兵/预言→情报)+稀缺四维预算(人才/时间/资源/集中度);
- [ ] 升级阶梯 5 级有命名与可辨识跨级信号; "为何不先用禁咒"答案落在机制上(二次打击/目标不匹配/反噬);
- [ ] 威慑三要件(能力/可信度/传递)与二次打击成立; 自我约束四机制(威慑/MAD/公约/反噬)齐备;
- [ ] 末日魔法=国家财产, 不扩散三重门槛(技术/原料/监督)与公约条款(清单/封存/督察/制裁)完整, 且有失灵时刻;
- [ ] 法师军团组织三形态各配代价(独立军团=政变风险/配属=压制进步/自由职业=私掠魔法);
- [ ] 反制螺旋串起技术史("旧禁咒为何失效"有答案); 克劳塞维茨式摩擦未消失(施法者会疲劳误判);
- [ ] 超自然按环节(生产/机动/侦察/防护/后勤/指挥/杀伤)重写战争规则, 非"魔法=火炮"贴皮; "谁垄断/谁付钱/谁受害"已追问;
- [ ] 军事档案 14 项(编制/军种/兵源/军官/军饷/装备/训练/后勤/情报/交通要塞/军法/财政/科技树/战史决策链)齐备;
- [ ] 一致性三式互证(人口×动员率/财政×占比/军费÷人均成本); 战役距离 vs 补给 vs 行军时间表自洽; 多场战争对人口财政的累积效应已核算; 编制数与损失数全书对账。
