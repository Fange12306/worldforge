# 增长停滞与转型

> 斯密型与熊彼特型增长、有机经济上限、高水平均衡陷阱、大分流、勤勉革命与路径依赖——文明何时繁荣、为何停滞、如何突破。

## 核心机制

### 1. 两种增长模式

| | 斯密型增长(分工扩张) | 熊彼特型增长(创新替代) |
|---|---|---|
| 动力 | 市场范围扩大→分工细化→专业化→生产率提升 | 企业家引入"新组合"(新产品/工艺/市场/原料/组织) |
| 技术 | 既定技术下扩展 | 生产函数被替换 |
| 天花板 | 分工受市场范围限制: 市场无法再扩张时增长停止 | 不受要素报酬递减约束, 可持续 |
| 典型案例 | 商业革命、航运黄金时代 | 工业突破 |

几乎一切前工业繁荣都是斯密型, 且均未自我升级为持续增长; 熊彼特型是可持续增长的必要引擎。

### 2. 有机经济上限

一切前工业经济都是"有机经济": 所有产出最终依赖土地光合作用捕获的太阳能, 存在**硬性上限 = 土地面积 × 土地生产率**。人口与产出增长→土地压力→报酬递减→负反馈。精致农业+贸易+燃料替代(泥炭/煤炭取暖)可勉强撑到"高级有机经济"顶端, 但仍在天花板下。突破的本质是转向"矿物经济": 用不可再生能源替代土地, 解除能源约束。

### 3. 人口压力: 陷阱还是引擎?

- **陷阱面**: 技术进步只暂时提高人均收入, 随即被人口吞噬, 人均回归生存线;
- **引擎面(集约化)**: 人口压力是主动变量——人口密度上升倒逼农业集约化(休耕期缩短: 森林休耕→灌木休耕→短期休耕→一年一熟→多熟复种)。压力既诱发集约化, 也常压低人均福利——混合图景更真实。

### 4. 高水平均衡陷阱(停滞是"理性的选择"而非愚蠢)

农业高产、人口稠密、技术先进的文明自我锁死:

1. 劳动力极其廉价 → 任何节约劳动的机械创新都无利可图(**要素价格反向淘汰技术**);
2. 农业剩余被人口增长吞噬 → 无资本积累转向工业;
3. 人均产出贴近生存线 → 创新回报微薄。

停滞的精髓是**"创新在边际上无利"**: 不是"想不到", 而是"做出来没人买"。停滞世界应充满微创新(单产提高、技艺改良)却无范式跃迁——"都改进了却没人变富"。

### 5. 大分流: 突破是地缘偶然

两个发展水平相当的文明(生活水平、市场发育相当), 分流常源于两个近乎偶然的因素:

1. **优质能源恰好在甲处**: 靠近工业中心且易开采的煤田;
2. **"幽灵土地"**: 海外殖民地提供棉花、糖、木材等土地密集型产品, 让一国绕开土地约束。

另一文明周边无同等外部生态资源, 遂在有机经济内"内卷化"(人均停滞、生活精致化)。**分流原因应是地理与运气, 而非种族/文化优劣。**

### 6. 勤勉革命(需求侧前奏)

突破发生前先有文化变迁: 家庭将劳动时间从休闲/自给重新配置到市场导向生产——工时延长、休闲贬值、购买更多市场商品(茶、糖、棉布、瓷器)。这是消费革命, 为供给突破准备购买力与工作伦理, 与供给侧突破互为条件。

### 7. 路径依赖与锁定

技术/制度因历史偶然事件被选定后, 靠学习效应、网络外部性、规模经济与协调效应自我强化, 即使存在更优替代也锁定不移。既得利益、意识形态与沉没成本使制度变迁同样路径依赖。**打破锁定需要"关键事件": 战争、灾变、革命或意外冲击。**

### 8. 增长转型的触发条件(五条)

1. **解除资源约束**: 能源替代(煤/晶石/灵能)、外部土地(新大陆/异界殖民);
2. **需求拉动**: 市场规模扩大+消费革命;
3. **知识与人力资本**: 识字率、出版、教育、知识传播;
4. **制度**: 产权、专利、金融、竞争保护;
5. **要素价格倒逼**: 劳动昂贵→节约劳动创新被市场采纳。

## 构建操作

1. 给经济设定可量化的"能量上限": 为世界定义有机经济的资源预算(可耕种土地、可捕获能源), 让读者看到人口/产出逼近天花板时物价、地租、工资的挤压; 停滞剧情必须配一个"突破物"(新能源或外部土地), 并让它的位置成为地缘政治核心;
2. 用要素相对价格决定"谁发明什么": 劳动力充足的社会不会发明省力机械——想技术突破, 先制造劳动力稀缺(瘟疫/战争/城市化/奴隶解放); 写"天才发明却无人购买"(价格倒挂)比"天才+官僚阻力"更有经济学深度;
3. 把停滞写成理性选择: 展示一个农业高产、人口密集、商业发达却停滞的文明——资本去向是囤地、放贷与奢侈品而非工厂, 行会与官僚理性维护现状, 微创新不断而范式不变;
4. 用勤勉革命刻画转型前奏: 突破前先写文化变迁——工作伦理强化(宗教运动式)、休闲贬值、异域商品消费风潮、家庭劳动时间重组, 这是一场可细致描写的"无声革命";
5. 用路径依赖制造结构性冲突: 世界用着明显更差的方案(旧能源/旧轨距/旧法术体系)因为所有人都在用, 既得利益集团(旧能源寡头、行会、教会)是锁定代理人; 打破锁定需"关键事件", 这天然是主角切入点;
6. 用大分流设计世界内部不对称: 给两个发展水平相当的文明, 让"能源位置+海外领地"的偶然决定谁先突破, 被分流一方写"内卷化"悲剧(人均停滞、生活精致化);
7. 用人口转型设计突破后的新矛盾: 持续增长触发教育投资上升与生育率下降——家庭小型化、城市膨胀、教育阶层崛起、旧家族衰落; 也可写"转型失败"版: 技术进步被人口增长完全吞噬、回到均衡, 作为悲剧结局;
8. 用五条触发条件给任一文明打分: 能源上限是否解除? 需求是否扩大? 知识是否积累? 制度是否保护创新? 要素价格是否倒逼节劳? 全不满足→合理停滞; 满足若干→半转型(斯密型繁荣无熊彼特型突破); 全部满足→自我持续增长。

## 检查点/清单

- [ ] 世界的能量上限与"突破物"已定义, 突破物位置有地缘意义
- [ ] 劳动力丰缺与发明方向一致(劳动廉价则无节劳创新)
- [ ] 停滞文明写得"理性": 资本流向、微创新、无人变富的自洽解释
- [ ] 转型前奏有勤勉革命式文化变迁描写
- [ ] 存在至少一个被锁定的低效方案及其利益集团
- [ ] 双文明大分流的分叉点(能源+领地)明确且非文化优劣
- [ ] 突破后的新矛盾(人口转型/家族兴衰)已设计
- [ ] 每个文明按五触发条件有打分记录, 与其实际状态一致
