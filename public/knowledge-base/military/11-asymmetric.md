# 非常规与不对称战争

> 弱者如何取胜、强者为何输掉小战争——游击、叛乱、混合战争、地形战与信息认知战。

## 核心理论

**1. 游击战三阶段与人民战争**
- **三阶段论**: 战略防御→战略相持→战略反攻; 相持阶段是枢纽, 敌我力量消长在此完成; 以时间换空间, 同时驳斥"速胜论"与"亡国论"。
- **十六字诀**: 敌进我退, 敌驻我扰, 敌疲我打, 敌退我追——主动、灵活、不与强敌硬拼。
- **人民战争**: "兵民是胜利之本"——游击队如鱼入水, 情报、兵源、补给皆来自民众; 敌人无法区分战斗员与平民, 因而无法根除。
- **根据地逻辑**: 落脚点提供兵源、税收、情报、后方医院与政治合法性, 使流动游击获得持久性; 敌后根据地与正面战场配合。

**2. 叛乱与反叛乱(COIN)**
- 叛乱是"次革命战争": 敌人藏于平民, 战场即人民; 情报网格化(居民登记、身份控制)是第一线。
- **人口是重心**: 人群分 20% 积极少数 + 80% 中立多数, 目标不是消灭叛乱者而是争取中立者。
- 四步法: 消灭武装分子→控制区布防并切断其与民众联系→赢得民众支持→建立正规军警。
- 兵力比约 10:1 起; 政治占 80%、军事占 20%; "清-稳-建"三阶段。
- **反叛乱悖论**: 重火力镇压→平民伤亡→民众倒向叛乱者; 军事胜利与政治失败可并存(军事打赢、政治破产)。

**3. 第四代战争与混合战争**
- 四代谱系: 第一代线式战术、第二代火力、第三代机动; **第四代 = 国家失去对战争的垄断**——非国家行为体、网络化结构、文化/意识形态战争、无明确前线、直接攻击民众意志与政治合法性; 敌人不是军队而是观念。
- **混合战争**: 常规军+游击队+恐怖袭击+犯罪网络+信息战+经济手段同时或顺序使用, 模糊和平/战争、战斗员/平民、内政/外交界限。
- 非军事手段(政治、经济、信息、心理)与军事手段比例约 4:1; 以"反射控制"、虚假信息、代理部队开路。

**4. 地形战: 复杂地形是"技术抵消器"**
- **城市战**: 地下-地面-高层三维战场, 近战密集, 技术优势被压缩; 平民羁绊与逐屋争夺使代价极高。
- **山地战**: 制高点、隘口、峡谷决定战术; 补给线脆弱易被伏击; 高海拔削弱人员装备效能。
- **丛林战**: 能见度低、湿热病疫、交通困难; 小规模、近距离、点状遭遇, 重装备难以展开。
- 共同机制: 弱势方借地形稀释强者火力与机动, 把战争拉回近距离、低技术、拼意志的形态。

**5. 信息战/认知战/心理战**
- 宣传 = 对符号的有意操纵以影响态度; 心理战三重目标: 削弱敌军士气、分化敌方联盟、争取中立者与己方信念。
- **认知战**: 攻击对象从机器转向人脑认知——操纵感知、记忆、身份认同, 使目标人群无意识改变行为; 与网络战、虚假信息、深度伪造结合, "人脑是最终战场"。
- **反射控制**: 向对手投送精心构造的信息, 诱使其按己方意愿决策; 信息空间被当作独立作战域, 先于或并行于火力。
- 信息战可翻转军事结局的叙事: 军事惨败被包装为战略转折, 动摇对方国内舆论。

**6. 弱者制胜机制**
- 恐怖暴力是"沟通性暴力": 直接受害者是工具, 真正观众是舆论、政府与潜在支持者; 经典策略是**挑衅—过度反应**循环——引诱政权镇压平民以自毁合法性。
- 弱者以"间接战略"获胜的概率约为正面硬抗的 4 倍, 五条机制:

| 机制 | 内容 |
|---|---|
| 时间不对称 | 叛乱者以生存为目标、时间充裕; 政府受选举周期、财政与舆论约束耗不起 |
| 意志不对称 | "身体敏感": 平民伤亡引发国内反战, 强者输掉的是国内政治而非战场 |
| 成本转嫁 | 把冲突成本导向平民(难民潮、经济破坏)以制造政治压力 |
| 合法性争夺 | 在国际舆论场把"镇压"改写为"解放", 争取外援并推动制裁敌方 |
| 扩散防御义务 | 攻击对手不得不保护的大片区域, 使其资源摊薄 |

## 构建操作

1. 先给双方定义不同的"胜利货币": 强者按歼灭与领土结算, 弱者按时间、生存与合法性结算; 结局不必是弱者"打赢", 而是强者先失去继续的意志——帝国因国内反战与财政崩溃撤军, 或弱者换得自治与谈判席位;
2. 再用三阶段论搭起义弧线: 潜伏恐怖阶段(城市地下)→根据地相持阶段(政权"治安恶化")→战略反攻阶段(正面决战或政治谈判); 每阶段切换地形(城市→山地/丛林→首都)与战术(暗杀→伏击袭扰→正规作战), 让读者感知战争性质的演变;
3. 让地形成为角色: 为抵抗组织选一种主导地形并推导全部战术后果——丛林(点状遭遇、疾病、走私补给线)、山地(隘口伏击、部族网络)、城市(地下道、巷战、人质); 同时给强者设计笨重对策(战略轰炸、清扫、强制迁移);
4. 把民众支持度做成显式"争夺曲线": 每次过度镇压(屠杀、强制搬迁、酷刑)使曲线向叛乱者倾斜; 展示镇压的技术效率与政治反噬并存, 避免"正义必胜"式单线叙事;
5. 平行于军事建立信息战线: 为冲突设计完整宣传体系——双方口号、战地记者叙事、假消息("行刑室"式舆论炸弹)、纪念仪式; 可设计一个"军事惨败被包装成战略胜利"的转折, 动摇帝国国内舆论并触发其撤军;
6. 造一个混合战争式对手: 同时使用正规军、雇佣兵/代理民兵、走私与犯罪网络、网络破坏、经济封锁与宗教-意识形态动员, 使主角无法判断"这是国家行为还是私人行为", 制造情报与道德灰色地带;
7. 用"挑衅—过度反应"循环作剧情引擎: 抵抗组织袭击教堂/平民区, 引诱帝国处决人质或轰炸平民, 把中立者推向抵抗阵营; 让主角直面"手段正当性"的伦理拷问;
8. 用双时钟制造张力: 叛乱者拥有"无限耐心"(世仇、代际使命), 帝国面临"倒计时"(选举、财政、舆论); 同时在叛乱者内部埋设路线斗争(速胜派 vs 持久派);
9. 展示反叛乱者的道德滑坡: 身份登记制度、酷刑、集中村、斩首行动, 走"技术有效却政治失败"的路线, 为强者一侧提供悲剧性纵深与移情;
10. 为弱势方设计外部支援网络: 跨境庇护所、海外侨汇、国际同情团体与军火走私链; 引入第三国"棋手后的棋手", 使本地冲突升级为代理人战争。

## 检查点/清单

- [ ] 双方"胜利货币"不同(歼灭/领土 vs 时间/生存/合法性);
- [ ] 起义弧线按三阶段推进, 每阶段切换地形与战术;
- [ ] 抵抗组织有明确主导地形及其战术后果, 强者有笨重对策;
- [ ] 民众支持度是可变的"争夺曲线", 过度镇压有反噬;
- [ ] 信息战线完整(口号/叙事/假消息/纪念), 有"叙事翻转"事件;
- [ ] 反派是混合战式对手, 行为体与手段界限模糊;
- [ ] 有"挑衅—过度反应"循环与伦理拷问;
- [ ] 双时钟(无限耐心 vs 倒计时)存在, 叛乱内部有路线斗争;
- [ ] 反叛乱者道德滑坡路径清晰;
- [ ] 弱势方有外部支援网络与代理人升级可能。
