# 气候系统

> 气候是"行星参数 + 海陆分布 + 地形"的投影。这是流程的第 7 步。

## 三圈环流与气压带风带

- **三圈环流**: 哈德莱(0–30°, 热力直接)、费雷尔(30–60°, 斜压涡旋驱动)、极地(60–90°)。
- **气压带**: 赤道低压(0°)、副热带高压(~30°, 马纬度)、副极地低压(~60°)、极地高压(90°)。
- **风带**: 信风(0–30°, 北东北/南东南)、盛行西风(30–60°)、极地东风(60–90°)。
- **ITCZ**: 赤道辐合带随"热赤道"季节摆动(海洋 ±10°, 陆上可深入 20–25°N)——这是季风的同一机制。
- **降水带**: ITCZ 全年多雨(1500–3000+mm); 副热带高压干旱(<250mm); 副极地锋面多雨; 极地少但蒸发更弱。

## 柯本气候分类

主类判据全部基于月均温与降水, 不依赖植被, 可直接迁移到虚构行星:

- **A 热带**: 最冷月 ≥18°C(Af 雨林 / Am 季风 / Aw 干湿季)
- **B 干旱**: 年降水 < 阈值(BW 沙漠、BS 草原; 年均温 18°C 分热/冷)
- **C 温带**: 最冷月 −3~18°C(Csa/Csb 地中海夏旱, Cfa 湿润亚热带, Cfb 海洋性)
- **D 大陆性**: 最冷月 ≤−3°C 且最热月 ≥10°C(Dfa/Dwb/Dwc)
- **E 寒带**: 最热月 <10°C(ET 苔原、EF 冰盖)

## 洋流

- **表层环流**: 风应力 + 科里奥利力 → 埃克曼输运(与风向成 90°)→ 副热带涡旋(北半球顺时针、南半球逆时针)。
- **西边界流**(湾流、黑潮): 窄、急、暖; **东边界流**(加那利、本格拉、秘鲁、加利福尼亚): 宽、缓、冷, 常伴上升流(富营养渔场)。
- **温盐环流/全球输送带**: 高纬冷却下沉, 千年尺度全球周转; 使西欧比同纬暖 5–10°C。

## 季风

- **驱动**: ①海陆热力差异(夏热低压/冬冷高压)②ITCZ 季节迁移 ③科里奥利力偏转越赤道气流 ④大地形抬升增强(青藏+喜马拉雅南坡, 年雨量可破万 mm)。
- 全球季风区覆盖 ~60% 人口; 大洲东南缘海岸 → 夏湿冬干、雨热同季。

## 地带性参数

- 垂直直减率: 标准 0.6°C/100m, 干绝热 ~1°C/100m;
- 雪线: 赤道 ~4500–5000 m、中纬 ~2500–3500 m、极地近海平面;
- 内陆年温差巨大(可达 >60°C), 沿海温差小; 大陆面积越大, 季风与内陆荒漠越强。

## 五步出图法

1. 画 0/30/60/90° 气压带及季节摆幅(按轴倾角与自转调整);
2. 画信风/西风/极地东风箭头;
3. 画各海盆副热带涡旋(西边界暖流、东边界寒流);
4. 叠加地形抬升与雨影(迎风坡多雨、背风坡干旱);
5. 用柯本字母给每块大陆命名。

## 构建指导

- **用 ITCZ 摆动造季风**: 大洲东南缘 → 夏湿冬干(稻作文明); 大陆西缘 30–40° → 地中海冬雨; 内陆大盆地 → 极端大陆性温差。
- **洋流是"气候的血管"**: 暖流使高纬西岸宜居; 寒流沿岸造海雾与荒漠; 上升流区是渔场与聚落热点; 关闭某条海道可设计"冰期型/温室型"世界甚至环流崩溃式突变剧情。
- **垂直带是低成本的高密度地理**: 一座山等于一条压缩的纬度带; 用雪线高度与直减率反推山高、居民点海拔与山口商道位置。
- **慢自转/潮汐锁定调整**: 慢自转 → 副热带高压带外移(35–45°); 潮汐锁定 → 恒星下点低压、晨昏圈高压环。

## 一致性自检

- 西岸 vs 东岸不对称(寒流西岸/暖流东岸);
- 内陆冬冷夏热; 30° 附近有荒漠带;
- 迎风坡多雨、背风坡干燥;
- 大洲东南缘季风性; 暖流沿岸比同纬偏暖湿。
