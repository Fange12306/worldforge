# 技术停滞与路径依赖

> 目的: 让"先进文明为什么卡住不进步"有机制可写——停滞不是一句"衰落"带过, 而是相对价格、制度矩阵、知识载体三者的咬合结果。
> 前置: 经济篇的要素价格与财政结构; 与历史篇(周期)、法则篇(魔法成本)、文明篇(利益集团)双向咬合。

## 核心机制

### 停滞的四种主机制(先选一种作主因, 再叠加辅助)

| 机制 | 一句话定义 | 判定条件 | 典型表现 |
|---|---|---|---|
| 高水平均衡陷阱 | 人均产出高却技术停滞 | 劳动力极便宜、资源极贵 | 理性生产者拒绝省力机械 |
| 路径依赖锁定 | 次优技术因递增收益胜出并被锁死 | 学习效应+网络外部性+规模经济 | 旧标准无法被撼动 |
| 制度锁死与利益集团 | 受益集团有组织地维持现状 | 制度互相补充、改一项成本极高 | 行会与官僚联合抵制变革 |
| 知识断裂 | 知识存量收缩、载体消失 | 行政系统/学校/度量衡/师徒链瓦解 | 遗迹可见, 能力已失 |

### 高水平均衡陷阱: 停滞可以是"最理性的选择"
- 人口稠密、精耕细作 → 人均土地下降、粮食需求上升 → 劳动力极便宜而资源(土地/燃料/水力)极贵 → 节约劳动力的机械投入产出比极差 → 增加劳动投入比采用机器更划算 → 人口压力与技术停滞互成负反馈, 把社会锁在"高水平的穷均衡"里。
- 关键: 停滞不是无知或愚蠢, 而是在给定要素价格下理性的选择; 写作时要让反派算得清这笔账, 而不是脸谱化地保守。

### 路径依赖与锁定: 历史小事件定生死
- 递增收益四来源: 学习效应(用得越多越熟练)、网络外部性(用的人越多越有价值)、规模经济、协调成本(配套标准与互补品)。
- 递增收益 → 多重均衡并存 → 早期某个"历史小事件"(一场竞赛、一个标准、一份畅销手册)决定最终胜者 → 次优技术一旦先发即被锁入, 事后证据再有力也难翻盘。
- 注意: "锁定即市场失败"并非必然——旧技术可能在当时权衡下就是最优; 写作时保留"是否真的次优"的争论维度更有深度。

### 制度锁死与利益集团: 谁在捍卫现状
- 制度变迁同样有报酬递增: 现有制度塑造受益集团, 他们掌握政治资源、有激励维持现状。
- 制度互补: 产权、税收、行会、考试取士彼此咬合, 单独改一项成本极高。
- 分配性联盟: 长期稳定的社会会积累大量寻租集团(行会、垄断商帮、世袭官僚), 它们不创造财富而分配财富, 且有组织地抵制任何可能淘汰其租金的技术变革——社会越稳定越久, 僵化越深。

### 停滞之谜的诸解释(对"先进文明不进步"的归因工具箱)

| 归因方向 | 核心论点 | 虚构落地 |
|---|---|---|
| 供给不足 | 缺系统化的"有用知识"生产(实验-数学结合) | 无学术共同体、无期刊专利 |
| 需求不足 | 要素价格使节约劳动技术无市场; 市场规模被抑制 | 劳动力廉价、商路被堵死 |
| 制度 | 精英吸纳进官僚体系、商人产权无保障、行会官营垄断 | 考试取士吸纳天才、重农抑商 |
| 文化 | 重伦理轻技术、宇宙观不鼓励框架突破 | 技术被视为匠人之事、僭越禁忌 |
| 地理巧合 | 缺廉价能源与扩张通道 | 无煤矿、无贸易纵深 |

多数解释并不互斥, 共同的指向是: 发明不稀缺, 采用与扩散被卡死。

### 知识断裂: 断的不是配方, 是载体
- 技术 = 命题性知识(为什么, 原理) + 处方性知识(怎么做, 工艺) 两层; 只有配方没有原理, 技术无法自我改进。
- 崩溃断掉的是知识载体: 帝国行政系统、城市学校、货币经济、标准化度量衡、师徒链条; 隐性知识(配方细节、天文历算)随机构与师徒链失传。
- 写作区分"物品清单"与"能力清单": 后人看得见引水渠与水泥, 却读不懂、修不了、造不出——遗迹不是能力。

### 停滞 ≠ 不发明, 而是不采用
- 几乎所有停滞文明都在发明(印刷、火药、指南针、蒸汽玩具、收割机原型), 卡住的是采用与扩散。
- 采用需承担转换成本(改工艺、换设备、重训劳工)、冒风险、对抗既得利益; 若制度抽走采用收益(税、行会规费)或惩罚僭越(文化风险厌恶), 理性人就不采用。
- 采用成本 > 采用收益 → 原型机永远停在宫廷与修道院里。

### 突破停滞的五类触发器
1. 相对价格剧变: 劳动力变贵或资源变便宜, 新技术突然划算;
2. 制度裂缝: 中央权威瓦解、飞地自治、行会失去强制力, 采用成本骤降;
3. 知识增长与传播: 印刷、大学、专利、跨域交流使有用知识存量累积成正反馈;
4. 外部冲击: 战争、瘟疫、外来竞争打破分配性联盟;
5. 关键小事件 + 正反馈: 某个不受管制的工匠率先采用, 网络效应接管, 旧标准被抛在身后。

## 构建操作

1. 先定要素价格结构: 为停滞文明写下"劳动力 vs 资源"的相对价格(劳动力极便宜/关键资源极贵), 然后推演"最理性的生产者会拒绝什么"——这是停滞的第一根支柱;
2. 再搭制度矩阵: 列出至少三个互相咬合、共同捍卫现状的机构(行会垄断工艺 + 官僚垄断许可 + 产权模糊使投资无保障), 并写明"单独改一项要付出什么代价";
3. 给知识载体瘦身: 设定无印刷、无标准化度量衡、无公共学校, 技术只靠秘传师徒制存续——为"知识断裂"预埋断层线;
4. 让原型机沉睡: 设计 2~3 件惊人的发明(永动机、蒸汽战车、光学仪器), 每件都写明"被谁封存、以什么理由"——发明—不采用本身成为可探索的场景;
5. 写一份"能力清单"而非"物品清单": 为崩溃后的世界列出哪些知识失传、哪些靠残页勉强保留、哪些被抄本误抄, 考古解密成为主线任务;
6. 给突破装触发器: 瘟疫或战争使劳动力变贵→省力机械突然划算; 中央权威瓦解→行会失去强制力→飞地工匠自由采用; 敌国新武器→保守派被迫放行——让读者看出"为什么偏偏是现在";
7. 写突破时刻用"小事件+正反馈": 被流放的工匠在无人管辖的边境复制原型机, 加上偶然的赢家信号(一场竞赛、一份畅销手册), 网络效应接管。

## 检查点/清单

- [ ] 停滞有主机制(四选一)且有辅助机制叠加, 不是一句"衰落";
- [ ] 相对价格写清楚, "理性拒绝新机器"的账能算出来;
- [ ] 至少三个互锁的制度机构在捍卫现状, 且改一项代价明确;
- [ ] 知识载体薄弱有设定(无印刷/无标准/无学校);
- [ ] 有沉睡的原型机, 且写明封存者与理由;
- [ ] 区分了"物品清单"与"能力清单"(遗迹≠能力);
- [ ] 突破有可检验的触发器, 不是突然开悟;
- [ ] 突破时刻包含小事件与正反馈机制;
- [ ] 保留"旧技术是否真的次优"的争论维度;
- [ ] 停滞与历史周期表、魔法成本、财政结构无矛盾。
