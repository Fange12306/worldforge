# 种族总流程与接口

> 目的: 从 0 到 1 构建一套自洽的种族体系——先定生态位,再填形态,沿"行星参数→生理→心理→文化→技术"推导链生成种族档案,最后与地理、法则、文明模块接口咬合。
> 前置: 消费行星参数(重力/大气/光照/季节)与地理生物群系的输出;生产文明模块的输入(社会结构/技术/观念)。若世界存在魔法/灵魂法则,生理必须与之有明确定义的接口。

## 核心立场: 生态位先于物种

- **第一问不是"长什么样",而是"它吃什么、被谁吃、在哪儿活、何时活动"**——先给生态位(n 维超体积: 食物/温度/空间/时间),再填形态。两个物种无法长期占据同一生态位,弱者被排除或被迫分化,这是检验"种族是否冗余"的硬标准。
- **环境压力塑造形态,形态是约束的"解"**: 飞行、穴居、水生、巨型化形态在独立谱系中反复出现(趋同演化),说明形态由环境解方程得出,而非作者任意发明。用行星参数(重力/大气/恒星辐射/季节)解方程,物种形态就是答案。
- **生理决定文化上限**: 与生计最相关的文化特征(亲属、产权、分配、宗教中的生态成分)受环境与技术约束最强。种族文化不是自由变量——主干必须能由"生理+环境"推导出来。
- **代价守恒**: 智力、寿命、体型、繁殖率、感官灵敏度之间存在权衡。任何优势都要付账(高大脑能量成本以缩小肠道支付,高智力↔长幼态期或低繁殖率,长寿↔低生殖投入)。智慧种族档案必须写明"它为智能付出了什么"。
- **谱系学思维**: 每个物种应位于一棵演化树上——祖先是谁、与近缘种何时分化、何种隔离驱动分化。没有谱系的物种是"创生式"设定,多样性无法自我解释。
- **法则接口**: 若存在魔法/灵魂,必须写明能量从何来、灵魂与肉体如何耦合、施法成本是什么。能力必须有成本与限制,否则种族设定坍缩为无差别超能力。
- **人类基线问题**: 智慧种族天然以人类为模板("人类换皮"),差异停留在皮肤层。打破基线须至少改动感知通道、繁殖方式、生命周期、认知模块之一,而非外观装饰。
- **智能是多路径的**: 有认知却短命独居无文化积累的类型、工具使用与社会学习型、社会化智能型……"智能类型"应先于"智能等级"定义,并与寿命、社会结构强耦合。

## 模块依赖链与接口

| 层 | 关键参数(输出) | 接口对象 |
|---|---|---|
| 行星参数 | 重力/大气成分/恒星辐射/季节与灾变频率 | 本模块输入 |
| 地理生物群系 | 生态位矩阵、资源分布、地理屏障 | 本模块输入 |
| 物种生理 | 感官/代谢/生殖/生命周期/代价 | 文化推导、文明模块 |
| 文明文化 | 语言/亲属/禁忌/技术,各标注约束来源 | 文明/历史模块 |

依赖方向单向: 行星→生物群系→物种→文明。反向回填须逐级一致性检查,并用版本号记录推导链变更,避免"先画龙后画风"式返工。

## 种族档案清单("五卡"结构)

| 卡 | 内容要点 |
|---|---|
| 生理卡 | 感官/代谢/生殖/生命周期/代价(至少一项优势对应一项劣势) |
| 生态卡 | 生态位、食谱、天敌、地理分布、与智慧种族关系(驯化/共生/竞争) |
| 推导链 | 行星参数→生理的一行因果链,标注硬/软约束 |
| 谱系卡 | 演化树位置、近缘种、分化时间与隔离机制 |
| 文化卡 | 语言/亲属/禁忌/技术,每个特征标注约束来源(地理/资源/生理/历史偶发) |

## 构建操作

1. 先固化依赖顺序图(行星参数→生物群系→法则→物种→文明),任何模块改动沿链回填并登记版本号;
2. 先做生态位矩阵: 列出目标世界全部生态位(能量来源/捕食者/被捕食者/繁殖策略/地理分布/昼夜活动),再逐个"招标"填物种——无生态位的"装饰性怪兽"删除或补全;
3. 按"单源树"产生多样性: 设计一个共同祖先+适应辐射+历史偶然(迁徙/灾难/工程改造)生成分支,比逐物种捏造更省力、更自洽,且天然支持后续演化叙事;
4. 为每个智慧种族强制写"代价卡",并用平方立方律检验体型(尺寸翻倍则质量×8而承重截面仅×4: 散热、承重、呼吸随之受限);
5. 执行人类换皮自检: 移除外观差异后若该种族在社会行为、认知、价值上仍与人类无区别即失败;必须至少改动感知通道、繁殖方式、生命周期或认知模块之一,并让改动在文化卡上产生可见涟漪;
6. 反"一帽"检查: 每个文化至少两个内部张力轴(地域方言/阶级/宗教分裂/职业亚文化),且至少一个张力轴可由生态卡推导;
7. 竞争排斥审查: 任何两个智慧种族生态位重叠时必须写出分化维度(空间/时间/食性/体型/社会分工),否则合并或删减其一;
8. 核对法则接口: 若存在魔法/灵魂,写明能量来源、耦合方式、施法成本,并检查是否被故事实际使用。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 先画外形再找生态位 | 先写"吃什么/被谁吃/在哪儿活/何时活动"再填形态 |
| 全族一帽(整个种族只有一个性格特征) | 每个文化至少两个内部张力轴,其一可被生态推导 |
| 人类换皮(换额头装饰即算外星人) | 至少改动感官/繁殖/生命周期/认知之一并向下游传导 |
| 种族过多却无法区分 | 竞争排斥审查: 生态位重叠必须写分化维度 |
| 智力/寿命/生育全拉满 | 强制代价卡: 每项优势对应一项劣势 |
| 物种无谱系、无演化关系 | 放进演化树,标共同祖先、分化时间、隔离机制 |
| 魔法种族无成本无限制 | 明确能量来源、灵魂-肉体耦合、施法代价 |

## 检查点/清单

- [ ] 生态位矩阵齐全,每个生物有能量来源/天敌/繁殖策略/分布?
- [ ] 依赖顺序图固化,模块改动沿链回填并有版本记录?
- [ ] 每个智慧种族有完整"五卡"(生理/生态/推导链/谱系/文化)?
- [ ] 代价卡存在且每项优势对应劣势?
- [ ] 体型设定通过平方立方律检验?
- [ ] 人类换皮自检通过(至少一项根本差异且文化可见涟漪)?
- [ ] 每个文化至少两个内部张力轴,其一可由生态推导?
- [ ] 竞争排斥审查通过,无冗余种族?
- [ ] 与法则模块的能量/灵魂接口明确定义?
