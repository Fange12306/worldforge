# 魔法语言与言语行为

> 目的: 让"念出的词能改变世界"拥有自洽机制——魔法语言不是咒语堆砌, 而是把言语行为理论推至极端的语言系统。
> 前置: 语言档案(音系/词汇)与法则篇(魔法规则); 本文产出"魔法语言的规则书"。

## 核心理论/机制要点

**言语行为: 言即行**
- 三个层面: 言内行为(说出有意义的句子)、言外行为(言说本身即完成行为: 承诺、命名、宣判、起誓)、言后行为(对听者造成的效果)。
- 施为句 vs 记述句: 记述句描述世界, 施为句改变世界("我命名这艘船为……""我宣布你们结为夫妻")。
- 恰当条件: 施为要生效须满足——说话者有相应权威、程序正当、内心真诚、情境匹配; 缺一条即无效或反噬。
- 魔法语言的本质: 把施为句的"言出法随"推至极端, 言语与世界之间的缝隙被取消。

**言语行为五分类 → 法术系映射**

| 分类 | 本质 | 魔法对应 |
|---|---|---|
| 宣告类 | 直接改变制度性实在(命名/宣判/封禁) | 即发咒: 言出法随 |
| 承诺类 | 立约、起誓 | 契约/誓约魔法, 违约有实体惩罚 |
| 指令类 | 命令、驱役 | 御使/驱役咒 |
| 表达类 | 祝福、诅咒、道谢 | 祝祷系法术 |
| 断言类 | 陈述事实 | 预言/真实视域(语言诚实性保证可信) |

- 为每类设计独立代价与反制, 避免"大锅烩"。

**真名系统**
- 万物皆有真名, 由创世语给定; 真名是事物的本质, 知其真名者得其支配权。
- 名字分层: 真名/日用名/绰号/头衔; 用日用名藏起真名。
- 命名仪式(成年赐名、互名结义)是天然剧情节点; 念出自我真名可降服心魔。

**创世语**
- 世界由语言创生: 圣言"要有"即存在; 语言与理性法则合一; 亦有"语言女神""以心所思、以舌所言"的造物模式。
- 创世语失传后: 凡人语言是堕落/污染版本; 原初语言残片(地名、神名、祷文)保有残余力——寻找"太初之言"即史诗主线。

**不能说谎的语言**
- 若语言与真实一一对应, 假命题不是合法表达式——说这种语言者生理上不能说谎。
- 漏洞: 省略、误导、玩文字游戏、字面主义履约("我说过会来, 没说何时")——不能说谎≠不能骗。
- 可设能量守恒: 用魔法语施法/妄言消耗代价, 规避则代价转移。

**禁忌语与避讳**
- 名字即灵魂的一部分: 敌人得知名字即可加害 → 隐名、避称死者之名、君王之名禁口、以代称("那位")指代。
- 抹去名字即抹去存在(碑铭毁名=杀死其人)。
- 反向用法: 把名字变成定位信标——说出禁忌之名即暴露位置; 沉默成为有力量的行为(匿名=自由, 被指名=被绑定)。

**魔法文字**
- 文字是把言语行为"固化"进物质: 契约、碑铭、护符让施为脱离说话者的在场而持久生效。
- 符文本义"秘密/耳语"; 符文既是字母又是魔力单元, 可组合、可反向刻写(解除)、一笔错即反噬。
- 字母可被视为创世构件(刻字赋命, 抹字即毁); 文字本身可被当圣物崇拜。

## 构建操作

1. 先建双层语言系统: 日常语与魔法语必须分立, 并明确差异机制——魔法语违反"符号任意性"(词与物因果绑定, 故不能撒谎、不能乱说), 日常语因规避真名而存在; 规定学魔法语的门槛(须知真名、须先立誓、发声/书写有生理代价), 让"会两种语言"成为身份标志;
2. 再把五分类映射为法术系(见上表), 为每类定代价与反制, 让"宣告=即发咒、承诺=契约、指令=驱役、表达=祝福诅咒、断言=预言"各成体系;
3. 设计"真名寻命"剧情引擎: 给每个关键角色做名字分层(真名/日用名/绰号/头衔), 真名=弱点也是钥匙; 主线用三幕——藏名(隐瞒与误认)→寻名(考古、审讯、交易、语言学的逆向工程)→用名(制敌/救赎/自我认同); "得知敌人真名"与"敌人得知我真名"是对称的高潮节点;
4. 给"诚实语言"留漏洞: 开发省略、隐喻、反讽、转述、断章取义、字面主义履约——天然产出契约博弈、文字陷阱、法庭式斗法剧情;
5. 把避讳做成世界张力: 设定"不可说之名"(神名、君王名、亡灵名), 说出即触发后果(定位/召来/诅咒), 让角色为此改名、代称、禁语; 可组合使用"隐名避讳+抹名即杀+名字定位"三种机制;
6. 定符文系统规则: 刻写成本(材料稀缺、一笔不可错、刻错反噬、需注入能量)、读写规则(朗读铭文=触发施为、反向刻写=解除、涂改=篡改契约)——自然产生考古解密、伪造文书、破坏封印等故事线;
7. 以创世语为世界基石并保留"不可说"悖论: 最强力量属于"不可言说者"(可名者皆有限), 为"不可名状之物"与"圣名失传"提供自洽解释, 让"求知"与"敬畏"成为世界观张力。

## 检查点/清单

- [ ] 双层分立: 日常语与魔法语机制差异明确(任意性 vs 因果绑定)?
- [ ] 五分类: 每类言语行为都有对应法术、代价与反制?
- [ ] 恰当条件: 施为失败/反噬的条件已写(权威缺失/程序不符/心不诚)?
- [ ] 真名分层: 关键角色的真名/日用名/绰号/头衔已备案, 真名=弱点?
- [ ] 命名仪式: 赐名/互名/改名有社会仪式或剧情节点?
- [ ] 诚实漏洞: "不能说谎"语言有可玩的规避手段(省略/字面主义)?
- [ ] 避讳系统: 不可说之名有后果机制, 沉默被赋予战术价值?
- [ ] 符文规则: 刻写/朗读/反向/涂改规则自洽, 一笔错有反噬?
- [ ] 创世语: 原初语言失传、残片有力, "不可名状"有自洽解释?
- [ ] 代价守恒: 魔法语言的使用有能量/生理/承诺代价, 无免费午餐?
