# 宇宙构建方法论与一致性总检

> 目的: 把宇宙构建变成工程——立宇宙档案六件套,建法则-事实依赖链,装叙事引擎,跑一致性总检,按 need-to-know 披露给读者。
> 前置: 本页是 cosmos 系列的收口方法: 位面(08)、死后世界(09)、多元宇宙(10)、世界间旅行(11)、宇宙之外(12)的产物都要在此登记、挂链、受检。

## 核心理论: 一致性是宇宙存在的前提,不是锦上添花

- **次级世界与内在一致性**: 虚构宇宙是"次级创造"的产物,唯一硬性要求是**内在一致性**——只要世界内部自洽,读者即产生次级信念;一旦自洽性破裂,信念立即崩溃。这是宇宙构建的总纲。
- **分层构建**: 法则层(魔法/技术原理、物理法则、天体力学、地理)→ 事实层(文明、派系、冲突)→ 可延后细节。工程化表达: **法则层**定义宇宙常数(重力/光速/魔法原理/恒星类型),**事实层**由法则推导(行星/生态/文明/历史),每个事实登记**依赖链**(引用哪条法则),面向故事暴露**接口**(读者能感知与利用的规则表面)。新设定要么挂接既有法则,要么先修法则再批量迁移依赖——杜绝"孤儿设定"。
- **硬构建 vs 原位迭代**: 两条路线——先在纸面推演完整逻辑(硬构建,适合严谨设定),或边写边补(原位迭代,灵活但易积累矛盾)。实践共识是**混合**: 法则层硬推演,事实层原位生长,并建立变更管理。
- **魔法系统定律**(适用于一切超自然实体): ①用超自然能力解决冲突的程度,与读者理解该能力的程度成正比; ②局限性比能力更有趣; ③先拓展既有系统,再引入新系统。任何位面、神明、种族能力都必须是**可理解的规则系统**,而非随机发生器。
- **Guy-at-the-Gym 测试**: 角色在普通情境展现的能力(如一拳破墙)若未被该世界的社会、军事、经济体系合理利用,即世界逻辑不自洽。两种合法方案二选一且全宇宙贯彻: 世界遵循与地球相同的物理法则,或**根本不同**的法则。
- **多元宇宙隔离与旅行代价**: 多元宇宙有效性的前提是**隔离性**——各宇宙有独立法则与因果边界;跨宇宙旅行必须有明确代价(能量/身体损伤/时间错位/身份耗散)。若无代价与隔离,多元宇宙退化为单一宇宙的布景轮换。
- **宇宙尺度的叙事时间**: 宇宙档案必须有**时间箭头**(熵增、恒星演化、位面相位、文明生命周期),否则是静态布景。把宇宙史压缩为"一年日历"是时间轴可视化方法;宇宙尺度叙事可承载哲学主题("以宇宙本身为主角")。
- **一致性工具化**: 用交叉引用型工具(数据库/知识库/自建参数表)替代记忆;制定 retcon 政策(明确 canon/soft canon/废弃条目),重大改动以作者注公开声明而非静默篡改;按 **need-to-know 披露**(冰山理论: 只把10%给读者,90%是隐形地基)。

## 宇宙档案六件套

| # | 档案件 | 内容要点 | 关键字段 |
|---|---|---|---|
| 1 | 宇宙学参数表 | 物理常数/魔法法则/熵状态 | 引用法则ID、最后校验日期 |
| 2 | 恒星表 | 光谱/质量/主序寿命 | 依赖链、寿命倒计时 |
| 3 | 行星表 | 轨道/宜居带/生态 | 依赖恒星ID、生态接口 |
| 4 | 位面图 | 节点+连接+法则差异+入口代价 | 法则差异钩子 |
| 5 | 多元宇宙拓扑 | 隔离层/共享层/通道 | 隔离机制、渡桥与破口 |
| 6 | 宇宙时间线 | 纪元/天象事件/文明生命周期 | 时间箭头、事件触发器 |

**依赖链实例**: 恒星类型(光谱/主序寿命)→ 宜居带 → 行星轨道 → 潮汐锁定 → 生态 → 文明的单向推导;任何上行改动必须级联检查下游。**天体机制驱动文明史**: 把宇宙学参数(恒星寿命、位面相位、天体周期)绑定到倒计时/日历/预言,宇宙即叙事引擎。

## 构建操作

1. 先立宇宙档案六件套(参考上表),全部带字段: 每条记录含"引用法则ID"与"最后校验日期",空字段宁缺勿滥;
2. 建立法则→事实依赖链并强制登记: 每个事实条目标注"依据法则X的推论";改法则时跑一遍依赖链回溯,列出所有受影响事实;无法追溯来源的设定一律标记"孤儿设定"并删除或补挂;
3. 给宇宙装叙事引擎: 恒星寿命倒计时(按主序寿命公式给主角世界设"还剩多少年")、位面相位表(周期循环的法则窗口,如"每500年两界对齐")、多元宇宙事件队列(带触发条件的宇宙级事件)——让日历、预言、宗教教义直接引用这些参数;
4. 执行一致性总检清单(见下): 每完成一个模块跑一遍,重大改动后全量重跑;
5. 位面法则钩子规则: 每个位面必须回答"它独有的法则差异是什么、故事如何利用它";答不出的位面删除或合并——位面不是景点,是规则系统;
6. 多元化旅行代价设计: 定义至少一种代价类型(能量/身体/时间错位/身份/记忆),并让代价可被角色权衡而非单纯收费;
7. 用工具而非记忆: 交叉引用型工具或自建参数表;用"一年日历"压缩时间轴可视化宇宙史;制定 retcon 政策,重大改动以作者注公开声明;
8. 按 need-to-know 披露: 宇宙档案是私密地基,故事只暴露接口;违反此原则会以设定倾倒摧毁叙事节奏。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 只堆设定无依赖链 | 每个事实标注"依据法则X",孤儿设定删除或补挂 |
| 改法则不级联 | 改动前跑依赖链回溯,列出所有受影响事实 |
| 静态宇宙无时间箭头 | 恒星演化/熵增/文明生命周期入档,宇宙是过程不是布景 |
| 位面当景点 | 每个位面回答"独有法则差异+故事如何利用",答不出就删/合并 |
| 旅行免费 | 每次跨宇宙/位面有明确代价(能量/身体/时间/身份/记忆) |
| 一致性靠记忆 | 交叉引用型工具+retcon 政策,重大改动公开声明 |
| 设定倾倒给读者 | need-to-know 披露: 只给10%,90%是隐形地基 |
| 能力不被社会利用 | Guy-at-the-Gym 测试: 展示的能力须被社会/军事/经济合理利用 |

## 一致性总检清单

- [ ] **法则层自检**: 每条法则是否可证伪/可观察,无循环定义?
- [ ] **事实-法则核对**: 每个重大设定是否违反依赖链?
- [ ] **Guy-at-the-Gym 测试**: 展示过的能力是否被社会/军事/经济体系合理利用?
- [ ] **旅行代价核对**: 每次跨宇宙/跨位面是否有明确成本?
- [ ] **静态性检查**: 宇宙有时间箭头、文明有生命周期,非静态布景?
- [ ] **隔离性检查**: 多元宇宙各世界是否互不泄漏?
- [ ] **孤儿设定排查**: 无无法追溯来源的设定?
- [ ] **披露边界核对**: 读者看到的≤10%,90%留在地基?
- [ ] **变更管理**: 重大改动有公开声明(retcon 政策),无静默篡改?
