# 语言政策与语言政治

> 目的: 把"谁说哪种话、谁禁止哪种话"写成世界最锋利的政治工具——语言政策可统一帝国, 也可撕裂国家。
> 前置: 社会分层篇(域表/声望)与政治篇(政体/合法性); 本文产出"语言制度"供帝国与民族国家剧情调用。

## 核心理论/机制要点

**语言规划三分法**

| 规划类型 | 管什么 | 权力工具示例 |
|---|---|---|
| 地位规划 | 哪种语言用于哪种领域 | 国语法、官方语言名录、法庭语言 |
| 本体规划 | 文字/正字法/词汇/语法标准 | 词典编纂、正字法敕令、语法规范 |
| 习得规划 | 通过教育体系推广 | 教学语言、考试语言、双语教育 |

- 三者常被混为一谈, 却是三个独立的权力杠杆; 一个政权可只动其一, 也可三管齐下。

**标准化四阶段**
- 选标准(选定某方言为基准)→ 定规范(编词典/语法书定形)→ 扩功能(扩展到科技/法律等新领域)→ 获接受(靠学校、法庭、媒体强制普及)。
- 标准语本质是"被选择+被制造"的产物, 不是自然演化; 规范战争永无终局(拼写改革可争议数百年)。

**通用语的扩散机制**
- 语言不因"优越"而扩张, 而因其载体渠道: 军事行政、宗教圣典、贸易网络、科技出版、教育体系、流行文化。
- 兴衰随其承载的文明权力起伏; 帝国崩溃后, 通用语往往退守为宗教/学术语, 或裂解为方言群。
- 双重载体(帝国+教会/学校两条腿)是通用语长寿的关键。

**距离/扩建裁决**
- 距离型: 靠与邻语在词汇语法上的天然距离自成一体; 扩建型: 靠标准化工程人为拉开界限。
- "一种语言"与"一种方言"的边界是政治裁定而非纯语言学结论——这是语言版图划分的最重要理论武器。

**语言意识形态三取向**
- 问题取向: 多语是麻烦 → 同化、消灭; 权利取向: 多语是权利 → 保护、官方化; 资源取向: 多语是资源 → 经济/外交利用。
- 同一语言现实, 三种取向导出完全相反的剧情; 不同政权各取一取向即生成边界摩擦与外交戏。

**语言死亡与逆转**
- 死亡不是瞬间事件, 而是使用领域逐层被剥夺的梯度过程: 失去学校→失去公共场合→失去工作场所→只剩老人在家使用。
- 逆转必须从最底层(家庭代际传递)往上修; 濒危语言内部存在"半讲者"代际断层(只会片段、不完整传承的一代)。

**正字法/文字选择高度政治**
- 采用哪种文字(表意 vs 表音、字母变体、本土 vs 借用)直接决定语言身份; 文字改革常是政权更替的配套工程。
- 文字与语音可分离: "同文异音"——政令通行而口音互不相通(文字统一≠语音统一); "同音异文"——口语互通却因拼写分裂而政治对立; 统一与分裂可同时为真。

**国语与民族建构**
- 标准语文本的大规模印刷流通塑造"想象的共同体"; 国语建构是民族国家工程的核心——谁的语言成为国语, 谁就定义了"谁属于这个国家"。

**机制速查表**

| 机制 | 内容 | 剧情用法 |
|---|---|---|
| 双重载体 | 帝国+教会/学校两条腿扩散通用语 | 帝国亡而宗教续命, 通用语退守圣坛 |
| 书同文 | 行政文书统一, 口语任其分裂 | 统一帝国里的语音万花筒 |
| 学院式规范 | 词典编纂以"宫廷最文雅用法"为标准 | 词典之战: 改革派 vs 守旧派 |
| 法律平等/功能失衡 | 多语法律平等, 实际集中于少数工作语 | 理想宣言与翻译成本的张力 |
| 标准语自救 | 方言差异大→无法标准化→无法进入教育, 死循环 | 统一语工程决定民族存亡 |
| 国语选择冲突 | 选谁的方言当标准语=选谁掌权 | 可引爆内战级剧情 |

## 构建操作

1. 先画"语言生态图"再写剧情: 为每个政权/族群列出语言、地位等级与使用领域(宫廷/宗教/法律/市集/家庭), 标注声望高低与濒危程度——语言冲突因此有了精确坐标, 而不是笼统的"王国语言不同";
2. 再给每门通用语设计 2~3 条具体扩散渠道: 帝国官僚文书、圣典传教、跨海商路、学院出版, 并让语言随载体兴衰——帝国崩溃后退守宗教/学术语, 或分裂为方言群;
3. 用"标准化的物质技术"表现语言政治: 字书/词典编纂(可设定历时数十年的编典工程)、正字法敕令、印刷工坊、文官考试——让读者看见"规范是被造出来的";
4. 设计双言张力: 神圣语/古典语(高)与俗语(低)并存, 角色在法庭诵典、市井骂街间切换语体即切换权力位置; 再写"低语体文学兴起"挑战经典地位的逆袭线;
5. 按八级梯度给少数语言排"死亡倒计时": 先失去学校→再失去街道→只剩老人独语; 主角可以是被派去记录"最后一说者"的语言学者, 复兴剧情从"语言巢"式祖孙沉浸开始;
6. 把"选谁的方言当标准语"写成核心政治冲突: 新政权建国时选择国语=选择谁的利益集团掌权; 可参照"反标准语运动迫使官方语无限期保留"与"语言运动引发国家分裂"两类真实结局;
7. 设计语言管理机构及其失效: 语言学院、文字改革委员会、双语法令、语言配额、语言警察; 并让政策工具反弹——禁语令催生地下文学, 强制同化刺激复兴运动;
8. 用三种语言意识形态驱动不同政权: 同化型帝国(语言=问题)、权利型联盟(语言=权利)、资源型商业城邦(语言=资源)——同一世界不同国家各取一取向, 自然生成持续的边界摩擦。

## 检查点/清单

- [ ] 生态图: 每政权/族群的"语言×领域×声望×濒危"已入图?
- [ ] 规划三分: 语言政策明确落在地位/本体/习得哪一类, 未混为一谈?
- [ ] 标准化: 标准语有"选标准→定规范→扩功能→获接受"四阶段时间线?
- [ ] 载体渠道: 每门通用语的 2~3 条扩散渠道与兴衰事件对应?
- [ ] 意识形态: 每个政权的语言政策可归入问题/权利/资源之一并自洽?
- [ ] 文字政治: 文字选择/改革附带了政权更替或身份塑造的剧情?
- [ ] 死亡倒计时: 濒危语言按梯度标注了失守顺序与剩余领域?
- [ ] 国语冲突: "选谁的标准语"有明确利益集团与反对运动?
- [ ] 机构失效: 语言管理机构存在, 且其政策有可预见的反弹?
- [ ] 分离悖论: 需要时, "同文异音/同音异文"已用来制造统一与分裂并存?
