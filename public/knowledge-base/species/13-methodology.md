# 种族构建方法论与一致性总检

> 目的: 把种族构建从"灵感驱动"改为"流程驱动"——五卡档案、四步流程、竞争排斥审查、反换皮测试, 结尾给总检清单。
> 前置: 汇总物种篇全部约束(生态位、生物物理、神话、种族-文明); 输出(种族档案+审查记录)是文明篇与历史篇的输入。

## 核心理论: 七个原则

1. **生态位是种族档案的坐标盒**: 生态位是物种在多维环境/资源空间中的"坐标超体积", 区分**基础生态位**(潜在可占)与**实际生态位**(竞争压缩后真实占据)。种族档案里的"生态卡"本质就是这个坐标盒: 食物、栖息地、活动节律、耐受范围, 每一维都必须有值。

2. **竞争排斥原理是第一硬规则**: 完全占据同一生态位的两个物种无法稳定共存, 一方必然被排除或被迫分化。一个世界里两个"智慧种族"若吃同样的食物、住同样的地方、在同一时段活动, 设定上就必须给出它们为何尚未互相淘汰的解释。量化版: 共存要求生态位重叠低于阈值(生态位间距/宽度比)——两种族资源利用曲线越像, 越不能共存; 共存必须在至少一维错开(食物尺寸、活动时间、地理范围、取食方式)。

3. **趋同进化与适应辐射**: 相似生态位塑造相似形态——若两种生物占据相同生态位, 演化会逼它们长得像, 所以"精灵=人类+尖耳"式的换皮在生态学上恰好违背演化逻辑。适应辐射: 单一祖种在空生态位中快速分化——谱系卡必须包含"何时、从谁、因何空生态位而分化"的历史, 否则种族的多样性没有来源。

4. **生态位构建**: 生物通过改造环境改变自身及其后代的选择压力(筑坝、改土、农业)。关键推论: 文化与生态是**双向反馈**而非单向决定——种族改造环境, 环境反过来选择种族。

5. **能量学约束**: 营养级间能量传递仅约 10%; 体型越大、食性越肉食、营养级越高, 可持续种群密度越低。智慧种族的人口上限、城市规模、战争资源都受此硬约束。

6. **文化生态学与生物本质主义批评**: 文化是对环境的适应策略系统, 但"环境约束"≠"环境决定"——同一环境可容纳多种文化解。把文化/道德属性绑定到生物学上(精灵必然优雅、矮人必然贪婪)是最常见的结构性错误: 它混淆了"生态约束塑造可能域"与"基因决定文化"。

7. **五大常见错误**: ①人类换皮(人形+贴图差异); ②全族一帽(星球一文化一生态位, 与竞争排斥相悖); ③无推导链(特征无"因为所以"); ④生物无生态位(生态卡五问答不出); ⑤种族即国家(一民族一王国)。

## 五卡档案制

| 卡 | 内容 | 审查问题 |
|---|---|---|
| 生理卡 | 体型/代谢/感官/寿命/繁殖/耐受 | 每条特征有推导链吗? |
| 生态卡 | 食性/天敌/栖息地/能量收支/竞争者 | 五问答得出吗? |
| 推导链卡 | 每项特征注明"因为…所以…"的来源 | 最终落到法则层吗? |
| 谱系卡 | 祖种/分化时间/近亲物种 | 时间线可追溯吗? |
| 文化卡 | 内部变体/禁忌/技术/政治形态 | 与生态约束一致且有变体吗? |

## 构建操作

1. 固定四步流程, 不许跳步: ①法则层(物理/魔法/能量规则)→②生态层(环境、食物网、生态位)→③推导链(形态/生理/行为逐项从生态位推出)→④文化层(生态约束解空间内的文化方案); 顺序颠倒(先画尖耳朵再找理由)是换皮的总根源;
2. 建五卡档案: 生理卡、生态卡、推导链卡、谱系卡、文化卡五卡互相引用, 无来源的特征不允许存在;
3. 生态卡五问检验: ①吃什么、能量从哪来? ②谁吃它、被捕食压力如何塑造了它? ③住哪、微栖息地是什么? ④它改造了什么环境(生态位构建)? ⑤它与谁竞争、在哪一维错开? 任何一问答不出, 该种族即无生态位;
4. 竞争排斥审查: 列出全部智慧种族, 两两比对生态位; 完全重叠者必须写清分化维度(昼夜节律/地理/食物尺寸/工具代偿), 写不出的合并为一个物种的两种文化; 多智慧种共存的大陆必须给出隔离史或共生关系;
5. 反换皮三项测试: ①删去全部外貌词, 行为-生理-文化是否仍可区分? ②换肤改色后是否仍是"该种族"? ③每项超人类能力(长寿、夜视、魔法亲和)是否都能从生态位或推导链导出? 通不过即换皮;
6. 文化必须解耦生物学: 同一物种写 2~3 种互异文化(高原渔猎/平原农耕/沙漠商旅), 各自由生态约束导出; 禁止"矮人=贪婪、精灵=优雅"的本质主义帽子; 若全族单一文化, 必须显式设置单一化条件(极低人口、神创、灭绝战争);
7. 能量学上限倒推: 按体型×代谢×营养级位置估算最大种群密度, 再反推城市规模、军队人数、贸易结构; 大型食肉种族的人口上限天然低于杂食小体型种族, 地缘格局应从数字里长出来而非拍脑袋;
8. 借用岛屿生物地理学做多样性预算: 大陆越大、隔离越多→亚种与歧化越多; 孤岛/小种群受遗传漂变影响→可合理解释"孤僻种族"的异常形态与文化; 用地理结构自动生成多样性, 而不是给每个种族手工戴一顶帽子;
9. 一致性总检: ①生理卡每条特征是否有推导链? ②推导链是否最终落到法则层? ③生态卡五问是否全答? ④竞争排斥审查是否通过? ⑤文化是否与生态约束一致且含内部变体? ⑥"环境→生态→形态→行为→文化"五层能否双向验证? ⑦五大错误是否为零? ⑧谱系卡是否有可追溯分化时间线?

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 先画尖耳朵再找理由 | 四步流程: 法则→生态→推导链→文化 |
| 特征无来源 | 五卡互相引用, 无来源不允许存在 |
| 生态卡五问答不出 | 该种族即无生态位, 回炉重做 |
| 全族一帽 | 文化解耦生物学, 每族 2~3 种互异文化 |
| 一民族一王国 | 种族≠国家, 绑定需世界史理由 |

## 检查点/清单

- [ ] 四步流程(法则→生态→推导链→文化)顺序未颠倒?
- [ ] 五卡齐全且互相引用, 无来源特征为零?
- [ ] 生态卡五问全部可答?
- [ ] 竞争排斥审查通过(全种族两两比对)?
- [ ] 反换皮三测试全部通过?
- [ ] 每族 2~3 种互异文化, 无本质主义帽子?
- [ ] 能量学上限与城市/军队/贸易数字闭合?
- [ ] 多样性由地理结构(面积/隔离)生成?
- [ ] "环境→生态→形态→行为→文化"五层双向可验证?
- [ ] 五大错误(人类换皮/全族一帽/无推导链/无生态位/种族即国家)为零?
