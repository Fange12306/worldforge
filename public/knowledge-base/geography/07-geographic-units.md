# 具体地理单元: 半岛/地峡/岛屿/裂谷/海峡/海湾/湖泊

> 这些单元的统一杠杆 = **构造 × 气候 × 海平面变化**。

## 核心机制

- **海侵/海退是关键杠杆**: 冰后期海面上升 ~120 m, 直接"淹没"出一整组海岸形态。
- **半岛与地峡互为对偶**: 半岛=三面环水一面连陆(海侵淹没低地后"幸存"的高地); 地峡=连接两大陆的窄陆带(被淹没脊线或沉积充填的"桥")。
- **岛屿四分成因**: 大陆岛(陆架岛)、火山岛(洋中脊/热点/岛弧)、珊瑚岛(含环礁)、冲积岛; 另有复合型。

## 各单元成因与参数

| 单元 | 成因机制 | 关键参数/实例 |
|---|---|---|
| 半岛 | 海侵淹没高地 / 构造山系入海 / 三角洲淤积 | 海拔须高于当时海面数十米 |
| 地峡 | 岛弧+沉积封闭(巴拿马)/ 海退露陆(白令陆桥, 冰盛期海面 −120~−130 m)/ 构造抬升 | 相对海面变化、抬升速率 |
| 大陆岛 | 大陆架(<200 m 水深)被海隔开 | 英国、台湾 |
| 火山岛 | 洋中脊(冰岛)/ 热点(夏威夷链)/ 俯冲岛弧(日本、印尼) | 板块移动速率 |
| 珊瑚岛 | 限南北纬 30° 内、表层水温 >20°C、水深 <40–50 m、水清 | 环礁=沉降+海侵 |
| 冲积岛 | 大河河口与潮流辐聚区 | 崇明岛 |
| 构造湖 | 裂谷/地堑 | 贝加尔 >1600 m |
| 冰蚀湖 | 冰川刨蚀+冰碛堰塞 | 五大湖、北欧 |
| 牛轭湖 | 曲流截弯取直 | 弯月形, 仅曲流平缓段 |
| 泻湖 | 砂质低平海岸, 需潮差小 | 地中海沿岸 |
| 火山湖 | 火山口/破火山口积水 | 长白山天池、多巴湖 |
| 裂谷 | 主动(地幔柱驱动, 东非)/ 被动(板块拉张, 莱茵地堑) | 演化: 穹隆→三叉裂谷→失败裂谷/幼年洋 |
| 海峡 | 断陷/海侵溺谷/冰川侵蚀 | 琼州海峡、博斯普鲁斯(溺谷)、台湾海峡(陆架淹没) |
| 海湾 | 溺谷(ria)、峡湾(fjord)、构造湾、障壁泻湖湾 | 挪威、智利峡湾; 西班牙西北里亚斯岸 |

## 构建操作

1. **先构造骨架后画海岸**: 板块边界+地幔柱 → 裂谷/岛弧/火山岛/山链; 再叠加一次海侵—海退事件定海岸轮廓。
2. **用一次海侵事件批量生成海岸地物**(+~100 m): 大陆岛(低地被淹)+半岛(高地残存)+溺谷海湾(河谷被淹)+海峡(山脊缺口被淹)——互相天然自洽, 是最快且最合理的海岸生成法。
3. **纬度决定"地形特产"**: 赤道至 30° 放珊瑚岛; 高纬/高山放冰蚀湖与峡湾(需冰期史); 干旱内陆放盐湖; 湿润构造带放裂谷湖。
4. **河湖自洽法则**: 先分水岭再湖泊; 牛轭湖只在曲流平缓段、泻湖只在低潮差砂质海岸、构造湖必须骑断层线。
5. **三角洲与地峡是文明锚点**: 类比巴拿马/苏伊士/尼罗河——交通咽喉、贸易与战争叙事。
6. **用深时要素做"历史遗迹层"**: 河流阶地(多次抬升)、环礁(沉降+海侵)、裂谷湖深(百万年尺度)映射地壳事件纪年, 赋予地形"年龄"。

## 量级检查

- 岛弧长百~千 km、裂谷宽数十 km、海峡宽数十~数百 km、湖深数十~1600 m;
- 禁止矛盾组合: 珊瑚岛≠高纬冷水, 冰蚀湖≠热带低地, 泻湖≠强潮海岸。

## 叙事挂钩

- 地峡=物种交流与文明接触叙事; 海峡=军事航运咽喉; 裂谷湖=文明摇篮(类比东非); 火山岛=灾难与神话题材。让成因直接成为地名与传说的来源。
