# 音系与书写系统设计

> 目的: 先定文明的"听觉气质",再填音位表与配列规则;让音节结构自然派生文字类型,给声调写"出生证明",给文字写编年史,用书写分层塑造社会结构。
> 前置: 与类型学篇(02)的"声调/复辅音"维度联动;为词汇篇(05)与命名篇(07)提供全部语音原料。

## 核心理论

- **音位清单落在自然范围**: 人类语言音位总数约 11~141,常见中位数 25~35;"辅音 20~40 + 元音 5~10"即可,不必刻意求怪。三元音 /i a u/ 与五元音 /i e a o u/ 最普遍,七元音以上即属复杂;元音与辅音数量存在弱的负相关。
- **"对称矩阵 + 空洞"是真实感来源**: 真实清单是"发音部位×发音方法"的对称矩阵,但允许空洞(如缺某个送气对、缺流音)——空洞是历史音变的化石,是给世界造史的天然抓手。
- **标记性控制奇音剂量**: 无标记音(p/t/k、m/n、i/a/u)最常见;有标记音(挤喉音、边擦音、咔哒音)少见、习得晚、易在历史中失落。虚构语言的"奇音"应少而精,并配备"孤儿音"解释其来源。
- **音节结构从纯 CV 到重辅音丛**: 所有语言都有 CV 音节;复杂度按响度序列原则约束(响度向音节核递增)。配列约束本质是"位置性"的: 哪些辅音可作首/尾、哪些可相邻、同化规则。设两三组"允许/禁止"即有系统感。
- **音节重量与韵律**: 长元音与闭音节为"重",与重音/声调位置联动;有些语言按"拍"(时长单位)而非音节计数。设计"轻重如何影响重音或调位"是高性价比参数。
- **声调 2~6 调均自然**: 平调系统对曲折调系统;调值用五度制记写,关键是调型分布要有"几何感"(高低相间、曲折调不扎堆)。发声态可叠加(低调伴嘎裂声是普遍倾向)。
- **变调是语境触发**: 调值随邻音变化,方向性(左向/右向扩散)是可设定参数;1~2 条规则即可,不必全系统。
- **声调可以"从无到有"(声调发生)**: ① 声母清浊对立丢失→高低调分裂;② 韵尾丢失→升调/降调;③ 前缀丢失。声调语言还倾向较简单的音节结构——音系内部相互制约,不是自由拼装。
- **书写系统六类型,各有气质**: 字母(平民化、识字门槛低,与印刷/民主绑定)、辅音音素文字(只写辅音、书法神圣化)、元音附标(基础字符=辅音+固有元音、宗教传抄性强)、音节文字(一字一音节、门槛低贴近口语)、语素文字(识字成本高→精英垄断、跨方言统一)、特征文字(字形编码语音特征、"理性王权为民造字")。
- **文字演化总趋势: 象形→表音**: 象形 → 假借(同音符号表音)→ 形声(声符+义符/限定符)→ 楷化(笔划规范简省)。字符数趋向经济(数千语素字→五十假名→二十余字母),模糊性(歧义)驱动改革。

## 六类型文字气质对照(选型表)

| 类型 | 机制 | 气质/社会后果 |
|---|---|---|
| 字母 | 辅元音均为独立字符 | 平民化、识字门槛低;与印刷、宗教改革、民主绑定 |
| 辅音音素文字 | 只写辅音,元音靠推断 | 辅音骨架承载词根;书法神圣化 |
| 元音附标 | 基础字符=辅音+固有元音,其他元音用附标 | 宗教传抄性强;随宗教东传扩散 |
| 音节文字 | 一字一音节 | 门槛低、贴近口语;适合民歌/私信/物语 |
| 语素文字 | 一字一语素/词 | 识字成本高→精英垄断、跨方言统一、经典权威 |
| 特征文字 | 字形编码语音特征 | "理性王权为民造字"的启蒙叙事 |

## 音位配列规则示例(设定模板)

| 规则类型 | 示例写法 |
|---|---|
| 首辅音许可 | 禁 /tl/ 起首、禁同部位塞音相邻 |
| 尾辅音许可 | 只允许 /n/ /t/ /s/ 收尾 |
| 同化规则 | 鼻音在塞音前同化为同部位 |
| 元音和谐(可选) | 词内元音须同属前后/圆唇一组 |
| 重音规则 | 重音落在重音节(长元音或闭音节)上,否则首音节 |

## 机制与案例(可迁移的设定模板)

- **音系极端光谱**: 纯 CV+多元音(8 辅音+5 元音、长短对立)——"海上贸易族"气质;大辅音库(几十个辅音+密集挤喉音/清塞音、闭音节为主)——"冰川蛮族"气质;超复杂复辅音丛(六连辅音)——"山地古族"气质。
- **声调"出生证明"模板**: 第 4 调来自古韵尾脱落(→升调)、第 2 调来自浊声母清化(→低调域)——每个调都能写来源,再定 1~2 条变调规则(如"低调遇低调变高调"),对话中的声调变化即可被读者感知。
- **变调方向性模板**: 普通话式"相邻触发"(第三声遇第三声变第二声)、闽南语式"除末音节全变"的连锁变调——选一种方向(左向/右向)即可。
- **书写分层案例**: 三系统并用(语素字+音节字,分别源自草书与部件拆分);神圣古体 vs 世俗简体双轨(仿古埃及三体);混合文字(语素+音节)600+ 字符。设"神圣古体+世俗简体"双轨直接决定识字率、书籍形态与教育权力分配。
- **"最古老文字里藏着最现代文字的种子"**: 语素文字中的单辅音符号实为字母雏形——古文字里埋着未来文字的系统,是极好的世界细节。
- **媒介决定形态**: 泥板(笔画刚硬、楔形)、竹简(直排)、纸莎草(草书化)、石碑(庄严正体)——书写方向与字体演变绑定材料;碑铭用古正体,私信用连笔草体。

## 构建操作

1. 先定义文明的"听觉气质"再填表: 飘渺精灵=纯 CV+五元音+无清浊对立+几乎无辅音丛;重权矮人=大辅音库(挤喉音、清浊满格)+闭音节为主+低调嘎裂声;航海商族=音节简单+元音对立丰富(便于远距离喊话);
2. 用"对称矩阵+1~2 空洞"落成音位表;空洞即传说("古语某音已亡,借词仍带它"),让空洞承载历史;
3. 让音节结构派生文字类型: 纯 CV→音节文字或元音附标;重辅音丛→字母文字;辅音词根型→辅音音素文字;单音节孤立语→语素文字——先定音系,文字顺理成章,避免"CV 语言配辅音音素文字"的违和;
4. 给每个声调写"出生证明": 设计声调发生史(如"第 4 调来自古 -ʔ 尾脱落"),再定 1~2 条变调规则,让声调变化可被感知;
5. 按"象形→假借→形声→楷化"写文字编年史: 四阶段各配一个历史事件——图画记事时代→同音假借引发的歧义危机→限定符/形声字正字→某王统一文字时楷化简省;每阶段留下物质遗迹(碑铭用古体、法典用新体);
6. 用文字分层塑造社会结构: 设"神圣古体+世俗简体"双轨——祭司/贵族垄断语素古体(神秘、排他),民间流行简化音节字(开放、通俗);
7. 绑定媒介与字体: 为每种书写材料设定字形特征与书写方向,碑铭正体、私信草体;
8. 允许"不完美": 留 5% 的历史残留(同音字、多音字、不规则拼写),写一场"正字法改革之争"——廉价而高质的真实感来源。

## 检查点/清单

- [ ] 音位清单落在自然范围(辅音 20~40+元音 5~10 或刻意偏离并有解释)?
- [ ] 清单是"对称矩阵+空洞"结构,空洞有历史解释?
- [ ] 奇音(挤喉/咔哒/边擦)少而精,有来源说明?
- [ ] 音节结构明确(纯 CV / 简单丛 / 重丛),配列"允许/禁止"规则已写?
- [ ] 重音/拍规则与音节重量联动已设定?
- [ ] 声调(若有)2~6 调、分布有几何感、每个调有"出生证明"?
- [ ] 变调规则 1~2 条,方向性明确?
- [ ] 文字类型由音节结构派生,无"CV 配辅音音素文字"违和?
- [ ] 文字编年史四阶段(象形→假借→形声→楷化)各有历史事件?
- [ ] 神圣/世俗双轨已设定,并决定识字率与权力分配?
- [ ] 字体与媒介(泥板/竹简/纸莎草/石碑)绑定,有古体/草体之分?
