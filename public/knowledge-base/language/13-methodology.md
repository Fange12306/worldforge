# 语言构建方法论与一致性总检

> 目的: 把"造一门语言"从灵感变成可验证的工程——档案八件套、构建流程、命名-语言-文化一致性、总检清单。
> 前置: 本文是全语言篇的总纲, 产出"语言档案"供其他各篇(社会/政策/魔法/翻译/生态)调用。

## 核心理论/机制要点

**语言档案八件套(后台资产)**
1. 音系表: 音位清单+音位配列+重音/声调;
2. 构词法纲要: 派生与屈折、语序与格标记;
3. 句法纲要: 语序类型、基本句式、从句策略;
4. 核心词汇: 基础词表起步(百词级), 优先抗借用的词表;
5. 文字系统: 正字法, 与音系一一对应的转写规则;
6. 样例文本: 附逐词标注与自由翻译, 须"可回译"验证;
7. 谱系树: 含祖语与亲属语言;
8. 语言地图: 地理分布、方言连续体、语言接触带。

**构建操作流程(先定角色再逐层向下)**
- 定角色→音系→语法→词汇→文字→历史→使用。
- 第一步"定角色"决定一切: 语言在故事里承担什么叙事功能(身份标记/神秘感/历史回声), 据此定规模而非求全。
- 音系先行: 仅 20~30 个音位即可决定一门语言的听感与命名风貌, 是"最小成本最大收益"的构建点。
- 词汇围绕故事需要的语义场, 而非字典式堆砌; 文字系统可后期添加。
- "历史"指用历时方法拟构祖语与音变规则, 反推出亲属语言; 最后是"使用"——方言、语域、双语、俚语等社会分层。

**一致性原理(命名-语言-文化三位一体)**
- 同一语言区内一切地名、人名必须服从该语言音系限制。
- 文化概念塑造词汇空缺与词汇场(如无"雪"词的沙漠文化、无"债务"词的馈赠文化)。
- 借词方向必须由历史接触事件解释(征服者语言留下地名层, 贸易语留下商品词)。
- 语言不是标签集, 而是系统: 真实语言充满不规则、历史残渣与接触痕迹——"自然主义"是判定标准。

**语言作为叙事引擎**
- 命名揭示历史: 地名词源学/词源学是历史层的地图。
- 语码转换暴露身份: 换语言/方言/语域即身份切换。
- 翻译误解推动情节: 双关、误译、禁忌词误用是现成冲突源。
- 语言可塑造世界观: 虚构语言能表达"非人化"认知(如无"成功"概念的语言、无时间范畴的语言)。

**常见错误对照表**

| 常见错误 | 症状 | 正确做法 |
|---|---|---|
| 一锅语言 | 互不兼容特征堆叠(语法来自甲乙丙) | 先锁音系与语序类型, 所有特征服从同源约束 |
| 过度规则 | 无例外无不规则, 语言失真 | 保留历史残渣: 不规则动词、例外拼写、化石词 |
| 无时间轴 | 语言千年不变, 古典与现代不分 | 设祖语→古典语→现代语分期, 各期留残存 |
| 跨语言混用 | 英语词尾硬安、异语言碎片乱拼 | 借词必须标注来源与年代, 适配目标音系 |

**一致性总检原则(可验证性)**
- 正字法↔音系 100% 对应; 文本可逐词回译; 谱系树与地图吻合; 借词带来源与年代标注; 每个词条可追溯首现出处。

## 构建操作

1. 先定叙事角色, 再定规模: 问"这门语言在故事里做什么"(身份/谜团/历史回声), 只造被镜头照到的部分; 档案是后台资产, 用"冰山原则"写入正文;
2. 再锁音系且"小而美": 先定 20~30 个音位+音节结构+重音, 所有命名、文本、借词适配都服从它——音系是听感与"不像英语"的第一来源, 也是命名一致性的根;
3. 用比较法造一族语言: 想要两个有渊源的民族, 先拟祖语, 再写 3~5 条音变规则(如某辅音在特定环境腭化), 亲属语言自动获得"同源异貌"; 借词方向随之自洽;
4. 命名三关检查: 每个地名/人名过三关——音系合法? 构词可解(如"河口镇"式复合词)? 词源与历史地理自洽(山名来自古语、城名来自征服者)?
5. 用专业规范做内部一致: 核心词汇以抗借用基础词表起步; 样例文本附逐词标注以便任何人回译验证; 维护"语言档案"(音系表/词表/语法页/文本库);
6. 设语言时间轴: 祖语→古典语→现代语分期, 各期留下残存(现代词形是音变的化石); 碑铭文献用古典语, 口语用现代语, 避免"千年不变";
7. 把语码转换当人物塑造工具: 让角色在情绪、场合、身份切换时转换语言/方言/语域; 混入外语不翻译的插入句是塑造"双语者/局外人/等级"的最廉价工具;
8. 把"不可译"与误译当情节引擎: 提前在词表中埋入同音词、多义词、禁忌词, 用双关误解、口译失误、词源误认推动冲突;
9. 最后跑总检清单(见下), 并把语言档案与地理地图、谱系树、历史事件逐项核对, 迭代修正。

## 检查点/清单

- [ ] 档案八件套: 音系/构词/句法/核心词/文字/样例文本/谱系/地图齐备(至少覆盖故事用到部分)?
- [ ] 音系一致: 所有命名与文本服从音位配列, 无违例词?
- [ ] 正字法: 正字法↔音系一一对应, 转写规则无例外?
- [ ] 回译性: 样例文本可逐词回译, 无英语直译残留?
- [ ] 谱系: 亲属语言共享创新可解释, 音变规则 3~5 条可复现?
- [ ] 借词: 每个借词有来源语言与年代, 方向由历史接触事件解释?
- [ ] 时间轴: 古典语/现代语分期清晰, 现代词形是音变化石?
- [ ] 词汇缺口: 文化概念已塑造词汇空缺与词汇场, 非字典堆砌?
- [ ] 叙事引擎: 命名/换码/误译已接入剧情, 非装饰?
- [ ] 自然主义: 有不规则与历史残渣, 无"过度规则"与"一锅语言"?
- [ ] 可溯源: 每个词条可追溯首现出处, 无无源之词?
