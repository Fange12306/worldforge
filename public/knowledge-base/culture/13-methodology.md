# 文化构建方法论与一致性总检

> 文化是"习得的复合整体": 任何习俗都与其他要素咬合, 不能单点设定, 更不能跨世界搬运。本文件给出"文化档案 11 项清单、公理推导链、双向一致性检查、叙事引擎三机制、常见错误对照、总检清单"。

## 核心立场

- 文化是知识、信仰、艺术、道德、法律、习俗及成员习得的全部能力与习惯的**复合整体**——不是自由变量, 主干必须能由"环境+生理+公理"推导。
- 每种文化是特定历史条件的产物, 必须内部理解: **文化不能跨世界直接搬运**, 必须从该世界的独特前提推导。
- 文化是"意义之网": 每个行为/物品都应能"被解读出意义"——没有意义的细节是装饰。
- 文化是动态的: 变迁三大来源——创新、传播、涵化; 静止的文化设定是假的。
- 世界是"次创造", 硬标准是**内部一致性**与**可扩展性**: 允许增量生长而不自相矛盾。

## 核心工具一: 文化档案 11 项清单

| # | 项 | 内容要点 | 强制项 |
|---|---|---|---|
| 1 | 核心公理 | 神是否存在、魔法如何收费、死后何往、资源上限 | 必填 |
| 2 | 世界观 | 宇宙如何运作、人在其中的位置 | 必填 |
| 3 | 价值观 | 五取向: 人性观/自然关系/时间取向/行动取向/人际关系 | 必填 |
| 4 | 规范禁忌 | 可执行规则及其分类逻辑 | 必填 |
| 5 | 仪式库 | 过渡礼仪、节日、集体仪式 | 必填 |
| 6 | 艺术风格 | 造型、音乐、叙事母题 | 可选 |
| 7 | 习俗 | 饮食、婚丧、服饰、礼仪 | 必填 |
| 8 | 神话 | 起源叙事、神圣谱系 | 必填 |
| 9 | 文化记忆 | 双层记忆、记忆之场、谁定义过去 | 必填 |
| 10 | 内部多样性 | 阶级/性别/地域/世代差异, 至少两个张力轴 | **强制项** |
| 11 | 变迁史 | 至少两代人的观念代差、一次外来冲击 | **强制项** |

内部多样性与变迁史是防止"文化扁平"与"文化静态"的强制项——缺了它们, 文化就是一帽设定。

## 核心工具二: 公理推导链

**公理→价值观→规范→制度→仪式→物质痕迹**:

1. 公理是底层事实(神是否存在、魔法代价、死后确定性、资源稀缺性);
2. 价值观是公理在"何者值得"上的投影——价值观必须能从公理逐条推导, 禁止凭空出现"这个文化崇尚 X";
3. 规范/禁忌把价值观转成可执行规则;
4. 制度(法律、宗教、家族、行会)为规范提供执行载体, 并反向索取合法性;
5. 仪式把制度变成可重复的体验;
6. 物质痕迹(建筑朝向、服饰、饮食禁忌、墓葬)是仪式的空间沉淀。

**反向检验**: 任取一个物质痕迹应能反推出仪式→制度→价值→公理, 链条断裂处即设定漏洞。文化在整体设定中充当"中层胶水": 公理向上接世界观与法则, 向下接制度、人物与情节; 跨模块时以"文化为制度供合法性、制度为文化供载体"为双向校验句。

## 核心工具三: 双向一致性检查

| 检查对象 | 两个必答问题 | 答不出怎么办 |
|---|---|---|
| 制度 | ①它从哪条价值观取得合法性? ②它给价值观提供了什么载体(机构/仪式/文本/建筑)? | 删除或补全 |
| 仪式 | ①它强化什么集体意识? ②它标记什么状态变化? | 删除或补全 |
| 禁忌 | 它对应哪条分类逻辑? (禁忌是该文化分类体系的负片) | 补分类图式 |
| 物质痕迹 | 能反推出仪式→制度→价值→公理吗? | 补链或标注为剧情伏笔 |

- 仪式若不同时满足"强化集体认同"与"标记个体状态变化"两个功能, 就是装饰。
- 过渡礼仪的三阶段(分离—阈限—聚合)是普适结构: 阈限期规则悬置、身份未定、等级可倒转, 冲突密度最高。

## 核心工具四: 文化作为叙事引擎的三种机制

| 机制 | 原理 | 用法 |
|---|---|---|
| 价值观冲突 | 两个由不同公理推导的价值系统在个体身上撕扯(荣誉vs生存、义务vs情感) | 角色内在戏剧性 |
| 仪式节点 | 过渡礼仪天然是叙事结构(成年礼、婚丧、即位)触发阈限期 | 身份未定、规则悬置, 冲突密度最高 |
| 记忆钩子 | 被压抑/被篡改/被遗忘的文化记忆在情节高潮被唤醒(考古发现、节日回归、口传真相) | 主线引爆点 |

取故事优先从价值观冲突与仪式节点取, 而非从习俗清单取细节。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 文化扁平(单一标签) | 补内部多样性: 至少两个张力轴(阶级/性别/地域/世代) |
| 习俗清单病(罗列无推导) | 逐条挂回价值, 再由价值挂回公理 |
| 价值观无推导 | 回补公理卡, 禁止凭空"崇尚 X" |
| 仪式无功能 | 删, 或补"强化集体意识+标记状态变化" |
| 文化静态 | 加变迁史: 两代代差+一次外来冲击 |
| 文明=文化=语言=种族四合一 | 解耦: 同一文明可多文化, 同一语言可跨文明 |
| 跨世界搬运突兀元素 | 从本世界公理重新推导, 或标注"历史偶发"并给出传入路径 |
| 设定膨胀(世界构建病) | 只深化与故事相关的 3~5 个设定簇, 其余按冰山法则留白 |

## 构建操作

1. 先写**公理卡**(5~8 条不可再约的底层事实), 再写一切——价值观必须能逐条推导, 不允许"这个文化崇尚 X"凭空出现;
2. 用**五取向**给每种文化建档打分(人性观/自然关系/时间取向/行动取向/人际关系), 文化间差异由此可比较, 冲突有结构来源("未来取向"文明 vs"过去取向"文明);
3. 跑一遍**公理推导链**并留档: 每条记录"由什么推出、受什么限制", 任一物质痕迹可反向验证;
4. 填齐**文化档案 11 项**, 强制完成内部多样性与变迁史两项——先写张力轴, 再写代差与外来冲击;
5. 对每个制度与仪式跑**双向检查**: 答不出两个必答问题就删或补全;
6. 把仪式写成**剧情节点**: 用过渡礼仪三阶段制造阈限时刻(成年礼夜、即位间隙、禁忌解禁日), 让主角身处规则真空;
7. 设置**记忆钩子与记忆政治**: 写下"谁记得什么、谁被允许忘记、谁在篡改档案", 让核心真相以文化记忆回归为引爆点;
8. 用**一致性总检清单**收尾, 并对照常见错误表自查一遍。

## 总检清单

- [ ] 公理卡存在(5~8 条), 每条价值观可追溯到某条公理?
- [ ] 文化档案 11 项齐全, 内部多样性与变迁史两项完成?
- [ ] 每个制度答出两问(合法性来源? 载体是什么?)?
- [ ] 每个仪式答出两问(强化何集体意识? 标记何状态变化?)?
- [ ] 每个禁忌对应一条分类逻辑?
- [ ] 任取 3 个物质痕迹(建筑/服饰/葬俗/饮食)可反推完整链条?
- [ ] 文明/文化/语言/种族已解耦, 无一一映射?
- [ ] 无"跨世界搬运"的突兀元素, 或已标注传入路径?
- [ ] 记忆有选择性: 谁记得/谁被允许忘记/谁在篡改?
- [ ] 文化作为叙事引擎: 至少一个价值观冲突+一个仪式节点+一个记忆钩子?
- [ ] 冰山法则: 呈现量约 10%, 文档备 100%?
