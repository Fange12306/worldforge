# 世界间旅行与法则差异

> 目的: 设计"换世界即换规则"的系统——先画世界拓扑图,再制法则差异参数表,给每种旅行方式定价,用适应三阶段控制穿越者的成长节奏,最后用反套路三招规避题材陷阱。
> 前置: 与位面旅行(08)、多元宇宙拓扑(10)、宇宙构建方法论(13)互相咬合;本页聚焦"世界与世界的接口"与"穿越者的体验曲线"。

## 核心理论: 世界模型决定旅行手段,法则差异决定穿越体验

- **"世界"的物理本体论**: 跨世界叙事的第一步是定义"世界"是什么。四类模型: ①**位面**——同宇宙内的平行现实层; ②**晶壁球**——被晶壁包裹的独立太阳系,壁外是虚空介质; ③**平行宇宙**——量子分岔或膜上的同类宇宙; ④**泡泡宇宙/高维嵌套**——大爆炸产生的岛宇宙,或高维空间中的低维切片。模型决定旅行手段的物理合理性。
- **旅行方式类型学**:
  - **门户类**(通道/门/传送阵): 固定或临时的空间奇点,需三要素——坐标(锚点)、能量(维持成本)、稳定器(防塌缩);
  - **桥梁类**: 世界间实体通道(彩虹桥/巨树/海沟),代价是桥本身成为战略要地;
  - **渡劫/飞升类**: 力量/境界达阈值时世界自动"放行",多为单向、个体化,与"天道"设定天然契合;
  - **载具类**(晶壁船): 以物质船穿越虚空介质,可运货载人、可被拦截——世界间贸易的最佳载体;
  - **中转层类**: 借道中间地带(星界位面),中转层的时间/距离规则可独立设计。
- **限制的三组对称**: ①**力量上限**: 世界只能容纳≤N的力量,超限者被压制或被"驱逐"; ②**法则压制**: 换世界后物理/魔法规则改写,旧技能失效——"穿越落差感"的引擎; ③**单向性**: 无法回头(代价、坐标丢失、世界排斥力)——防止"回家如买菜"。
- **法则差异可测量化**: 让角色"感觉到"换了世界,把差异变成可感知参数——灵气/魔力浓度(呼吸感、施法耗能)、元素属性丰度(火系更强)、时间流速(天上一天地下一年)、生死规则(复活/轮回是否可行)、物理常数(重力/光速)、语言与货币。**换世界即换规则**的工具箱是参数表。
- **适应机制三阶段**: 力量封印(保留记忆、失去能力)→ 法则重构(旧能力以新形式复苏: 火球术→火焰异能)→ 身体改造(身体被新世界法则重写: 灵根/魔核)。三阶段对应三幕剧节奏。
- **多元宇宙一致性**: 同一人多版本(counterpart)、时间线保护、蝴蝶效应。同一人多版本相遇需明确规则(可感应/不可共存/合体即融合/必有一死);时间线保护要有惩罚机制(悖论修正者/因果回收)——乱改时间线有真实成本。
- **穿越题材常见陷阱**: 金手指过强导致无冲突;语言/货币/文化障碍被"系统翻译"抹掉;信息差红利无限使用;原住民集体降智;双标道德(穿越者杀人无罪);设定堆砌但不进入剧情。**穿越红利的代价化**是破局关键——前世人格持续在场、能力缓慢成长、原住民有独立意志。

| 生死规则 | | | | 复活/轮回是否可行 |
| 物理常数(重力/光速) | | | | 行动迟滞、影子方向 |

**时间流速差必须配代价**(引力、质量、寿命会计),否则变成刷经验外挂。**传送越便宜,世界越廉价**: 至少保留一条"昂贵路线"作为主线枢纽。航行即冒险: 燃料、船队、海盗、检疫——让跨世界旅行成为职业体系而非传送按钮。

## 构建操作

1. 先画"世界拓扑图": 一页图标注每个世界的层级(晶壁球/位面/泡泡)、与邻界的介质(虚空/海/雾/星界)、通行方式与限制——拓扑图决定"能不能去、怎么去、要多久";
2. 制作"法则差异参数表"(参考上表): 每个世界列8项参数,并为穿越者设计3个感官细节(呼吸滞重/施法延迟/影子方向)让读者"感觉到"换世界;
3. 给每种旅行方式定价: 能量、寿命、坐标风险、单向性、通关文牒(世界许可)——规则"传送越便宜世界越廉价",至少一条昂贵路线做主线枢纽;
4. 严格执行"适应三阶段": 封印(能力清零+记忆保留)→重构(旧能力新形态+新体系入门)→改造(身体重塑+代价显现),每阶段设剧情事件节点,禁止主角跳段;
5. 设计多元宇宙一致性规则: 同一人多版本相遇规则明确化,时间线保护有惩罚机制,让乱改时间线有真实成本;
6. 反套路三招: ①穿越红利明码标价(记忆损耗/人格侵蚀/旧世界债主追杀); ②原住民有反制手段(测谎术/记忆检查/世界排斥力); ③至少一个世界对穿越者"免疫"(无灵气世界克制魔法,科技世界克制玄学);
7. 一致性自检三问再动笔: 高魔世界为何不反攻低魔世界(能量差/通道稀缺)?穿越的能量守恒如何解释(世界间能量不守恒才是常态)?语言障碍如何解决(翻译系统要有代价或边界,如只能听懂不能说)?

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 世界模型未定义就写穿越 | 先定"世界"本体论(位面/晶壁球/平行宇宙/泡泡),模型决定手段 |
| 换世界无感知差异 | 建8项法则参数表+3个感官细节(呼吸/施法延迟/影子方向) |
| 传送免费随意 | 给每种旅行方式定价;传送越便宜世界越廉价,保留昂贵主线枢纽 |
| 主角秒适应 | 严格执行封印→重构→改造三阶段,每阶段设剧情节点 |
| 金手指过强无冲突 | 穿越红利明码标价(记忆损耗/人格侵蚀/债主追杀) |
| 原住民集体降智 | 给原住民反制手段(测谎/记忆检查/世界排斥力) |
| 语言障碍一笔带过 | 翻译系统有代价或边界(只能听懂不能说) |
| 时间流速当外挂 | 流速差配寿命会计/引力/质量代价 |
