# 位面旅行与半位面

> 目的: 为世界设计一套位面交通系统——先定拓扑与连接规则,再给每种旅行方式配代价清单,最后把传送门、半位面、位面战争做成可玩的叙事引擎。
> 前置: 与宇宙构建方法论(13)、多元宇宙拓扑(10)、世界间旅行(11)互相咬合;位面法则差异要挂接"法则-事实依赖链"。

## 核心理论: 位面之间没有距离,只有连接关系

- **多层拓扑是前提**: 位面体系建立在"宇宙不是单一空间,而是多层结构"之上。两种经典结构模型——"大车轮": 物质位面居中,内层为元素位面,外层为阵营位面,星界与以太位面充当通道层;"世界轴": 以世界之树意象组织的天体结构。关键原理:**位面之间没有"距离",只有"连接关系"**——旅行本质是拓扑重连而非物理位移。设计位面体系就是回答三个问题: 什么能连、什么不能连、为什么。
- **传送门=宇宙的钥匙孔**: 门是两个位面被"拉近"的定点,开关受 key(钥匙)控制。key 可以是物品、姿势、情绪、暗语、季节。原理:**门不认人、只认条件**——"门找人,不等人找门"。门户系统天然是叙事谜题引擎。
- **星界是共享的精神空间**: 星界无物理距离,旅行速度随思想速度变化,导航靠"对地点的记忆"而非航向。灵体投射时灵魂沿**银线**离开肉体——银线是唯一命门,断裂即死亡或永久滞留。星界的地理是集体记忆与信念的投影: 迷路不是因为没地图,而是因为"想象不出目的地"。
- **仪式门槛=宇宙轴点**: 世界树、圣山、洞穴、河流交汇处、十字路口是位面最薄处;仪式=在正确时间、正确地点、以正确姿态"打开"它。门槛本身承载意义——这解释了传送门为何总出现在神话地点。
- **半位面是寄生结构**: 依附于某位面或锚点的微型口袋宇宙,存在依赖**锚点**(创造者的意志、神器、誓约)。锚毁则半位面崩塌或漂浮进星界。最有力的叙事属性: **可变时间流速**与**封闭性**——同时适合做密室、牢笼、避难所、会议厅。
- **位面战争是法则的战争**: 秩序-混沌的永恒战争是**宇宙减压阀**——战争消耗混沌,反而保护了物质位面。元素位面冲突不是军队对军队,而是**物理法则互相侵入**: 火元素入侵=整片区域热力学法则被改写;位面裂缝是法则渗出的伤口,永久改变地貌。
- **导航是分层技能**: 新手依赖引路人(向导/萨满/亡灵引渡者),进阶者依赖航图(记录连接关系而非地理的图),大师依赖直觉与自我锚定——构成清晰成长阶梯。

## 旅行方式与代价清单

| 方式 | 机制 | 典型代价 | 失败出口 |
|---|---|---|---|
| 传送门 | 定点拉近,钥匙开门 | 收"物"(不可转让的钥匙) | 钥匙失效、门后是陷阱 |
| 星界航行 | 精神之海,思想即速度 | 收"时间与记忆" | 迷失(想象不出目的地)、肉体失守 |
| 灵体投射 | 银线离体 | 收"身体风险"(银线断裂) | 死亡或永久滞留 |
| 仪式开门 | 薄地+时辰+姿态 | 收"献祭/债务" | 仪式失败、请错东西 |
| 半位面中转 | 借道口袋宇宙 | 时间流速差、锚点风险 | 锚毁坍缩、流速错位"物是人非" |

**时间流速差的两种用法都必须配代价**: 加速训练场(一天=一年)要有硬约束——禁止携带物资、极端环境、每人终生限入次数、每次出来积累疯狂值,避免"免费升级";反向的"仙境一日人间百年"让时间流失成为戏剧引擎——归来时物是人非。旅行失败模式四类: **时间流失、精神损伤、肉体畸变、永久滞留**,每种都要规则化(可判定、可预防、可被剧情回收)。

## 构建操作

1. 先写"连接规则宣言": 一页纸回答什么能连、什么不能连、为什么——位面间只有连接关系没有距离,拓扑图(节点+连线+每条线的代价与原因)先于任何故事;
2. 再给每种旅行方式开一张"代价清单"(参考上表): 每种方式收什么(物/时间/身体/债务)、失败出口是什么,写进设定文档,让角色每次穿越前明知代价仍有选择——代价要能被剧情回收;
3. 把"找钥匙"做成谜题引擎: 每扇门配一个不可转让、一次性的 key(情绪/遗物/名字/季节),key 的线索指向一段历史或一个人物——门即支线任务入口;坚持"门不认人只认条件",防止钥匙泛滥;
4. 为每个半位面定义"心锚"(创造者的心脏、誓约石、一棵树)并写明"锚毁则坍缩进星界": 锚点即弱点,给反派可攻击目标,制造"避难所随时变成坟墓"的紧张感;
5. 设计导航成长线: 一级雇引路人(向导收钱也收秘密),二级收集航图碎片(图记录"连接关系"而非地理),三级自体导航(需完成一次心灵试炼)——把"认路"做成可成长技能系统;
6. 把位面入侵写成"法则入侵"而非"军队入侵": 火元素裂缝先改变温度与地貌,军队只是后续产物;征服标志是"天空变色/植物变异/法则失效"而非旗帜——环境是第一层敌人,军队留作高潮;
7. 给位面战争一个"存在理由": 写明"若A与B停战,C必被吞噬",让战争成为宇宙平衡的一部分——停战谈判本身是顶级剧情钩子,和平比战争更危险;
8. 用门城/中继结构做文化交融点: 在门户附近建定居点,居民同时信奉两边法则,形成独特方言、货币与禁忌——中继结构不只是交通枢纽,更是位面文明的前哨与间谍温床。

## 半位面四种叙事用法

| 用法 | 锚点形式 | 剧情张力 |
|---|---|---|
| 密室(秘密议会) | 议会法印/誓约 | 封闭=安全,也=监听与围杀 |
| 时间加速训练场 | 造物者遗留核心 | 加速=账单(疯狂值/身体损耗) |
| 囚笼(封印强敌) | 牢笼钥匙/封印石 | 锚点=越狱的唯一钥匙 |
| 避难所(末日方舟) | 方舟信标 | 避难所随时变成坟墓 |

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 只画位面地图,不写连接规则 | 先写"什么能连、什么不能连、为什么"宣言,拓扑图先行 |
| 钥匙泛滥,门=免费传送 | 门不认人只认条件;key 一次性、不可转让 |
| 半位面无锚点 | 每个半位面有心锚+明确"锚毁则坍缩进星界" |
| 时间加速无代价 | 硬约束(禁食/限次/极限环境)+疯狂值账单 |
| 位面入侵写成军队入侵 | 先法则后军队,环境是第一层敌人 |
| 位面战争无存在理由 | 停战有后果,战争是宇宙减压阀 |
| 导航无成长曲线 | 引路人→航图→自体导航三级,做成可成长技能 |
