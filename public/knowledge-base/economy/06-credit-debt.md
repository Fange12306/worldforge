# 信贷、债务与金融

> 债务先于货币、利息的道德史、解负令与债务危机——信贷如何分层、奴役与重启社会。

## 核心理论/机制要点

- **债务先于货币**: 最早的经济记录是"以银计价的记账信用"——大部分交易在账簿上完成, 铸币是晚近发明; 货币本质上是可转移的债务。历史在"虚拟信用货币时代"与"金属货币时代"之间交替, 前现代以信用为主、铸币为辅。
- **债务的道德谱系**: 三种道德关系——"我欠你"(义务、等级)、"你欠我"、"我们互不相欠"(共产基线)。在人性经济中债务维系社会纽带、可减免可转化; 在商业经济中债务被量化、可转让、可收买, 债主与债务人固化为等级。战争→俘虏→人身抵押→债务奴役是一条完整转化链。
- **利息的本质与道德化**: 利息=时间价格+风险溢价+资金机会成本。古典道德观认为货币是中性不生育的, 收息等于出卖时间、出售不存在之物。宗教禁令分层:

| 禁令形态 | 规则 | 后果 |
|---|---|---|
| 只禁对"同胞"取息 | 允许对"外方人"取息 | 形成"异族放贷者"的族群分工 |
| 普世化禁令 | 一切取息皆为罪 | 放贷者被污名化, 催生变相利息 |
| 全面禁令 | 禁止一切利息 | 转而发展利润分成等替代安排 |

- **信贷的阶层分化机制**: 信贷把"信用"资本化——农民借款→歉收→复利滚雪球→失地→债务奴役; 商人却借信用扩张贸易、创造财富。核心机制=信息不对称+复利+抵押品处置权, 造成财富单向向放贷方转移、寡头化。
- **解负令(反寡头机制)**: 君主登基或灾后宣布债务注销、释放债务奴, 防止土地与人身的永久性被吞噬——债务注销的制度化存在, 恰是"债务不可废除"的反面。两次解负令之间的窗口期=权力斗争周期。
- **债务奴役作为身份制度**: 以人身为抵押的债务、妻女抵债、卖身契、债务监狱、劳役偿债; 年限与赎回条款构成制度化身份——它是角色出身、黑历史与残酷景观的现成素材。
- **债务危机的完整生命周期**: 信贷扩张→资产泡沫→触发事件(歉收/战争/君主赖账)→挤兑与违约潮→债务注销或政权崩溃→信贷重启——每个阶段都有可写的社会现象(囤地、卖儿鬻女、钱庄倒闭、义军起事)。
- **身股与合伙伦理**: 商号以"身股"(人力入股)激励掌柜, 合伙责任从无限走向有限是信任制度的深化——身股是"商人如何留住能人"的制度答案, 也是家族分裂与叛逃的剧情点。
- **债务的世代继承**: 债务可随家族延续数代——父债子偿、田产质押跨代, 使"还清债务"成为家族的世代目标, 也是仇杀与赎罪的叙事引擎。

## 机制与案例

- 神庙同时是金库与借贷中心, 以谷物(约20%利率)与白银(约33%)放贷, 借贷石板即契约; 法典限定债务奴役以3年为限; 每代王登基宣布解负令——"金融重启";
- 解负令("卸除负担"): 废除人身抵押债务、赎回被卖为奴的公民、禁止以人身为担保——防止贵族寡头化, 是公民共同体的基石;
- 罗马债务之路: 以人身为抵押的债务引发平民逃亡与骚乱; 限利率并规范债务奴役, 最终废除人身抵押; 但大地产+借贷使平民失地为佃农——缺失定期债务注销, 寡头化最终拖垮古典文明;
- 中世纪金融工具链: 修道院金库→骑士团跨境保管转账→商人银行; 关键工具**汇票**(两地货币兑换+延期支付合一, 以汇率收益隐藏利息——禁令反而催生金融创新); **刻痕木签**(国库向富商借款削木为契、刻痕记金额、一分为二各执一半、兑付合验、可转让流通); **符木**(民间赊账木牌, 最朴素的无纸票据);
- 中国原生金融: 异地汇兑凭据、钱铺信用票据演化的纸币雏形、钱庄(兑换+存款+放贷)与票号(汇兑网络、身股制度、总号-分号体系); 官府放贷以抑私贷; 违约以田宅乃至人身抵偿;
- 现代镜像: 债务积累→资产泡沫→违约/注销之争——机制不变, 为虚构世界提供"债务危机周期"模板。

## 构建操作

1. 先做"记账货币先行": 不必让新世界一上来就有硬币——设定神庙/商会/领主以谷物或银为单位的"账簿信用", 普通人财富是账上数字, 铸币反而是晚期国家行为; 把"债务文书"(承兑票据/刻痕木签/赊账牌)设为通用支付手段, 其可否"背书转让"即金融发达度标志, 可直观画出贸易路线的信用网络;
2. 用禁令塑造金融生态位: 若世界有"禁止对同族取息"的教条, 会自动生成"异族放贷者"——族群冲突与阴谋论的天然叙事装置; 商人发明变相利息(汇率差价/罚金条款/利润分成)绕禁, 这些复杂金融文本是"金融家族"的业务机密与传家宝;
3. 把解负令做成政治引擎: 设定王权登基/灾后/圣日宣布"债务注销"——王权(收买平民)与放贷寡头(废除注销、吞并土地)的世纪斗争主轴; 两次解负令之间的窗口期=权力斗争周期, 朝臣密谋、金融家族囤地、农民暴动都挂在这条时间线上;
4. 设计债务奴役身份制度: 设定"以人身为抵押"及其年限(3年/7年/直到还清)与赎回条款; 妻女抵债、卖身契、债务监狱、劳役偿债——既是角色出身与黑历史素材, 也是残酷景观;
5. 用利率画社会地图: 给不同对象定利率(神庙贷20%/商人月息/当铺"九出十三归"), 谁借得起、谁被吞噬一目了然; 复利的时间尺度决定"失地周期"——据此设计家族几代内兴衰、土地易主的节奏;
6. 让金融家族与政权联姻: 设计"包税人/财政承包"——领主把税收外包给家族, 家族预支现金收取高额回报, 换得征税暴力与情报网; 或仿国库木签——国家向富商借款打白条, 票据流通市面成准货币; 家族权力来自"掌握国家的负债表", 也埋下"国家赖账"的危机引信;
7. 把债务危机周期化: 每50~100年安排一次违约潮→挤兑→钱庄票号倒闭→土地抛售→变革或内战——危机既是世界动荡引擎, 也是主角抄底、清算、拯救、复仇的介入窗口;
8. 给债务以道德与超自然重量: 借贷契约写成仪式对象(刻契、证人、神明见证、违约诅咒); 若有神学, 设定"神圣债务"(欠神之账)与世俗债务的兑换规则——赎罪券、神庙赎罪贷都是现成情节装置;
9. 建立"债务档案"作为剧情数据库: 为重要家族/角色各写一张负债表(欠谁/利率/抵押物/到期日), 债务到期即事件触发器;
10. 设计"赖账-追债"的暴力光谱: 从口头催讨到拘押、抄家、卖身为奴——追债手段的烈度本身就是社会底线与人物道德的表尺;
11. 定义"可抵押之物"的谱系: 从田地、房产到妻女、自由身——抵押物的层级即社会尊严的层级, 抵押品被夺走的顺序就是角色坠落的路径;
12. 设计"债务的世代线": 为 1~2 个家族写三代负债史(祖父借地→父辈滚利→子孙卖身), 让债务成为家族史的主轴。

## 检查点/清单

- [ ] 账簿信用/记账货币先于铸币存在;
- [ ] 债务文书的可流通性(背书转让)已定义, 信用网络可画;
- [ ] 利息禁令与变相利息机制存在, 无"合法高利贷"悖论;
- [ ] 解负令时间线与政治斗争窗口期已定;
- [ ] 债务奴役的年限与赎回条款明确;
- [ ] 利率按对象分层, 失地周期可推演;
- [ ] 包税/国家负债机制存在, 赖账引信埋好;
- [ ] 50~100年债务危机周期已排入历史表;
- [ ] 债务危机生命周期(扩张→泡沫→违约→注销)的阶段现象已写;
- [ ] 债务具有仪式与(如适用)神学重量;
- [ ] 至少一个家族有跨代债务线。
