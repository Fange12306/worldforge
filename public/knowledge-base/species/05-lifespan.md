# 寿命、繁殖与生命周期

> 目的: 用生活史理论把寿命、繁殖与死亡观念做成文明节奏的引擎——先算代际数, 再定技术迭代速率; 先问"怎么生孩子", 再定家庭与社会骨架。
> 前置: 输入环境稳定性与灾变频率(决定 r/K 倾向); 输出社会结构、技术树、宗教与历法。

## 核心理论

- **生活史权衡**: 生物把有限能量在"生长—维持—繁殖"间分配, 形成协变特征(寿命/性成熟年龄/窝仔数/亲代投入)。核心是**权衡**: 长寿必然以低繁殖率、慢发育为代价, 反之亦然。r-策略者(短命、多产、少投入)与 K-策略者(长寿、少产、高投入)是光谱两端; 人类属极端 K 端。
- **衰老是选择压力随年龄递减的副产品**: 衰老不是磨损, 而是三条机制叠加——①晚年才表达的有害突变不被选择清除(突变积累); ②早年起作用的有利基因若在晚年有害仍会被保留(拮抗多效); ③体细胞修复的投入只够撑到繁殖窗口结束(可抛弃体细胞)。推论: **自然选择不"需要"老年, 衰老是繁殖期的附属品**。
- **代际间隔是文明演化的"时钟"**: 文化演化快于生物演化, 但每一代人的更新换代仍是技术迭代的时钟——知识传递、范式更替都按"世代"发生。代际间隔越长, 单位时间换代次数越少; 年龄结构老化会拖慢社会学习与创新。
- **亲代投资决定择偶与分工**: 两性中投入更多的一方成为"限制性资源", 择偶竞争集中于投入少的一方; 由此推出性别二态、求偶炫耀、一夫多妻等形态——**繁殖模式直接塑造家庭、性别与劳动分工**。亲代与子代的利益分歧(亲代-子代冲突)解释代际矛盾。
- **死亡意识是文化强度的引擎**: 死亡意识被压入潜意识后, 文化世界观(宗教/民族/荣誉)与自尊用于缓冲对死亡的恐惧; 死亡突显会加剧内群体偏好、排外与对异见者的攻击。对死亡的态度不是观念点缀, 而是文化强度的引擎。
- **死亡态度有历史形态谱系**: ①被驯服的死亡(死亡是公共仪式); ②自我的死亡(个体戏剧化); ③他人的死亡(浪漫化哀悼); ④被禁止的死亡(医疗化、隐匿、否认——死亡被藏起来如性一般)。
- **长寿与迭代的张力**: 个体经验累积(记忆型文明) vs 世代更替的快速试错(迭代型文明)存在根本矛盾; 长者占据权力会锁死制度(老人政治), 指向"文化冻结"风险。

## 寿命×繁殖→社会形态速查表

| 生活史配置 | 社会/文化后果 | 典型写法 |
|---|---|---|
| 长寿+低生育+高投入(K端) | 文化积累深、创新慢、家族/系谱记忆发达 | 精灵式: 万年不变、工艺百年如一日 |
| 短寿+高生育(r端) | 文化快速翻新、遗忘即宽容、战争频繁而生命廉价 | 鼠人式: 一代人发明新武器 |
| 永生 | 权力财富冻结、冒险偏好下降、历史包袱过载 | 反乌托邦: 文化冻结、新人无上升通道 |
| 单性生殖/克隆繁殖 | 谱系即克隆系、无性别分工、用"型/阶"替代性别 | 工蜂/兵蚁式阶层=劳动分工的物种化 |
| 半生殖策略(一生只繁殖一次即死) | "大繁殖潮=全民死亡节"人口周期 | 鲑鱼式: 震撼性文化仪式 |
| 社会角色决定寿命(蜂后vs工蜂) | 同一基因组寿命悬殊, 寿命是角色而非基因 | 工蜂型短命族群 |

## 构建操作

1. 先算"代际数", 再定技术节奏: 用"寿命÷成熟年龄=代际数"为文明设钟——人类千年约 120 代, 若精灵千年仅 10 代, 其工艺水平应百年如一日; 若鼠人 1 岁成熟, 一代人即可发明新武器; 让技术树与代际数严格挂钩;
2. 长寿必须有生物学代价: 长寿命种族应低生育、长童年、高亲代投入、代谢慢(K 端); 反过来设定"永生靠透支繁殖或免疫"。避免"永生且多子且强壮"——至少设计一个明确权衡(如精灵人口近乎零增长, 每子皆是奇迹);
3. 让繁殖模式决定社会骨架: 有性+投入不对称→性别分工与婚制; 单性/多型繁殖→用"型/阶"替代性别; 群繁殖→家庭退位、巢穴政治。设定"家庭长什么样"前先问"他们怎么生孩子";
4. 用寿命差制造冲突机制: 短命种族靠换代快速迭代(但忘性大、重犯历史错误); 长命种族靠记忆稳健(但保守、卡在旧怨中千年不忘——把"千年世仇"写得合理); 永生者政权可用"思想定期强制更新""长老轮流休眠"等机制防止文化冻结;
5. 让死亡观念与寿命挂钩: 短命族——死亡日常、哀悼从简、祖先崇拜弱、文化快餐化; 长命族——系谱记忆=政治资源、葬礼纪念碑化、临终仪式成为专业宗教; 永生族——死亡禁忌化或"死亡=罪"。让每个种族的宗教、建筑、历法都从"怎么看待死"导出;
6. 利用"繁殖后生命"阶段: 借鉴祖母假说——绝经后老人作为知识库与保姆是社会支柱(解释为何社会尊敬老人); 或设定半生殖策略→"大繁殖潮=全民死亡节", 作震撼性文化仪式与人口周期;
6b. 把长童年+长寿写成对"学习型大脑"的投资: 长寿与知识经济互为因果——设定"学得越多活得越久"或"传承即增殖"的制度(长童年是为了装下更大的知识库, 长寿是为了回收这笔投资);
7. 用人口周期驱动历史: r 策略种族 boom-bust, 饥荒/战争随人口潮汐周期性爆发; K 策略种族人口长期稳定, 战争稀有但一旦爆发即为灭族级。把"人口学"写进国策, 避免战争动机空洞化;
8. 用死亡突显塑造文化强度: 越是死亡风险高的社会(短命/战乱), 宗教、荣誉、排外越强烈; 永生者的文化反而世俗化、宽容而倦怠。用死亡焦虑的强度解释各文明"信仰浓度"的差异。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 永生+多子+强壮全拉满 | 至少一个明确权衡(低生育/长童年/代谢慢) |
| 技术节奏与代际数脱节 | 技术树严格按"寿命÷成熟年龄"设钟 |
| 家庭形态凭空设定 | 先问繁殖模式, 再推导家庭/性别/分工 |
| 千年世仇无机制 | 长命种记忆稳健、旧怨千年不忘天然合理 |
| 死亡观念与寿命无关 | 宗教/建筑/历法从"怎么看待死"导出 |
| 战争动机空洞 | 人口周期与繁殖竞争入国策 |
| 老人政治无解 | 用强制更新/轮流休眠等机制防文化冻结 |

## 检查点/清单

- [ ] 每个种族算过代际数(寿命÷成熟年龄)并据此定技术节奏?
- [ ] 长寿种族有明确生物学代价(低生育/长童年/高投入/代谢慢)?
- [ ] 家庭/性别/劳动分工由繁殖模式推导?
- [ ] 寿命差被用作跨种族冲突机制(世仇/贴现率/骗局)?
- [ ] 死亡观念与寿命挂钩, 宗教/建筑/历法可溯源?
- [ ] "繁殖后生命"阶段(老年照料/半生殖策略)被利用?
- [ ] 人口周期已写入历史与战争动机?
- [ ] 死亡突显强度解释了各文明"信仰浓度"差异?
