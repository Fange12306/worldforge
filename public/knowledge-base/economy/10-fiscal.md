# 财政与国家

> 财政-军事循环、专断权力与基础性权力、税制与利益集团、包税卖官、财政危机与可信承诺——国家的骨架是预算。

## 核心机制

### 1. 财政-军事循环(国家形成引擎)

"战争造就国家, 国家反过来发动战争"。循环链条:

```
战争 → 需要钱 → 强化征税 → 征税机构扩张与官僚化 → 更高效榨取 → 更大战争
```

临时性"战争税"反复征收后沉淀为制度化常设财政——**国家组织本身是财政压力的产物**。政权可按循环阶段标注: 初建(临时战争税)→制度化(常设税署、清丈田亩)→榨取过度(加派)→崩溃/改革。

### 2. 专断权力 vs 基础性权力(2×2 矩阵)

| | 基础性权力低 | 基础性权力高 |
|---|---|---|
| **专断权力低** | 失败国家(收不上税、将军拥兵自重) | 渗透型代议国(能征税、能动员) |
| **专断权力高** | 纸面帝国(政令不出京城) | 极权渗透国(全民征兵、普查、高效征管) |

关键洞见: **"强国家"≠"专制国家"**。许多前现代帝国看起来专断, 实际基础性权力极弱; 民主政体专断权力低但基础性权力高, 财政能力反而更强。这解释了为何同样"强大"的政权财政能力天差地别。

### 3. 统治者是"受约束的岁入最大化者"

征税能力受三条约束:

1. **臣民的谈判能力**: 谁掌握资源、能否退出或反抗(可迁走/可抗税即谈判筹码);
2. **征管的交易成本**: 清丈、登记、监督成本(基础性权力不足则收不上税);
3. **统治者的贴现率**: 面临战争威胁、地位不稳者更短视、更掠夺。

**准自愿服从**: 纳税人并非单纯被强制才缴税, 而是在"税收大体公平+相信他人也在缴+国家提供可感知公共品"时自愿服从, 强制只威慑搭便车者。**税制可持续性取决于合法性, 不只是暴力。**

### 4. 税制类型与利益集团

| 税基 | 征管特点 | 打击对象 | 政治后果 |
|---|---|---|---|
| 土地税 | 需清丈田亩, 成本高 | 地主 | 地主士绅隐匿田亩、抗税 |
| 人头税 | 征管最简单 | 平民 | 累退不公, 极易引爆平民暴动 |
| 关税/贸易税 | 口岸征收, 成本低、隐蔽 | 商人 | 商人集团与国家冲突或勾结 |
| 专卖/垄断 | 盐铁酒茶国家垄断 | 消费者+民间商 | 官商共同体, 巨大寻租空间 |
| 包税 | 拍卖征税权给私人 | 纳税人 | 包税商豪门, 超额榨取 |

**写清楚"谁免税、谁逃税、谁暴动"**, 税制不公直接作为宫廷阴谋与民变的剧情燃料。

### 5. 包税制、卖官鬻爵与实物税

- **包税制**: 征税权拍卖给私人包税人, 预付现金、自负盈亏超额征收。优点: 立即得现金、免官僚征管; 代价: 超额榨取、腐败、中央丧失对收入直接控制——包税人逐渐成为地方实力派, 中央财政能力随包税化衰退;
- **卖官鬻爵**: 出售官职与爵位融资, 官职可继承、官僚系统被私有化, 形成靠"投资—回报"逻辑运作的寄生集团;
- **实物税**: 征收粮食布帛, 伴随运输损耗、仓储腐败、折色换算纠纷, 天然抑制商业化。

### 6. 财政危机与政权更替

"预算即国家的骨架", 财政危机是最经典的政权更替触发器:

- **加派/增税** → 抗税暴动;
- **主权债务违约** → 摧毁信贷与精英联盟;
- **战争失败** → 暴露财政脆弱;
- 最致命的是**财政能力危机**: 收不上税 + 借不到钱 + 发不出军饷 = 政权空心化。

### 7. 可信承诺: 有约束的政府更有信用

统治者反复赖账(强制借款、没收、贬值铸币) → 债权人理性预期违约 → 国债利率极高、金融市场萎缩。当议会控制税收与支出、限制专断没收权, 统治者**自我约束**作出可信承诺, 利率大幅下降、国债市场与中央银行兴起。结论: 制度约束→低贴现率→强财政-军事能力。约束形式不必是议会: 以特定收入抵押还债、债权人委员会、央行独立皆可。

## 构建操作

1. 用财政-军事循环作世界引擎: 为每个政权定义外部军事压力源(邻国/蛮族/海寇/恶魔入侵), 用它驱动财政需求, 再让财政需求推动官僚化与税制演化, 并标注各政权所处循环阶段;
2. 用专断×基础双权力矩阵为政权画像, 四象限各写一个代表政权——"政令不出京城的纸面帝国"与"渗透型代议国"并存, 剧情可信度立增;
3. 为每个政权从土地税/人头税/关税/专卖/包税中选2–3种主干税基, 每种税绑定一个政治势力, 写清"谁免税、谁逃税、谁暴动";
4. 设计"准自愿服从"合法性账本: 围绕四个触发器做文章——战败加派、新征不公之税、赈灾/修渠缺位、权贵逃税曝光, 触发其一即可能引发抗税、拒纳粮、罢市;
5. 把包税商、捐纳官员、漕运粮道做成叙事装置: 超额榨取与民怨、官职买卖市场、仓储亏空与账目造假、"国库为何没钱"的谜题; 设计总包税人/税监/漕运总督等"财政触手"角色;
6. 若世界存在国债或银行业, 必须设计约束统治者的制度(议会批税、专款抵押、债权人委员会、央行), 否则按理性预期, 赖账名声会让利率飙升、战争融资失败; 可写完整弧线: 赖账→债市崩溃→商人联盟政变→新宪章→利率下降→财政复兴;
7. 为每个政权埋2–3个财政危机节点(战争加派、铸币贬值、工程透支、包税商暴利、灾年赈济缺口、军饷拖欠), 每个节点都是政权更替触发器;
8. 用"税收货币化程度"标记现代化进程: 实物税转货币税(折色改革)重塑权力——削弱实物地主、利好商人、推动市场扩张, 但使农民暴露于粮价波动; 在世界时间轴上标各文明"货币化指数"。

## 检查点/清单

- [ ] 每个政权有外部压力源、财政需求与循环阶段标注
- [ ] 双权力矩阵四象限各政权齐备, 且与叙事能力(征兵/普查/征管)一致
- [ ] 税制组合明确, 每种税有对应利益集团与冲突剧本
- [ ] 合法性账本的四个触发器各配了一个可触发事件
- [ ] 包税/卖官/实物税的腐败链条与角色已设计
- [ ] 有金融/国债设定的政权必有约束制度与违约史
- [ ] 财政危机节点已排入时间线, 且通向政权更替或改革分岔
- [ ] 货币化指数与各文明的财政-军事能力、商人地位一致
