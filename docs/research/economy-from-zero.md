# 经济体系: 从0到1构建虚构世界的经济 — 完整研究手册

> **目的**: 给定世界的地理资源底图与文明档案, 按本手册从"定位与总流程"出发, 依次完成整合模式与生计、货币与价格、信贷与商业组织与贸易、经济地理、财政、周期与增长转型、超自然经济八个环节, 构建自洽、可推演、可叙事的虚构世界经济体系。
> **范围**: 经济人类学与嵌入性、生计与生产、货币、价格与市场、信贷债务金融、商业组织与商人阶层、贸易网络与世界体系、经济地理与区位、财政与国家、经济周期与人口动态、增长停滞与转型、超自然经济接口(与地理/文明/历史/法则篇衔接)。
> **用法**: 每步含 [输入] → [操作] → [决策规则] → [输出产物] → [检查点]。13 个主题的详细研究笔记见 `docs/research/notes/`(70-82, 前缀 economy-)。
> **贯穿示例**: 内嵌示例世界「米拉斯」经济篇——神权城邦灵枢城 × 航海共和国潮邦 × 风语游牧三套整合模式并存, 41 年血月周期作为经济节拍器, 灵脉施法成本作为超自然经济锚点。

# 第一部分: 执行流程

## 第 0 步: 定位与总流程——先定立场, 再定依赖链

**[输入]** 地理资源底图(可耕地/矿脉/河流/气候带/灵脉等特殊资源)+ 文明档案(政体/宗教/人口/技术)。

**[操作]**
1. **定理论立场**: 默认采用**实体主义/嵌入性**视角——经济嵌于血缘、宗教、等级与权力, "理性最大化的自由市场"是 19 世纪英格兰的历史特例而非人类通则; 为每个文明标注"嵌入程度"(Polanyi vs Granovetter 之间取连续值)。
2. **固定依赖顺序**: 地理资源 → 农业产出与人口上限(马尔萨斯检验)→ 分工与剩余 → 流通与货币 → 财政与政体。前序模块定稿后不得被后序反向推翻; 经济档案应记录依赖链的反向引用(如"此货币依赖北部银矿, 银矿枯竭则体系崩溃")。
3. **建三层账本**(布罗代尔): 底层物质生活(自给村庄、实物税)、中层市场经济(市集、铸币、行会)、顶层资本主义(远程贸易、银行、汇票、垄断)。三层各自回答"钱从哪来", 并设计层间通道(商人、包税人、贵族投资)。
4. **跑两个硬检查点**: ①能量检查——食物热量总产出 ≥ 设定人口所需(前现代约 75-90% 人口务农, 城市率 ≈ 农业剩余率); ②运输检查——陆运成本约为水运 5-20 倍, 远程贸易只能是高价值低运量商品, 否则"千里运粮""全境统一物价"类设定失真。
5. **写"反现代主义"自检表**: 金币无来源? 物价永远静止? 无农业人口? 无运输成本? 全市场社会? 每项都是高危错误。

**[决策规则]**
- 经济 = 嵌入社会关系的制度化过程, 不是独立运转的机器;
- 每个政权先"定调"整合模式, 再谈细节(帝国≠市场社会);
- 魔法的存在必须同时设计成本锚点(法力/材料/冷却/寿命代价), 否则价格体系整体坍缩;
- 政体-财政接口: 军队可维持人数 = 剩余提取率 × 农业产出 − 行政损耗。

**[输出产物]** `经济定位书`(理论立场 + 依赖链 + 三层账本 + 两大检查点结果 + 自检表)。

**[检查点]** 依赖顺序无循环引用; 能量与运输两关通过; 每个文明有明确整合模式定位; 魔法资源与地理矿脉同等对待。

## 第 1 步: 定整合模式与生计基础

**[输入]** 经济定位书 + 地理篇的生计资源分区(平原/草原/荒漠/海岸/高原)。

**[操作]**
1. **为每个文明定"整合模式配方"**(Polanyi 三模式): 部落氏族=互惠主导; 帝国/神庙王国=再分配主导(贡赋+国库仓储+徭役); 商业城邦=市场主导(但受行会与宗教节日节律约束)。各配一个边缘模式(帝国边陲走私市场、部落间库拉式仪式交换)。
2. **用互惠谱系画"社会距离地图"**(Sahlins): 亲属=概化互惠(无账目), 熟人=均衡互惠(礼尚往来、债务记录), 陌生人=负互惠或市场; 设置"陌生人界线"(族外交易区/禁婚区/港口自由区), 规则在此突变, 人物跨线即冲突。
3. **按生计模式分别写"经济性格"**: 狩猎采集=低欲望、短工时、强互惠、反积累(原初丰裕, 剩余以仪式消耗); 农业=延迟回报、产权焦虑、储藏与借贷; 畜牧=牲畜即活储蓄、不可储存、周期性劫掠——与农业社会构成"双生关系"(季节贸易集市+贡-掠交替外交); 手工业=依赖他人剩余, 最脆弱。
4. **先定"粮食剩余率"再定世界规模**: 农业人口 90%/75%/60% 分别推导城市率上限与脱农职业种类; 任何"超大规模文明"必须先解释粮食从哪来(90% 的世界只有零星小城与兼职工匠, 60% 的世界才能养常备军、专业商人、学者与纪念建筑)。
5. **用 Chayanov 家庭经济学驱动农户叙事**: 农户"干到够用即停"(劳动-消费均衡), 劳动强度随家庭抚养比波动; 税收/物价的微小变动会把自给户推入市场或推向破产——冲突与叛乱的微观引擎。
6. **构建声誉经济/声望品体系**(库拉/夸富宴/莫卡三变体): 设计不可兑换为生计品的贵重物, 权力 = 能欠多少债 + 能办多大的宴; 禁止声望品与食物互兑, 让"贵族破产"与"暴发户买爵"成为可书写的堕落事件。
7. **把再分配机器做成可运营设施**(印加 qolqa/美索不达米亚神庙模板): 粮仓、配给册、劳役轮值、书吏阶层——用具体流程(征粮-仓储-节日发放)让经济可见; 设定"再分配失灵"触发机制(旱灾/书吏腐败/酋长吝啬)→ 道义经济起义(Scott)。
8. **设定交换领域隔离的禁忌法**(Tiv 模式): 明文规定"哪些不可买卖"(人、荣誉、神圣物、土地)及违者后果(神罚/放逐/战争), 用法律/宗教文本形式呈现。
9. **用 Boserup 设计技术史与政治史**: 人口增长强制刀耕火种走向精耕; 决定点在强化后是"勤劳革命"(人均产出上升)还是"过密化"(人均停滞, 明清模板)——两类文明气质截然不同。

**[决策规则]**
- 三模式非进化阶段而是可共存类型——真实社会多为混合配置;
- 市场制度是需要历史条件支撑的稀罕物, 不要默认所有文明有市场;
- 剩余率低不是无能, 可能是社会选择的稳态(反积累);
- 强化(Boserup)不等于繁荣; 单位土地产量与单位劳动产量是两套相反指标。

**[输出产物]** `整合模式地图`(每文明配方+社会距离地图+禁忌清单)+ `生计台账`(每区生计模式/剩余率/城市率上限/经济性格)。

**[检查点]** 相邻文明模式不同且冲突可预演; 声望品与生计品不可互兑; 再分配失灵有明确触发器; 人口上限与剩余率对得上; 自给:市场比例决定社会性格。

## 第 2 步: 设计货币与价格

**[输入]** 整合模式地图 + 贵金属/盐/特殊资源分布(地理篇)。

**[操作]**
1. **先定"记账单位", 再定"钱长什么样"**: 设计虚拟算账基准(银马克/祭司筹码/盐石), 日常用铜币/贝壳/粮票结算, 大额用记账与债务凭据——记账单位可先于铸币存在(Polanyi), 也制造"算账与实付不一致"的戏剧空间。
2. **分层设计三档货币**(Bhatia 金字塔): 日常层(小面额金属币/实物凭证, 易得、信用弱)、大额层(银锭/金币/汇票/商人票据, 依赖商号或国家信用)、高端储备层(国库金属/神庙金库/土地珍宝)。层间设定兑换摩擦与汇率——上层稀缺、下层通胀, 成为政权危机伏笔。
3. **用"税收资格"锚定货币信用**(Knapp/Lerner 国家货币说): 王廷宣布"税赋、罚金、诉讼费只收御铸货币"——比"国王印钱大家就用"更符合历史机制, 自然引出"为什么民间接受这种币"; 多政权并存时设计多税币兑换混乱。
4. **明确铸币权归属**: 谁铸、纯度、贬值史; 铸币图案=意识形态战场; 诸侯私铸、伪币、"重铸新币"(1696 大重铸模板)作为关键历史事件。
5. **设计特殊用途货币**(Tiv/Polanyi): 新娘财富、赎罪金、献祭、贡赋的专用物品, 规定领域间不可兑换——财富无法跨领域变现本身就是权力结构。
6. **建双轨价格引擎**(阿奎那公平价格/官方限价): 同时维护"官方牌价"(市政公告、每周重算的面包令)与"真实市场价"两条数据线; 缺口越大, 走私、囤积、行贿越猖獗, 越需要"黑市联络人"角色。
7. **粮价剧情引擎参数化**(森/汤普森): 按低需求弹性设换算表(歉收 10% → 涨价 20-40%, 弹性 -2~-4); 每季按"收成骰子"推粮价 → 面包价 → 工资 → 饥荒阈值 → 暴动/移民/卖儿鬻女。
8. **一价定律当"套利竞速"玩法**: 两地价差 = 距离 × 运输费率 + 过路费 + 信息时滞(驿马/帆船/信鸽速度); 价格信息即财富, 可设统治者以禁令垄断粮价信息(达蒂尼书信=早期"电报")。
9. **用"货币短缺"作叙事引擎**(Munro bullion famine): 矿山枯竭/贵金属外流 → 白银荒 → 民间代币、实物折纳、以物易物回归、汇票盛行、物价兵饷崩溃。

**[决策规则]**
- 前现代经济信用为主、铸币为辅(Graeber: 物物交换是"野蛮的虚构");
- 货币贬值与债务危机是天然的历史转折触发器;
- 限价管制制造短缺, 短缺催生黑市(戴克里先《最高价格敕令》/法国 1793 限价令的反噬弧线);
- 道德经济学: 粮价突破"道德阈值"时, 暴动者自认在执法而非作乱(汤普森)。

**[输出产物]** `货币三件套档案`(贵金属来源与矿权/铸币权与贬值史/信用层)+ `价格数据线`(官方牌价 × 市场价)+ `丰歉-粮价换算表`。

**[检查点]** 货币有来源、有发行者、有兑换摩擦; 税收资格解释了货币需求; 限价必然伴随黑市; 粮价弹性表可推演完整饥荒链。

## 第 3 步: 设计信贷、商业组织与贸易网络

**[输入]** 货币档案 + 政体类型(文明篇)+ 主要地理通道(地峡/海峡/河流/山口)。

**[操作]**
1. **记账货币先行**: 神庙/商会/领主以谷物或银为单位开"账簿信用", 普通人财富是账上数字; 债务文书(承兑票据/刻痕木签 tally/赊账牌符木)设为通用支付手段, 可否"背书转让"即金融发达度标志。
2. **用禁令塑造金融生态位**: 设定"禁止对同族取息"的教条 → 自动生成"异族放贷者"(犹太-基督教史上外邦人放贷的对应物); 商人发明变相利息(汇率差价/罚金条款/利润分成 mudaraba/commenda)绕禁——这些复杂金融文本就是金融家族的传家宝。
3. **解负令作为政治引擎**(Hudson): 王权登基/灾后/圣日宣布债务注销+释放债务奴(美索不达米亚 misharum/圣经禧年模板)——王权(收买平民)vs 放贷寡头(吞并土地)的世纪斗争主轴; 两次解负令之间的窗口期即权力斗争周期。
4. **债务奴役作为身份制度**: 以人身为抵押(nexum 式)+年限(3 年/7 年/直到还清)+赎回条款; 妻女抵债、卖身契、债务监狱、劳役偿债——既是角色出身素材, 也是残酷景观。
5. **设计"组织进步树"**: 单人商贩 → 家族合伙(compagnia, 无限责任)→ 康孟达(出资与经营分离, 海上贸易解锁)→ 有限合伙 → 股份公司 → 特许公司(战争与治理)。每次升级对应新的风险分配规则与新的剧情张力。
6. **给每个城市配"行会政治"**: 3-5 个主要行会(毛纺/金融汇兑/造船/香料/军械), 各设准入门槛(学徒-工匠-大师三级+杰作考核)、垄断范围、守护圣徒与徽章; 城市议会席位按行会分配(中世纪城市=行会的联盟)——行会战争即剧情(佛罗伦萨 Ciompi 起义模板)。
7. **用"声誉-制度"双轨设计跨城商网**(Greif): 一个靠内部通报+集体惩罚(违约者被全网络排斥, 马格里布商团/晋商票号), 一个靠公证人+合同+法院(热那亚路径); 两网交汇城市制造制度冲突, 账本/密码/暗语/汇票作剧情道具。
8. **把"特许状"做成核心争夺物**: 君主以垄断权交换贷款与税收(汉萨城市特权/东印度公司特许状); 商人向君主放贷, 君主赖账引发金融风暴(富格尔家族/西班牙 1557/1575/1596 国家破产); 特许公司可拥有军队与铸币权——商战自动升级为微型国家冲突(VOC/EIC 模板)。
9. **画商路与转口港**: 四大商路类型(绿洲陆路/季风海路/跨沙黄金-盐之路/同盟水路)+ 马六甲式转口港与商站(kontor); 节点即权力——控制节点者拥有收税、定价、发通行证权; 自由港免税 vs 垄断特许是城市内部政争议题。
10. **标世界体系位置**(布罗代尔/沃勒斯坦): 为每区域标"核心/半边缘/边缘", 用资源禀赋+运输成本+技术差距解释; 设计贸易战升级阶梯: 关税 → 禁运 → 护航 → 私掠 → 全面战争(航海法案/英荷战争模板), 走私者与中立国转口作灰色缓冲带。

**[决策规则]**
- 债务是道德关系也是权力工具——量化、可转让的债务把债主与债务人固化为等级(Graeber);
- 金融工具史 = 禁令与规避的军备竞赛(de Roover);
- 商路走向 = 权力走向, 反之亦然——商路变迁改写城市兴衰(汉萨 vs 荷兰);
- 奢侈品(高值低量)与大宗商品(低值高量)双轨物流, 控制者不同(海军强国 vs 内陆帝国)。

**[输出产物]** `金融地图`(记账信用网络/解负令日历/债务奴役法条)+ `商业组织树`(行会/康孟达/特许公司)+ `商路图`(节点/成本/关税/走私线)+ `世界体系标图`(核心-半边缘-边缘+霸权候选)。

**[检查点]** 每种债务工具都有发行者与可转让性; 行会垄断与政权关系明确; 商路成本符合运输检查点; 核心-边缘梯度可由禀赋+成本解释; 贸易战有升级阶梯。

## 第 4 步: 设计经济地理与区位

**[输入]** 商路图 + 地形/水文/气候底图(地理篇)。

**[操作]**
1. **先画"吨-里成本"地图, 再放城市**: 河/海运费 = 1, 陆运 = 10-20; 城市优先出现在河口、江河交汇、可航河段末端、换装点; 无水道的大陆腹地只有低等级聚落, 只有高值货物(丝绸/香料/盐)能走通长途陆路。
2. **每座大城市周围画杜能圈**(冯·杜能): 城郊菜园/鲜奶(易腐、单位价值高)→ 林地(笨重)→ 轮作谷物 → 三圃制 → 牧场(牲畜自行走向市场)→ 荒野; 沿大河拉长圈层、被山脉沼泽打断; 被切断补给线的围城是绝佳戏剧场景。
3. **用中心地等级铺聚落**(克里斯塔勒): 先定 K 值(和平商路区 K=3 市场原则/交通区 K=4, 封建割据区 K=7 行政原则); 集市镇间距 ≈ 一日行程(按世界速度设定); 每级中心地配"服务清单"(铁匠/磨坊 → 商会/铸币厂 → 大学/大教堂); 廖什修正: 资源分布不均时出现城市密集带与空带。
4. **把稀缺资源放在"异乡"**: 盐、铁、锡、良木、战马、渔场分布不均 → 天然产生贸易线与冲突线; 仿盐铁专卖设计"帝国垄断品"(《盐铁论》模板)——财政来源+战争导火索; 资源城(矿城/盐都/渔港)可偏离六边形体系。
5. **用卡口定义边界与城市**: 关隘、渡口、瀑布转船点、绿洲即税卡与军镇; 渡口两岸常成对出现"双子城"(征税与驻军分治); 山口两侧分属不同势力时, 商税分成协议与走私路线即剧情燃料。
6. **让政治中心与经济中心分离**: 首都选在易守难攻处, 最大贸易港在水运枢纽, 两者之间靠运河/漕运维持(北京-京杭大运河模式); "首都粮食危机"即长期矛盾点。
7. **按区位定工业**(韦伯): 失重原料(2 吨矿出 1 吨铁)使工厂倾向原料地; 增重/遍在原料使工厂倾向市场; 当劳动力节省额 > 偏离运输最优点的运费增加时, 工厂偏离(等运费线分析)。
8. **安排一次交通技术变迁重写地图**: 开凿运河、铺设铁路或引入魔法传送 → 旧枢纽衰落、新城崛起(大运河之于北京、铁路之于 19 世纪美国), 制造"昨日繁华区/今日新兴区"的层级变迁。

**[决策规则]**
- 城市实力 ≈ 其可达腹地的规模与富庶度(港口-城市-腹地);
- 区位地租 = 售价 − 生产成本 − 运输成本, 随距市场距离递减, 出价最高者占据最近圈层(bid-rent);
- 首都位置 ≠ 经济最优, 往往需要工程维持补给线;
- 交通网络演化有时序: 港口先兴、内陆枢纽后起(Taaffe-Morrill-Gould 模型)。

**[输出产物]** `吨-里成本图` + `杜能圈图层`(每大城市)+ `中心地等级表`(门槛人口/服务范围/服务清单)+ `资源-卡口-城市对照表`。

**[检查点]** 每座重要城市都有区位成因(中转点/卡口/资源地/腹地); 中心地等级与人口密度匹配; 首都补给线有明确工程依赖; 稀缺资源分布产生真实贸易流向。

## 第 5 步: 设计财政与国家

**[输入]** 政体档案(文明篇)+ 税基资源分布 + 军事压力源(邻国/蛮族/海寇/恶魔入侵)。

**[操作]**
1. **用"财政-军事循环"作为世界引擎**(Tilly): 外部军事压力 → 财政需求 → 官僚化与税制演化 → 更高效榨取支撑更大战争; 为每政权标注循环阶段: 初建(临时战争税)→ 制度化(常设税署/清丈田亩)→ 榨取过度(加派)→ 崩溃/改革。
2. **用 Mann 双权力矩阵为政权画像**: 标专断权力(不经协商强加意志)与基础性权力(渗透社会贯彻政策)的高低——"强国家"≠"专制国家"; 政令不出京城的纸面帝国(专断高、基础低)vs 渗透型代议国(专断低、基础高)vs 极权渗透国(双高)vs 失败国家(双低)。
3. **为每政权设计税制组合并绑定利益集团**(列维): 土地税→地主士绅的隐匿抗税; 人头税→平民暴动引信; 关税/商税→商人集团与口岸城市; 专卖→官商垄断家族; 包税→包税商豪门。写清"谁免税、谁逃税、谁暴动"。
4. **设计"准自愿服从"的合法性账本**: 税收可持续取决于①公平感知 ②相信他人也在缴 ③国家提供可感知公共品; 四个触发器: 战败加派、新征不公之税、赈灾/修渠缺位、权贵逃税曝光——触发其一即抗税运动/拒绝纳粮/城市罢市。
5. **把包税制与卖官鬻爵做成叙事装置**: 总包税人(奥斯曼 iltizam/malikane、法国 ferme générale、宋元扑买)、捐纳官员(法国 paulette 官职世袭化/清代捐纳)、漕运总督——超额榨取、官职买卖市场、仓储亏空、"国库为何没钱"的谜题。
6. **用可信承诺机制设计国债线**(North & Weingast): 若要国债, 必须设计约束统治者的制度(议会批税/特定收入抵押如盐税专款/债权人委员会/央行); 否则按理性预期, 赖账名声使利率飙升、战争融资失败(光荣革命前 10% → 革命后 3-4% 模板)。完整弧线: 国王赖账 → 债市崩溃 → 商人联盟政变 → 新宪章 → 利率下降 → 财政-军事复兴。
7. **预设财政危机时刻表**: 每政权埋 2-3 个危机事件(战争加派/铸币贬值/宫殿运河工程透支/包税商暴利/灾年赈济缺口/军饷拖欠)——每个都是政权更替触发器, 呼应"财政危机 → 抗税/违约/兵变 → 改朝换代"的节奏。
8. **用"税收货币化程度"标记现代化进程**: 折色改革(实物税转货币税, 两税法/一条鞭法/殖民地货币税模板)重塑权力——削弱实物地主、利好商人、推动市场扩张, 但使农民暴露于粮价波动并引爆现金短缺。

**[决策规则]**
- "战争造就国家, 国家反过来发动战争"(Tilly);
- 预算即国家的骨架——财政史即国家史(Schumpeter/Goldscheid);
- 财政能力危机(收不上税+借不到钱+发不出军饷)= 政权空心化, 比经济危机更致命;
- 税制选择是政治均衡的结果, 不是技术选择(Steinmo/Scheve & Stasavage);
- 有约束的政府 = 更有信用的政府 = 更强的财政-军事能力。

**[输出产物]** `财政档案`(每政权: 税制组合/利益集团/财政-军事循环阶段/双权力坐标/危机时刻表/合法性账本)。

**[检查点]** 军队规模 ≤ 剩余提取率×农业产出−行政损耗; 税制与政体类型互洽(强制密集 vs 资本密集); 国债必有约束制度否则利率失控; 财政危机节点可触发政权更替。

## 第 6 步: 设计周期、增长与转型

**[输入]** 财政档案 + 人口估算 + 技术状态 + 能源/资源上限。

**[操作]**
1. **设定马尔萨斯上限与"逃生阀"**: 定土地产出上限与人口承载力; 明确世界卡在陷阱里(周期性饥荒/瘟疫重置)还是已突破; 给突破设定明确触发条件——这决定整个文明史的基调与时间尺度。
2. **建立丰歉-粮价换算表**(低需求弹性): 歉收 5% → 涨 20%、10% → 60%、20% → 200%、30% → 粮价失控+饥荒; 用其推演灾年物价、租金与工资购买力, 让"荒年"成为剧情确定性引擎。
3. **设计人口冲击后的制度反弹**: 写一场减员 1/3 的大瘟疫(黑死病模板): 工资上涨 → 当局颁《劳工法令》冻结工资、禁流动 → 黑工市场与罚金遍地 → 农民起义 → 农奴制松动或强化; 走向取决于统治精英议价能力。
4. **用铸币贬值螺旋做"王朝危机"叙事**: 国库空虚 → 王室降成色(亨利八世 1544-51 含银量 92.5%→25% 模板)→ 物价飞涨+旧币窖藏/外流(格雷欣法则)→ 税基再缩 → 要么重铸(改革)要么崩溃(内战); 北欧 1350-1594 证明这是前纸币时代常态化的财政工具。
5. **制作长波分期表**(康德拉季耶夫/熊彼特/佩雷斯): 世界史切 50-80 年技术纪元, 每纪元写"核心创新-狂热资产(运河/铁路/魔晶反应堆)-清算崩溃-制度化扩散", 使每个时代有标志性产业、贫富格局与世界观。
6. **设计"价格革命"式财富再分配**(博丹/阿兹皮尔库埃塔/费雪 MV=PT): 新矿脉/新贸易线 → 2-3 代人的渐进通胀(16 世纪百年涨 4-6 倍模板)→ 固定地租与年金缩水、商人崛起、旧贵族衰落——无需战争即可完成阶层洗牌。
7. **用增长类型给文明定级**: 斯密型增长(市场范围扩大→分工细化, 有天花板"分工受市场范围限制")vs 熊彼特型增长(创新→生产函数替换, 不受要素报酬递减约束); 按五条触发条件打分: ①能源上限解除? ②需求扩大? ③知识与识字积累? ④制度保护创新? ⑤要素价格倒逼节劳?
8. **把停滞写成"理性的选择"**(Elvin 高水平均衡陷阱): 劳动力廉价 → 省力创新无利可图("做出来没人买"); 展示"微创新不断却无范式跃迁"; 用路径依赖(David QWERTY/Arthur 递增收益)制造锁定——旧能源寡头、行会、教会是锁定的代理人, 需"关键事件"(战争/灾变/革命)打破。
9. **用大分流设计世界内部不对称**(彭慕兰): 两文明发展水平相当, "煤田位置+海外领地"的偶然决定谁先突破; 被分流一方的内卷化(人均停滞、生活精致化)本身就是悲剧性剧情; 分流原因应是地理与运气而非种族/文化优劣。
10. **勤勉革命作转型前奏**(德弗里斯): 突破前先写文化变迁——工作伦理强化(新教伦理式宗教运动)、休闲贬值、新商品消费风潮(茶/糖/瓷器式异域品)、家庭劳动时间重组——一场可以细致描写的"无声革命"。

**[决策规则]**
- 周期是概率性倾向而非铁律——每次循环被偶发冲击改写;
- 前工业一切繁荣遵循"马尔萨斯-恢复"循环(黑死病后人均↑ → 人口两百年恢复 → 人均回落);
- 分工红利可以被完全"耗尽"——斯密型增长不自动升级为持续增长(宋代中国/17 世纪荷兰);
- 突破 = 解除资源约束 + 需求拉动 + 知识 + 制度 + 要素价格五线交汇(英国 1760-1830);
- 强化不等于繁荣: 区分"勤劳革命"与"过密化"(黄宗智)。

**[输出产物]** `周期日历`(马尔萨斯上限/丰歉表/长波分期/贬值螺旋/人口冲击)+ `增长诊断书`(每文明: 增长类型/五条件打分/锁定机制/突破触发器)。

**[检查点]** 人口-产出-价格闭环可推演; 每周期有相位标注与剩余时长; 停滞有机制解释而非"愚蠢"; 突破条件具体可触发; 大分流不对称有地理/运气解释。

## 第 7 步: 超自然经济与一致性总检

**[输入]** 前六步全部产物 + 法则篇的魔法规则(施法成本/能量源/传送限制)。

**[操作]**
1. **给法术画供给曲线**: 供给量 = 施法者人数 × 人均产出(法术位/法力); 分解四条约束: ①人力资本(学院/血统, 长期供给缓移, 类似医生律师执业壁垒); ②容量(每日法术位/法力池, 短期供给近乎垂直——价格暴涨也无法立刻增产); ③材料成本(边际成本上升, 卷轴/魔法物品定价的依据); ④管制(行会/神殿/帝国特许→租金与黑市)。高阶法术 = 垂直供给+配额制, 价格由需求与关系决定而非成本。
2. **给货币立"锚档案"**: 发行者(神殿/帝国/宗门)、锚定物(金/法力/信仰/地城产出)及其可消耗性; 货币本身有使用价值(灵石既是钱又是修炼燃料, 花掉=消耗)→ 结构性通缩与囤积理性; 复合锚定(多锚篮子)越稳, 但任一锚供给变化都是冲击源; 用格雷欣法则检查"为什么劣币还在流通"(内在价值高于面值的币会被熔毁吸走)。
3. **传送术只折叠一部分成本**: 规定传送的载量/重量/生命体/安全性限制 → 自然形成"高值小件走传送、大宗走船"的分级运输; 中心地层级被重排(法阵枢纽-辐条 vs 港口枢纽); "距离之死"(Cairncross)的实质是对空间距离的租金(港口费/关税/中间商)重新分配而非消失。
4. **外生冲击必须走传导链**: 每次"灌入地城金币/龙宝藏/遗迹科技"列出三步: 货币面(价格与债务)、实体面(资源与产能)、制度面(谁被洗牌、谁造反); 对照西班牙白银(货币扩张→价格革命)与史矛革(龙藏金=货币紧缩 / 龙吃生产性矮人=供给侧冲击)两模板。
5. **神力经济用信用模型**: 神 = 信用发行人, 信徒祈祷/香火 = "信仰 GDP"; 赐福=负债、香火=收入; 赎罪券/圣物/神力债券的"超发-贬值-挤兑"是现成剧情曲线(路德《九十五条论纲》=对救赎信用的挤兑); 神死后"神性"清算为债务资产(Craft Sequence 钩子)。
6. **用三问检视每个经济情节**(Zhang): 谁获益? 谁付费/成本由谁承担? 外部性是什么? (魔法纺织机外部性=织工失业→暴动; 复活术外部性=人口结构与继承法崩溃。)
7. **按"稀缺-丰裕"光谱定调**(Skwire): 复制器/量产魔法世界回答"丰裕之后钱变成什么"(注意力/地位/寿命成新货币); 资源枯竭世界回答"极端稀缺下的产权与暴力"——选好光谱位置再设计制度。
8. **跑一致性总检清单**(见第三部分): 货币从哪来/谁发行/可消耗吗; 魔法资源是存量还是流量/会枯竭吗; 谁垄断供给/管制结构; 价格如何传导到粮价/地租/军费; 存在哪些套利者与黑市; 短期冲击与长期均衡分别是什么; 每个设定与世界时间线自洽(帝国财政能否支撑常备军); 最后再过一遍三问。

**[决策规则]**
- 魔法资源稀缺性应与地理矿脉同等对待——法力节点 = 新"矿山";
- 任何创造价值的魔法必须有成本锚点, 否则摧毁价格体系;
- 传送/浮空改变运输成本 = 重画经济地图, 但只折叠部分成本;
- 经济设定要"焊死"在世界里: 每个元素都要回答"谁获益/谁付费/外部性"。

**[输出产物]** `魔法经济档案`(法术供给曲线/货币锚档案/传送成本表/外生冲击传导链/神力资产负债)+ `一致性总检报告`。

**[检查点]** 魔法服务价格由最紧约束决定; 可消耗货币有通缩与囤积情节; 传送不消灭运输只重排层级; 每次冲击有完整传导链; 经济层与世界时间线自洽。

# 第二部分: 贯穿示例(米拉斯经济篇)

> 地理篇: 龙骨山脉(灵脉主带)/苍原高原(灵脉第二富集区)/丰饶平原(苍河流域)/风语草原(雨影黑钙土)/白雾荒漠(雾盐湖)/北寒原/火链群岛/银海裂谷(泪湖群)/缝合地峡(南北唯一陆桥, 万兽走廊)。
> 文明篇: 灵枢城(神权城邦联盟, 祭司-灵脉解释权)/潮邦(商人寡头航海共和国)/云顶寺(隐修)/风语游牧(部落联盟)/雾盐邦(沙漠商路城邦)/北境遗民; 41 年血月周期=灵脉爆发-枯竭节拍器; 800 年前"灵权革命"=轴心时刻。

## 第 0 步: 米拉斯经济定位书

- **立场**: 嵌入优先——三套整合模式并存: **灵枢城=再分配主导**(灵脉圣所粮仓、灵稻贡赋、祭司书吏配给), **潮邦=市场主导**(商人寡头、季风贸易、行会), **风语草原=互惠主导**(游牧赠礼、马-粮交换、血月丰年南下)。不存在全境统一市场; 云雾边境的走私市集是各模式的边缘补丁。
- **依赖链**: 龙骨山脉灵脉 + 雾盐湖盐 + 季风 → 灵稻/稻作/畜牧/采盐 → 剩余(灵枢城约 25-30%, 支持祭司/书吏/工匠/雇佣军)→ 铜币-银锭-灵晶三层流通 → 灵脉税/关税财政。依赖链反向引用: "银锭体系依赖雾盐邦盐权; 盐湖枯竭则铸币权易主"。
- **三层账本**: 底层=灵稻自给村落与游牧帐篷(实物贡赋/赠礼); 中层=城邦市集(铜币、行会、盐仓); 顶层=潮邦商团与灵枢城灵晶结算(汇票、康孟达、灵晶金库、祭司记账)。
- **硬检查点**: 能量检查——灵稻为高产魔法作物, 支撑丰饶平原+潮风平原 85% 务农人口与两座大城; 运输检查——银海海运=1, 缝合地峡陆运≈15, 龙骨翻山 20+, 故大宗粮盐走海、灵晶盐晶走陆。
- **自检**: 全市场社会? 否——草原互惠、圣所再分配并存; 物价静止? 否——血月周期驱动 41 年波动; 魔法无成本? 否——施法消耗灵脉能量(见第 7 步)。

## 第 1 步: 米拉斯整合模式与生计

- **灵枢城=再分配机器**(印加 qolqa 模板): 灵脉圣所粮仓沿泪湖群设仓, 灵稻贡赋=税基, 祭司即书吏(灵纹源于记账, 与文明篇衔接), 灵户籍登记灵脉亲和度; 血月枯竭年再分配失灵 → 神义论("灵脉不悦")解释权危机 → 道义经济起义。
- **潮邦=市场+港口受控贸易**: 商人寡头议会(威尼斯 Serrata 模板), 季风航路(冬去夏返), 银海西岸溺谷良港群; 受控贸易港制度把市场逻辑挡在腹地之外(黎凡特贸易港模板)。
- **风语草原=互惠主导**: 族内概化互惠(共食), 部落间均衡互惠(马-粮赠礼), 对过路商队负互惠(劫掠); 血月丰年(灵脉爆发→草场丰盛)→ 游牧南下压力 = 赫勒敦边缘-中心动力学(与历史篇王朝循环衔接)。
- **雾盐邦=再分配+盐专卖**: 白雾荒漠雾取水+盐湖采盐; 盐=必需品+来源集中 → 天然专卖与长途贸易; 商路城邦, 类比威尼斯之于盐; 盐晶碑=失传的前灵纹纪年(历史篇痕迹复用)。
- **生计光谱**: 北寒原遗民=狩猎采集(原初丰裕+低欲望, 与农耕/商业文明的价值观碰撞: 双方互视"贫穷/贪婪"); 丰饶平原=灌溉精耕灵稻(高密度, 支撑国家与灵枢城); 风语草原=畜牧(活银行, 与灵枢城"贡-掠"交替外交); 白雾荒漠=采盐(盐湖藻类+雾生植物)。
- **禁忌法**(Tiv 模式): 灵碑法典明文"灵脉神圣物不可买卖、活人不可抵债、盐晶碑不可移动"; 血月大祭期间的债务注销与之呼应(神圣领域的定期重置)。
- **Chayanov 驱动**: 多子女灵稻农户接受更苛刻的灵稻贡赋并进入市场卖粮换银; 血月枯竭年税赋微调即可把自给户推入债务奴役链。

## 第 2 步: 米拉斯货币与价格

- **记账单位先行**: 灵刻度量衡+"盐石"算账基准; 灵枢城税册以"灵稻石×盐石"记价, 铸币是晚近国家行为(与文明篇"灵刻度量衡/盐本位"设定衔接)。
- **三层货币**: ①铜币=日常层(城邦市集、雇佣兵军饷); ②银锭=大额层, **盐本位**——雾盐邦产盐=铸币权(盐即银的"锚", 谁控盐湖谁控币值); ③灵晶=高端储备层, 魔法结算+施法燃料双重属性(花掉=消耗 → 结构性通缩偏置)。
- **税收资格**: 灵枢城宣布"灵脉税只收银锭与灵稻折色", 潮邦"关税只收银锭"——两套税币并存, 兑换混乱即汇兑商行(钱庄式)的业务与权力来源。
- **铸币权争夺**: 雾盐邦控盐=控铸币权(与灵枢城的盐税分成协议是长期外交线); 潮邦私铸铜币、灵枢城血月大祭前"大重铸"灵晶币(降纯掺银→格雷欣法则→良晶窖藏)都是历史事件素材。
- **双轨价格**: 灵枢城官方牌价(灵碑每周公告的灵稻面包令, 《面包与麦酒条例》模板)vs 潮邦市场价; 缺口 → 缝合地峡黑市与囤积三罪(拦购/转售/囤积)的立法史; 官方"badger"执照商与黑市同一生态的两面。
- **道德经济学**: 灵稻歉收 → 粮价突破道德阈值 → 抢粮/强卖/攻打圣所粮仓(暴动者自认在执法); 祭司"开仓平粜" vs 加派镇压是每次血月危机的政策分岔——镇压毁合法性, 平粜耗国库。

## 第 3 步: 米拉斯信贷、商业组织与贸易

- **记账信用**: 灵脉圣所=神庙金库(灵稻约 20%/白银约 33% 放贷, 借贷泥板契约, 美索不达米亚模板); 潮邦钱庄发行可背书转让的承兑票据; 山西票号式总号-分号汇兑网络在潮邦港-雾盐邦之间运营。
- **解负令**: 每 41 年血月大祭, 灵枢城祭司宣布债务注销+释放债务奴(美索不达米亚 misharum/禧年模板)——这是祭司(收买平民)与潮邦放贷寡头(吞并土地)的世纪斗争主轴; 两次大祭之间即权力斗争周期(朝臣密谋、金融家族囤地、农民暴动都挂在这条时间线上)。
- **利息伦理**: 灵教教义禁"对信众取息"(兄弟条款模板) → 雾盐邦异族商人成为放贷者 → 族群冲突与阴谋论叙事; 潮邦商人发明汇率差价/利润分成(commenda/mudaraba)绕禁。
- **行会政治**: 潮邦议会席位按造船/香料/盐/军械四大行会分配(佛罗伦萨模板); 灵枢城行会受祭司特许管制; 行会徽章、守护圣徒与血月节日游行是可见的文化层。
- **康孟达**: 潮邦海上贸易普遍使用(出资人得 3/4、船长 1/4, 单航季结算)——季风航行即康孟达的天然温床。
- **声誉-制度双轨**(Greif): 潮邦靠公证人+合同+海事法院(热那亚路径); 雾盐邦商队靠族缘信用网络+内部通报集体惩罚(马格里布路径); 两网在潮邦港交汇, 制度冲突即剧情(谁违约、谁被全网络排斥)。
- **商路**: ①缝合地峡陆路(南北唯一陆桥, 君士坦丁堡模板——关卡税+万兽走廊, 商税分成协议与走私路线); ②银海季风航路(潮邦垄断, 冬去夏返); ③白雾荒漠-丰饶平原盐粮商路(雾盐邦, 骆驼商队, 绿洲间距≈一日行程)。
- **世界体系**(布罗代尔/沃勒斯坦): 灵枢城=核心(宗教文化+灵晶垄断+灵脉解释权); 潮邦=半边缘商业枢纽(转口商); 雾盐邦/北境=边缘原料(盐/皮毛/木材/灵草); 风语草原=中间商+游牧压力带; 中心可迁移——若潮邦控制缝合地峡, 中心东移。
- **贸易战阶梯**: 潮邦-灵枢城关税 → 禁运(潮邦封锁银海峡口)→ 护航 → 私掠 → 全面战争(缝合地峡冲突升级线, 与历史篇"商路冲突升级"衔接)。
- **特许状**: 灵枢城祭司向商团授"灵晶经销特许"(垄断+铸币税包收); 潮邦商人向祭司议会放贷, 祭司赖账(血月枯竭年)→ 金融风暴 → 商人联盟政变或"第二次灵权革命"。

## 第 4 步: 米拉斯经济地理

- **吨-里成本图**: 银海海运=1; 缝合地峡陆运≈15; 龙骨山脉翻山=20+。大宗(灵稻/盐)走海; 高值(灵晶/盐晶/灵草/丝绸)走陆; 灵晶密卷可走法阵(见第 7 步)。
- **杜能圈(灵枢城)**: 泪湖群沿岸菜园鲜奶 → 灵稻精耕带(灵脉富集区, 单位价值高, 类比"自由农作圈")→ 轮作谷物带 → 山地牧带 → 荒野; 圈层沿泪湖群拉长、被龙骨山脉打断; 围城(断灵稻漕运)是现成的戏剧场景。
- **中心地等级**: 一级=灵枢城(灵脉学院/灵晶铸币厂/大祭圣所)、潮邦港(商会/海事法院/钱庄); 二级=城邦市镇(盐仓/磨坊/巡回法庭); 三级=集市镇(铁匠/粮市), 间距≈一日牛车行程; 灵枢城联盟用 K=7 行政原则(神权控制), 潮邦自由市镇用 K=3 市场原则——两种聚落法则在缝合地峡交汇。
- **资源地**: 雾盐湖=盐都(专卖+盐道+盐仓决定城市兴衰, 自贡模板); 龙骨山脉灵脉矿=灵晶产地(废弃矿井=灵权革命遗迹, 禁地); 火链群岛=香料与奇珍(隔离演化区系, 潮邦独家航路); 苍原高原=灵草药材(云顶寺隐修经济)。
- **卡口**: 缝合地峡=关隘税卡+驻军+商栈(万兽走廊起点); 潮湾三角洲=河口换装点(稻作+港口双重身份); 苍河渡口=双子城(征税与驻军分治)。
- **政治-经济中心分离**: 灵枢城(神权中心, 易守难攻的裂谷岸)vs 潮邦港(贸易中心)——灵枢城靠苍河-泪湖漕运线维持灵稻补给(北京模式); "首都粮食危机"即长期矛盾点, 断漕=灵枢城命门。
- **交通变迁伏笔**: 法阵驿站网络若普及(灵脉航道化), 缝合地峡地位下降、潮邦港转型——"昨日咽喉/今日废港"的层级变迁。

## 第 5 步: 米拉斯财政

- **灵枢城=强制密集**(Tilly 强制轴): 主干税=灵脉税(对灵脉产出与灵晶交易抽成)+灵稻贡赋+盐税(向雾盐邦转口抽成); **祭司阶层豁免一切税赋**(法国贵族免税模板)→ 税负全部压在农民与工匠 → **革命导火索**(第三次血月大祭前的加派即引爆点, 与历史篇"灵权革命"衔接)。
- **潮邦=资本密集**(Tilly 资本轴): 主干税=关税(季风税/港税)+商税; 战争融资靠商人议会借款与国债(以盐税专款抵押=可信承诺); 议会批税 → 低利率 → 舰队扩张(荷兰共和国模板)——财政制度比面积人口更能决定军事力量。
- **雾盐邦=专卖财政**: 盐专卖(《盐铁论》模板)+过路费; 关隘税收承包(宋元扑买式)归商队首领。
- **Mann 双权力矩阵**: 灵枢城=专断高、基础中(灵户籍登记强但依赖雇佣军, 暴力能力弱); 潮邦=专断低、基础高(渗透型征收网); 风语草原=双低(征不了税, 靠赠礼与劫掠); 雾盐邦=专断中、基础中(商路税卡即渗透点)。
- **合法性账本**: 灵枢城"准自愿服从"靠 ①祭司提供"灵脉赐福"公共品叙事 ②血月大祭的赈济与债务注销 ③灵碑税则的"公平"宣示; 四个触发器: 战败加派、祭司逃税曝光、枯竭年赈灾缺位、灵晶税改(实物转现金)。
- **财政危机时刻表**: 血月枯竭年(灵脉税减收)→ 加派 → 抗税暴动; 潮邦战争贷款 → 赖账风险 → 债市崩溃 → 商人议会政变或宪章改革; 灵枢城"大重铸"灵晶币 → 物价再分配 → 固定年金者受损、商人受益。

## 第 6 步: 米拉斯周期、增长与转型

- **马尔萨斯上限**: 丰饶平原+潮风平原可耕地 × 灵稻单产 = 人口承载力; 灵稻增产被人口吞噬(过密化风险, 黄宗智模板)——"精耕但停滞"是灵枢城的底色。
- **41 年血月周期=经济节拍器**: 血月蚀=灵脉爆发年(灵晶供给暴涨、灵稻丰产、草场丰盛、游牧南下)→ 灵脉枯竭年(灵晶短缺、粮价暴涨、再分配失灵)。**灵晶价格随血月周期波动**: 灵晶=可消耗货币 → 丰年灵晶供给扩张(通胀)、枯竭年灵晶供给近乎垂直(通缩+囤积)+银锭走强; 全世界的物价、债务、税率、大祭赈济都锚在这 41 年的钟摆上——这是米拉斯经济的第一发动机。
- **丰歉弹性表**: 灵稻歉收 10% → 粮价 +40%; 20% → +200%; 30% → 饥荒+抢粮+开仓平粜; 血月枯竭年叠加歉收 = 双杀(灾年+再分配失灵=起义年)。
- **人口冲击模板**: 缝合地峡瘟疫(借道商路传播, 黑死病模板)→ 潮邦水手减员 1/3 → 工资上涨 → 商人议会颁《劳工法令》冻结工资 → 黑工市场 → 水手起义 → 寡头松动或强化。
- **贬值螺旋**: 灵枢城国库空虚 → 灵晶降纯(掺银)→ 格雷欣法则(良晶被窖藏/熔毁为燃料)→ 税基再缩 → "大重铸"改革或崩溃; 与潮邦银锭贬值形成"双币竞贬"。
- **长波分期**: 米拉斯技术纪元以"灵脉技术"为轴——①灵纹记账/灵稻育种(轴心时代)②灵晶铸币/盐业扩张③灵脉深矿/法阵初步④传送法阵网络(当下正在安装期: 基础设施狂热+法阵税泡沫)——每纪元标"核心创新-狂热资产-清算-制度化"。
- **增长类型**: 潮邦=斯密型增长(季风贸易扩大市场范围 → 分工深化 → 转口繁荣), 天花板=银海市场饱和+缝合地峡拥堵; 灵枢城=Elvin 式高水平均衡(劳动力廉价+祭司垄断创新 → 省力技术无利可图——灵稻收割机"做出来没人买"); 风语草原=畜牧稳态。
- **大分流点**: 潮邦 vs 灵枢城的分流 = 缝合地峡控制权(商路咽喉)+ 灵脉区位(能源)+ 海外领地(火链群岛/青环礁)——谁同时拿到三样谁突破有机经济上限; 突破物=灵脉深层矿(龙骨山脉禁地)或异界/银海外域殖民(为续章留钩子)。
- **路径依赖**: 盐本位锁定(即使发现新银矿也不改, 因税收资格+铸币权既得利益); 灵纹记账系统锁定(祭司垄断释经权+灵户籍); 打破锁定需"关键事件"——血月大祭即现成的关键事件。

## 第 7 步: 米拉斯超自然经济与总检

- **灵脉施法成本**(法则篇衔接): 施法消耗灵脉能量 → 灵晶=燃料+货币双重属性 → 花掉=消耗 → **结构性通缩偏置**; 灵晶供给=灵脉存量(存量而非流量), 随血月周期波动(丰年右移、枯竭年左移近垂直)。
- **法术供给曲线(灵枢城)**: 灵术师=灵脉学院毕业生(人力资本约束, 长期缓增, 精英过剩=历史篇设定的革命压力源之一); 法术位/法力池(容量约束, 短期垂直); 灵晶材料成本(边际成本上升——卷轴/灵纹器物定价=成本加成); 神殿特许(管制约束 → 黑市与"法术黄牛", 云顶寺=不受管制的第二供给源)。

- **外生冲击**: 龙骨山脉废弃矿井(禁地)若被重新打开 = 灵晶供给外生扩张 → 物价革命式再分配(白银流入模板: 灵晶通胀、固定灵稻贡赋缩水、商人受益、祭司受损); 古墓/龙藏灵晶被倾入市场 = 货币扩张; 灵脉枯竭 = 供给侧冲击(史矛革模板)——每次冲击走"货币面-实体面-制度面"三步传导链(谁被洗牌、谁造反)。
- **神力经济**: 灵教=信用发行人, 信徒祈祷/香火=信仰 GDP; 血月大祭=救赎信用的大规模发行(祭司垄断灵脉解释权=垄断"救赎货币"); 若大祭预言落空(神义论失灵)→ 信徒挤兑 → 灵教信用贬值 → 世俗王权/商人抬头(与历史篇"第二次灵权革命"分支衔接)。

# 第三部分: 一致性总检清单(经济篇)

**基础层**(第 0-1 步):

- [ ] 财政危机时刻表与政权更替节点对应; 货币化指数标注。

**周期层**(第 6 步):

- [ ] 长波分期表(核心创新-狂热资产-清算-制度化);

**超自然层**(第 7 步):
