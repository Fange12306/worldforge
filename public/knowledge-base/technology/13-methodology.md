# 技术构建方法论与一致性总检

> 目的: 把技术构建变成可执行的四段流水线, 并提供全卷一致性总检——让每条技术有档案、有前置、有社会配套, 让"先进文明"与"中世纪背景"都不失真。
> 前置: 全部技术篇产物(停滞/知识/革命/奇点/魔法); 与经济篇(成本)、法则篇(现象)、文明篇(制度)咬合。

## 核心机制

### 技术档案清单(每项技术一张档案卡, 而非一行字)

| 字段 | 内容 | 缺省后果 |
|---|---|---|
| 名称 | 技术名 | — |
| 原理 | 对应现象库中哪条自然/魔法/生物现象 | 无出处 = 凭空发明 |
| 关键前置 | 依赖的节点技术 | 无法画前置图 |
| 产物与副产品 | 产出物与废弃物 | 无副产品 = 经济账失真 |
| 资源与能源 | 消耗什么 | 无成本 = 价格体系坍缩 |
| 发明者与年代 | 谁、何时 | 历史无锚点 |
| 扩散状态 | 到哪、为何(用五属性评语) | 同步扩散 = 失真 |
| 社会配套 | 制度/组织/法律/观念/人才 | 缺配套 = 实验室技术 |
| 失败分支 | 曾尝试被放弃的路径 | 科技树无死胡同 |

### 四段流水线(先做 X 再做 Y)
1. 现象库: 只列"世界允许发生的事"(物理定律、魔法规则、生物特性、材料属性), 不列技术;
2. 组合: 现象×现象的合法拼接生成候选技术, 禁止凭空发明;
3. 前置图: 依赖关系做成有向无环图(DAG), 防环、防跳变;
4. 配套矩阵: 每项技术与制度/组织/法律/观念/人才逐项配对, 缺配套者降级为"实验室技术"而非社会现实技术。

### 扩散五属性(决定"一夜普及"还是"千年小众")

| 属性 | 含义 | 高/低的影响 |
|---|---|---|
| 相对优势 | 比旧方案好多少 | 高则快 |
| 兼容性 | 与既有价值观/习惯契合度 | 低则遇文化阻力 |
| 可试验性 | 能否小规模试 | 低则不敢冒险 |
| 可观察性 | 效果能否被看见 | 低则无人跟风 |
| 复杂性 | 理解与使用难度 | 高则只限精英 |

采用呈 S 曲线: 创新者(约 2.5%)→早期采用者(约 13.5%)→早期多数(34%)→晚期多数(34%)→落后者(16%); 早期采用者中的"意见领袖"决定曲线斜率。

### 技术不是自主的: 解释柔性、技术动量、多层视角
- 解释柔性: 同一技术在工匠/医生/用户眼里意义不同, 经"闭合"与"稳定化"才定型——技术树的生长是社会博弈的结果, 不是自动解锁的关卡;
- 技术动量: 大型技术系统(电网、法力网)= 硬件+组织+制度+观念, 越成熟动量越大越难逆转; 系统的"瓶颈部位"正是创新与危机的温床;
- 多层视角: 微观利基(创新孵化)、中观制度(现有技术-社会秩序)、宏观景观(大环境压力)三层互动——停滞 = 制度层高度稳定; 突破 = 利基蓄势 + 景观压力共振。

### 停滞三件套(冻结万年必须同时给出)
1. 制度性禁令或垄断组织(法令/宗教教义/卡特尔);
2. 资源/能源瓶颈(燃料/魔力/材料短缺);
3. 路径锁定沉淀成本(已建成基础设施阻碍换代)。

缺一件, 停滞即站不住——检查"世界长期不变"类设定时逐项核对。

### 常见错误对照表

| 错误 | 表现 | 解药 |
|---|---|---|
| 单点超前、整体滞后 | 差分机已现, 教育金融制度仍中世纪 | 配套矩阵强制填表 |
| 同步扩散 | 所有文明同时掌握同一技术 | 地理隔离/贸易壁垒/知识垄断 |
| 前置跳变 | 无铁器直接出火药 | DAG 跳变检查 |
| 无成本技术 | 魔法/机械不耗资源 | 资源与能源字段必填 |
| 无失败史 | 科技树全是成功路径 | 保留失败分支 |

### 一致性总检六账(每卷自查一次)
- 时间线: 无矛盾; 人物知识边界(角色不知道的, 作者不提前用);
- 经济账: 成本与产出对得上; 能源账: 动力源守恒;
- 制度账: 配套机构出现不早于技术本身;
- 规模账: 人口/产量/产能匹配。

## 构建操作

1. 先建现象库: 只列"世界允许发生的事", 写不出原理出处的技术先砍掉或改写成"外来引进/考古遗物";
2. 再做组合与前置图: 现象×现象生成候选技术, 依赖关系用 DAG, 技术等级差超过两个节点时强制补写解释(逆向工程/遗物/禁忌重启), 从机制上杜绝跳变;
3. 配套矩阵强制填表: 每项技术配社会配套栏(制度/组织/法律/观念/人才/市场), 空栏即标记为实验室技术, 禁止直接当社会现实使用;
4. 用五属性写扩散评语: 为每条关键技术写一句五属性评分, 据此决定它"一夜普及"还是"千年小众"; 用地理隔离、贸易壁垒、知识垄断打破"同步扩散";
5. 停滞用三件套解释: 世界冻结万年必须同时给(1)制度性禁令或垄断组织,(2)资源/能源瓶颈,(3)路径锁定沉淀成本;
6. 把技术写成剧情: 发明=解谜奖励(谁先组合出某现象); 扩散=社会冲突(新旧制度斗争/垄断与盗版/观念抵抗); 停滞=背景张力(主角要打破的墙); 每条档案补一个"剧情钩子"字段;
7. 保留失败分支: 记录"曾发明但被社会拒绝"的技术(被禁令的机械、被宗教压制的印刷术), 失败史是世界深度与续作伏笔的最佳来源, 也解释科技树为何有死胡同;
8. 每卷收尾跑一遍一致性总检: 时间线/知识边界/经济账/能源账/制度账/规模账逐项核对。

## 检查点/清单

- [ ] 现象库已建, 每条技术档案"原理"字段可回溯到具体现象;
- [ ] 前置图是 DAG, 无环、无跳变, 跳变均有解释;
- [ ] 每项社会现实技术都有配套矩阵, 空栏者被降级为实验室技术;
- [ ] 每条关键技术有五属性扩散评语, 无"同步扩散";
- [ ] 停滞类设定通过三件套检查(禁令/瓶颈/锁定);
- [ ] 无"单点超前、整体滞后"的蒸汽朋克败笔;
- [ ] 无"无成本技术", 资源与能源账闭合;
- [ ] 有失败分支记录, 科技树含死胡同;
- [ ] 时间线/人物知识边界/经济账/能源账/制度账/规模账六项总检通过;
- [ ] 技术档案与停滞、知识、革命、奇点、魔法各篇无矛盾。
