# 语言构建总流程与接口

> 目的: 从 0 到 1 构建一个世界的语言体系——先定语言角色,再自底向上造语言,派生谱系,写全档案,最后与历史、地理、文明接口咬合。
> 前置: 地理篇产物(地形/迁徙/隔离区)决定语系分布;与文明篇(政体/宗教/阶层)、历史篇(征服/接触期)、魔法篇(真名/咒语)双向咬合。

## 核心立场: 语言是分层系统,不是单词表

- **四层结构缺一不可**: 一门语言 = 音系(音位清单/音位配列/音节/重音) + 形态构词 + 句法 + 词汇语义。必须自底向上(音系→构词→句法→词汇)构建,任何一层缺失都会在命名与文本中露馅。
- **按目标分级,工作量差一到两个数量级**: 命名语言(音系+构词规则+150~300 核心词,只产出人名地名器物名)以天计;完整艺术语言(含形态句法与历时演变)以月—年计;实验/逻辑语言按规则完备度计。先定角色再动手。
- **"过度规则"本身就是错误信号**: 不存在完全规则的自然语言——真实语言充满不规则、空缺、借用与冗余;规则与例外要成对出现,语言是活的。
- **音系先行,其余皆受其约束**: 音位清单决定语言"长什么样",也是人名、地名、咒语、借词、文字的共同约束源;先定语音审美,再谈其他。
- **语法类型学是快速定骨工具**: 用形态类型(孤立/黏着/屈折/多式综合)与语序类型(SOV/SVO/VSO…)几分钟内定出骨架,使语言彼此区分且自洽。
- **语言史 = 历史语言学**: 谱系树模型解释"祖语→女儿语"裂变;波浪模型解释方言连续体扩散;"音变规律无例外"是历史音变的公理;核心词表可粗估分化年代。
- **地理 = 方言连续体与语言地图**: 山脉/海洋阻隔产生分化,平原与商路产生趋同;等语线画出特征边界。
- **文字是独立于语音的平行系统**: 文字类型与正字法深度决定"拼写与发音脱节"现象,这是"古文字/神圣文字"的现成机制。
- **语言即社会分层**: 双言制中高变体(宗教/文学/官方)与低变体(日常口语)并存——这正是"魔法语言 vs 日常语言""祭司古语 vs 民众土语"的学术原型。

## 语言档案八件套清单

| # | 档案件 | 内容要点 |
|---|---|---|
| 1 | 音系表 | IPA 音位清单、音位配列、音节结构、重音/声调规则 |
| 2 | 构词与句法纲要 | 词缀系统、语序、核心语法范畴(格/时/体/一致) |
| 3 | 核心词汇表 | 100~200 核心词 + 文化域词汇,附 IPA 注音 |
| 4 | 文字系统 | 文字类型、字符表、书写方向、正字法深度说明 |
| 5 | 样例文本一 | 带逐词标注(如莱比锡标注法)的一段叙述文本 |
| 6 | 样例文本二 | 带标注的一段对话/口语文本,展示语域差异 |
| 7 | 谱系树 | 祖语→女儿语分叉图,标注各支主要音变 |
| 8 | 语言地图 | 语族分布与地形/迁徙/政体对应图 |

## 构建操作

1. 先写"语言角色清单": 列出世界需要的每门语言及其级别(命名级/完整级/仅词汇级)、使用者、功能(日常/官方/宗教/魔法)——直接控制总工作量,防止"每族都做完整语言";
2. 再为每个文化建音位表+配列规则,人名、地名、咒语、借词一律从表内生成;可用词汇生成器批量产出再人工筛选;
3. 词汇按三层扩展: 100 核心词 → 文化域词汇(农业/战争/航海/宗教,必须与文明设定对齐)→ 专有词;敬语、禁忌语、咒语词单独建域;
4. 建立谱系树与语言史时间轴: 设计祖语 → 声明 2~4 条音变规则 → 对祖语词表施加规则得女儿语,两支再各自变化得兄弟语言;用词汇统计学粗定分化年代;
5. 命名规则独立成档: 人名、地名、称号各一条生成规则,且只用本语言音系;明确禁止跨语言混用(同一文明不得混入另一语系的词汇)——这是最常见的返工源;
6. 为魔法/神圣语言设"双言制"接口: 用"古语高变体 vs 口语低变体"解释咒语、真名、仪式来源;若真名魔法存在,让名字在语言史中有据可查(名字随音变漂移、真名保留古音);
7. 语言地图与地理联动: 语族分布与山脉、海、迁徙路线、征服史一致;平原画方言连续体,山区画碎裂语言带;
8. 每完成一个模块跑一遍检查清单。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 只堆单词表,无音系/语法 | 自底向上: 先音系,再构词,再句法,再词汇 |
| 每族都做完整语言,工作量爆炸 | 按叙事可见度分级: 命名级/语法草图级/完整级 |
| 语言过度规则,像数学符号 | 规则与例外成对出现;例外用类推/借词/音变解释 |
| 人名地名混用多语言音系 | 每语言命名规则独立成档,只用本语言音系 |
| 谱系不可追溯,语言各自孤立 | 画谱系树: 祖语→音变→女儿语,标注借用来源 |
| 魔法语凭空造词、无来由 | 用双言制接口: 古语高变体=仪式/咒语/真名的来源 |
| 语族分布与地图/迁徙矛盾 | 语言地图与山脉、海、征服史逐条核对 |
| 无样例文本 | 每语言至少两段带标注文本(叙述+对话) |

## 检查点/清单

- [ ] 每门语言有音系文档(音位表+配列规则)?
- [ ] 命名只使用本语言音系,无跨语言串味?
- [ ] 谱系可追溯: 每支语言标注诞生时代、主要音变、借用来源?
- [ ] 语言地图与地理/迁徙/征服史一致?
- [ ] 每语言至少两段带标注样例文本(叙述+对话)?
- [ ] 魔法语与日常语接口明确(双言制/借词层/禁忌语)?
- [ ] 语言角色清单已定,工作量和叙事需求匹配?
- [ ] 词汇分层完成: 核心词→文化域→专有词,无缺失层?
