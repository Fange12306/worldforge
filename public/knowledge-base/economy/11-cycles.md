# 经济周期与人口动态

> 马尔萨斯陷阱、丰歉-粮价弹性、价格革命、长波周期、铸币贬值螺旋与人口冲击——经济的节奏就是历史的节拍器。

## 核心机制

### 1. 马尔萨斯陷阱(前工业基准模型)

人口增长快于食物产出增长, 人均收入总被拉回生存线。两类抑制:

- **积极抑制**: 饥荒、瘟疫、战争(死亡率上升);
- **预防性抑制**: 晚婚、独身、禁欲(出生率下降)。

人口-土地负反馈闭环: 人口↑ → 耕地扩张至边际土地 → 人均产出↓ → 实际工资↓ → 死亡率↑ → 人口↓。任何技术进步先被人口稀释——**先决定世界卡在陷阱里(周期性饥荒/瘟疫重置)还是已突破, 这决定文明史基调与时间尺度**。

### 2. 丰歉-粮价放大机制(生存必需品低弹性)

谷物是生存必需品, 短期需求价格弹性极低: **供给小波动→价格大波动**。危机未必是绝对短缺, 而是低弹性把短缺放大为价格灾难。参考换算表(按世界设定微调):

| 歉收幅度 | 粮价上涨 | 社会后果 |
|---|---|---|
| 5% | ≈20% | 可承受, 穷人吃紧 |
| 10% | ≈60% | 城市贫民骚动, 需要官方粮仓平抑 |
| 20% | ≈200% | 大面积饥荒, 流民潮 |
| 30% | 失控 | 人相食、疫病、政权危机 |

低弹性+存储不足+市场分割 → 丰年"谷贱伤农"、灾年"米贵如珠"交替伤害。

### 3. 货币数量论与价格革命

货币量×流通速度 = 物价×交易量(MV=PT)。大量贵金属/货币流入 → 物价普遍上涨、存量财富重新分配:

- 16世纪式价格革命: 新大陆白银百年内物价涨4~6倍;
- 反向案例"铸币荒": 货币收缩 → 长期通缩与商业危机。

价格革命的分配后果: 固定地租与年金实际缩水 → 商人、自耕农受益, 靠固定收入的领主受损——**一个无需战争即可完成阶层洗牌的自然机制**。

### 4. 康波长波与创新集群

约40~60年一轮的长波, 由基础创新集群驱动: 基础创新出现 → 企业家蜂拥模仿 → 信贷扩张推动繁荣 → 过剩消化与清算。每轮技术纪元三阶段: **狂热(金融泡沫、基础设施狂热)→ 清算(崩溃)→ 制度化(全面扩散)**。前工业时代亦可套用(运河热、贸易扩张热)。

### 5. 铸币贬值螺旋与格雷欣法则

君主财政危机 → 降低铸币成色/重量套取铸币税 → 物价上涨、实际铸币税收入反而下降 → 再度贬值, 形成螺旋。同时劣币驱逐良币: 成色足的旧币被窖藏、熔毁或出口, 劣币充斥流通。终点是货币崩溃或"重铸"改革。

```
国库空虚 → 降成色 → 物价飞涨、良币外流 → 税基再缩 → 重铸(改革)/崩溃(内战)
```

### 6. 人口冲击改写经济结构(大瘟疫模板)

人口骤减1/3量级 → 劳动力骤缺 → 实际工资上涨, 工资-地租剪刀差反转 → 地主收入下降、农业转向畜牧与高附加值作物 → 农奴制瓦解(代役租化)、庄园制衰落 → 人均财富上升、城市工匠与消费需求扩张。**国家机器反扑**: 当局出台冻结工资法令试图压制工资上涨, 其成败取决于统治精英议价能力, 可衍生整条阶级冲突线(法令+人头税→农民起义)。

### 7. 人口-结构崩溃检测(四要素)

当一国同时出现四要素, 标记其进入革命倒计时:

1. 粮价高涨;
2. 人口过剩(相对土地承载力);
3. 精英竞争加剧;
4. 国家财政危机。

四者叠加是前工业化政治动荡的统一解释, 可作地图上的"政治动荡热区"预测器。

## 构建操作

1. 设定马尔萨斯上限与"逃生阀": 确定世界土地产出上限与人口承载力, 明确世界卡在陷阱里还是已突破, 给突破设定明确触发条件;
2. 建立丰歉-粮价换算表(上表), 用它推演灾年的物价、租金与工资购买力, 让"荒年"成为剧情确定性引擎;
3. 写一场减员1/3的大瘟疫, 按真实机制推演: 工资上涨→冻结工资法令→社会反抗(农民起义)→农奴制松动或强化, 两种走向取决于精英议价能力;
4. 用铸币贬值螺旋做"王朝危机"叙事循环(见上), 这是可反复使用的政治-经济剧情循环;
5. 制作长波分期表: 把世界史切成50~80年技术纪元, 每纪元写明"核心创新-狂热资产-清算崩溃-制度化扩散", 使每个时代有标志性产业与贫富格局;
6. 设计"价格革命"式财富再分配: 当世界发现新矿脉/新贸易线, 用2~3代人的渐进通胀改写社会结构(固定收入者衰、商人兴);
7. 用四要素崩溃检测标记动荡热区: 当一国同时出现粮价高涨+人口过剩+精英竞争+财政危机, 写入革命倒计时;
8. 把弹性原理写进贸易与存储: 市场分割放大地区价差, 丰收区谷贱、歉收区饿殍; 设计跨区套利商队、官方粮仓与投机囤积者, 让"粮食政治"成为地缘博弈抓手。
