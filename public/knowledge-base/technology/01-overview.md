# 技术构建总流程与接口

> 目的: 从 0 到 1 构建一个世界的技术体系——先定法则现象库,再推导可行技术域,画前置依赖图,逐项写档案,最后接社会配套。
> 前置: 法则篇产物(自然法则/魔法规则=现象库)与地理篇产物(矿脉/能源/材料分布);与文明篇(组织/财政)、军事篇(兵种)、历史篇(周期)双向咬合。

## 核心立场: 技术不是发明清单,而是"系统"

- **技术是系统,不是器物**: 一项技术的完整档案 = 原理 + 发明条件 + 前置链 + 成本曲线 + 扩散路径 + 社会配套(谁制造/谁付费/谁维护/谁受益/谁受损) + 局限与副作用。缺任何一环,档案即不完整。
- **形态是社会协商的产物,不是内在必然**: 同一技术在不同群体(使用者/资本/国家/军方)眼中意义不同,胜出的形态是"被接受"的形态而非"最优"的形态;一个世界不必为每项技术只保留一个"正确形态"。
- **系统一旦成型便获得惯性(技术动量)**: 既成体系(既有能源网、旧兵种、行会、旧信仰组织)会系统性抵制替换;替换成本而非知识有无,才是技术变迁的主要阻力来源。
- **发明时间 ≠ 普及时间**: 许多"停滞"实为"采纳滞后",必须用成本、信息、制度条件解释,不能默认"发明即天下皆知"。
- **技术必须带社会配套**: 技术变革的后果往往不在战场与技术本身,而在制度层——新武器必然要求新兵制、新财政;配套缺失的技术只能设定为"实验性/未定型"。
- **停滞是机制性的,不是"他们没兴趣"**: 任何技术停滞都应归入两类机制之一——供给不足(缺知识/材料/人才/实验传统)或需求不足(制度不激励、权力与利益分配压制)。

## 总体工作流(先做 X 再做 Y)

```
第 0 步: 法则输入——自然法则/魔法规则 → 定"现象库"(先于技术存在)
   ↓
第 1 步: 推导可行技术域——从现象筛出法则上可能的技术,砍掉不可能项
   ↓
第 2 步: 画前置依赖图——DAG,每节点指向其直接前置,拓扑排序保证无环
   ↓
第 3 步: 逐项写技术档案——固定字段模板,先为 3~5 项核心技术建样板
   ↓
第 4 步: 建配套矩阵——技术 × 组织/经济/军事/地理资源 四维核对
   ↓
第 5 步: 跑检查点清单——跳变/停滞/配套/替代/动量五查,迭代修正
```

## 与其他大类的接口与依赖顺序

| 上游模块 | 接口内容 | 技术档案要写什么 |
|---|---|---|
| 法则(先定) | 魔法=可被认知与编程的自然现象,现象库决定可行技术域 | 每节点标注"由哪些现象+哪些既有技术组合而来" |
| 地理(并行) | 矿脉/能源/材料分布决定技术可行域与成本 | 资源地图、成本曲线、运输依赖(陆运≈水运5~20倍) |
| 文明(并行) | 政体/财政/文化决定技术的社会配套 | 配套矩阵(谁造/谁付费/谁维护/谁受益/谁受损) |
| 军事(后定) | 新武器必然要求新兵制新财政;兵种替代要有过渡期 | 配套变形、并行期、旧兵种受益者的抵抗 |
| 历史(后定) | 停滞与倒退嵌入周期表;危机即政权更迭触发器 | 每个停滞时代附一条供给/需求机制解释 |

依赖纪律: 任何一步落定后,前序模块不可再做推翻性改动;档案应记录反向引用(如"此魔网依赖北境水晶矿,矿枯则网崩")。

## 技术档案应包含的清单

1. 原理(依赖的法则/现象);
2. 发明者及时地(发明年);
3. 前置技术节点(直接前置链);
4. 研发与制造成本(成本曲线);
5. 发明年与普及年(两个独立时间戳);
6. 传播路径(扩散走廊与各文明采纳时间差);
7. 社会配套(谁造/谁付费/谁维护/谁受益/谁受损);
8. 局限与副作用;
9. 被替代的旧系统及其受益者/抵抗者;
10. 与地理/经济/军事/历史的反向引用说明。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 凭空发明: 技术无直接前置 | 每节点必须回溯到现象库+既有技术组合 |
| 全员同步: 各文明同时拥有新技术 | 发明年/普及年分离,用扩散 S 曲线分配采纳时间差 |
| 无配套: 新技术无组织/财政支撑 | 每技术过"三问"——谁组织生产?谁负担成本?谁维护运转? |
| 停滞无解释: 百年无技术事件 | 每次停滞选"供给不足"或"需求不足"写明机制 |
| 替代无过渡: 旧系统瞬间消失 | 写清并行期、成本对比、政治抵抗与各自"配套变形" |
| 无阻力: 新技术畅通无阻 | 为旧系统指定受益者(行会/旧兵种/旧信仰),让动量入戏 |

## 构建操作

1. 先建现象库再推导: 写下世界的法则现象清单,从现象组合生成可行技术域,任何无法回溯的节点一律删除或补设定;
2. 再画前置依赖图: 用 DAG 把每项技术接到直接前置,拓扑排序保证无环、层数=时代数,关键路径决定"时代最短通关时间";
3. 为 3~5 项核心技术先写样板档案(字段见上),验收后再推广到全部节点;
4. 给每项技术标"发明年"与"普及年"两个时间戳,普及必须写明成本下降、基础设施、社会接受三个条件;
5. 用扩散 S 曲线为各文明分配采纳时间差,自然产出"先进/滞后文明"差异,避免全员同步;
6. 每项技术过"三问"(谁组织生产/谁负担成本/谁维护运转),配套缺失的技术只能设定为实验性;
7. 把技术节点落在资源地图上(铁矿/煤矿/稀有材料/魔能节点),资源枯竭可成为技术倒退的正当理由,也制造剧情冲突;
8. 为每次停滞指定一个"既得利益集团"作阻力源(行会/旧兵种/旧信仰),把"替换成本"而非"知识有无"写成冲突来源——这是可复用的叙事引擎。

## 检查点/清单

- [ ] 跳变检查: 每项技术的直接前置真实存在且已普及过?
- [ ] 停滞检查: 每跨越 >100 年无技术事件,附一条供给/需求机制解释?
- [ ] 配套检查: 每项技术对应一个社会组织、制度或财政安排?
- [ ] 替代检查: 每次新技术出现,旧系统受益者是谁、如何抵抗?
- [ ] 动量检查: 既有大系统(能源/兵种/信仰)为新技术的扩散设置了什么阻力?
- [ ] 双时间戳检查: 每项技术发明年≠普及年,普及三条件(成本/设施/接受)已写明?
- [ ] 资源接口检查: 技术树节点落在资源地图上,无"无来源材料"?
- [ ] 反现代主义自检: 无凭空发明? 无全员同步? 停滞有机制? 旧系统在抵抗?
