# 文明/政体/文化: 从起源到兴衰 — 完整研究手册

> **目的**: 给定世界法则与地理底图, 按本手册逐步构建一个完整、合理、契合主题的虚构文明的起源、演化、扩张与兴衰。
> **范围**: 只涉及文明/政体/文化本身(与地理篇衔接, 政治文化层在此展开)。不含现实国别编年史。
> **用法**: 每部分有 [输入] → [操作] → [决策规则] → [输出产物] → [检查点]。13 个主题的详细研究笔记见 `docs/research/notes/`(14-26)。
> **贯穿示例**: 内嵌示例世界「米拉斯」的文明篇, 展示每一步实际输出。

---

# 第一部分: 六步执行流程

## 第 0 步: 输入——世界法则 + 地理底图 + 主题指令

**[输入]**
- 地理篇产物: 大陆轮廓、气候带、生物群系、资源分布、区划树(这是文明的"底图")。
- 世界法则: 超自然规则(魔法/神明是否真实存在并干预)、文明阶段基调。
- 主题指令: 故事需要的文明要素(如"要有一个衰落的魔法帝国""要有航海城邦联盟")。

**[操作]**
1. 把主题指令翻译成**文明需求清单**(叙事需求 → 文明要素映射)。
2. 给世界定**文明数量与分布**: 1~2 个原生文明摇篮 + 若干次生文明 + 边缘"蛮族"带(参考地理篇的生物地理底图)。
3. 建立"文明圣经"文件(后续每步追加)。

**[检查点]** 需求清单与主题一一对应; 文明位置与地理底图(河流/平原/海岸)吻合。

---

## 第 1 步: 文明起源——摇篮与机制

**[输入]** 地理底图(哪些地方有农业潜力)+ 世界法则。

**[操作]**
1. **选摇篮位置**: 大河冲积平原/可预期洪泛区(两河/尼罗河/黄河模式)、绿洲、湖滨——必须是"可存储的农业剩余"能产生的地方。
2. **选起源机制组合**(2~3 个, 参考笔记 14/15/16):
   - 环境压力(干旱走廊逼迫聚集)、人口压力(Boserup: 人口增长先于集约化)、灌溉/水利(争议大, 建议作辅助而非主因)、贸易再分配(Polanyi: 神庙/王宫作剩余中心)、仪式中心(Göbekli Tepe模式: 先建神庙再种地)、限域+战争(Carneiro: 被围合的富饶谷地)。
3. **定"谁的剩余被谁拿走、如何记账、凭什么合法"**——答案即神权/王权/寡头/商邦的骨架。
4. **选判据组合**(Childe 十项判据是"症状群"而非清单): 为文明选 3~5 项并说明缺席项(如"有文字无城市"的宗教文明、"有城市无文字"的安第斯式文明)。

**[决策规则]**
- 起源机制必有代价: 灌溉→水利科层; 仪式中心→祭司垄断天文; 限域战争→军事贵族。
- **让"缺席"成为特征**: 参考印度河(无宫殿)、卡拉尔(无陶)、奥尔梅克(无冶金)——反套路文明最有辨识度。
- 原生/次生关系: 1~2 个原生摇篮, 周边以传播/模仿/对抗次生演化。

**[输出产物]** `文明起源档案`(摇篮位置/起源机制组合/判据组合/权力骨架雏形)。

**[检查点]** 机制与制度痕迹一致; 判据缺席项有替代方案(结绳、仪式建筑等)。

---

## 第 2 步: 农业与生计基础

**[输入]** 起源档案 + 生物地理(可驯化物种)。

**[操作]**
1. **给每个文明定"标志作物包"**(参考笔记 15):
   - 谷物(麦/稻/粟)→ 可见、可储存、可计量、可征税 → 便于集权(Scott 谷物逻辑);
   - 薯芋/根茎 → 埋地下难清点 → 松散平等社会;
   - 稻作 → 集体水利 → 水利官僚;
   - 葡萄/橄榄 → 长周期投资 → 庄园制与土地私有。
2. **定驯化动物**: 按 Diamond "安娜·卡列尼娜原则"(群居/等级制/不惊逃/杂食/生长期短)选可驯化物种; 马改变战争形态, 牛改变耕作与产权。
3. **让作物"反向塑造"人**: 小麦要求季候劳役, 水稻要求水权分配——问"这种作物把人改造成了什么"。
4. **定定居形态**: 先定居后农业(纳图夫/Göbekli Tepe模式)或先农业后定居; 利用"驯化前栽培"的漫长时差(栽培数百年、形态无区别)做历法与土地记忆设定。

**[决策规则]**
- 农业是"选项"而非"阶段": 允许拒绝者(沿海渔业/根茎族群)、半途而废者、被农业"俘获"者——天然生成文明分叉与冲突线。
- 多中心而非单一摇篮: 2~4 个独立驯化中心, 各有独特作物, 碰撞即世界史引擎。
- 农业有代价(更矮/龋齿/传染病/森林退化)——定居的阴暗面是叙事富矿。

**[输出产物]** `生计档案`(每文明: 标志作物/驯化动物/定居形态/农业代价)。

**[检查点]** 作物包与政体形态逻辑一致; 驯化物种符合可驯化性原则。

---

## 第 3 步: 国家形成与政体形态

**[输入]** 生计档案 + 地理(限域条件)+ 世界法则。

**[操作]**
1. **选国家形成路径**: 限域+战争聚合(Carneiro)、水利科层(Wittfogel, 慎用)、贸易再分配中心(Service)、内部冲突固化(Fried)、酋邦渐进(Service 四阶段: 游群→部落→酋邦→国家)。
2. **定政体形态**(参考笔记 17): 在光谱上定位——部落联盟/酋邦/城邦/王国/帝国/共和/封建/神权。用 Tilly 的"强制-资本"模型设计分化: 强制密集(大地主+军队)、资本密集(商人寡头)、资本化强制(二者结合)。
3. **为每个政体写"合法性公式"与"结构性弱点"**(参考笔记 18): 神权怕神迹失灵, 共和怕寡头化, 封建怕王权坐大/割据失控, 帝国怕边缘离心——弱点即故事引擎。
4. **设计政体分岔点**: 每条时间线放 2~3 个"如果"(资源是否受限→酋邦还是部落联盟; 是否被强敌环伺→是否军国化; 祭司与王权谁胜出→神权还是世俗王朝)。
5. **政体与物质技术联动**: 书写→官僚与法典; 骑兵→军功土地分配(封建化); 灌溉→水利集权; 航海→城邦与商路共和国。

**[决策规则]**
- 把政体当"问题解决方案"而非"文明等级": 先定地理与资源禀赋, 再反推政体形态。
- 善用循环与退化: 酋邦崩溃、帝国解体、共和腐化为寡头, 都比"稳定王国"真实。
- 制造政体光谱与混血: 神权共和、商人寡头城邦、封建帝国、部落联邦、无国王的城市——真实存在过的"怪胎"最有记忆点。
- 同一大陆混存多政体(城邦文化区+帝国+部落带+国家逃避者), 用边界/朝贡/劫掠/联姻织成国际体系。

**[输出产物]** `政体档案`(每文明: 政体形态/合法性公式/结构性弱点/权力结构)。

**[检查点]** 政体与生计/地理自洽; 合法性公式与仪式配套; 弱点明确。

## 第 4 步: 社会结构、制度与治理

**[输入]** 政体档案。

**[操作]**
1. **用三条轴分层**(Weber, 参考笔记 19): 经济(阶级)、声望(地位)、权力(政治)独立设置——允许"地位崇高但无实权"的祭司、"富可敌国但低贱"的商人, 错位即剧情。
2. **选封闭—开放位置**: 种姓式(世袭+内婚+洁净禁忌+职业分工)/ 等级式(法权分等)/ 阶级式(名义流动); 为每种配物质标记(服饰颜色、发型、饮食禁忌、称谓、居住隔离、语言变体)。
3. **把亲属制度当宪法写**(参考笔记 19): 先定继嗣规则(父系/母系/双系)、居住规则、外婚规则, 再推演王位继承、联姻外交、谱牒合法性。
4. **设计"五种标准器物"**(参考笔记 20): 度量衡(标准器+铭文+惩罚)、货币(重量本位还是铸币)、历法(谁置闰? 改正朔=改朝换代)、户籍、邮驿——每项都是国家"可读性"投资。
5. **定国家能力短板**: 财政/法律/暴力三类能力(曼的基础性权力)不可能全强——给文明设短板作戏剧引擎(文书载体短缺、度量不统一、祭司垄断置闰)。
6. **设计成文法状态**(参考笔记 20): 是"王权纪念碑"(汉谟拉比式刻石宣示)还是"平民斗争产物"(十二铜表法式公开权利)? 法律来源神话、书吏阶层、法典修订政治。

**[决策规则]**
- 用蒂利机制让不平等"自我永续": 范畴对+机会囤积+空间隔离——结构性常态而非偶发事件。
- 设计血缘→地缘的转型事件(文字/赋税/征服/城市化/宗教改革), 同时保留旧制残余让转型半途而废。
- 文字诞生于行政记账(苏美尔模式)——文字首先是治理技术。

**[输出产物]** `社会档案`(分层结构/亲属制度/标准器物/成文法状态/国家能力短板)。

**[检查点]** 分层与物质标记配套; 亲属规则可推演继承冲突; 标准器物每项有设计。

## 第 5 步: 宗教、意识形态与合法性系统

**[输入]** 政体档案 + 世界法则(神明/魔法是否真实)。

**[操作]**
1. **选政教关系模式**(参考笔记 21): 法老式(王权吞并神权)/ 双剑式(双轨并立竞争)/ 哈里发式(政教合一、教法即宪法)/ 法理式(世俗化、宗教为私事)。
2. **用涂尔干设计"合法性再生产系统"**: 仪式日历(年度大祭/丰收节/凯旋礼/先王忌日)——集体欢腾维持社会凝聚; 庆典荒废=文明衰败信号。
3. **用韦伯设计统治者与危机**: 魅力来源(神裔血统/神谕加冕/预言应验)+ 魅力常规化机构(祭司团/圣职授予/圣典正典化); 卡里斯玛领袖挑战传统祭司=经典剧情。
4. **用意识形态理论设计统治机器**: 区分镇压机器(神殿卫队/裁判所)与意识形态机器(圣典学校/官方史馆/宗教剧场); 让统治思想以"常识/自然"形式存在; 为反抗力量安排异端教义/乌托邦。
5. **植入神义论作社会稳定器**: 给苦难官方解释(来世/业报/选民考验); 解释失灵(旱灾/战败/预言落空)→合法性崩塌。
6. **设计"宗教改革时刻"作文明引擎**: 参考埃赫那吞改革与宗教改革——教义重组=神学辩论+权力斗争+经济伦理转型+边疆战争, 一次性重构宇宙观/政体/日常伦理。

**[决策规则]**
- 混合合法性才真实: 传统+魅力+法理、神圣+世俗复合体; 不同来源互相支撑也互相摩擦, 摩擦处=政变/内战/分裂爆点。
- 政教合一模式下, 合法性危机表现为"谁的释经权有效"。

**[输出产物]** `意识形态档案`(政教模式/仪式日历/合法性公式/统治机器/神义论方案/改革时刻)。

**[检查点]** 仪式系统与政体配套; 神义论与现实(苦难)自洽; 改革时刻有触发条件。

## 第 6 步: 扩张、互动与兴衰(文明之间的动力学)

**[输入]** 全部档案 + 地理篇(边疆/商路/海峡)。

**[操作]**
1. **定扩张驱动**(参考笔记 22): 军事征服/贸易扩张/殖民定居/文化同化——四型可组合, 每种有内在代价(贸易帝国怕节点成本、征服帝国怕边防开支、定居帝国怕边疆离心)。
2. **画边疆几何**: 边疆=生态梯度(山/海/草原/沙漠交界)——扩张是"填满边疆"(特纳式内部殖民)还是"越过梯度"(拉铁摩尔式接触带)? 画三带图(核心区/过渡带/异质边缘), 每带配不同统治技术(郡县/藩属/朝贡/征而不治)。
3. **建"统治菜单"**: 行省(高收益高成本)/附庸藩属(中收益低成本)/朝贡(名义收益极低成本)/羁縻点(要塞+商栈)——让政权沿菜单移动。
4. **设计同化机制具体通道**: 公民身份阶梯/通婚政策/宗教皈依税收优惠/边缘精英入仕/退伍军人定居点——同化的本质是提供上升通道。
5. **装"世界体系"骨架**(参考笔记 23): 中心-半边缘-边缘(沃勒斯坦); 半边缘最出戏(夹在两大帝国间的商业城邦); 贸易网络有物理节奏(季风/商队季节/分段贸易接力); 给物品写"文化传记"(单一商品叙事线串起多文明)。
6. **设计兴衰弧**(参考笔记 25): 用四模型叠加——斯宾格勒(文明有机体/阶段对照)、汤因比(挑战-应战/创造少数→统治少数)、泰恩特(复杂度边际收益递减/崩溃=理性简化)、戴蒙德(五因素审计表); 加"精英过度生产"周期(图尔钦)。
7. **设计"轴心时刻"作世界观枢纽**(参考笔记 24): 多个政体同时经历城市化+文字普及+王权危机, 各自产生超越性反思并定形经典——此后一切正统/异端都回望这一时代。
8. **区分政治崩溃与文化连续性**: 设定"文明母体"(文字/宗教/技术/礼仪)在帝国覆灭后存活, 经历"中间期"重组——帝国灭亡不是终点, 是复兴纪元起点。

**[决策规则]**
- 过度扩张当叙事引擎: 给帝国可量化财政指标(税基 vs 边防军费), 让两者失衡(多线战争/精英职位过剩/边疆总督自立)。
- 首次跨大陆接触套用"大交换"链条: 病菌→人口崩溃→劳动力重组→作物牲畜置换→生态重塑→制度话语殖民——征服者靠"生物包裹"而非武力。
- 衰落≠一夜崩塌: 渐变-触发-重组三阶段设计。
- 反本质主义: 每个文明内置异端与辩论, 文明"核心"永远是动态再诠释。

**[输出产物]** `文明动力学档案`(扩张驱动/边疆几何/统治菜单/同化通道/世界体系位置/兴衰弧/轴心时刻/文明母体)。

**[检查点]** 兴衰与财政/环境/精英结构自洽; 接触事件有连锁反应; 文明互动史完整。

## 第 7 步: 一致性总检(文明篇)

**起源层**:
- [ ] 摇篮位置有农业剩余的地理理由; 起源机制与制度痕迹一致;
- [ ] 判据缺席项有替代方案; 原生/次生关系明确。

**生计层**:
- [ ] 作物包与政体逻辑一致(谷物→集权, 薯芋→平等, 稻作→水利官僚);
- [ ] 驯化物种符合可驯化性原则; 作物反向塑造人(劳动节律/产权/水权)。

**政体层**:
- [ ] 政体与生计/地理自洽; 合法性公式与仪式配套;
- [ ] 结构性弱点明确且是故事引擎; 政体分岔点有"如果"记录。

**社会制度层**:
- [ ] 三条轴分层(阶级/地位/权力)独立; 物质标记配套;
- [ ] 亲属规则可推演继承冲突; 标准器物每项有设计;
- [ ] 成文法状态与书吏阶层明确; 国家能力短板作戏剧引擎。

**意识形态层**:
- [ ] 政教模式定位; 仪式日历与集体欢腾系统;
- [ ] 神义论与现实自洽; 改革时刻有触发条件。

**动力学层**:
- [ ] 扩张驱动有代价; 边疆几何与统治菜单匹配;
- [ ] 同化通道具体(上升通道); 世界体系位置明确;
- [ ] 兴衰弧与财政/环境/精英结构自洽; 文明母体设定;
- [ ] 第 0 步需求清单逐条满足。

# 第二部分: 贯穿示例(米拉斯文明篇)

> 地理篇的米拉斯世界: 龙骨山脉(灵脉)、苍原高原、丰饶平原、风语草原、白雾荒漠、北寒原、火链群岛、缝合地峡。

**第 0 步(需求)**: "魔法文明核心""航海贸易文明""冰封北境上古战场""沙漠商路文明""隐修文明"。

**第 1 步(起源)**: 原生摇篮在「泪湖群沿岸」(地中海式气候 Csa, 灵脉交汇)——起源机制组合: 仪式中心(灵脉圣所先于城市)+ 贸易再分配(盐晶与灵矿长途贸易); 判据: 有文字(灵纹, 源于记账)无大型纪念建筑(灵脉本身即"神殿"), 祭司即书吏。次生文明: 潮邦(模仿+对抗演化)、云顶寺(避世分支)。

**第 2 步(生计)**: 泪湖沿岸标志作物=灵稻(谷物, 可计量可征税→城邦联盟税制); 丰饶平原=苍麦(灌溉农业→水利官僚, 但被灵脉干扰水权); 风语草原=游牧(马+羊); 白雾荒漠=雾生藻+盐(绿洲商路); 火链群岛=渔+香料(海岛贸易)。

**第 3 步(政体)**: 灵枢城=神权城邦联盟(祭司-灵脉解释权=合法性); 潮邦=商人寡头航海共和国(资本密集, Tilly 资本路径); 云顶寺=神权隐修政体; 风语游牧=部落联盟(裂变制); 雾盐邦=沙漠商路城邦; 北境遗民=军事守备酋邦。分岔点: "灵脉爆发(41 年血月周期)时祭司权力 vs 世俗王权谁受益"→历史上曾发生过一次"灵权革命"。

**第 4 步(社会制度)**: 灵枢城=等级制(灵脉亲和度分等, 物质标记=灵纹刺绣); 亲属=母系继嗣(灵脉亲和经母系遗传); 标准器物: 灵刻度量衡(灵晶恒重)、盐本位货币、双月历(血月置闰=祭司权力)、灵户籍(灵脉亲和登记); 成文法=灵碑法典(祭司宣示+平民援引双重性); 国家能力短板: 灵枢城财政强但暴力能力弱(依赖雇佣军)→外患剧情。

**第 5 步(意识形态)**: 政教模式=哈里发式变体(灵教法即宪法, 灵脉祭司=释经权持有者); 仪式日历=血月祭(41 年大祭)/双月节; 神义论="灵脉赐予与收回"(干旱=灵脉不悦); 改革时刻=历史上"灵权革命"(卡里斯玛先知挑战祭司垄断)→现代灵枢城的正统/异端之争。

**第 6 步(动力学)**: 潮邦=贸易扩张(控制银海峡口与季风航路, 半边缘转口商); 灵枢城=文化同化(灵教传播, 上升通道=灵脉学院); 缝合地峡=边疆接触带(南北文明缓冲); 兴衰弧: 灵枢城正处于"创造少数→统治少数"的汤因比式衰落期(祭司寄生化), 41 年血月大祭临近=合法性审判时刻; 世界体系: 潮邦(半边缘商业枢纽)-灵枢城(中心-宗教文化)-雾盐邦/北境(边缘原料)-风语草原(中间商+游牧压力); 轴心时刻=800 年前的"灵权革命"时代(诸文明同时经典化); 文明母体=灵纹文字+灵教+历法, 经历过一次"中间期"后重组。

**第 7 步(检查)**: 全部通过; 需求清单: 魔法文明核心✓ 航海贸易✓ 北境战场✓ 沙漠商路✓ 隐修✓。
