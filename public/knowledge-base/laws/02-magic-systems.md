# 魔法系统设计

> Sanderson 三定律、硬软魔法光谱、代价与限制、能量来源、魔法与科技边界。

## 桑德森魔法三定律

1. **第一定律**: 作者用魔法解决冲突的能力, 与读者对这套魔法的理解程度成正比——硬魔法适合解谜破局, 软魔法适合制造惊奇; 用读者不懂的魔法解决危机, 读者会感到被骗。
2. **第二定律**: 限制比力量更重要——系统的趣味来自代价/弱点/约束而非能力清单; "什么都能做"的系统在叙事上等于没有系统。
3. **第三定律**: 在已有魔法上扩展, 而非不断添加新魔法——新增能力稀释一致性, 扩展现有能力加深读者理解。

## 硬魔法 vs 软魔法(光谱而非二元)

| | 硬魔法 | 软魔法 |
|---|---|---|
| 规则 | 明确、读者可知、可预测 | 模糊、机制神秘 |
| 叙事用途 | 解谜/谋划/"用规则破局" | 敬畏/惊奇/不可测神力 |
| 读者参与 | 可推理、可博弈 | 只能旁观 |
| 案例 | 迷雾之子金属学/修仙境界 | 中土甘道夫/冰与火低魔 |

多数成熟系统落在光谱中间; 推荐"硬内核+软边缘"(硬规则管日常冲突, 软现象管世界观惊奇)。**光谱位置就是叙事承诺, 不可摇摆。**

## 代价与限制的四种形态

1. **消耗**: 法力/体力/材料/稀有资源→资源管理/补给线/经济设定(迷雾之子金属库存=战斗即库存管理);
2. **副作用**: 精神腐蚀/寿命缩短/肉体变异/灵魂损伤→角色弧线与禁忌职业(裂金术毁容灵魂→异端教团);
3. **禁忌/社会代价**: 施法被宗教禁止/法律管制/道德地位代价→猎巫与禁魔法;
4. **机会成本与时间**: 数十年学徒/每日仪式/施法前摇→魔法师成为稀缺社会角色。

## 能量来源(权力拓扑分类学)

| 类型 | 机制 | 社会连锁 |
|---|---|---|
| 个人型 | 血脉/天赋/内气 | 天赋贵族制与血统决定论(迷雾之子贵族) |
| 环境型 | 自然/土地/季节/星象 | 地理决定论, 魔法强弱随地域变化 |
| 神圣型 | 神灵授予/神选 | 神权政体与祭司阶层, 魔法是恩典而非技能 |
| 器物型 | 法器/金属/卷轴/魔杖 | 工匠/收藏/黑市与掠夺经济 |

多数系统为复合型, 但应有一个主导来源作为"第一因"。

## 魔法与科技的边界

系统化/可复制/可量产的魔法本质就是"科技"(Clarke 第三定律反向成立)。这条边界决定: 生产力水平/战争形态/知识传承方式(口传vs文献vs学院)。**魔法可系统化→世界经历"科学化→工程化→工业化"(迷雾之子第二纪元示范); 魔法不可系统化(中土型)→历史节奏由神话事件而非生产力驱动。**

## 构建操作

1. **法则第一, 设定随后**: 确定"能量来源+消耗+限制+媒介"后立即推演连锁反应——谁能施法(阶级)、施法需要什么(贸易/矿藏/朝圣)、有何禁忌(宗教/法律)、如何被组织(学院/教会/行会/军队)、历史被什么改写;
2. **用第二定律反推世界**: 先定"代价"再定"力量"——代价是角色与世界摩擦面的来源;
3. **从单一核心法则生长而非堆砌**: 像金属学从"金属+消耗"一个核心长出三套体系——先定一个不可再分的第一法则再派生; 每加新能力都问: 它是否违背已展示的来源与代价?
4. **一致性红线+铺垫豁免**: 所有已被读者理解的规则解决关键冲突时必须遵守; 引入新能力必须提前铺垫——把"新能力救场"从偶然降为"读者可预见的必然"。
