# 文化总流程与接口

> 目的: 从 0 到 1 构建一套自洽的文化体系——先定意义公理, 再推导规范与制度, 沿"世界观公理→价值观→规范→制度→仪式习俗→物质痕迹"推导链生成文化档案, 最后与文明、语言、地理、经济模块接口咬合。
> 前置: 消费文明模块的社会结构/技术/生态输出; 生产语言、神话、艺术、习俗等文化产品的输入。若世界存在超凡力量, 文化须与之有明确定义的接口。

## 核心立场: 意义先于习俗

- **文化是意义之网**: 由代代传承的符号系统构成, 人是悬挂在自己编织的意义之网上的动物。文化分析是寻求意义的解释, 不是罗列现象——每个习俗都要回答"它意味着什么", 而非只记录"发生了什么"。
- **文化≠文明(意义系统 vs 组织制度)**: 文化是意义系统(软件层: 价值观/观念/象征), 文明/社会是组织系统(硬件+组织层: 结构/角色/制度)。二者互为接口: 文化为制度供给合法性, 制度为文化供给载体。构建时必须分档建、连箭头, 不可混写。
- **公理先行**: 每个文化先回答五问(人性观/人与自然关系/时间取向/活动取向/关系取向), 此后一切规范、仪式、艺术、禁忌都必须能回溯到这些公理。答不出的习俗即删。
- **仪式必须过功能关**: 仪式不是装饰, 是社会结构的压力阀与黏合剂——每个仪式强制回答: 转换什么身份? 处理什么张力? 团结谁? 标记什么集体记忆?
- **唯物主义一致性**: 物质基础(生产/生态/人口)构成约束集, 文化在其上选择与回填。用三层模型(基质=生产方式 / 结构=制度 / 上层建筑=宗教艺术意识形态)核对习俗与生计的兼容, 防止"文化空转"。允许"神圣"与"理性"两套解释并存, 但二者都要存在。
- **文化是整体人格**: 每个文化围绕少数主导主题把习俗整合成连贯模式, 不是习俗清单。"清单病"正是缺整合审查所致。
- **文化靠濡化传递**: 教育、学徒制、育儿方式、仪式都是价值观代际传递的管道——虚构世界里"价值观如何传下去"必须写明具体通道(如成人礼即灌输载体)。

## 推导链与接口

| 层 | 关键内容 | 接口对象 |
|---|---|---|
| 世界观公理 | 五问之答、本体论假设(何物存在/起源/死后/能动性/人-自然) | 本模块输入 |
| 价值观 | 价值取向、道德基础、时间观自然观 | 本模块内部 |
| 规范 | 禁忌/允许、法律、道德 | 本模块内部、文明模块 |
| 制度 | 角色与组织、权力、继承 | 文明/历史模块 |
| 仪式习俗 | 节日、通过仪式、仪式库(每条含功能栏) | 本模块输出 |
| 物质痕迹 | 器物、建筑、葬式、饮食 | 地理/经济模块 |

依赖方向单向: 公理→规范→制度→仪式→物质痕迹。每一环须能逆推回上一环; 断裂处即"无推导价值观"或"无功能仪式"。反向回填须逐级一致性检查, 并用版本号记录推导链变更。

## 文化档案清单

| 字段 | 内容要点 |
|---|---|
| 核心公理 | 五问之答, 一条一行 |
| 世界观 | 本体论、时间观、自然观、空间观 |
| 规范与禁忌 | 分级(神圣/民德/礼节), 每条标注来源公理 |
| 仪式库 | 每条含功能栏(转换/张力/团结/记忆) |
| 艺术风格 | 符号语义、审美对立轴 |
| 生活史节点 | 出生/成年/婚/丧习俗 |
| 神话与神谱 | 创世机制、宪章神话 |
| 语言文化编码 | 称谓/敬语/时态与价值取向互检 |
| 文化记忆 | 创伤与黄金时代、选择性遗忘 |
| 内部多样性 | 中心-边缘、正统-异端、代际/性别差异 |
| 变迁史 | 外来冲击、改革与保守、价值冲突场景 |

## 构建操作

1. 先固化依赖图与版本号: 明确文化模块的输入(地理/生态/经济/文明制度)与输出(语言/神话/艺术/习俗), 任何外部模块改动沿链回填并登记版本, 避免"先画龙后画风"式返工;
2. 先写公理页: 回答五问+本体论问题, 写入档案首页, 作为全模块推导根——此页未定, 不动习俗;
3. 沿推导链逐层生成: 公理→价值观→规范→制度→仪式习俗→物质痕迹, 每层标注回指的上层条目, 断裂即补或删;
4. 为每个仪式写功能卡: 强制回答转换什么/处理什么张力/团结谁/标记什么记忆, 并用"分离→阈限→聚合"三阶段核查结构完整度;
5. 做唯物主义一致性审查: 用三层模型核对每个习俗与生产、生态、生理基础的兼容(沙漠文明葬俗、渔猎文明禁忌、极端气候成年礼), 允许"神圣/理性"双解释并存;
6. 制造内部多样性: 每个文化至少两个内部张力轴(地域/阶级/宗教/代际), 至少一个可由生态推导; 配置正统-异端与失范者及其惩罚;
7. 与语言/文明模块互检: 称谓、敬语、时态应反映价值取向(未来取向文化多有丰富未来时态); 每个制度注明"合法性来源", 每个意义注明"物质载体";
8. 内置变迁接口: 设计外来冲击、改革派与保守派、价值冲突场景, 让文化成为会自我表演、会冲突的活系统, 而非静态设定。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 把文化写成习俗清单 | 围绕少数主导主题整合, 每习俗回答"意味什么" |
| 文化与文明混写 | 意义层与制度层分档, 连箭头注明接口 |
| 价值观无推导(悬浮设定) | 一切规范/禁忌回溯到公理, 答不出即删 |
| 仪式无功能(装饰性节日) | 仪式功能卡: 转换/张力/团结/记忆 |
| 文化空转(与生计/生态脱节) | 三层模型一致性审查 |
| 全族一帽(单一扁平文化) | 至少两个张力轴, 其一可由生态推导 |
| 文化静态不变 | 内置变迁接口: 冲击/改革/冲突场景 |
| 价值观不知如何传递 | 写明濡化管道: 教育/学徒/育儿/仪式 |

## 检查点/清单

- [ ] 公理页齐备(五问+本体论), 一切规范可回溯?
- [ ] 意义层与制度层分档, 接口箭头标注完整?
- [ ] 推导链每环可逆推, 无断裂?
- [ ] 每个仪式有功能卡并通过三阶段核查?
- [ ] 唯物主义一致性审查通过, 无"文化空转"?
- [ ] 至少两个内部张力轴, 其一可由生态推导?
- [ ] 濡化管道明确(价值观如何代代相传)?
- [ ] 变迁接口存在(冲击/改革/冲突)?
- [ ] 语言、文明模块互检完成?
