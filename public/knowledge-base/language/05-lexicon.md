# 词汇与语法设计

> 目的: 从核心词表起步建设词汇库,按语义场逐场扩展,用派生词缀编织词汇家族,按接触史分层借词,选 1~2 个"语法签名"深度塑造,并在自然与人工之间取得平衡。
> 前置: 音系篇(04)提供全部语音原料(借词音系适配的依据);与类型学篇(02)的语法特征、历史篇(03)的接触期联动。

## 核心理论

- **核心词表 = 基本词汇采样器**: 100 词表剔除了易被借词替换的文化词(雪/盐),保留代词、身体部位、亲属等泛文化词项,因此更稳定;207 词表在 100 词基础上增补环境、动作、状态词。词表不再用于精确断代,但仍是亲属关系速测与词汇建设的起点。
- **稳定性梯度**: 人称代词、身体部位、亲属、数字 1~2、日月水火最稳;文化器物与低频词最易替换。高频核心词几乎不被替换,是判断"哪些是借词"的关键线索。
- **语义场按"演化阶梯"逐级扩展**: 色彩词按"黑/白→红→黄/绿/蓝→…"的等级序列逐级增加,不是随机堆叠;扩展机制有隐喻(身体部位→空间/抽象: "头"→顶端、首领)、转喻(容器→内容、工具→职业)、语义漂移(变宽/变窄)、词义攀升(委婉化)。
- **派生造新词,屈折表范畴,二者是连续统**: 派生创造新词位并可改变词类;屈折表达时/格/数而不造新词。词汇家族=一个词根+一组派生词缀构成网络;词缀分能产(可自由造新词)与化石(残存于少数词)两层,这是自然语言常态。
- **借词按历史接触期分层**: 每层对应不同语义域与音系特征,是"地层学"式的语言史证据;音系适配(归化)强制改写借词——音段替换、增音、删音、重音规则化;也可故意保留"外来层"发音作社会/文体标记。借词语义常收窄或移位。
- **语法特色只取 1~2 项深度做**: 作格(不及物主语与及物宾语同格)、名词类(互斥类别+一致关系)、证据性(语法化的信息来源范畴: 视觉/非视觉/推断/假定/传闻)、自由语序(服务于话题焦点等语用,绝非随机排列)。
- **语序与格系统联动**: OV 语言修饰语前置、VO 语言修饰语后置(分支方向谐和);SOV 语言约半数用格标记,SVO 语言更依赖语序区分角色。标记位置分依附标记与从属标记,决定格/一致形态落在哪一端。
- **自然 vs 人工的平衡**: 自然语言的不规则是高频磨损与历史演变的结果(高频词更易磨损、更易保留不规则);人造语言天然过度规则。自然主义的做法: 先设原始形式,再施加历史音变与形态合并,让不规则"有来源"。

## 语义场扩展路径表(逐场清单)

| 语义场 | 扩展路径 | 示例 |
|---|---|---|
| 色彩 | 按等级阶梯逐级增加(黑/白→红→黄绿蓝→灰棕橙紫粉) | 三色系统 vs 六色系统 |
| 亲属 | 按亲属制度生成(二分制/直系制/夏威夷制) | "堂表亲"是否与"兄弟姐妹"同词 |
| 身体→空间 | 身体部位隐喻投射(头→顶端、背→后面、口→入口) | 方位词来源 |
| 情感 | 身体感受转喻情感(心/肝/腹为情感器官) | 情感动词的构词 |
| 技术 | 新物命名三策: 造新词/复合/借词 | 铁器、马具、书写工具 |

## 词缀分层与借词适配规则(设定模板)

| 机制 | 说明 | 设定写法 |
|---|---|---|
| 能产词缀 | 可自由造新词(复数、否定、使动) | 10~15 个,配派生规则 |
| 化石词缀 | 残存于少数词,不产新词 | 留 3~5 个作"古语残留" |
| 借词音段替换 | 外来音换成最接近的本语音 | 借词表+替换映射表 |
| 借词增音 | 插入元音拆散外来辅音丛 | 借词读音明显"本土化" |
| 借词删音/重音化 | 删除难发音段、套本语重音 | 重音规则统一化 |
| 外来层保留 | 故意保留外来发音作文体标记 | 贵族/学者口音的来源 |

## 机制与案例(可迁移的设定模板)

- **语法签名组合范例**: "作格+证据性"组合——作格塑造"结果导向"文明(谁被视为施动者),证据性塑造"崇尚实证"文明(视觉直接证据成为强制范畴);每个签名写成完整规则页,其余语法采用典型类型。
- **作格分裂模板**: 按时体分裂(现在时主宾格、过去时作格)或按人称层级分裂(一二三人称不同对齐)——"部分作格"比全作格更自然,可作"过渡态古语"设定。
- **名词类模板**: 语义核心清晰+形式规则延伸(类前缀同时标记单复数,使"类"与"数"纠缠);规则从语义主导到形式主导连续变化。
- **构词范例**: 无界复合(整词连写)、向心复合(中心词决定词类,如"黑鸟")与离心复合(整体词类异于部件,如"红头");一个词根加一组派生词缀构成词族,词族反映历时借词的多层沉积。
- **特色语言示范(陌生化梯度)**: 冷门语序+作格标记→外星异质感;动词形态层+不规则复数→"活语言感";名词类前缀+证据性策略→生态文明感。

## 构建操作

1. 先定"语法签名": 从作格、名词类、证据性、自由语序中选 1~2 项深度做,写成完整规则页;其余语法采用典型类型,防止特征堆砌导致不自然;
2. 词汇库三层建设: ①100~207 核心词全自创、形态尽量简单、高频词允许不规则;②从 20~30 个词根辐射出词汇家族,定 10~15 个能产词缀并配派生规则;③借词按文明接触史分层,每层配一套音系适配规则(如"精灵语借词保留长元音,人类语借词增音填音节");
3. 用"演变脚本"生成不规则: 写 3~5 条历史音变规则(元音链移、词尾辅音脱落等),手工套用到高频词,得到有词源依据的不规则动词/复数/属格,而非随机乱造;
4. 语序与格联动设计: 选定主序后按谐和原则推副序(SOV→后置词+属格前置);若做自由语序,必须配套话题/焦点标记与语用规则,并说明格系统如何分担语义角色;
5. 语义场扩展清单化: 按色彩等级阶梯、亲属系统(可做二分亲属)、身体→空间隐喻等路径逐场扩展,每新增一词记录"词源+构词路径",汇成词源词典;
6. 借词层写入世界史: 每层借词对应一个文明接触期,借词方向即权力/文化关系;区分征服层、宗教层、科技层的借词域;
7. 控制同音歧义密度: 每百词制造 1~3 个同音/多义词增强自然感,但保证语序、助词、话题标记等语境消歧手段存在;可让"神名/禁忌词"触发同音回避作叙事钩子;
8. 产出三份配套文档: 音系规则手册、构词/词缀手册、词源与借词词典,保证后续创作中词汇与语法高度一致。

## 检查点/清单

- [ ] 语法签名 1~2 项已定,其余语法为典型类型,无特征堆砌?
- [ ] 100~207 核心词全部自创且高频词不规则(有词源解释)?
- [ ] 20~30 个词根 + 10~15 个能产词缀,词汇家族已建?
- [ ] 不规则形式有演变脚本来源(音变/形态合并),非随机乱造?
- [ ] 语序与格系统联动正确(谐和原则),自由语序配套语用规则?
- [ ] 语义场逐场扩展完成,每词有词源+构词路径记录?
- [ ] 借词层与接触史一一对应,每层有音系适配规则?
- [ ] 同音/多义词密度受控(每百词 1~3 个),消歧手段存在?
- [ ] 三份配套文档(音系手册/构词手册/词源词典)齐全且一致?
- [ ] 无"全球通用核心词"——各语言核心词音系内自洽?
