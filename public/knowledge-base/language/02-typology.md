# 语言学基础与语言类型学

> 目的: 用跨语言统计规律给虚构语言定"骨架",使其在统计意义上"像真的"——先选基本语序,再用谐和相关对自动推导其余语序,按特征配方逐项检查。
> 适用: 任何需要"一门听起来/读起来可信的语言"的世界构建;与音系篇(04)、词汇篇(05)、演化篇(03)配套使用。

## 核心立场: 语言类型学 = 以共性为目标、以差异为材料

- **蕴含共性优先于枚举差异**: 类型学不罗列"哪门语言有什么",而是回答"若语言有 X 则必有/常有 Y"。世界构建用蕴含式做"配方检查",比照抄某一门真实语言更省力。
- **语序是头号骨架参数**: 六大基本语序全球分布约为 SOV 41% / SVO 35% / VSO 9% / VOS 2% / OVS 1% / OSV <1%;主语前置占绝对优势,宾语后置亦占绝对优势。选冷门语序(OVS/OSV/VOS)可制造异质感,但要有文化或历史解释。
- **VO/OV 两大阵营共变(分支方向谐和)**: 递归性成分(属格、关系从句、介词短语)按"头前/头后"与动词-宾语方向同侧。OV 语言倾向"属格-名词、名词-关系从句、后置词、动词后副词";VO 语言反之。形容词位置与基本语序弱相关——"形容词前置"不等于"头前语言",这是常见设定误区。
- **格系统与语序自由度是权衡项**: 显性格标记语言(屈折/附着)容许更自由语序;无格标记语言语序僵化。二者都强是罕见配置;格弱化常与语序固定化同步。
- **特色机制只取 1~2 个**: 作格、名词类、证据性、多一致、自由语序等"特色范畴"各需绑定触发条件与文化动机;堆砌过多特征必然不自然。

## 关键特征选型表(8~12 特征配方)

| 特征维度 | 主流选项 | 世界构建用途 |
|---|---|---|
| 基本语序 | SOV / SVO / VSO(冷门: VOS/OVS/OSV) | 全语言骨架,决定其余语序 |
| 介词类型 | 前置词(VO 谐和) / 后置词(OV 谐和) | 与基本语序必须谐和 |
| 格标记 | 零标记 / 附着 / 屈折 | 决定语序自由度 |
| 对齐类型 | 主宾格 / 作通格 / 分裂作格 | 塑造"结果导向"文明气质 |
| 名词类 | 无 / 2~4 类(语义核心+任意延伸) / 10+ 类(类前缀+全链一致) | 分类即世界观(元素/物质/神性) |
| 动词一致 | 主语一致 / 多一致(标引主宾乃至间接宾语) | 仪式语、古语质感 |
| 证据性 | 无(词汇策略) / 2~5 系强制范畴 | 神谕语辨真伪、祭司话语权 |
| 声调 | 无 / 2~6 调 | 地域聚集特征,音系气质 |
| 复辅音 | 无(纯 CV) / 简单 / 复杂丛 | 与声调倾向互斥(声调语多简单音节) |
| 疑问策略 | 助词 / 疑问词移位 / 语序变化 | 对话文本的细节素材 |

## 蕴含关系速查(配方检查表)

- 前置词语 → 属格后置名词;后置词语 → 属格前置名词。
- SOV → 后置词 + 属格-名词 + 名词-关系从句 + 动词后副词。
- SVO → 前置词 + 名词-属格 + 关系从句-名词 + 动词前副词。
- VSO → 几乎必为前置词语言。
- 无格标记 → 语序僵化(靠语序区分角色);显性格 → 语序自由。
- 声调语言 → 倾向简单音节结构(少复辅音)。
- 刻意违反某条相关对(如"VO 底层+OV 表层"的框架结构)时,必须写一段历史漂移/语言接触的设定作解释。

## 特色机制设计要点

- **分裂作格**: 同一语言按维度切换对齐——按时态/体(过去/完成体用作格,如印地语式)、按人称(一二三人称层级)、按生命度层级。设定时必须明确分裂维度,否则作格设定无效。
- **名词类**: 约 1/4 语言有强制性名词分类;核心语义清晰(人类/器物/可食植物/其余)、边缘任意延伸。类前缀+全链一致(形容词/动词/代词皆随类变化)是强机制;设计"语义核心+任意边缘"的模板。
- **证据性**: 强制语法范畴,区分亲历/听闻/推断/传闻;需同时规定句法义务(是否每句必选)与社会语用(谁有权用亲历系——可映射为祭司/贵族话语权)。
- **多一致与名词并入**: 助动词同时标主/宾/间接宾语人称数(巴斯克式),或把宾语名词并入动词词干(纳瓦特尔式);多式综合语把整句压入一个"词",适合塑造古语/秘仪语质感。

## 构建操作

1. 先选"骨架"语序(SOV/SVO/VSO),再按谐和相关对一次性定下介词类型、属格位置、关系从句位置、副词位置、疑问词位置,形成内部一致的"类型包";
2. 用 8~12 特征配方表逐维选值,逐对检查蕴含关系,排除统计上互斥的组合(如"无格标记+完全自由语序""SOV+前置词");
3. 特色机制只取 1~2 个,并绑定触发条件与文化动机: 元素文明用物质名词类、神谕语言用证据性区分真伪、魔法语言用逆向一致体现"受动者中心"世界观;
4. 格系统与语序自由度配套设计,并物化为世界观隐喻: 显性格语言设定为"古籍/古代语"(语序自由),无格标记现代语语序固定;
5. 参照地理聚集规律画"语言地图"而非孤立语言: 让相邻语系共享类型特征,设置 1~2 个语言联盟(如"大陆中部的后置词联盟");核心文明语言保守古旧,边疆/商路语言混合漂移;
6. 音系与类型匹配: 按常见音段选音系(三元音 /i a u/、p/t/k、m/n),奇异音段(吸气音、超复杂复辅音)只出现在地理或文化可解释的角落;
7. 多一致/名词并入用于"仪式语": 把复杂度分配给"过去高地位语言",符合真实语言兴衰规律;
8. 设定文档中为每项特征标注类型学依据(对应 WALS 特征号或原理),使设定可审计、可修订,避免"想到哪写到哪"的内在矛盾。

## 检查点/清单

- [ ] 基本语序选定,且介词/属格/关系从句/副词位置全部谐和?
- [ ] 无统计上互斥组合(无格标记+自由语序 / SOV+前置词)?
- [ ] 特色范畴 ≤2 个,各绑定触发维度与文化动机?
- [ ] 分裂作格写明了分裂维度(时体/人称/生命度)?
- [ ] 证据性写明了义务性与社会语用(谁有权用亲历系)?
- [ ] 名词类有语义核心+任意延伸,且一致规则完整?
- [ ] 格系统与语序自由度配套,无"双强"违和配置?
- [ ] 相邻语系共享类型特征,语言联盟已设定?
- [ ] 音系与类型匹配(声调/复辅音不互相打架)?
- [ ] 每项特征可追溯设定依据,无拍脑袋项?
