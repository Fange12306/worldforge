# 星系与星际环境

> 目的: 把文明放回星系尺度——星系类型、银河系结构、星际介质、星团星云、暗物质与星系际空间,以及"星系环境如何约束宜居性"。
> 前置: 02 的星系形成与 03 的尺度;本篇输出星图与航线环境,是恒星际政治、星际航行与区域设定的输入。

## 核心理论/机制要点

**星系分类(哈勃序列)**

| 类型 | 特征 | 文明基调 |
|---|---|---|
| 椭圆 E0–E7 | 年老恒星、少气体、红色,星系团中心富集 | 资源枯竭、衰亡与考古 |
| 透镜 S0 | 无旋臂盘状 | 过渡型 |
| 旋涡 Sa–Sc / 棒旋 SBa–SBc | 有气体与活跃恒星形成,盘面年轻蓝星 | 活跃星际文明带 |
| 不规则 Irr | 结构散乱,多为相互作用或矮星系 | 蛮荒、粗粝但可藏匿 |

- **矮星系**(矮椭球、矮不规则)数量占绝大多数,暗物质占比最高;分类不是静态的——并合、潮汐作用让星系在类型间演化。

**银河系结构(棒旋星系四部分)**
- 银盘(薄盘厚约 300–1000 pc,厚盘 1–2 kpc): 年轻星、气体、尘埃、疏散星团,金属丰度高——文明腹地与交通干线;旋臂是恒星形成主要场所,是"密度波"图案而非物质臂。
- 核球与棒(银心区,年老星为主): 危险又富集的权力中心。
- 银晕: 球状稀疏分布的年老贫金属恒星与球状星团(约 150–200 个,年龄可达 130 亿年,银河系最古老天体)——"每个球状星团是一个封闭文明方舟"。
- 暗物质晕: 质量主体,不可见骨架。
- 参考坐标: 太阳位于本地臂内缘,距银心约 2.6 万光年,绕银心一周约 2.2–2.4 亿年(银河年),并上下穿越银道面振动。

**星际介质(多相模型: 空间不是真空)**

| 相 | 温度/密度 | 构建用途 |
|---|---|---|
| 分子云 | ~10 K,10²–10⁶ cm⁻³ | 恒星形成摇篮=无法穿行的屏蔽区 |
| 冷/温中性氢 | 50–6000 K | 普通空间 |
| 暖电离氢(H II 区) | ~8000 K | 高辐射禁航区 |
| 热电离冕气体 | ~10⁶ K | 超新星遗迹 |

- **尘埃**造成消光与红化(远方恒星变暗变红),银盘平均消光约每 kpc 1 等——远程观测被限制,"星图的不完整"是叙事资源;暗星云=天然伏击暗区,尘埃带=航行减速带。
- **宇宙线**(约 90% 质子)由超新星激波加速,被银河磁场约束;磁场通过磁压支撑气体,影响分子云坍缩。

**星团与星云**
- 星团: 疏散星团(年轻、富金属、银盘)vs 球状星团(年老、贫金属、银晕)。
- 星云按发光机制四类: 发射星云(H II 区,发 Hα 红光)、反射星云(尘埃散射星光呈蓝色)、暗星云(吸收背景光)、行星状星云与超新星遗迹(恒星演化产物)。

**星系际空间与暗物质/暗能量**
- 星系际介质是稀薄电离氢(可观测为吸收线森林);星系团内充满百万度热气体(发射 X 射线)。
- 大尺度物质构成**宇宙网**: 丝状结构连接节点(星系团),其间是巨大空洞(void)。丝状结构=天然"星际高速公路",星系团节点=枢纽,空洞=无信号的绝地。
- 暗物质(约 27%)由星系旋转曲线推断,是星系旋转与结构形成的"看不见的骨架";暗能量(约 68%)驱动空间加速扩张。

**恒星际环境宜居约束**
- 行星宜居不只看恒星,更受星系环境影响: **银河系宜居带**是介于内界(超新星、伽马暴频率过高,恒星形成过旺)与外界(金属丰度不足,难以形成类地行星)之间的环带。
- 危险源: 银河宇宙线(难以屏蔽的穿透辐射)、太阳粒子事件、近距离超新星(<50 pc 即可耗损臭氧层)、伽马暴对臭氧与大气层的破坏。行星磁场+大气层是主要屏蔽;星际航行要面对宇宙线剂量上限与高速微流星/星际尘埃撞击(相对速度数十 km/s)。

## 构建操作

1. 先给主角星系做"类型身份证": 旋涡星系=盘内有活跃星际文明带、晕中有古老遗民;椭圆星系=恒星形成早已停止,适合"文明衰亡与考古";不规则/矮星系=蛮荒粗粝但可藏匿——类型直接决定星图布局与势力分布;
2. 再用银河系结构当"世界观地图": 银盘=文明腹地与交通干线,旋臂间=蛮荒边疆,核球=危险又富集的权力中心,银晕/球状星团=与世隔绝的远古文明,空洞=流放地与监狱星域——政治地理直接由天文结构派生;
3. 把星际介质当作"地形与天气": 分子云=屏蔽区(隐藏新生文明或舰队基地)、H II 区=高辐射禁航区、暗星云=伏击暗区、尘埃带=减速带;尘埃与微流星密度差异让航线有真实风险差异;
4. 用星系动力学定"大周期": 旋臂穿越周期(数千万年)、银河年(2–3 亿年)与银道面振动设计成文明兴衰的"大年历";密度波经过时恒星形成爆发→"星潮期"带来资源与灾变;
5. 以银河系宜居带制造稀缺性: 宜居世界集中于窄环带,内界受超新星/伽马暴威胁、外界贫金属——宜居星即战略资源,边境冲突、航道争夺顺理成章;不同辐射环境迫使各文明发展不同科技(护盾/深居/生化适应);
6. 暗物质与宇宙网作"隐藏结构": 暗物质晕是星系不可见的骨架——可设定为"幕后文明寄居的质量层";宇宙网丝状结构是"星际高速公路",空洞=无信号绝地;
7. 星际航行设定要有物理锚点: 宇宙线屏蔽代价(被动屏蔽需极大质量)决定舰船设计逻辑;微流星撞击频率与相对速度限制航线选择——这些约束比"跃迁引擎"更易营造硬科幻的真实感。

## 检查点/清单

- [ ] 星系类型与文明基调、星图布局一致?
- [ ] 银盘/旋臂间/核球/银晕/空洞各自承担了叙事功能?
- [ ] 航线图标注了分子云/H II 区/暗星云/尘埃带等"天气"?
- [ ] 星系动力学大周期(银河年/星潮期)驱动了历史节奏?
- [ ] 宜居星稀缺性成立,辐射环境差异影响科技路线?
- [ ] 星际航行有宇宙线/微流星物理约束?
- [ ] 暗物质/宇宙网"隐藏结构"有设定用途?
