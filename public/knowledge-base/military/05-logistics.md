# 后勤与补给

> 目的: 用每日消耗表与补给链为一切战争设定建立硬约束——军队不是"先集结再补给", 而是"能补给到什么程度, 才能维持多大规模、走多远"。

## 核心机制

**1. 后勤决定战争**
- 战争胜负往往不由战略天才或战术优劣决定, 而由"喂饱军队"的能力决定。
- 推论: **机动速度的上限是补给速度, 而非行军速度**。补给线拉长、就地征粮失败即可致全军崩溃, 无需一场会战。

**2. 每日消耗表(所有军队的共同账单)**

| 单位 | 日均消耗 | 备注 |
|---|---|---|
| 步兵 | 约 1-2kg 谷物 + 约 3L 水 | 古代军团配给约 0.9-1kg/日 |
| 马/骡 | 10kg 以上草料 | 骑兵部队饲料重量常超过人粮("骑兵贵"的真因) |
| 火药武器 | 弹药无法就地补充 | 战斗常因"打完最后一发"而结束 |

**3. 杂志系统 vs 以战养战**

| 维度 | 杂志系统 | 以战养战 |
|---|---|---|
| 方法 | 边境与进军路线预设仓库(面包房/弹药库/饲料站), 沿"补给弧线"推进 | 就地征发/掠夺/采购养活军队 |
| 优点 | 稳定、可支撑大军、不扰民 | 机动快、可深入敌境 |
| 缺点 | 速度慢、路线僵硬、仓库是防守负担 | 依赖战区富庶与季节, 激怒民众引发游击战 |
| 军队性格 | 守强、怕断粮 | 机动快、怕焦土与坚壁清野 |

- 两种模式决定军队的"性格": 攻守节奏、可深入距离、对占领区民众的态度。

**4. 供给链三要素(粮/弹药/军饷)**
- 粮: 数量最大、无法跳过;
- 弹药: 火药时代重且无法就地补充, 弹药补给线是炮兵与火枪兵的命脉;
- 军饷: 无饷则兵变、劫掠、逃亡; 军饷来源(国库税收/战利品分成/雇佣金/贡赋)直接定义政权性质, **拖欠军饷是哗变与军队政治化的常规触发器**。
- 三条链任何一条断裂, 军队即告瓦解, 无需一场会战。

**5. 水运优先原则**
- 古代水运成本约为陆运的 1/10-1/20: 小麦陆运约 200 英里价格翻倍, 海运横跨大海仅上涨约 1/3。
- 陆运极限: 车辆与牲畜需自带草料, 超过约 3-5 日行程, 牲畜消耗即吞掉大部分载重("运输者吃自己"); 远程陆运损耗可达 90% 以上。
- 结论: 河流交汇点、海港、运河 = 天然的战略咽喉; 军队"能坐船就坐船, 能走河就走河, 陆路只走最短一程"。

**6. 围城逻辑 = 双方补给能力的对赌**
- 攻方须维持围困阵地并保护自身补给线; 守方靠存量(粮仓、水源、弹药、兵员)拖延时间。
- 断水比断粮更快致命(人 3 日无水); 缺粮按"定量减半→吃马→吃皮革→投降"的节奏崩溃。
- 计时器公式: 城市人口规模 × 日均消耗 = 存粮可撑天数; 围城多数结局不是破城而是"饿降"或"饿退"。

**7. 远征可行性三问(出发前必须回答)**
1. 吃什么? ——自带/采购/征发/掠夺/海运, 对应季节与路线(秋收后出征、沿粮区与河流走);
2. 军饷谁付? ——国库/贡赋/贷款/战利品预期, 对应战争的政治承受力;
3. 辎重是否可切断? ——补给线的脆弱点(山口、渡口、沙漠、海峡)是否有保障。

- 铁律: **行军路线即补给路线**。远征几乎总是贴着海岸线与河流进军, 深入内陆的行程严格受谷物收获季节约束。

**8. 魔法/超自然后勤**
- 传送门抹掉"距离"瓶颈(吞吐量成为新上限); 储物袋放大单兵携带量(远征持续时间被重写); 造粮术抹掉"食物"瓶颈。
- 必然伴随**瓶颈转移**: 食物不再是约束后, 军饷、弹药铸造、马匹饲料、医疗、士气、指挥带宽成为新约束; 魔法节点(传送法阵、法师本人)成为高价值战略目标, 围城逻辑可能反转——城市不再怕断粮, 却怕传送门被破坏或法师被暗杀。
- 稀缺性决定一切: 全城只有一个传送门 = 瓶颈仍在, 只是换了位置。

## 构建操作

1. 建立"每日消耗表": 为军队定一张账单——每兵×kg 粮+水, 每马×kg 草料, 乘以人数与天数, 立刻获得体量感; 用数字决定进军路线(沿河/沿海/沿粮区)与出征季节(秋收后), 让"为什么走这条路"成为剧情理由;
2. 把补给线做成冲突引擎: 袭击辎重队、封锁渡口、山口伏击是真实的战略动作; 设计"纵深防御"——敌人故意放你深入再断你粮道; 正面对峙+后勤绞杀战双线并行, 比单纯会战更富层次;
3. 用"杂志 vs 征粮"区分政权: 富裕帝国用仓库系统, 游牧/蛮族用征粮; 双方互相克制形成军备竞赛, 也决定占领区民众的敌我态度(征粮者失去民心→补给更难的恶性循环);
4. 水运优先+咽喉叙事: 河流交汇、海港、运河即兵家必争; 让帝国修运河作为史诗工程线; 内陆远征必须给出"运一石耗几石"的成本账, 否则读者出戏;
5. 围城剧本公式: 写下守方存粮天数(人口×日均消耗)、水源、攻方补给线长度与季节; 用节拍推进——第 N 天定量减半→吃马→骚乱→投降/突围, 或攻方瘟疫与断粮→解围军到达;
6. 军饷=忠诚开关与政权定义器: 明确军队经费来源; 用"拖欠军饷→哗变/劫掠→民心尽失"作为转折点; "谁付钱"直接展示政体(封建义务/雇佣军/税收国家/圣战经费);
7. 魔法后勤必须设上限并展示瓶颈转移: 给传送门定吞吐量/维护者/能耗, 储物袋定容量与稀有度, 造粮术定次数; 撤掉食物瓶颈后立刻引入新瓶颈, 并让传送法阵成为敌方特种部队的首要破坏目标——魔法不是解除后勤, 而是把后勤变成新的战场;
8. 远征可行性三问做成"参谋部审查表": 让王国议会以"吃什么/谁付钱/辎重可否切断"否决或批准远征, 使政治戏与军事戏互相咬合; 夸张远征(翻雪山、穿沙漠)必须有后勤解释(魔法冰桥、绿洲链、补给列车、以战养战), 赋予其可信度。

## 检查点/清单

- [ ] 每日消耗表建立, 行军天数×人均日耗已核算, 无"轻松后勤";
- [ ] 每支军队有补给模式定位(杂志/征粮/混合), 及其对占领区民众的影响;
- [ ] 三条链(粮/弹药/军饷)各自来源明确, 无"粮从天上掉";
- [ ] 水运优先原则应用: 咽喉点(河交汇/海港/运河)是兵家必争, 内陆远征有成本账;
- [ ] 围城戏有计时器(存粮天数/水源/攻方补给线), 崩溃节奏有节拍;
- [ ] 远征通过三问审查(吃什么/谁付钱/辎重可否切断), 政治戏与军事戏咬合;
- [ ] 魔法后勤有上限, 瓶颈转移已展示, 魔法节点成为战略目标。
