# 生理-心理-文化推导链

> 目的: 掌握"环境→生理→心理→文化→技术"的约束传递链方法论, 让每个种族特征都能沿链回溯, 并彻底通过"人类换皮"检验。
> 前置: 输入行星参数(重力/光照/大气与溶剂/季节与灾变频率)与生态位; 输出文化卡与技术树。

## 核心立场: 推导链是约束传递链, 不是因果决定链

- **硬约束 vs 软约束**: 硬约束生理上不可违反(给定重力下的体型上限); 软约束昂贵/困难但可被文化克服。生物在约束下寻优, 产生**倾向性而非必然性**的特征; 同一约束可容纳多个解(多重可实现性), 整条链是概率性推导而非逐点锁定。
- **行星参数的四条生理通道**: 重力→体型/运动/骨骼; 光照→感官/昼夜节律/认知隐喻; 大气与溶剂→代谢率/呼吸/化学基础/技术燃料; 季节与灾变频率→生命史策略(寿命/繁殖/演化速率)。参数必须成组考虑, 单参数推导必然失真。
- **生理→心理的两大支点**: 心理是适应过去环境的模块化机制; 生命史理论把心理视为对"时间-能量预算"的分配策略——环境可预测性影响风险偏好、延迟满足与养育投入。感官结构直接决定认知隐喻: 视觉主导→"看见=理解""光明=善"; 嗅觉/听觉主导的文化会有完全不同的隐喻与艺术体系。
- **心理→文化**: 文化是独立于基因的第二继承通道(双继承), 受基因-文化协同演化调节; 生物会主动改造环境再反作用于自身演化(生态位构建), 链是**循环而非单向**。文化形式必须落在个体生理-认知可自发重现的能力范围内("潜在解区"), 超出范围的文化无法被复制维持——这是"文化必须可由生理支撑"的硬检验。
- **文化→技术**: 技术 = 文化知识 × 环境可用材料/能源 × 生理操作能力。大气含氧量低至约 15–16% 以下难以维持燃烧→无金属、无火药文明; 红矮星弱光→太阳能低效, 转向化学能/地热; 材料有无决定技术路径。技术是推导链最远端、最可检验的一环。
- **推导链可逆性**: 每个文化特征应能沿链回溯到某个生理特征或环境约束(支持性回溯); 回溯不到的必须显式标注为"文化漂变/历史偶然"——它们是合理例外而非漏洞。可逆性 ≠ 唯一性: 允许一因多果。
- **决定论边界**: 生理设硬约束(不可能)与软约束(昂贵但可克服), 文化自主性存在于软约束空间之内, 由历史偶然、传播与漂变填充。完全决定论(环境=文化)与完全自由(文化与环境无关)同为错误极端。

## 参数→特征推导速查表

| 环境参数 | 生理响应 | 心理/文化倾向 | 技术后果 |
|---|---|---|---|
| 高重力 | 矮壮、粗肢、低重心、密骨 | 强调力量与坚韧 | 结构力学优先的建筑/载具 |
| 低重力 | 高瘦、细骨、偏好跳跃与滑翔 | 垂直空间思维 | 高塔/空中交通发达 |
| 高氧大气(约30%) | 巨型化节肢/大表面积呼吸 | 体型崇拜 | 冶金与火技术容易 |
| 低氧大气 | 小型化、大表面积呼吸器官 | 节能伦理 | 无火/无金属技术树 |
| 红矮星弱光 | 大眼、红外倾向视觉(有热噪声代价) | 夜间主导的隐喻体系 | 化学能/地热优先 |
| 极昼极夜 | 昼夜节律重塑、季节性心理节律 | 循环时间观、储存文化 | 迁徙/储存技术发达 |
| 强季节 | 储存、迁徙、冬眠、同步繁殖 | 集体主义、节庆文化 | 仓储与历法为核心科技 |
| 高灾变频率 | r 策略、表型可塑性、世代快速更替 | 文化记忆断层、当下主义 | 技术反复"文明重启" |
| 稳定环境 | K 策略: 长寿、少后代、高投入 | 文化精细化、积累型 | 技术缓慢但深厚 |

## 构建操作

1. 先建参数表, 再建生理卡, 逐环写推导理由: 每个"参数→生理→心理→文化→技术"条目各写一行"因为……所以……", 标注硬/软约束; 写不出理由的条目立即删改;
2. 执行"人类换皮检验"三步: (a) 换脑——文化特征不变只换外形, 若成立即失败; (b) 换感官——主感官换掉后隐喻体系必须全部重写; (c) 换时间——寿命×10 或 ÷10, 看叙事节奏、历史深度、技术积累是否随之改变;
3. 做可逆性审计表: 为每个文化特征建一列"支持性约束"; 无法关联者放入单独"文化漂变"栏, 全种族不超过 1–2 个;
4. 感官替换法落地: 选定主感官后重写语言隐喻、艺术媒介(气味雕刻 vs 壁画)、宗教仪式(气味祭仪 vs 光明崇拜)、建筑(回响优先的声学空间 vs 视线优先的视觉空间)、社交礼仪(气味名片);
5. 用"寿命×群体规模"重算文化参数: 估算口述史可维持长度与创新扩散速度——长寿种慢创新但文化深度高, 短寿种快速试错但易遗忘, 让两者技术树自然分化;
6. 以地球生态位做"趋同锚点": 沙漠、深海、洞穴、高纬、岛屿的生态方案(储存/共生/生物荧光/同步繁殖/侏儒化)可移植到异星; 趋同演化本身就是跨行星设计合法性的论据;
7. 给同一生理基础设计 2 个分支文明: 同样的参数与生理, 因迁徙方向、资源分布、创始人效应等历史偶然发展出不同文化——直接演示"软约束空间内的文化自主性";
8. 从大气与能源反推技术树: 先定大气成分与恒星类型, 再推导可用能源(火/太阳能/地热/化学)与材料(金属/陶瓷/生物材料), 无火药、无远航、生物技术优先等技术差异便自然成立。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 环境直接"决定"文化(完全决定论) | 区分硬/软约束, 文化在软约束空间内自主 |
| 文化特征无生理支撑 | 逐条做支持性回溯, 回溯不到进"文化漂变"栏 |
| 只换外形不换感官/寿命/繁殖 | 至少一项根本差异并让全部下游随之改变 |
| 单参数推导(如只看重力) | 参数成组考虑, 四条通道联合推导 |
| 文化大量"例外"而无标注 | 全种族显式漂变条目 ≤1–2 个 |
| 技术树与大气/能源脱节 | 先定大气与恒星, 再反推可用燃料与材料 |
