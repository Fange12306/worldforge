# 命名体系与地名学

> 目的: 用专名学原理让"名字"成为世界观载体——做语言地层表、姓名模板卡、地名词根库,绑定文化价值观,设计改名事件并保留旧名残迹,让读者从地名读出"谁先来、谁后到"。
> 前置: 音系篇(04)提供命名音系约束;与地理篇(地貌)、历史篇(征服/迁徙)、文明篇(阶层/宗教)联动。

## 核心理论

- **专名是"语言化石"**: 专名一旦凝固,字面义消隐,但作为音义单位存活并承载记忆——因此专名是历史语言学与历史地理学最可靠的材料来源之一;人名学与地名学是两大支柱。
- **地名分层论: 地名的地层结构**: 一片土地的地名像地层一样叠压历代语言——底层(被征服/被同化民族的残留语)、征服层(占领者的语言)、纪念层(政权刻意书写的层: 圣徒名/帝王名/革命名)。底层词汇尤其集中在**水文名**中,因其最耐久、最难被替换。
- **地名功能分类(生成时的抽样框)**: 描述性(地形地貌)、所有性/关联性(以人或族群命名)、事件性(纪念某事件)、纪念性(纪念人物)、溢美性、民间词源(旧名被新语言重新解释)、人造名、移用名(把旧地名搬到新地)、误植名(误传)。
- **耐久性梯度**: 大河名 > 山名 > 聚落名 > 细碎地名(田地/小路)。河流必须是最古层的保存者——征服者往往"借来"河名而换掉村名。
- **姓名结构 = 社会制度的音系化**: 父名制(无阶层/氏族社会)、氏族/家名制(宗族组织,长链式系谱即身份)、多段名制(本名+氏族名+家支名+称号,精确编码公民身份与等级);称号是荣誉与职能的附加层。
- **名字即世界观**: 名字是文化价值观的浓缩器——神名嵌入(希伯来式 -el/-iah、北欧式 Thor-、埃及式"某神之子")、美德名(信仰文化)、战功名(尚武文化)、避讳/护符名(贱名好养、"真名隐藏"信仰: 名字被视为灵魂的一部分,命名即祝祷)。
- **改名从不彻底**: 改名四大动因——征服、政治革命、民族自决、避讳。旧名残留在宗教仪式、诗歌、方言、家族记忆中,或被**民间词源**重新收编(新语言用母语近似音"重新解释"旧名: 语音同化→语义附会→传说回填),成为活的历史断层。
- **接触地带地名学**: 双语竞争地带会出现双层/混合地名,征服层覆盖原住民名,但原层残留在小地名与河道名中——"改名即改写历史"。

## 地名功能分类表(地名词根库的抽样框)

| 功能类型 | 机制 | 词根示例(虚构) |
|---|---|---|
| 描述性 | 地形地貌 | dur=水、kar=石、hal=山口 |
| 所有性/关联性 | 以人或族群命名 | 氏族名+后缀 |
| 事件性 | 纪念某事件 | "战败地""焚城" |
| 纪念性 | 纪念人物 | 王号+城/庙 |
| 溢美性 | 颂扬/祝愿 | "新希望""丰饶" |
| 民间词源 | 旧名被新语言重新解释 | 古词误读出新义 |
| 人造名 | 刻意构造(乌托邦式) | 官方新造词 |
| 移用名 | 旧地名搬到新地 | "新X"式殖民命名 |
| 误植名 | 误解/误传 | 探险者听错记错 |

## 姓名结构类型表(社会制度映射)

| 姓名结构 | 机制 | 对应社会 |
|---|---|---|
| 父名制 | 孩子名=父名+性标记 | 无贵族姓氏的平等/氏族社会 |
| 氏族/家名制 | 姓+名,或长链系谱(本名+父名+祖父名+部族) | 宗族组织社会,系谱即身份 |
| 多段名制 | 本名+氏族名+家支名+称号 | 等级社会,精确编码身份 |
| 双姓制 | 父姓+母姓 | 双系血统并重社会 |
| 单名演化链 | 单名→地名氏→职业氏→固定家姓 | 城市化与财产继承制度成熟期 |

## 机制与案例(可迁移的设定模板)

- **征服层叠压机制**: 一条河名(前古层)→ 旧都名(古典层)→ 城镇名(征服层)→ 村落名(近代层),层层叠压;政区名多取纪念/祈愿义,水名多存古语底层。
- **民间词源机制链**: 新语言不理解旧名 → 用母语近似音重新解释 → 旧名获得新语义并继续演化 → 传说回填为地名提供合法性叙事——这是把冲突历史"软化成自然"的关键装置,也是考古式悬念的来源。
- **姓名结构运作模板**: 无贵族姓氏的平等社会用父名制;宗族社会用长链系谱;双姓制度编码双系血统;由单名→加地名氏→职业氏→固定家姓的演化,正对应城市化与财产继承制度的成熟。
- **改名事件模板**: 征服后官方改名清单 + 旧名三渠道存活(诗歌与仪式用语、老人与流亡者的口音、民间词源化的新语义)——一层潜台词讲完一部历史。
- **耐久度实证**: 大河名可上溯前古层,而两岸村庄名却换了好几茬语言——设计虚构世界时,河流必须是最古层的保存者。

## 构建操作

1. 先为世界做 2~3 层语言地层表: 定"古语层/征服层/纪念层"三套地名词根(如古层 dur=水、征服层 ster=要塞、纪念层以神名/王号起首),并规定: 大河与山脉只用古层,城镇用征服层,行政区与皇宫用纪念层;
2. 给每个文化写一张姓名模板卡: 明确结构式(如"本名+父名(性数变化)+氏族名+称号"),配一个父名/母名后缀系统,再规定贵族、平民、奴隶、外来者的名制差异——姓名结构直接呈现社会分层;
3. 按地名功能分类建"地名词根库": 分 9~10 类收集词根(描述地形、所有性人名、纪念君主、移用"新X"、民间词源化产物、误植名),生成地名时按分类抽样,保证类型分布均匀且风格自洽;
4. 让命名规则绑定文化价值观: 宗教文化→神名嵌入(给每位神设计名字词素);清教徒式文化→美德名;尚武文化→战功称号;怕鬼文化→护符贱名与真名禁忌——用命名规则代替设定文本;
5. 设计一场"改名事件"并保留旧名残迹: 写出征服/革命/改宗后的官方改名清单,再让旧名以三种方式存活(诗歌与仪式用语、老人与流亡者的口音、民间词源化的新语义);
6. 建一份"命名词典"并严格复用: 按语言/性别/阶级/时代分表的词表+词根词缀表+组合规则,每生成一个新名字先查库;同一语言内严禁混入另一语言的音系特征;
7. 用地名反推被抹去的民族: 设定一个已灭亡民族,让其语言只存活在河名、山名与民间传说中(如现代人叫的"永河"其实是古语"水"的误读),用"语言化石"制造考古式悬念;
8. 让命名规则与音系篇联动: 所有名字只从本语言音系生成,禁止跨语言混用——这是最常见的返工源。

## 检查点/清单

- [ ] 2~3 层语言地层表已建,且大河/山脉只用古层词根?
- [ ] 每文化有姓名模板卡(结构式+父/母名后缀+阶层差异)?
- [ ] 地名词根库按 9~10 功能分类,生成时按类抽样?
- [ ] 命名规则绑定文化价值观(神名/美德/战功/护符)?
- [ ] 改名事件已写,旧名有三渠道残迹(仪式/口音/民间词源)?
- [ ] 命名词典按语言/性别/阶级/时代分表,严格复用?
- [ ] 无跨语言音系混用(命名只出自本语言音系)?
- [ ] 被抹去民族的语言残留在水名/山名/传说中(考古悬念)?
- [ ] 地名功能分布均匀(不全是纪念名或全是描述名)?
- [ ] 民间词源机制已用(旧名被新语言重新解释并回填传说)?
