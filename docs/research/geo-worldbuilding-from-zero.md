# 从0到1构建完整地理世界 — 完整执行手册

> **目的**: 给定世界法则与其他主题指令, 按本手册逐步构建一个完整、合理、契合主题的虚构地理世界。
> **用法**: 每步都有 [输入] → [操作] → [决策规则] → [输出产物] → [检查点]。从头到尾走一遍; 也可从任意一步开始, 但前面的步骤决定后面的自由度。
> **配套**: 12 个主题的详细研究笔记见 `docs/research/notes/`(理论、机制、文献、来源链接全量存档)。
> **贯穿示例**: 本手册内嵌一个示例世界「**米拉斯**」(Miras, 双月魔法世界), 每一步展示实际输出, 帮你理解"每一步到底做出什么"。

# 第一部分: 十一步执行流程

## 第 0 步: 准备——世界法则与主题指令

**[输入]**
- 世界法则: 物理规则(是否类地物理)、超自然规则(魔法/真气/神明的运作方式)、世界的根本基调。
- 主题指令: 故事类型(史诗奇幻/科幻殖民/修仙/蒸汽朋克)、文明阶段、审美基调(黑暗/壮丽/苍凉)、叙事需要的"地理要素"(如: 要有大沙漠商路、冰封北境、群岛航海文明)。

**[操作]**
1. 把世界法则压缩成 **3~5 条"不可违反"的硬约束**(一句话一条)。例:
   - "本世界 = 类地物理, 唯一天文差异: 双卫星。"
   - "魔法 = 灵脉系统, 灵脉沿板块裂缝分布, 灵脉富集区改变当地生态。"
2. 把主题指令翻译成 **地理需求清单**: 每条叙事需求 → 对应的地理单元。例:
   - "要有横贯大陆的商路" → 需要: 一条低险阻走廊(草原带/河谷带), 2~3 个中转绿洲或港口。
   - "要有与世隔绝的隐修文明" → 需要: 一处难以到达的高原/孤岛/深谷, 且有特殊资源支撑自给。
3. 检查清单:
   - 法则之间无矛盾(如"魔法改变生态"与"生物群系按气候定标"需明确哪个优先);
   - 每条需求清单都能追溯到某条主题指令(防止需求凭空长出);
   - 给世界起名, 建立"世界圣经"文件, 记录第 0 步输出(之后每步都追加)。

**[输出产物]**
- `世界法则卡片`(3~5 条硬约束)
- `地理需求清单`(叙事需求 → 地理单元映射表)
- `世界圣经`(空模板, 后续每步填入)

**[检查点]** 法则可检验(能判断某个设定是否违反它); 需求清单与主题一一对应。

**示例(米拉斯世界)**:
- 法则卡片: ①类地物理+双卫星(银月/血月); ②魔法=灵脉, 沿古板块缝合线分布, 灵脉区植物异常生长、动物异变; ③血月蚀时灵脉爆发, 周期 41 年。
- 需求清单: "大陆中央要有一个魔法文明核心区" → 灵脉交汇的裂谷带; "要有航海贸易文明" → 群岛海; "要有冰封北境作为上古战场遗迹" → 高纬寒原+冰川侵蚀地貌。

## 第 1 步: 天文参数(第一因)

**[输入]** 世界法则卡片(尤其"是否类地物理"这条)。

**[操作]**
1. 选恒星光谱型(G/K/M 为主流; 若想"最像地球", 选 G2V 或 K2V)。记下: 光度 L、主序寿命、宜居带位置(按 r ∝ √(L/L☉) 缩放)。
2. 定轨道: 半长轴 a(对照宜居带, 取带内中部偏内/偏外决定"偏热"或"偏冷"基调)、偏心率 e(0~0.1 温和; 0.2+ 极端季节)。
3. 定行星本体: 质量/半径(决定重力 g、逃逸速度、地形上限)、内部热强度(放射性+潮汐)。
4. 定自转周期(10~30 h 地球式; 数天~数周慢自转; 或潮汐锁定 1:1)。
5. 定轴倾角 ε(0° 无季节; 20~30° 温和四季; >54° 气候反转)。
6. 定卫星: 有没有大卫星(倾角稳定器)? 几颗? 周期?
7. 算有效温度 T_eq = [L(1−A)/(16πσd²)]^¼, 定反照率 A 与温室强度, 得地表平均温度与冰线纬度。

**[决策规则]**
- 想省心 → 抄地球参数但改 1~2 个变量(如 ε=20°、自转 28 h), 其他全用地球值。
- 想要"震撼感" → 改大参数: 潮汐锁定(晨昏圈文明)、高倾角(极地热赤道冷)、慢自转(超长昼夜)。
- 法则与天文冲突时, 天文优先(它是第一因), 除非法则明确覆盖(如"神明固定了季节")。

**[输出产物]** `天文参数表`(恒星/轨道/本体/自转/倾角/卫星/温度/冰线纬度 + 一句"气候基调"描述)。

**[检查点]**
- 自转周期与轨道距离自洽(近星必锁定);
- 倾角稳定性与卫星配置自洽(无大卫星 → 倾角会漂移, 除非设定"最近几千年恰好稳定"或法则豁免);
- 恒星寿命 ≥ 需要的历史长度;
- 大气能留住(质量足够 / 有磁场 / 法则豁免)。

**示例(米拉斯)**: G2V 恒星(太阳同款)、a=1.02 AU、e=0.06; M=0.95 M⊕(g≈0.97 g); 自转 25.6 h; ε=24°(季节略强于地球); 双卫星: 银月(大, 稳定倾角)+血月(小, 偏心轨道); 反照率 0.31, 温室 +31 K → 地表均温 ~285 K(略暖于地球); 冰线 ~62° 纬度。气候基调: "类地球但季节更分明, 血月潮汐造成周期性海啸风险"。

## 第 2 步: 板块构造与大陆轮廓

**[输入]** 天文参数表(尤其重力——决定地形上限); 需求清单里"需要什么大陆形态"。

**[操作]**
1. 在空白球面上画 **6~12 块板块**, 标注运动方向箭头与边界类型(离散/汇聚/转换)。规则: 边界必须构成连续网络, 不能有"断头"边界; 三叉点(rift-rift-rift)要稳定。
2. 让大陆从板块中"长出来": 板块内部=稳定克拉通(低平); 汇聚边界附近=造山带(陆-陆碰撞→巨型高原, 洋-陆俯冲→海岸火山链, 洋-洋→岛弧); 离散边界=裂谷(陆内)或洋中脊(洋底); 转换边界=走滑断层谷。
3. 按运动史设计大陆形状: 两块大陆正在碰撞 → 缝合线两侧有"拼图吻合"的海岸线; 正在裂解 → 裂谷+年轻窄海(红海型); 已经漂远 → 被动边缘宽大陆架。
4. 放置火山: 俯冲带(安山质爆发型火山弧, 位于海沟后 90~300 km)+ 热点(玄武质盾形火山, 独立于板块边界, 画成年龄递变的火山链)。
5. 把灵脉/魔法资源(如有)挂到构造线上: 古缝合线、裂谷带、俯冲带——正好是灵脉富集区的天然位置。

**[决策规则]**
- 山脉只允许出现在边界/缝合线/热点上——这是本步最重要的纪律。
- 大陆数量与形状由板块数与运动史决定, 不要"先画好大陆再补板块"。
- 想快速: 3~5 块大板块 + 1~2 个岛弧链 + 1 个热点, 足够支撑大多数世界观。

**[输出产物]** `板块构造图`(板块+边界+箭头)与 `大陆轮廓草图`(含山系位置、火山、裂谷、岛弧标注)。

**[检查点]**
- 每条边界都有类型与两侧运动方向;
- 每座山/火山/海沟都能对应到边界;
- 大陆形状与运动史相容(碰撞处有缝合线, 裂解处有匹配海岸)。

**示例(米拉斯)**: 7 块板块。两大陆「奥兰」(北)与「维拉」(南)正在碰撞, 缝合线形成中央山脉「龙骨山脉」(灵脉主带, 魔法文明核心「灵枢城」所在); 东缘俯冲带形成「火链群岛」(岛弧, 航海贸易文明); 西侧离散边界正在裂开新洋「银海」(年轻窄海, 蒸发强盐度高, 盛产盐与魔法盐晶); 南大陆中部热点链「烬脊」是一串火山岛。双卫星的潮汐在「银海」峡口形成世界级大潮。

## 第 3 步: 宏观海陆分布与海岸线

**[输入]** 大陆轮廓草图; 天文参数(海陆比默认 2.4:1, 可按世界观调整)。

**[操作]**
1. 定海陆比: 70% 海洋≈地球; 50% → 大陆性强、荒漠广布; 85% → 大洋性、温和湿润、大陆少。
2. 放海洋: 每个洋盆 = 洋中脊 + 两侧深海平原 + 大陆边缘(被动型宽大陆架 / 主动型窄大陆架+海沟)。
3. **用一次"海侵—海退"事件生成海岸细节**(最高效技巧): 设定海平面比现在高 ~100 m 再退去(或反方向), 批量得到:
   - 大陆岛(低地被淹后残留高地)、半岛(高地残存)、溺谷海湾(河谷被淹)、海峡(山脊缺口被淹)、地峡(两陆之间的窄桥)。
4. 按冰期史补充: 若世界有冰期, 高纬海岸放峡湾(冰川 U 谷被淹)、冰碛半岛; 低纬浅海放珊瑚礁带(限 30° 以内、暖水)。
5. 河流入海处放三角洲(河口浅水+泥沙丰), 按海浪/潮汐强弱选形状(鸟足/扇形/潮控)。

**[决策规则]**
- 海岸线必须能追溯到过程(海侵/构造/冰川/沉积), 不要"随手画"。
- 半岛、地峡、海峡、海湾一次海侵批量生成, 互相天然自洽。
- 海陆比是世界观变量: 调它之前想清楚对气候的连锁影响。

**[输出产物]** `海岸线成品图` + `海陆分布表`(海陆比、各洋盆类型、大陆架宽窄、主要岛屿成因)。

**[检查点]**
- 每个岛屿可归入四成因之一(大陆岛/火山岛/珊瑚岛/冲积岛);
- 半岛/地峡/海峡成因可解释;
- 洋盆有年龄感(年轻海窄而盐、成熟洋有深海平原)。

**示例(米拉斯)**: 海陆比 68%。一次距今 8000 年的"银海退却"事件: 奥兰大陆东南原为浅海, 退却后露出大片大陆架平原与半岛「盐角」; 龙骨山脉南端残余高地成为半岛「楔角」; 两大陆间露出一条宽 300 km 的地峡「缝合地峡」(灵脉在此最浅, 是南北文明唯一陆桥); 银海本身是裂谷幼年海(年轻、盐度高), 其西岸多溺谷海湾——天然良港群, 孕育航海文明「潮邦」; 火链群岛为岛弧火山岛; 南方热点「烬脊」为火山岛链; 东部「青环礁」为珊瑚环礁群(纬度 18°)。

## 第 4 步: 地形地貌(山脉/高原/平原/草原/沙漠)

**[输入]** 板块图 + 海岸线图 + 天文参数(重力定地形上限)。

**[操作]**
1. **山脉**: 沿第 2 步的边界放山系——碰撞边界→高峻褶皱山(可达 6~9 km, 有山根); 俯冲边界→海岸山脉+火山链; 裂谷边缘→断块山(陡崖); 热点→火山堆。走向垂直于汇聚方向。
2. **高原**: 碰撞带腹地放碰撞高原(青藏型, 4000~5000 m); 俯冲带放高原(安第斯 Altiplano 型 ~3700 m); 热点/大火成岩省放熔岩高原(顶面近乎水平, 边缘陡崖); 古老克拉通抬升放残余高原(夷平面切割)。
3. **平原**: 大河下游+沉降盆地放冲积平原; 河口放三角洲平原; 古湖/海退区放湖积/海积平原; 高纬冰盖区放冰川平原(冰碛/冰水); 前陆盆地(造山带边缘)放山前平原。
4. **草原**: 中纬内陆(30~55°、年降水 250~750 mm)放温带草原带; 低纬干湿季(5~20°)放热带稀树草原。
5. **沙漠**: 按四成因放置——25~30° 副热带高压带放行星沙漠(撒哈拉型); 山脉背风坡放雨影沙漠; 大陆西岸 20~30° 寒流沿岸放雾漠(阿塔卡马型); 内陆封闭盆地放大陆性沙漠(塔克拉玛干型)。
6. 记录每处地形的高度/面积量级(山高 km、高原海拔 m、平原面积、沙漠面积), 用于后续气候与生物群系定标。

**[决策规则]**
- 地形高度受重力+均衡约束: 类地行星陆地最高 ~9 km; 想更高需调低重力或给法则豁免。
- 沙漠位置由"环流纬度+山脉走向+洋流"决定——放沙漠之前先检查第 5 步的气候骨架(可先粗排再细调)。
- 草原是森林与沙漠之间的"过渡带", 不要让它与两者同时紧贴(应沿降水梯度排列)。

**[输出产物]** `地形图`(山系/高原/平原/草原/沙漠分区 + 高度标注)与 `地形台账`(每处: 类型/成因/高度/面积)。

**[检查点]**
- 每条山系可追溯到构造边界; 高原顶面平坦(熔岩盖或夷平面);
- 沙漠都能用四成因之一解释;
- 高度与重力/均衡自洽。

**示例(米拉斯)**: 龙骨山脉(碰撞褶皱山, 主峰 7.6 km, 山根 65 km 地壳); 其西段腹地为「苍原高原」(碰撞高原, 4200 m, 灵脉第二富集区, 隐修文明「云顶寺」所在); 银海裂谷两岸为断块山(陡崖+长湖链「泪湖群」); 火链群岛为火山岛链(成层火山, 最高 4.1 km); 奥兰大陆中部为「丰饶平原」(龙骨山前陆盆地冲积平原, 大河「苍河」下游, 农耕文明中心); 北纬 28° 奥兰西岸有寒流「西风寒流」→ 沿岸雾漠「白雾荒漠」(靠雾取水的采盐文明); 龙骨山脉背风坡(东侧)有雨影草原带「风语草原」(游牧文明)。

## 第 5 步: 气候系统

**[输入]** 天文参数(自转/倾角/轨道)、海陆分布、地形图。

**[操作]**
1. 画气压带骨架(按轴倾角与自转):
   - 自转 ~24 h + 倾角 20~30°: 赤道低压(0°)、副热带高压(约 30°, 随季节移 5~10°)、副极地低压(60°)、极地高压。
   - 慢自转: 副热带高压带外移到 35~45°; 潮汐锁定: 恒星下点低压、晨昏圈高压环。
2. 画风带箭头: 信风(0~30°)、西风(30~60°)、极地东风。
3. 画洋流: 每个海盆一个副热带涡旋(北顺南逆)——西边界暖流(大陆东岸, 暖湿)、东边界寒流(大陆西岸, 冷干+上升流渔场); 高纬补充: 极地环流、温盐环流(大西洋型下沉点)。
4. 叠加地形: 山脉迎风坡多雨(地形雨)、背风坡雨影干旱; 高原热力作用增强季风。
5. 标季风区: 大洲东南缘(信风转季风)+ 大陆东岸中低纬——夏湿冬干。
6. **用柯本分类给每块区域命名**: 给每区估(年均温, 年降水)两个数, 套判据:
   - A 热带(最冷月≥18°C): Af 雨林 / Am 季风 / Aw 干湿季
   - B 干旱(年降水 < 阈值): BW 沙漠 / BS 草原(阈值 P_th = 20T+280 暖半年雨 / 20T+140 冷半年雨 / 20T+210 均匀; P < P_th/2 为沙漠)
   - C 温带(最冷月 −3~18°C): Csa/Csb 地中海 / Cfa 湿润亚热带 / Cfb 海洋性
   - D 大陆性(最冷月≤−3°C 且最热月≥10°C): Dfa/Dwb...
   - E 寒带(最热月<10°C): ET 苔原 / EF 冰盖
7. 定雪线与垂直带: 赤道 ~4500–5000 m、中纬 ~2500–3500 m、极地近海面; 山地 0.6°C/100m。

**[决策规则]**
- 五步出图顺序: 气压带 → 风带 → 洋流 → 地形修正 → 柯本命名。
- 沙漠三来源对号入座: 副热带(纬度 25~30°)、雨影(山脉背风)、寒流(西岸 20~30°)——一个区域可叠加多个成因。
- 西岸 vs 东岸不对称是"气候真实感"的最强信号: 同纬度西岸寒流干旱/地中海, 东岸暖流湿润/季风。

**[输出产物]** `气候图`(柯本分区着色) + `气候台账`(每区: 柯本代码/年均温/年降水/季节型/主导成因)。

**[检查点]**
- 30° 附近有副热带荒漠带; 迎风坡多雨背风坡干;
- 大陆西岸寒流→雾漠, 东岸暖流→湿润;
- 季风区夏湿冬干; 内陆冬冷夏热;
- 柯本命名与生物群系(第 7 步)一致。

**示例(米拉斯)**: 气压带标准(ε=24°)。奥兰大陆: 南纬 20~30° 西岸「白雾荒漠」(BWh, 寒流+副高, 年降水 40 mm); 中纬西岸「翡翠林地」(Cfb, 西风+暖流, 年降水 1100 mm); 大陆东岸 25~35°「潮风平原」(Cfa, 暖流+季风, 年降水 1500 mm, 稻作文明); 北纬 45° 内陆「风语草原」(BSk, 雨影+大陆性, 年降水 380 mm); 北纬 60°+「北寒原」(ET, 苔原); 龙骨山脉: 迎风坡(西)雨林「苍翠林海」、背风坡(东)雨影区; 苍原高原顶部「云顶高原」(Dwb, 高寒半干旱); 银海裂谷「泪湖群」沿岸为地中海式气候(Csa, 冬雨夏旱)——魔法文明「灵枢城」所在, 类比"魔法版罗马"。

## 第 6 步: 水文系统(河流/湖泊/流域)

**[输入]** 地形图(分水岭可从山脊线读出)+ 气候图(降水分布)。

**[操作]**
1. **画分水岭**: 沿山脊线(最高连线)把大陆切成一个个流域盆地。这是本步最重要的一笔——所有河流从分水岭出发。
2. **画河流**: 每流域一条干流 + 支流, 遵循: 自高向低、只合不分(树枝状/格状/放射状/向心状按地质选)、最终入海或入内流湖。支流汇入角度反映地质(锐角=均质, 直角=褶皱)。
3. 按气候定补给类型: 湿润区雨水补给(雨季汛期); 高山区冰雪融水补给(夏季汛期, 冬季断流); 干旱区地下水/融水补给(间歇河, 尾闾盐湖)。
4. **放湖泊**: 构造湖骑断层线(裂谷湖); 冰蚀湖在高纬/高山(需冰期史); 牛轭湖在曲流平缓段; 泻湖在低潮差砂质海岸; 火山湖在火山口; 干旱内流区放盐湖。检查: 入流+降水 > 蒸发+出流 才稳定成淡水湖。
5. **放阶地/裂点/三角洲**: 构造抬升区留阶地(古城遗址位); 硬岩/断层处留瀑布裂点(航运障碍+水力点); 河口放三角洲(按潮汐/波浪选形状)。

**[决策规则]**
- 河流铁律: 只合不分、单向入海(三角洲与干旱区冲积扇是仅有的分叉例外)。
- 内流区(endorheic basin)放雨影区或副热带高压带——河水流进沙漠/盐湖。
- 分水岭=天然政治边界; 流域大小决定文明规模上限。

**[输出产物]** `水文图`(流域边界+河网+湖泊+三角洲)与 `水文台账`(每流域: 干流/补给类型/汛期/尾闾; 每湖: 成因/淡水或盐湖)。

**[检查点]**
- 每流域有明确分水岭与唯一归宿;
- 湖泊成因与位置自洽(构造湖在断层上, 冰蚀湖在高纬);
- 补给类型与气候图一致。

**示例(米拉斯)**: 「苍河流域」: 发源于龙骨山脉东麓(冰雪融水补给, 夏汛), 流经丰饶平原(雨水补给叠加), 注入东岸「潮湾」三角洲(浪控扇形三角洲, 稻作文明「潮邦」腹地)。「银海裂谷水系」: 泪湖群为裂谷构造湖链(深 900 m 主湖「泪母湖」, 断层线), 湖水南泄入银海(地中海式气候, 冬雨)。「北寒原」冰蚀湖群(冰川史遗迹, 上古战场遗迹区)。「白雾荒漠」内流区: 无常年河, 仅有间歇河(wadi)与盐湖「雾盐湖」——采盐文明靠雾+盐湖生存。奥兰大陆东缘「缝合地峡」两侧分属两大流域, 地峡脊线即分水岭——南北文明的天然边界。

## 第 7 步: 生物群系与生物地理

**[输入]** 气候图(柯本分区)+ 地形图(垂直带)+ 板块史(区系)。

**[操作]**
1. **气候→植被映射**: 用 Whittaker 温-雨双轴(或 Holdridge 三轴)把每块柯本区变成生物群系:
   - Af → 热带雨林; Aw → 稀树草原; BWh → 荒漠; BSh/BSk → 草原; Csa → 地中海硬叶灌丛; Cfa → 湿润亚热带常绿/落叶林; Cfb → 温带海洋性落叶林; Dfa/Dfb → 温带/北方混交林与针叶林(泰加林); Dw → 大陆性森林/草原; ET → 苔原; EF → 冰盖。
2. **垂直带谱**: 对每条主要山脉, 从基带(山脚气候)往上排: 雨林→云雾林→高山草甸→冰雪(热带高山全套); 温带: 落叶林→针叶林→高山草甸→冰雪。雪线按纬度查。
3. **生物地理区系**: 按板块史(第 2 步)划分 4~6 个"动物地理区": 长期隔离的大陆/岛弧各自演化独立区系; 深海槽/宽海峡=物种屏障(华莱士线意识); 陆桥期(冰期海退)允许交流, 间冰期再隔离。
4. **魔法/超自然生态**(如有): 灵脉区植物异常生长(巨树/发光菌)、动物异变; 确定灵脉如何覆盖在常规生物群系之上(叠加层而非替代层)。
5. **土壤带**: 由气候+母质推土壤(红壤↔雨林, 灰化土↔泰加林, 黑钙土↔草原, 荒漠土↔沙漠)——土壤决定农业承载力, 影响第 10 步文明分布。

**[决策规则]**
- 每个生物群系必须能由"年均温+年降水"解释——这是自洽底线。
- 火是稀树草原与地中海灌丛的维持者: 干季+火频率决定是"疏林"还是"密林"。
- 岛屿物种数按 S = c·A^z(z≈0.2–0.35) 估——大岛物种多、小岛少; 距陆近的岛物种多。

**[输出产物]** `生物群系图`(叠加在气候图上)+ `区系图`(动物地理区边界)+ `土壤带图` + `生态台账`(每区: 群系/代表物种/灵脉影响/农业潜力)。

**[检查点]**
- 植被与柯本代码一一对应;
- 垂直带与纬度雪线合理;
- 区系边界与板块史/海障自洽(不会出现"隔离区里跑着不可能到达的物种");
- 灵脉生态与第 0 步法则一致。

**示例(米拉斯)**: 苍翠林海(热带雨林, 灵脉巨树, 树冠城市「叶都」); 潮风平原(Cfa 湿润亚热带, 水稻+灵稻); 风语草原(BSk, 黑钙土, 游牧); 白雾荒漠(BWh, 雾生植物+盐湖藻类, 采盐文明); 翡翠林地(Cfb, 橡木+魔法菌); 北寒原(ET 苔原, 冰川遗迹, 上古战场); 龙骨山脉垂直带: 雨林→云雾林→高山针叶→草甸→冰雪(基带为雨林); 火链群岛为独立动物地理区(隔离演化: 大型有袋类替代胎盘类——"火链袋兽"); 缝合地峡在冰期曾是陆桥(两大陆区系混合带, 物种最丰富, "万兽走廊"); 灵脉区: 龙骨山脉(灵脉主带)植物发光、动物开智倾向; 苍原高原(第二富集区)有"灵草"药材。

## 第 8 步: 地理区域划分(自然区划 + 类型层)

> **范围说明**: 本步只处理**自然区划(含海洋)**与**类型层**两条线。政治/文化层(国家、语言、宗教等)不属于地理大类, 另行考虑。
> **两条线的区别(重要)**: ① **自然区划 = 严格的树**——每个节点是具体的空间单元, 空间连续、互不重叠、可无缝拼合回上一级(共轭性), 用于骨架/命名/检索; ② **类型层 = 非树的覆盖层**——柯本气候代码、Whittaker 生物群系、土壤类型是"类型"(classification), 同一类型可在不相邻的多处重复出现(如"热带雨林"同时存在于亚马逊、刚果、东南亚), 不满足空间唯一性。两者叠加使用: 树管"这个区域是什么、属于哪", 类型管"这块地方长什么样、和别处像不像"。

**[输入]** 以上全部图层(构造/地形/气候/生物群系)。

**[操作]**
1. **第一级(最大单元)**: 按构造+宏观气候切 3~5 个大区。例: "东部季风区 / 西部干旱区 / 高原高寒区"式三分; 或按大陆板块分。
2. **第二级**: 用温度带 × 干湿**筛选出具体空间单元**(如"XX 温带湿润区")——注意: 温度带/干湿只作为**属性标注**挂在单元上, 不构成树的层级本身; 树的每一级节点必须是真实存在的地点(有唯一边界), 而不是抽象类型标签。
3. **第三级**: 用大地貌切分(平原省/高原省/山地省/盆地省)。
4. **第四级及以下**: 用植被+土壤+地方性地貌细分(具体到"XX 河谷"/"XX 台地"); 可无限细分, 但每级只换一个主导指标(热量→水分→地貌→植被→土壤)。
5. **命名**: 按"地名+温度带+干湿+地貌+植被"复合命名(如"苍原温带半干旱高草原省")——名称中的温度带/干湿/植被部分即类型标签, 地名部分保证空间唯一性。
6. **海洋分区(独立的一棵树)**: 按深度带+洋流+表层温度分 4~6 个海洋区, 与陆地区划同粒度(近岸陆架区/开阔洋区/极地海区/暖流区/寒流上升流区); 海洋树与陆地树平行, 两棵树之间没有从属关系。

> **与黄秉维七级体系的对应关系(理论参照)**: 本步的四级操作是对黄秉维《中国综合自然区划草案》(1959)七级的压缩——①大区≈三大自然区; ②温度带×干湿≈温度带+自然地区+自然带(合并); ③大地貌≈自然省(地貌+植被+土壤); ④地方≈自然州+自然县。若需要更细粒度, 可展开为完整七级: 自然区 → 温度带 → 自然地区 → 自然带 → 自然省 → 自然州 → 自然县。

> **更细一层(自然县之下)的文献依据**: 两条纯自然地理脉络可接在自然县之下继续细分——① **苏联景观学派的景观形态单位**(贝尔格《景观概念和景观学的一般问题》; 伊萨钦科《自然地理学原理》《景观调查与景观图的编制》): 景观(ландшафт) → 地方(местность) → 限区(урочище) → 相(фация), "相"是最小自然综合体(单一地貌面+单一土壤+单一小气候); ② **中国土地类型学的土地分级**(《中国土地类型研究》, 1:100 万土地类型图; 蒙吉军《综合自然地理学》; 伍光和、蔡运龙《综合自然地理学》第 2 版): 土地纲 → 土地类 → 土地型 → 土地单元, 偏"可管理的地块"。生态区方向另有郑度等《中国生态地理区域系统研究》三级体系可参考。

**[决策规则]**
- 每级只换一个主导指标——这是区划不混乱的纪律。
- 树的节点必须空间连续、不重叠、可拼回上一级; **类型标签(柯本/群系/土壤)可多处重复, 只作覆盖层, 不进入树的层级**。
- 过渡带(ecotone)保留渐变, 不要画成硬边界——它们往往是故事舞台。
- 陆地树与海洋树是两棵独立的树; 政治/文化不进入本步。

**[输出产物]** `自然区划图`(陆地树 + 海洋树)+ `区划命名表`(每单元: 层级/名称/主导指标/边界依据/类型标签)。

**[检查点]**
- 树无重叠无空洞、每级指标一致;
- 命名能从名称读出气候与生态(类型标签)且不与其他单元重名(地名唯一);
- 同一类型标签可安全地出现在多个单元上(覆盖层不冲突);
- 区划与底层图层(地形/气候/生物群系)无矛盾。

**示例(米拉斯)**: 第一级三分: 「奥兰北境」(寒带/高原区)、「奥兰中土」(温带/季风区)、「银海裂谷带」(地中海式/断裂区) + 南大陆「维拉」(独立区系)。第二级: 温度带×干湿网格(温带湿润/温带半干旱/副热带干旱/寒带湿润...)。第三级: 「丰饶冲积平原省」「风语草原省」「龙骨山地省」「白雾荒漠省」「北寒原省」。第四级: 「苍河河谷」「泪母湖盆地」「缝合地峡区」「盐角半岛」... 海洋: 「银海陆架区」(浅、渔场、大潮)、「东青暖流区」(珊瑚礁)、「西风寒流区」(雾、上升流渔场)、「北冰洋区」(冰封)、「深渊海盆区」(超深渊, 传说区)。

## 第 9 步: 文明分布(地理→文明, 让地理契合主题)

> **范围说明**: 按当前边界, 政治/文化层**不属于地理大类**(另行考虑)。本步保留为"地理→文明"的**扩展参考**: 用已构建的自然地理推导文明分布——它展示地理如何被文明利用, 但不修改地理本身。

**[输入]** 生物群系图+土壤图+水文图+区划图+第 0 步的需求清单。

**[操作]**
1. **找文明摇篮**: 大河冲积平原+可预期洪水(农业盈余)→ 农耕帝国; 三角洲(富饶+港口)→ 商业城邦; 河谷阶地(防洪高地)→ 古城; 草原带 → 游牧民族(季节迁徙); 海岸多岛+深湾+季风 → 海洋贸易文明; 绿洲/盐湖 → 沙漠商路文明。
2. **用可驯化物种底图**: 每个大陆给 5~15 种可驯化大型动物+主粮作物清单(由气候带推); 东西轴线大陆(同纬度)技术扩散快 → 大一统文明; 南北轴线大陆 → 文化碎片化、技术缓慢。
3. **用河流参数定政体类型**: 洪水可预测温和→历法/神权型; 洪水凶猛需治水→水利官僚帝国; 河流短小破碎→城邦联盟; 无大河→山地部落。
4. **用气候事件做历史骨架**: 设计 2~3 次"小冰期"或"暖期"(±1°C 级), 安排: 减产→饥荒→游牧南侵→王朝更替; 暖期→大扩张/大航海。
5. **放置需求清单里的特殊文明**: 隐修文明(高原/孤岛)、魔法文明(灵脉交汇)、航海文明(群岛)、沙漠文明(绿洲商路)——确保它们的位置与地理成因一致。
6. **政治边界**: 沿自然边界(分水岭/山脉脊线/海峡/沙漠边缘)画国界; 过渡带设为争议区。

**[决策规则]**
- 地理给出"概率与代价"而非必然(可能论): 同一地理可容纳多种政体——给每个文明留一个"违背直觉"的巧思。
- 人口密度随生物群系生产力递减: 荒漠苔原几乎无人, 冲积平原人口密集。
- 需求清单是"必须满足"的约束, 但每个满足方式都要过地理自洽这关。

**[输出产物]** `文明分布图`(文明+语言区+国家边界+商路)+ `文明档案`(每文明: 位置/经济基础/政体/扩张方向/与地理的因果链)。

**[检查点]**
- 每文明的位置有地理理由(资源/地形/气候);
- 需求清单逐条满足;
- 政治边界与自然边界一致;
- 商路沿低险阻走廊(草原带/河谷/海路/绿洲链)。

## 第 10 步: 地图绘制与落地(投影/比例尺/一致性)

> **范围说明**: 本步绘制的是地理大类图层(自然区划树 + 类型覆盖层); 政治边界等文化层图层待后续模块再叠加。

**[输入]** 以上全部图层。

**[操作]**
1. 选投影: 世界总览图用 Winkel Tripel / Robinson / Mollweide(折衷或等积, 避免墨卡托面积错觉); 大陆区域图用等积圆锥(标标准纬线); 小区域详图用横轴墨卡托(UTM 式)。
2. 画经纬网: 1° 纬度 ≈ 111 km; 1° 经度 ≈ 111.3 × cos φ km; 标注比例尺、指北针、投影名称。
3. 分层绘制: 基底(海陆/经纬网)→ 地形(山系/高原/平原)→ 水文(河湖)→ 气候(柯本着色)→ 生物群系 → 区划 → 文明(城市/国界/商路)。每层可独立成图, 也可叠加。
4. **最终一致性总检**(全流程检查清单):
   - 河流: 自高向低、只合不分、必有归宿;
   - 山脉/火山/地震带: 沿构造线;
   - 沙漠: 与副热带高压/雨影/寒流吻合;
   - 海岸: 可追溯到海侵/构造/冰川/沉积过程;
   - 生物群系: 与温-雨参数匹配;
   - 垂直带/雪线: 与纬度相符;
   - 文明: 只在可居可耕之地;
   - 天文: 气候带与自转/倾角匹配。
5. 把全部初始参数与每步输出归档进"世界圣经"(含: 法则卡片、天文参数表、板块图、地形台账、气候台账、水文台账、生态台账、区划表、文明档案)——任何后续新设定都可回查。

**[决策规则]**
- 地图是"最后"画的东西, 不是"最先"——先有物理, 后有图。
- 允许"明知故犯"的例外, 但必须显式标注(如"此山脉由魔法升起, 非板块成因"——法则豁免要写在世界圣经里)。
- 不同比例尺子图用同一投影体系, 避免换算错乱。

**[输出产物]** `世界地图集`(总览图+区域图+各主题图层)+ `世界圣经`(完整参数归档)。

**[检查点]** 第 13 节的全流程检查清单逐项打勾。

# 第二部分: 面积与尺度标尺(贯穿工具)

> **用途**: 十一步流程中每一步都要回答"多大"——大陆多大、山脉多长、湖泊多宽、区划各级多少面积。本章给出地球的真实量级作为锚点, 以及"给定虚构大陆面积 A, 如何按比例分配各要素"的换算公式。构建时先把本部分通读一遍, 再回到各步骤执行。
> **核心方法**: ①定海陆比 → ②定大陆面积(参照真实大洲) → ③按比例公式锚定各要素(山脉/平原/沙漠/湖泊/河流/岛屿/海峡/三角洲) → ④用"十倍递减阶梯"分配行政区与区划层级。

## 2.6 给定虚构大陆面积 A 的比例公式表

> 设虚构大陆面积为 A(km²)。按下列比例锚定各要素, 一步落在真实量级内。三档示例: A=4,000 万(欧亚式)、A=2,000 万(南美式)、A=800 万(澳洲式)。

| 要素 | 建议公式 | A=4,000 万 | A=2,000 万 | A=800 万 |
|---|---|---|---|---|
| 最大平原 | 15–40% × A | 600–1,600 万 | 300–800 万 | 120–320 万 |
| 最大沙漠 | 10–30% × A(限 15–35° 纬/雨影) | 400–1,200 万 | 200–600 万 | 80–240 万 |
| 最大高原 | 5–15% × A | 200–600 万 | 100–300 万 | 40–120 万 |
| 最大湖泊/内陆海 | 0.3–1% × A | 12–40 万 | 6–20 万 | 3–8 万 |
| 最深湖深 | 裂谷背景 ≤1,700 m; 非裂谷 ≤500 m | — | — | — |
| 最大流域 | 15–25% × A(上限 40%) | 600–1,000 万 | 300–500 万 | 120–200 万 |
| 最长河 | 大陆最宽对角线 × 0.6–0.9 | 4,000–7,000 km | 3,000–5,000 km | 2,000–4,000 km |
| 最大岛 | 5–10% × A | 200–400 万 | 100–200 万 | 40–80 万 |
| 大型半岛 | 10–40% × A | 400–1,600 万 | 200–800 万 | 80–320 万 |
| 战略海峡 | 最窄 10–100 km | 15–40 km | 15–40 km | 15–40 km |
| 大河三角洲 | 0.3–1.3% × A | 12–52 万 | 6–26 万 | 3–10 万 |
| 草原带 | 与平原/高原可重叠, 20–40% × A | 800–1,600 万 | 400–800 万 | 160–320 万 |

**面积自检清单**:
- 平原+盆地+高原+山地+沙漠+草原 合计 ≈ A(草原可与平原/高原重叠);
- 最大单一单元 ≤ 大陆 30–35%, 否则地图观感失真;
- 大陆与最大岛保持量级差(格陵兰 216 万 vs 澳洲 770 万 ≈ 1:3.6——若虚构大陆仅 200 万 km² 就不要再设 50 万+ 的岛屿);
- 沙漠必须位于 15–35° 纬度或雨影侧;
- 高原面积若 >20% 大陆, 海拔必须压低(参照巴西高原), 否则违反均衡原理;
- 10 万 km² ≈ 华北平原/四川盆地("省级"); 30–40 万 ≈ 塔克拉玛干; 75–100 万 ≈ 恒河平原/蒙古高原(次大陆级); 250 万 ≈ 青藏高原; 400–900 万 ≈ 东欧平原/撒哈拉(洲际级)。

**单位换算速记**: 赤道 1°×1° ≈ 1.23 万 km²; 10°×10° ≈ 123 万 km²; "1 欧洲 = 1,000 万 km²"可作直观单位; 线性尺度 = √面积(100 万 km² ≈ 1,000 km 见方)。

# 第四部分: 综合一致性检查清单

## 天文/行星层
- [ ] 自转周期与轨道距离自洽(近星必锁定; 锁定时倾角应近 0)
- [ ] 倾角稳定性与卫星配置自洽(无大卫星 ≠ 倾角长期稳定)
- [ ] 恒星寿命 ≥ 世界历史长度
- [ ] 大气保留与重力/XUV 自洽(低重力+M 矮星 = 大气很快被剥光)
- [ ] 气候带位置与自转/倾角匹配(别把地球 30° 干旱带搬到慢自转世界)

## 地质层
- [ ] 板块边界构成连续网络、无悬空边界
- [ ] 山脉/火山/地震带都在边界或缝合线上
- [ ] 陆地最高点 ≤ 重力允许的上限(类地 ~9 km)且有山根(均衡)
- [ ] 洋盆有年龄梯度(越老越深)
- [ ] 河流自高向低、只合不分、必入海或内流归宿
- [ ] 分水岭沿山脊; 湖泊在洼地且入流 > 蒸发
- [ ] 每个岛屿可归入四成因(大陆/火山/珊瑚/冲积)

## 气候/生态层
- [ ] 30° 附近有副热带荒漠带; 迎风坡多雨、背风坡干燥
- [ ] 大陆西岸 vs 东岸气候不对称(寒流西岸/暖流东岸)
- [ ] 大洲东南缘季风性; 内陆冬冷夏热
- [ ] 生物群系与温-雨参数匹配(Whittaker 图反查)
- [ ] 垂直带与雪线随纬度合理(赤道 ~4500–5000 m)
- [ ] 动物区系与板块史允许祖先到达(华莱士线意识)
- [ ] 土壤带与气候植被对应(红壤/黑钙土/灰化土/荒漠土)

## 文明层(扩展参考, 属后续政治文化模块)
- [ ] 城市/国家/语言区只出现在可居可耕之地
- [ ] 人口密度随生物群系生产力递减(荒漠苔原几乎无人)
- [ ] 政治边界顺应自然边界(分水岭/山脉/海峡)
- [ ] 文明类型与河流水文/海岸形态匹配
- [ ] 气候事件在历史上留有痕迹(古湖盆/干河道/迁徙传说)
- [ ] 第 0 步的需求清单逐条满足且地理自洽
