# 感官与认知设计

> 目的: 用感官谱系设计种族的存在论边界、文化差异与冲突机制——感官决定物种感知不到什么, 而盲区比优势更能制造文化差异。
> 前置: 输入行星光照、大气、介质(空气/水/土壤)与生态位; 输出认知隐喻、艺术圣物、禁忌、社会组织与司法体系。

## 核心理论

- **感知世界决定存在论边界**: 每个物种生活在由自身感官与行动能力建构的专属环境中——感知世界(能接收的信号)与作用世界(能施加的行动)构成一个闭环。核心推论: **物种感知不到的东西, 对它而言在功能上不存在**, 也不受其行为与道德约束。盲区与优势同等定义物种; 文化冲突常来自不可通约的感知界面, 而非单纯的能力强弱。
- **感知空间 = 生态位维度**: 每种生物占据感知空间中的一个点——有视觉则占据"光"维度, 有电觉则占据"电场"维度; 感官差异即生态位分化。信号(光/声/化学/电场/磁场)在特定介质(空气/水/土壤/夜间)中的传播方式塑造感官进化。
- **感官等级是文化结构**: 每种文化对感官进行等级排序(什么被放大、什么被压抑), 并把感官与道德、宗教、社会价值挂钩(气味=善恶, 触觉=亲密或亵渎)。感官不是生物常数, 而是文化意义建构的通道——同一感官在不同文化中等级可以截然相反。
- **媒介改变感官配比**: 口语文化以耳为主, 文字印刷文化以眼为主。声音是**事件性的、瞬间消逝的、在场的、聚合的**; 文字是**空间化的、可分离主体的、线性的、可回看的**。主导感官直接塑造思维形态与知识存储方式。
- **认知不只在个体头脑里**: 认知分布在人、人工物与环境之间的表征传播与协调系统(分布式认知); 群智慧与超个体描述去中心决策——个体仅持局部信息, 借信号聚合达成群体共识。
- **时间感知与寿命耦合**: 贴现率随年龄与预期剩余寿命变化——寿命更长、前景更远者贴现率更低、时间地平线更长; 短寿者贴现率高、行为急迫。小体型高代谢物种时间分辨率更高(感知到的时间流速更慢), 时间感知与身体尺度耦合。
- **感官缺失可作为增益而非残缺**: 缺失一种感官不是"少了一个通道", 而是把世界重构为另一种完整文化(如视觉-空间手语文化: 目光接触=礼仪核心、视觉注意规则自成体系)。设计"缺失感官种族"时, 正面建构其完整文化而非按"残缺"想象。

## 感官谱系速查表

| 感官 | 机制 | 典型用法/代价 |
|---|---|---|
| 回声定位 | 发声+回声/多普勒频移 | 无光环境导航; 吸声环境(雪地/挂毯厅)中"失明" |
| 电觉 | 主动电场成像 / 被动探测电场 | 水中/绝缘体辨物; "看穿体温与电场" |
| 磁觉 | 感应地磁定向 | 导航; 方向即道德("正北"=正义) |
| 红外热感 | 热成像 | 黑暗中视物; 体温即隐私, 热伪装成礼仪 |
| 化学觉(嗅觉/味觉) | 气味编码信息 | 身份代码、气味名片; 无视觉时的主导通道 |
| 触觉 | 振动/接触感知 | 织物/纹身/雕刻为最高艺术; 蒙眼礼=最高禁忌 |

## 构建操作

1. 先画"感知清单"再画文化: 为每个种族写两表——"感官能力"(五感+扩展感官的参数: 频率范围/光谱/电场灵敏度/时间分辨率)与"感官盲区"(感知不到什么);
2. 用盲区反推禁忌: 无视觉种族把"看不见之物"神圣化或恐惧化; 红外热感种族"看穿体温"→体温即隐私; 回声种族在吸声环境中"失明"→此类空间成为法庭或禁地;
3. 用盲区而非优势制造冲突: 视觉族"看见火焰的光", 红外族"看见火焰的热", 电觉族"看不见"绝缘体内的生命——由此产生礼仪事故、宗教论争("谁的经验是真实的?")与战争借口, 冲突根源是**感知不可翻译**;
4. 让主导感官决定艺术、圣物与禁忌: 听觉主导→音乐即法律, 圣歌/钟/鼓为圣物, "无声的罪"为重罪; 嗅觉主导→焚香祭坛、香水=身份代码与道德审判; 磁觉主导→磁石/罗盘为圣物, 迷失=堕落; 触觉主导→织物/纹身/雕刻为最高艺术;
5. 让认知模式即社会组织: 蜂巢思维种族——个体是"探针", 无领袖, 靠法定人数投票共识决策, 可写"共识即法律、少数派无异议权"; 分布式认知种族——知识外置于歌之径/绳结/星图/石碑, 记忆是公共设施, 图书馆被毁=集体失忆之灾;
6. 按寿命设计时间贴现: 千年种族低贴现, 立"百年契约", 视短命者的急迫为粗俗; 十年种族高贴现, 仪式高频、艺术品短小易朽(花艺/冰雕)。长命族"现在投资五百年后还本"在短命族看来是骗局——贴现率差直接驱动经济与外交冲突;
7. 让司法与"证据"从感官谱系长出: 视觉族信目击证词, 听觉族信誓言与耳闻, 电觉族信"感应测谎", 磁觉族信方位佐证——法庭程序、刑侦工具与腐败形式(如何伪造"感知证据")随主导感官变化;
8. 用非视觉感官重建景观: 为每个种族绘制不同"地图形态"——歌之径(听觉地志)、气味航线(嗅觉导航)、磁场等高线(磁觉地图)、声呐剖面(回声城市模型), 写场景时用该种族的感官词汇描述环境;
9. 把跨种族交流写成翻译问题而非技术问题: 一方无法向另一方传达颜色/气味/电场体验, 于是产生"神秘主义"、"不可言说者"与感官霸权(强势感官种族把对方盲区污名为"低等")。
10. 给"感知证据"造假留出空间: 每种感官都有可伪造的"感知证据"(伪造气味圣痕/伪造回声图像/伪造磁场读数), 让刑侦与宗教审判天然带有感官技术含量, 也暴露"感官等级即权力等级"。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 只列感官能力不列盲区 | 感知清单必须含"感知不到什么"并反推禁忌 |
| 感官差异只作外观装饰 | 让盲区/优势进入隐喻、艺术、礼仪、司法 |
| 冲突源于"谁更强" | 冲突源于感知不可翻译(不可通约界面) |
| 换个主感官但隐喻体系照旧 | 语言隐喻/艺术/仪式/建筑/礼仪全部重写 |
| 群智慧写成心灵感应魔咒 | 写正反馈+负反馈+法定人数的机制说明书 |
| 全种族同一时间贴现率 | 按寿命×代谢设计贴现率差并驱动冲突 |

## 检查点/清单

- [ ] 每个种族有感官能力+感官盲区两表?
- [ ] 盲区已反推禁忌与空间(禁地/法庭)?
- [ ] 主导感官已决定艺术、圣物、禁忌(至少三项可见)?
- [ ] 认知模式(个体/群智慧/分布式)已写入社会组织?
- [ ] 贴现率按寿命设计并产生跨种族冲突?
- [ ] 司法证据体系随感官谱系变化?
- [ ] 每个种族有独特的"地图形态"与景观描述词汇?
- [ ] 跨种族交流失败是结构性翻译问题而非偶然?
