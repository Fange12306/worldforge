# 历史构建总流程

> 目的: 给定世界法则、地理底图、文明档案与一个"历史切片"(某时间点的世界状态快照), 合理前推过去(补充历史)与后推未来(推演历史)。
> 前置: 地理篇(底图)+ 文明篇(文明档案)。核心场景: 历史切片双向推演。

## 核心原则

1. **历史 = 世界法则 + 初始条件的确定性展开**: 一切历史事件都应是法则层(物理/魔法/神学)与地理约束的可推导结果——魔法/神祇不是装饰, 而是改写人口-技术-能量方程的自变量。
2. **解释—预测对称(亨佩尔覆盖律)**: 前推(补充过去)与后推(推演未来)本质是同一演算的两种方向——任何后推结论都能被前推检验(双向校验闭环)。
3. **结构确定、事件留白**: 结构层面(制度/技术/生态)推演最稳健, 具体事件(某场战争/某个人的生死)只能概率化——事件交给叙事去填。
4. **反设定病**: just-in-time 构建; 设定服务故事; 定期"年表瘦身"。

## 七步执行流程

```
第 0 步: 解剖切片——三层归档(长/中/短时段) + 痕迹层清单 + 完整性三栏
   ↓
第 1 步: 前推过去——痕迹取证 + 倒溯法 + 考古式反推 + 机制反推
   ↓
第 2 步: 后推未来——趋势外推 + 机制推演 + 周期叠加 + 反事实分支
   ↓
第 3 步: 对撞检查——过去必须解释切片全部细节; 未来必须能反推回现在
   ↓
第 4 步: 分层历史输出——宏观纪元(门槛切分)/中观朝代(周期律)/微观事件(改变结构者)
   ↓
第 5 步: 叙事与记忆设计——官方史vs民间记忆落差 + 记忆之场 + 创造性事件
   ↓
第 6 步: 一致性总检(历史篇检查清单)
```

## 流程要点

- **第 0 步(解剖切片)**: 三层归档(长时段=地理气候结构, 几乎不动; 中时段=制度经济周期; 短时段=事件); 痕迹层=废墟/地名/习俗/禁忌/世代创伤——每项都是过去事件的线索; 完整性三栏(已证实/推测/空白)。
- **第 1 步(前推过去)**: 倒溯法——对每个特征问"它需要多久形成"(制度数十年/技术1-3世纪/宗教数百年至千年/地理万年), 叠加=最低历史深度; 痕迹取证(废墟因何而毁? 地名是哪层语言? 禁忌在防什么?); 反向链条至少推两级直到触及起源点。
- **第 2 步(后推未来)**: 趋势外推必须设饱和点; 周期叠加(长波50-60年/霸权100-120年/王朝200-300年/世俗周期150-300年)——各周期转折点错开或对齐, 对齐处=史诗时刻; 反事实最小改写(每步只改一个因素); 三钟同步(事件层可突变, 结构层只能渐变)。
- **第 3 步(对撞检查)**: 未来的遗迹要在当前切片埋下"种子"; 过去必须解释切片全部细节; 缺口=隐藏历史。
- **第 4 步(分层输出)**: 纪元用"门槛"切分(5-8个门槛, 每个标注前提/跃迁/新能量流/遗留物); 朝代用周期律生成(赫勒敦四代论+图尔钦世俗周期); 事件只记"改变结构者"。
- **第 5 步(叙事记忆)**: 官方史与民间记忆产生落差(落差=张力与探秘入口); 安装记忆机制(谁记住什么/纪念仪式/被遗忘的历史); 用"创造性事件"设计转折(短时段事件穿透长时段结构)。
- **第 6 步(总检)**: 因果闭合/比例感/机制守恒/层间速率/双向校验/叙事落差。

## 一致性检查总纲

**切片层**: 三层归档完整; 痕迹层清单齐全; 完整性三栏明确(记录偏差是特性)。

**过去层**: 每个痕迹有成因; 特征形成时间与切片深度匹配; 反向链条至少两级; 多条独立证据链交叉锚定。

**未来层**: 趋势外推有饱和点; 周期相位标注; 反事实最小改写; 双向校验闭环。

**年表层**: 因果闭合无悬空事件; 比例感合理(千年无事一朝剧变); 门槛切分纪元; 周期律生成朝代。

**叙事层**: 官方-民间落差; 记忆之场随政权演化; 因果链双层解释(结构+行动者); 超自然机制本身遵守规则。

**反设定病**: just-in-time; 每段设定标注故事功能; 定期年表瘦身。
