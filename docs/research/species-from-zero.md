# 种族体系: 从0到1构建虚构世界的种族与生物 — 完整研究手册

> **目的**: 给定世界的法则/地理/文明/历史/经济/军事/技术/语言/宇宙底图与既有种族设定, 按本手册从"定位与总流程"出发, 依次完成生命起源与推导链、感官认知与寿命繁殖、智慧形态与种族谱系、种族与文明、经典与原创种族、生态位与幻想生物、神话原型与一致性总检八个环节, 构建自洽、可推演、可叙事的虚构世界种族体系。
> **范围**: 种族总流程与接口(生态位先于物种/依赖顺序图/五卡档案/生命判据/竞争排斥初审)、生命起源与地外生物学(生命四要素/溶剂约束/起源理论谱系/化学梯度生态/盖亚与大过滤器)、生理-心理-文化推导链(约束传递链/四条生理通道/潜在解区/可逆性审计)、感官与认知(Umwelt 感知清单/盲区制造文化/感官-文化映射/群智慧与分布式认知)、寿命繁殖与生命周期(代际数时钟/寿命权衡/繁殖-社会骨架/死亡观念四型)、智慧形态与意识(智慧四轴/群智慧机制说明书/意识判定法/累积文化)、种族谱系与演化(谱系四模式/适应辐射/地理隔离梯度/退化返祖)、种族与文明(三轴正交/种族≠文化≠国家/承袭规则/接触地带)、经典与原创种族(认知捷径/一次偏离+涟漪/超越经典三路径)、生态位与生物多样性(Hutchinson 生态位/竞争排斥/能量预算/岛屿生物地理学)、幻想生物设计(平方立方律/形态-功能一致/生物武器化/驯化遗传账/魔力生物能量学)、神话原型与民间传说(复合兽 MCI/龙蛇阈限/山海经公式/重新买单)、构建方法论与一致性总检(五卡互引/生态卡五问/反换皮三测试/五大错误)。
> **用法**: 每步含 [输入] → [操作] → [决策规则] → [输出产物] → [检查点]。13 个主题的详细研究笔记见 `docs/research/notes/`(135-147, 前缀 species-)。
> **贯穿示例**: 内嵌示例世界「米拉斯」种族篇——生命判据=水基+灵脉能量第二通道(灵脉法则/灵魂法则的生物接口); 四智慧种族: 人类(主体)/火链袋兽族(有袋育儿→母系继嗣, 与文明篇灵枢城母系衔接)/岩鳞族(火链群岛, 鳞片光合辅助+寿命 300 年→慢节奏记忆型文明, 与文明篇云顶寺衔接)/雾裔(白雾荒漠, 靠雾水代谢, 视觉盲区文化); 虚构生物: 灵脉巨树(灵脉营养/树冠城市叶都/群智慧候选)/烬脊火蜥(热液生态)/雾盐蝶(雾水收集); 神话原型"重新买单": 龙骨(灵脉守护兽, 以灵脉为食, 数量稀少=灵脉状态指示); 与法则/地理/文明/历史/宇宙/经济/军事/技术/语言各篇衔接。

# 第一部分: 执行流程

## 第 0 步: 定位与总流程——先定生态位, 再填物种

**[输入]** 法则篇(魔法/能量/灵魂规则)+ 宇宙篇(宜居带/卫星/生命前提)+ 地理篇(行星参数/生物群系/地理隔离)+ 历史篇(年代框架)+ 技术篇(能源体系)+ 文明篇(社会结构需求)。

**[操作]**
1. **写"生态位矩阵"而非"物种名单"**: 第一问不是"长什么样", 而是"它吃什么、被谁吃、在哪儿活、何时活动"——按食物、温度、空间、时间等多维环境变量列出目标世界的完整生态位矩阵, 再逐个"招标"填物种(Hutchinson 生态位/竞争排斥, 135: 生态位先于物种)。
2. **固化依赖顺序图**: 行星参数(重力/大气/辐射)→ 生物群系 → 法则 → 物种生理 → 文明文化; 种族模块处于中游——消费前两个模块的输出, 生产文明模块的输入; 层间只传参数表, 禁止下层静默改写上层, 用版本号记录推导链变更(135: 依赖顺序)。
3. **建"五卡"档案模板**: 生理卡(感官/代谢/生殖/生命周期/代价)+ 生态卡(生态位/食谱/天敌/地理分布)+ 推导链卡(每项特征注明"因为…所以…"的来源)+ 谱系卡(演化树位置/近缘种/分化时间)+ 文化卡(语言/亲属/禁忌/技术, 每特征标注约束来源: 地理/资源/生理/历史偶发)(135/147: 五卡结构)。
4. **先定"生命判据"**: 明确本世界生命的溶剂+信息+代谢+边界四要素(如水+DNA+氧化还原代谢+脂膜, 或甲烷+聚合物信息+辐射分解+丙烯腈膜); 判据直接决定"如何探测生命""什么算生物"(136: NASA 生命定义)。
5. **写"法则接口"声明**: 若世界有魔法/灵魂法则, 生物生理必须与之有明确定义接口——能量从何而来、灵魂与肉体如何耦合、施法成本是什么; 类比 Sanderson 魔法第一定律: 能力必须有成本与限制(135: 法则接口)。
6. **打破"人类基线"**: 智慧种族天然以人类为模板("人类换皮"停留在皮肤层); 至少改动感知通道、繁殖方式、生命周期或认知模块之一, 而非外观装饰(135: 人类基线问题)。
7. **强制"代价卡"**: 每个智慧种族至少一项优势对应一项劣势(高智力↔长幼态期或低繁殖率, 长寿↔低生殖投入), 并用平方立方律检验体型设定(135: 代价守恒)。
8. **建发布检查点**: 发布任何种族设定前——(a) 回溯至法则层; (b) 与行星/地理参数核对; (c) 与相邻模块接口核对(地理→种族→文明→历史闭环); (d) 用读者视角问"删掉是否损失", 无损失即删。

**[决策规则]**
- 生态位先于物种: 先给生态位, 再填形态——无生态位的"装饰性怪兽"删除或补全(135);
- 竞争排斥: 任何两个智慧种族若生态位完全重叠, 必须写出分化维度(空间/时间/食性/体型/社会分工), 否则合并或删减其一(135/147);
- 生理决定文化上限: 文化核心(亲属/产权/分配/宗教生态成分)受环境与技术约束最强, 文化主干必须能由"生理+环境"推导(Steward 文化生态学);
- 代价守恒: 智力/寿命/体型/繁殖率/感官灵敏度间存在权衡, 任何优势都要付账(昂贵组织假说);
- 依赖链单向: 上层是下层的输入参数源, 反向改写只允许显式"世界观例外声明";
- 人类换皮是失败模式: 移除外观差异后若该种族在社会/认知/价值上仍与人类无区别, 判定失败。

**[输出产物]** `生态位矩阵` + `依赖顺序图与层间参数表交接协议` + `五卡档案模板` + `生命判据书` + `法则接口声明` + `代价卡` + `发布检查点四步`。

**[检查点]** 生态位先于形态; 每族至少一个优势配一个代价; 文化主干可由"生理+环境"推导; 换皮自检通过(至少改动感知/繁殖/生命周期/认知之一并产生文化涟漪); 竞争排斥初审无完全重叠; 档案区分"法则条目"与"事实条目"。

## 第 1 步: 生命起源与推导链——先立判据, 再推生理到文化

**[输入]** 第 0 步生命判据 + 宇宙篇(宜居带/冰卫星/化学梯度能源)+ 地理篇(海洋/荒漠/雾区等溶剂分布)+ 法则篇(灵脉/灵魂如何参与生命)。

**[操作]**
1. **选生命起源谱系并配深时纪年**: 原始汤(Miller-Urey)/RNA 世界(信息+催化)/海底热泉(碱性热泉天然质子梯度)/泛种论(陨石播种)四选一或组合, 并映射地质纪年(生命起源→大氧化事件→雪球地球→寒武纪爆发), 埋"前代文明被深时抹平"的情节层(136)。
2. **用化学梯度代替阳光设计生态金字塔**: 仿海底热泉与深部生物圈, 用 H₂/SO₄²⁻、FeS 沉淀、辐射分解氢等氧化还原对供能——"地下文明""冰壳海洋文明"由此脱离宜居带限制(136)。
3. **给替代生物化学配代价表**: 硅基→刚性矿化躯体、代谢极慢; 砷替换磷→氧化环境脆弱; 氨/甲烷溶剂→低温慢节奏→文明节奏推导("千年一代"长寿种族或极致节能文明)(136)。
4. **逐环写推导链**: 每个"参数→生理→心理→文化→技术"条目各写一行"因为……所以……", 标注硬约束(生理不可违反)与软约束(昂贵但可被文化克服); 写不出理由的条目立即删改(137)。
5. **感官→认知隐喻重写**: 视觉主导→"看见=理解""光明=善"; 嗅觉/听觉主导的文化要有完全不同的隐喻、艺术与宗教体系(137)。
6. **用大气与能源反推技术树**: 大气含氧量决定火与冶金(约 15–16% 以下无金属文明); 恒星光谱决定可用能源(红矮星弱光→转向化学能/地热)——技术是推导链最远端、最可检验的一环(137)。
7. **盖亚式反馈把行星写成角色**: 生命圈调节反照率/云凝结核/甲烷通量, 可设定"行星免疫系统"或 Daisyworld 式恒温机制(136)。
8. **用大过滤器/Fermi 悖论定世界观基调**: 过滤器在过去(生命是宇宙奇迹)、在未来(文明自毁→末世感)或恐怖版(已被检测到), 并标注主角文明处于哪一阶段(136)。

**[决策规则]**
- 推导链=约束传递链, 不是因果决定链: 生物在约束下寻优, 产生倾向性而非必然性; 同一约束可容纳多个解(多重可实现性)(137);
- 参数成组考虑: 重力/光照/大气/季节四条生理通道单参数推导必然失真(137);
- 文化必须落在"潜在解区": 文化形式须在个体生理-认知可自发重现的能力范围内, 超出范围的文化无法被复制维持(137);
- 可逆性审计: 每个文化特征应能回溯到生理特征或环境约束; 回溯不到的显式标"文化漂变/历史偶然", 全种族不超过 1–2 个(137);
- 决定论边界: 生理定硬约束(不可能)与软约束(昂贵), 文化自主性存在于软约束空间之内; 完全决定论与完全自由同为错误极端(137);
- 替代生化必配代价, 防止"万能外星生物"(136)。

**[输出产物]** `生命判据书(四要素)` + `起源谱系选择与地质纪年表` + `化学梯度生态金字塔` + `替代生化代价表` + `推导链卡(逐环因为所以+硬软标注)` + `技术树推导(大气×能源×材料)` + `大过滤器定位声明`。

**[检查点]** 推导链每环有理由; "换脑/换感官/换时间"人类换皮检验三步通过(137); 每族文化特征可回溯(漂变≤2); 生态卡五问能答; 生命判据与世界法则(灵脉/灵魂)接口明确; 深时纪年存在(非静态布景)。

## 第 2 步: 感官认知与寿命繁殖——先画盲区, 再定社会骨架

**[输入]** 各族推导链 + 地理篇(光照/湿度/噪声/地热环境)+ 法则篇(灵魂/灵脉对感知与寿命的影响)。

**[操作]**
1. **画"感知清单"两表**: 每个种族写"感官能力"(五感+扩展感官的参数: 频率范围/光谱/电场灵敏度/时间分辨率)与"感官盲区"(感知不到什么); 用盲区反推禁忌——无视觉种族把"看不见之物"神圣化, 红外热感种族"看穿体温"→体温即隐私(138)。
2. **用盲区而非优势制造冲突**: 视觉族"看见火焰的光"、红外族"看见火焰的热"、电觉族"看不见"绝缘体内的生命——礼仪事故、宗教论争、战争借口皆源于感知不可翻译(138)。
3. **主导感官决定艺术/圣物/禁忌/司法**: 听觉主导→音乐即法律、圣歌为圣物; 嗅觉主导→焚香祭坛、香水=身份代码; 磁觉主导→磁石为圣物、方向即道德; 司法证据随感官谱系变化(目击证词 vs 誓言 vs 感应测谎)(138)。
4. **认知模式即社会组织**: 群智慧种族写"共识即法律、少数派无异议权"; 分布式认知种族知识外置于歌之径/绳结/星图, 图书馆被毁=集体失忆之灾(138)。
5. **算"代际数时钟"**: 寿命÷成熟年龄=代际数——人类千年约 120 代; 若某族寿命 1000 岁、100 岁成熟, 每千年仅 10 代, 科技与社会迭代慢一个数量级以上; 让技术节奏与代际数严格挂钩(139)。
6. **写"寿命权衡表"**: 长寿必须配低生育、长童年、高亲代投入、代谢慢(K 端); 禁止"永生且多子且强壮"——至少设计一个明确权衡(139)。
7. **繁殖模式决定社会骨架**: 有性+投入不对称→性别分工与婚制; 单性/多型繁殖→用"型/阶"替代性别(工蜂/兵蚁式阶层); 群繁殖→家庭退位、巢穴政治; 先问"他们怎么生孩子"再定"家庭长什么样"(139)。
8. **死亡观念与寿命挂钩**: 短命族→死亡日常化、丧葬从简、文化靠世代翻新; 长命族→系谱记忆=政治资源、葬礼纪念碑化、临终仪式专业化; 永生族→死亡禁忌化或"死亡=罪"(139)。
9. **按寿命设计时间贴现**: 千年种族低贴现、立"百年契约", 视短命者急迫为粗俗; 十年种族高贴现、仪式高频、艺术品短小易朽——经济与外交冲突直接由贴现率差驱动(138)。

**[决策规则]**
- Umwelt: 感官决定存在论边界——物种感知不到的东西对它而言在功能上不存在; 盲区与优势同等定义物种(138);
- 时间贴现率随预期寿命变化: 寿命更长者贴现率更低、时间地平线更长(138);
- 衰老是繁殖期的附属品: 自然选择不"需要"老年(突变积累/拮抗多效/可抛弃体细胞)(139);
- 亲代投资: 投入更多的一方成为限制性资源, 择偶竞争集中于投入少的一方(139);
- 死亡突显塑造文化强度(TMT): 死亡风险越高的社会, 宗教/荣誉/排外越强烈(139);
- 感官不是生物常数而是文化意义建构通道(感官人类学, 138)。

**[输出产物]** `各族感知清单(能力+盲区)` + `感官-文化映射表(艺术/圣物/禁忌/司法)` + `代际数时钟表` + `寿命权衡表` + `繁殖-社会骨架映射表` + `死亡观念四型表(短命/长命/永生/r-策略)` + `时间贴现分层表`。

**[检查点]** 盲区产生禁忌; 主导感官有可见文化涟漪(艺术/圣物/司法); 代际数-技术节奏挂钩; 无"永生且多子且强壮"; 死亡观念从寿命导出; 繁殖模式映射到亲属与分工; 司法证据随感官谱系。

## 第 3 步: 智慧形态与种族谱系——先定智慧坐标, 再画演化树

**[输入]** 各族推导链 + 意识理论选择 + 地理隔离史(山/海/沙漠/裂隙)+ 历史纪元(分化时间锚点)。

**[操作]**
1. **智慧四轴定位**: ①个体—集体(认知主体是单脑还是群体)②内嵌—抽象(认知绑定身体还是可符号化)③技术—非技术(是否物化工具)④文化累积(有无棘轮式世代积累)——各族取不同坐标, 而非全部拉满(140)。
2. **群智慧写"机制说明书"而非"心灵感应魔咒"**: 每个集体决策设计三条线——正反馈通道(舞蹈/信息素/舆论放大)+ 负反馈通道(停止信号/否决权)+ 法定人数阈值(quorum); 异议者不足法定人数时决策被锁死=天然戏剧冲突(140)。
3. **选"意识判定法"**: 从 IIT(高 Φ 即意识)/GWT(全局广播)/高阶理论(自表征)/自我模型论中选一套, 作为世界的"意识判定法"; 用指标而非人形特征判定"谁有意识", 并设"意识税"(意识需能量与整合成本)(140)。
4. **把累积文化当文明分水岭**: 技术文明=高保真社会学习(模仿+教学)+创新+长世代交叠; 可设定"个体天才遍地却无技术"(缺乏保真传递)或"个体平庸、技术爆炸"(棘轮飞转)(140)。
5. **先画演化树再写种族史**: 为每个种族标注共同祖先(MRCA)、分化时间(以纪元/代际锚定)、与邻族是姊妹类群还是远亲趋同; 混血可行性由树拓扑决定(141)。
6. **谱系四模式注记**: 同源分化(共同祖先适应辐射, 可育混血前提)/异源独立(趋同演化, 谱系不相干)/收养追认(养子/外来征服者被写入家谱)/堕变造物(神/术法造出或堕落扭曲)——主动混用打破"万物同源"的平庸(141)。
7. **适应辐射配方**: 一个祖先种+一组环境梯度(群岛/山脉/湖盆)+各自特化特征(特征对应生态位而非装饰)+辐射前提(空生态位为何空缺: 大灭绝/魔潮之后)(141)。
8. **地理隔离梯度控制"种族关系"温度**: 长期隔离→生殖隔离(混血不育); 近期隔离→混血可行但成社会禁忌; 相邻共存→靠选型交配/生态隔离维持差异(141)。
9. **把退化返祖写成机制**: 远古种族衰落=功能简化+多罗法则不可逆(失去的力量无法原样找回); 返祖个体(重现祖先特征)=休眠基因被重新表达, 作主角/先知/诅咒(141)。
10. **谱系表=意识形态文件**: 绘制族谱时植入被追认的收养祖先、被抹除的旁支、神话祖先与考古祖先的错位——家谱文书可伪造、可焚毁, "谱系之战"即权力叙事引擎(141)。

**[决策规则]**
- 智慧是多维空间不是单一量表: 虚构种族在四根轴上取不同坐标, 而非全部拉满(140);
- 超个体认知是涌现的: 没有中央脑, 群体水平性状无法从单个个体预测; 个体仅持局部信息(140);
- 群体智慧四条件(多样性/独立性/去中心化/聚合)即政体失效开关: 同质化上升则群体智慧坍缩为群体愚蠢(140);
- 混血服从生殖隔离梯度而非全有全无: 只有同源且隔离不完整的种族间才有可育混血(141);
- 多罗法则: 复杂结构一旦丢失几乎不会原样重现, 但功能可被"重新发明"(141);
- 单系群原则: 类群须按共有衍征建树, 而非按形态相似拼凑(141)。

**[输出产物]** `各族智慧坐标(四轴)` + `群智慧机制说明书(正/负反馈+法定人数)` + `意识判定法与意识税` + `累积文化分水岭表` + `演化树(共同祖先/分化时间/姊妹类群)` + `谱系四模式注记` + `适应辐射表` + `混血可行矩阵` + `退化返祖机制卡` + `谱系政治注记`。

**[检查点]** 各族智慧坐标不同且与寿命/社会结构耦合; 群智慧有正负反馈+法定人数; 演化树无"所有人形祖先却无分化机制"; 混血规则服从隔离梯度; 适应辐射有前提(祖种+空位+梯度); 返祖有分子层逻辑; 谱系表自带政治矛盾。

## 第 4 步: 种族与文明——先拆三轴, 再写身份政治

**[输入]** 各族谱系 + 文明篇(政治/经济/宗教结构)+ 历史篇(战争/迁徙/同化事件)。

**[操作]**
1. **拆三轴再设计**: 为每个文明分别定义生物学表型(可完全没有种族概念)、文化(语言/习俗/制度)、政治(国家/帝国/联盟), 三轴两两正交——主动构造"同族多国""一国多族""跨族共享文化"的交叉矩阵(142)。
2. **破解 Planet of Hats**: 给每个物种至少 2–3 个彼此冲突的文化(定居/游牧/离散)与内部分歧; 一个文化内要有阶级、地域、世代、职业亚文化; 外部"帽子"只作为他者印象(142)。
3. **把种族分类写进世界内观念层**: 设定分类法出自某政权/法典/户口/身份证(血统比例? 母系? 外貌? 宗教?), 展示其后果(纳税/通婚限制/兵役/选举权)(142)。
4. **用承袭规则制造冲突**: 为世界定义 descent 规则(父系/母系/双系/按社会接受度), 并让不同法域规则冲突——同一角色在甲国是"纯血"、在乙国是"混血"(142)。
5. **混血身份政治**: 借鉴杂合性(Bhabha)/克里奥尔化(Glissant): 混血不是污染而是第三空间与创造性过程; 让混血角色同时拥有可选与强加的身份, 展示分类斗争(142)。
6. **设计接触地带**: 贸易港/边境市镇/克里奥尔语/宗教融合/混血社区; 让误译、不可译概念(时间/祖先/荣耀/罪)成为剧情驱动, 而不是用万能翻译机消解差异(142)。
7. **歧视结构化**: 写居住区划、职业限制、法律定义、教育隔离等制度而非角色偏见; 让种族与阶级、性别、宗教交叉(交叉性视角)(142)。
8. **给种族-文明绑定留时间轴**: 设计历史中的同化、融合、复兴与重新分类事件, 说明文化边界可变、分类可被推翻(142)。

**[决策规则]**
- 种族是社会建构不是生物学事实: 表型沿地理渐变, 种族分类随政权/法律/话语而变(种族形成理论)(142);
- 种族≠文化≠国家: 民族是想象的共同体, 国家是政治行政单元; "种族即国家"是意识形态而非事实(142);
- 种族决定论与文化决定论是同一枚硬币: 用文化本质替代生物本质同样制造封闭边界(族裔绝对主义)(142);
- 族群性是边界过程不是内容清单(Barth): 认同由"我们/他们"的边界维持决定(142);
- 承袭规则从不"中立描述"混血, 而是维系种族等级的手段(142);
- 机制可迁移、表型不可映射: 殖民/奴役/登记/隔离的权力结构可以迁移, 但不要让虚构种族一一对应现实种族(142)。

**[输出产物]** `三轴正交矩阵(表型/文化/政治)` + `各族文化内部变体集(≥2–3 互异文化+张力轴)` + `世界内种族分类法(法典/户口/承袭规则)` + `承袭规则冲突表` + `混血身份谱` + `接触地带清单(港口/皮钦语/混血社区)` + `结构化歧视制度表` + `种族-文明关系时间轴`。

**[检查点]** 无"一民族一国家"未解释; 每族≥2–3 个互异文化且至少一个张力轴可由生态卡推导; 分类法出自政权并有可见后果; 承袭规则有冲突引擎; 歧视有制度载体; 跨族交流用接触地带而非翻译机; 不映射现实种族。

## 第 5 步: 经典与原创种族——先立锚点, 再超越经典

**[输入]** 各族生态卡/推导链/谱系 + 读者认知预期(经典种族图式)。

**[操作]**
1. **先立锚点, 后加深度**: 每个种族先用一句话说清"它是什么"(1–2 个可瞬间识别特征), 保证立即可读; 之后所有扩展不得稀释锚点(143)。
2. **执行"一次偏离+涟漪效应"并留推导记录**: 从生态/人类学/经典原型取一个可辩护的关键差异(繁殖/感官/代谢/社会结构/时间感知), 按营养→身体→社会→语言→价值观→冲突逐层推导, 写"理由链"表; 任何质疑都能被推导链回答, 而非"因为它魔法"(143)。
3. **把内部多样性写成制度**: 每族至少 3 个互斥的文化群/政治派系/历史分期, 再加一个"反类型"亚文化(精灵中的务实商人、矮人中的诗人); 族内冲突与族间冲突并存(143)。
4. **补谱系深度**: 为每族写演化史——与人类(或其他种族)的分叉点、关键适应、兴衰节点, 回答"为什么它现在长这样"(143)。
5. **人形度光谱定位**: 在近人/异人/异形光谱上给每族定位; 近人种族负责人性议题的变奏(托尔金式共情), 异形种族负责认知刷新与惊奇, 杜绝全员"人穿皮套"(143)。
6. **本质主义自检**: 自查——该族是否有内部争议? 是否所有成员共享同一价值观? 能力差异是否有环境/文化解释而非"天生"? 若全是"天生", 即已滑入生物决定论(143)。
7. **用语言与命名做低成本深度工具**: 方言差异、命名规则、未翻译词汇瞬间制造文化厚度与谱系感(143)。

**[决策规则]**
- 种族=认知捷径: 属级位阶使"精灵"一词自动加载身体/人格/文化/价值观, 不必逐条解释(143);
- 心理本质主义是双刃: 它让"精灵=长寿+优雅+魔法亲和"显得自明, 也把物种/文化/人格/道德四合一, 形成生物决定论式种族观(143);
- 人形度与恐怖谷决定叙事效果: 越近人越易投射共情, 越异形越产生认知刷新, 似人非人触发排斥(143);
- 超越经典三路径并行: 保留 1–2 个可瞬间识别的锚点(捷径)+ 内部多样性(深度)+ 谱系深度(合理感)(143);
- 捷径负责可读性, 多样性+谱系负责深度, 二者不冲突(143)。

**[输出产物]** `各族锚点句` + `一次偏离-涟漪推导链记录表` + `内部多样性清单(文化群/政治派系/历史分期/反类型亚文化)` + `谱系深度注记(分叉点/关键适应/兴衰)` + `人形度光谱定位表(近人/异人/异形+叙事分工)` + `本质主义自检表`。

**[检查点]** 每族一句话锚点成立; 偏离有推导链记录(非"因为魔法"); 每族≥3 内部群体+1 反类型; 人形度分工明确、无"全员皮套"; 本质主义自检通过(无全族单一价值观)。

## 第 6 步: 生态位与幻想生物——先算能量账, 再画怪物

**[输入]** 各族生态卡 + 地理篇生物群系 + 生物能量预算(初级生产力)+ 技术篇(能源体系对魔法的约束)。

**[操作]**
1. **开"生态位维度清单"**: 每个物种/种族列出 8–12 个维度(食物粒径/水分/温度/盐度/活动时段/繁殖场所/天敌/共生者), 分别标注基础生态位与实现生态位; 若两族在所有维度重叠, 按竞争排斥必须"写死一个或写分一个"(144)。
2. **用能量预算硬约束怪物密度**: 设定初级生产力后按每级约 10% 传递效率反推各营养级总生物量; 顶级捕食者(龙/巨兽)数量应稀少(密度∝M^-0.75), 给超大领地与极低繁殖率, 避免"遍地巨龙"(144)。
3. **同域共存要有"分割轴"**: 同区域物种至少错开一个资源轴(昼伏夜出/不同取食层/不同猎物/错峰繁殖); 用体型比≥1.3 或特征位移写"竞争导致形态分化"的背景故事(144)。
4. **用岛屿生物地理学设计地图**: 按 S=cA^z 规划物种数——大陆腹地物种多竞争激烈, 小岛物种少但特有种比例高易灭绝, 群岛=进化实验室与"脆弱文明"设定(144)。
5. **把营养级联与关键种写成叙事引擎**: "猎杀最后一只关键种"必须引发可见的连锁崩塌; 先画食物网箭头图预演任意物种移除后的级联(144)。
6. **巨型生物做"比例设计表"**: 骨截面/腿径比、散热器官(耳/气囊/长颈/鳍)与体温策略; 宁可"矮胖柱状"也不要"等比放大的人类"; 可设巨型生物为变温/巨温性(145)。
7. **飞行生物先定"飞行方式"再定翼**: 拍翼型约≤20 kg, 翱翔型可数百 kg; 大型飞兽配气囊肺+空心骨+依赖上升气流; 若用魔法悬浮, 明确"魔法提供升力而非肌肉功率"(145)。
8. **生物武器化=完整器官系统**: 喷火/喷酸兽给出"器官四件套"——燃料腺+氧化剂储囊+点火器(催化酶放热室或电器官火花)+热防护(耐火衬里+隔热黏液), 外加冷却间隔与进食代价(145)。
9. **驯化写"多代遗传账"**: 温顺选择→神经嵴连锁性状(垂耳/花斑/小齿/繁殖期提前)同时出现; 单只驯服≠驯化; 注明世代数与退野化风险; 基因改造(构装兽)设硬代价: 不育/免疫缺陷/行为异常(145)。
10. **魔力=生物能量学**: 魔力腺=储能器官(类比脂肪/电器官), 施法=消耗底物+产热+排废, 有施法上限与过载损伤; 施法者需进食补充, 大型魔法兽设"魔力蓄能"周期(145)。
11. **共生/寄生要有"账本"**: 每个共生物种写明互利点、成本与宿主免疫平衡; 魔力共生体参照珊瑚-虫黄藻; 寄生操控型(僵尸化/宿主跳跃)设抗性个体与军备竞赛(145)。

**[决策规则]**
- 竞争排斥: 完全占据同一生态位的两物种无法稳定共存(草履虫实验), 共存要求生态位重叠低于阈值(d/w 规则)(144/147);
- 林德曼定律: 能量每经一个营养级约损失 90%——营养级数有限(4–5 级), 顶级捕食者必然稀少(144);
- 形态是环境约束的"解": 趋同演化说明飞行/穴居/水生/巨型化形态在独立谱系中反复出现——形态设计是解方程不是发明(135/144);
- 巨型化靠异速生长而非等比放大: 平方立方律下尺寸翻倍质量×8 而承重截面仅×4(145);
- 魔力守恒: 任何魔法必须付代谢代价、有储存上限、有废热/废物排出, 否则"无限魔力"违背能量守恒(145);
- 生态位构建: 生物改造环境再反作用于自身演化——文化与生态是双向反馈而非单向决定(147)。

**[输出产物]** `各族/生物生态位维度清单(基础位+实现位)` + `营养级能量预算表(初级生产力→顶级捕食者密度)` + `同域分割轴表` + `多样性梯度地图(按 S=cA^z)` + `关键种与级联预演图` + `巨型生物比例设计表` + `飞行方式-翼设计表` + `生物武器器官系统清单(喷火四件套)` + `驯化遗传账` + `魔力代谢模板` + `共生寄生账本`。

**[检查点]** 生态位无完全重叠(或写清分化维度); 怪物密度符合能量预算(顶级捕食者稀少); 巨型生物过平方立方律; 飞兽定飞行方式(拍翼≤20kg/翱翔数百kg); 喷火兽有四件套; 驯化有多代账; 魔力有代谢代价与上限。

## 第 7 步: 神话原型与一致性总检——先定买单者, 再收全卷

**[输入]** 前六步全部产物 + 宗教/民俗(祭祀/禁忌/历法)+ 历史事件(灾变/改革/征服)。

**[操作]**
1. **建"异兽条目库"**: 用《山海经》公式(位置+状貌+声音+征兆)为每个神话生物写数据库条目, 征兆与叙事/机制后果直接挂钩("见则大旱"→触发旱情事件)——传说即攻略手册(146)。
2. **复合兽设计规则**: 拼装服从"超捕食者"逻辑(叠加顶级捕食者特征+人类形态), 只做 1–2 处 MCI 改动(多首/人身兽首/吐火), 保留"活物"锚点(四肢数/头位大体合理)以维持认知共鸣; 避免全盘乱拼(146)。
3. **原型-货币绑定表("重新买单"落地为机制)**: 给每个神话生物设"生存货币"(信仰/牺牲/禁忌/记忆/恐惧/命名/眼泪)与"法则更替点"(科技/宗教改革/移民/灾变/新神崛起); 展示原型如何换货币续命、变异或退化为考古层残余(146)。
4. **用阈限结构规划地理与叙事**: 把龙/蛇类守卫者放在"门槛"处(边界河/深井/山隘/季节转换点/成年礼现场); 屠龙=穿越阈限的死亡-重生仪式而非纯战斗, 守卫者被击败后"门槛另一侧"的规则应随之改变(146)。
5. **文化功能分层**: 为每个神话生物标注三重功能(禁忌/仪式/教化)及服务的社会层(王权合法性/成年礼/历法/生态管理); 灵/凶按"秩序内外"而非善恶划分, 设计两套互相镜像的对应兽(146)。

**[决策规则]**

## 第 5 步: 米拉斯经典超越

- **精灵→岩鳞族**: 锚点=长寿+慢节奏+记忆型文明; 一次偏离=鳞片光合辅助+红外热感(取代"魔法亲和"成为核心差异); 涟漪推导: 光合→低觅食压力→低竞争性文化→云顶寺隐修气质; 摆脱"优雅魔法精灵"本质主义——岩鳞=务实的档案管理员文明, 内部有记忆派(云顶寺)vs 革新派(潮邦雇佣的岩鳞顾问)之争。
- **矮人/侏儒→无直接对应**: 岩鳞承担"长寿工匠"角色但生态位完全不同(光合+热液而非矿业); 避免"矮人=贪婪"本质主义帽子(矮人式贪婪在米拉斯=岩鳞"百年契约"被短命人类误读为吝啬——贴现率差驱动的误解)。
- **龙→龙骨**(见第 7 步): 以灵脉为食的守护兽, 非"宝库守卫"式恶龙; 屠龙改写为"灵脉暴动时的封印仪式"而非寻宝。
- **兽人→无**: 米拉斯无"好战蛮族"刻板种族(人类内部的风语游牧承担"蛮荒他者"叙事, 且有自己的视角与正名——他者如何看他者)。
- **人形度光谱**: 人类/袋兽=近人(共情区); 岩鳞=近人偏异(鳞片+红外, 仍可共情); 雾裔=异人(面纱+非视觉认知, 认知刷新); 灵脉巨树=异形(群智慧, 无个体自我)。

## 第 6 步: 米拉斯生态位与幻想生物

- **各族生态位维度清单(节选)**: 人类=广适杂食/昼夜皆可/丰饶平原+风语草原/工具代偿(无特殊感官); 袋兽=林栖果食+小兽/昼夜兼有/火链群岛林区/育儿袋=繁殖场所+移动庇护; 岩鳞=岩壁苔藓+热泉微生物/日间光合时段/火山岩壁+热液口/红外热感; 雾裔=雾水+盐藓/雾周期活动/白雾荒漠/湿度觉导航。竞争排斥审查: 袋兽 vs 岩鳞同岛=时间轴(袋兽昼夜兼有/岩鳞日间光合)+空间轴(林区 vs 岩壁)+食物轴(果实小兽 vs 苔藓微生物)三维错开——通过。
- **灵脉巨树生态卡完善**: 能量来源=灵脉营养(根系扎入缝合线灵脉节点, 灵脉→有机物=生态位"基础生产者/能量转换器"); 天敌=灵脉枯竭/血月大潮灵脉暴动(41 年周期=巨树生长节律); 栖息地=龙骨山脉+缝合地峡灵脉节点; 生态位构建=树冠形成微气候、根系稳定灵脉流动("巨树=灵脉的呼吸器官", 与灵脉法则衔接); 树冠城市"叶都"=灵枢城/风语游牧的圣所与议事地; 群智慧候选=根系分布式认知(第 3 步); 能量预算: 巨树=顶级"生产者"体量, 数量=灵脉节点数(稀少、节点级分布)。
- **烬脊火蜥生态卡**: 热液生态(火链群岛热泉口, 化学梯度+灵脉微流供能); 形态-功能: 喷火=器官四件套(腹侧燃料腺+氧化剂储囊+催化酶点火室+耐火鳞衬里), 类比投弹甲虫分室储存防自燃; 冷却间隔+进食代价(喷火消耗灵脉储备, 施法后需热泉补充); 能量预算: 热泉口顶级捕食者→每热液区 1–2 只、领地=热泉流域(密度符合 M^-0.75 定律)。
- **雾盐蝶生态卡**: 雾水收集(翅面凝雾+盐晶析出=盐分循环); 生态位=雾水-盐分循环的关键种(雾盐蝶聚集地=盐田, 与雾盐邦盐本位经济衔接); 天敌=晴期鸟类(雾日安全=雾盐蝶择雾迁飞); 繁殖=雾季同步羽化(雾历=繁殖日历); 驯化账: 雾盐邦驯养雾盐蝶=多代选育温顺+翅盐量(神经嵴式连锁: 温顺蝶翅盐晶减少=驯化综合征的米拉斯版, 与雾盐邦盐业博弈)。

## 第 7 步: 米拉斯神话原型与一致性总检

- **龙骨"重新买单"**: 龙骨=灵脉守护兽, 以灵脉为食, 数量稀少=灵脉状态指示。买单史: 远古(灵脉丰沛期)=凶兽/吞噬者(山海经式条目: "龙骨现于龙骨山脉, 其鸣如地裂, 见则灵脉暴动")→ 三次灵脉战争时期=灾厄之兽(征兆编码入血月历法: 龙骨活跃=大潮年凶兆)→ 灵权革命后=祥瑞/守护神(灵枢城教义收编: "龙骨守护灵脉=灵脉正统"神学背书, 龙骨=祭司权威的活图腾); 新买单者=灵枢城神权(以灵脉税/祭礼供养龙骨传说); 若灵脉枯竭→龙骨退化为考古层传说(留白=世界观历史层)。阈限结构: 龙骨栖息地=龙骨山脉灵脉节点=南北陆桥门槛, "过龙骨山脉"=成年礼与商队仪式, 屠龙改写为"封印仪式"=穿越阈限的死亡-重生。
- **灵脉圣兽(复合兽规则)**: 龙骨=蛇身+龙鳞+发光灵脉纹(超捕食者特征叠加), 仅 1–2 处 MCI 改动(发光灵脉纹+地鸣), 保留四足/头位"活物"锚点; 四灵四凶式镜像: 灵脉暴动对应兽=「血月蚀兽」(龙骨的反像, 大潮年"失序"征兆)——灵/凶=秩序内外而非善恶。
- **雾盐蝶传说**: 雾裔传说"雾盐蝶引路"(蝶群迁徙路线=雾季预报与盐田选址的生态记录, 传说=前科学预警系统); 白雾荒漠边界=门槛, 雾盐蝶=守门者(引路人/迷途者双重形象); "见则雾至"=征兆-机制挂钩(蝶群聚集=雾锋临近, 触发商队行程变更)。
- **一致性总检(八项抽查)**: ①五卡互引——岩鳞族文化卡"记忆型文明"回溯至推导链卡(300 年寿命→低贴现), 再落到法则层(灵脉亲和=低代谢能量来源)✓; ②推导链落到法则层——灵脉巨树营养卡=灵脉法则推论, 无孤儿设定✓; ③生态卡五问——灵脉巨树/烬脊火蜥/雾盐蝶全答(能量来源/天敌/栖息地/生态位构建/竞争错开)✓; ④竞争排斥——袋兽 vs 岩鳞三维错开, 四族无重叠✓; ⑤文化含内部变体——人类四政体/岩鳞记忆派-革新派/袋兽各部落✓; ⑥五层双向验证——雾裔"面纱禁忌"可沿"雾水代谢→视觉退化→盲区禁忌"正向推导, 也可反向验证✓; ⑦五大错误——无人类换皮(雾裔感知通道、岩鳞生命周期均根本不同)/无一帽(各族多文化)/无无推导链/无无生态位生物/种族≠国家(人类多国)✓; ⑧谱系可追溯——异源独立+隔离史(火链群岛隔离演化)+返祖机制✓。retcon 政策: 混血规则/龙骨神话修订以作者注登记。

# 第三部分: 一致性总检清单(种族篇)

**基础层**(第 0-1 步):
- [ ] 依赖链单向: 行星参数→生物群系→法则→物种→文明, 层间只传参数表, 例外显式"世界观例外声明";
- [ ] 五卡档案齐备(生理/生态/推导链/谱系/文化), 互相引用, 无来源的特征不允许存在;
- [ ] 生命判据四要素明确(溶剂/信息/代谢/边界), 与世界法则(灵脉/灵魂)有明确定义接口;
- [ ] 生态位先于形态: 每个物种先填生态位矩阵再填形态, 无生态位的装饰性怪兽已删除或补全;
- [ ] 代价守恒: 每族至少一项优势配一项劣势(高智力↔长幼态期, 长寿↔低繁殖), 体型过平方立方律;
- [ ] 人类换皮检验通过: 至少改动感知通道/繁殖方式/生命周期/认知模块之一, 且改动在文化卡上产生可见涟漪;
- [ ] 深时纪年存在: 生命起源→地质事件→文明史有时间轴, 无"先画龙后画风"式返工。

**推导链层**(第 1-2 步):
- [ ] 推导链每环写"因为…所以…"并标注硬/软约束, 写不出理由的条目已删改;
- [ ] 可逆性审计: 每个文化特征能回溯到生理或环境约束, 回溯不到的"文化漂变"项全族≤1–2;
- [ ] 感官清单两表齐备(能力参数+盲区), 盲区反推禁忌(无视觉→看不见之物神圣化, 红外→体温即隐私);
- [ ] 主导感官决定艺术/圣物/禁忌/司法证据(口耳文化 vs 目读文化各有映射);
- [ ] 代际数时钟: 寿命÷成熟年龄=代际数, 技术节奏与代际数挂钩(长寿族慢创新高深度, 短寿族快速试错);
- [ ] 寿命权衡: 无"永生且多子且强壮"; 永生/长寿命配低生育、长童年、高投入或休眠等机制;
- [ ] 繁殖模式决定社会骨架(母系/父系/克隆/群繁殖→亲属/分工/婚制), "家庭长什么样"由"怎么生孩子"导出;
- [ ] 死亡观念从寿命导出(短命日常化/长命系谱记忆/永生禁忌化), 死亡突显塑造文化强度。

**谱系层**(第 3 步):
- [ ] 演化树: 每族标注共同祖先/分化时间(纪元或代际锚定)/姊妹类群, 无"所有人形祖先却无分化机制";
- [ ] 谱系四模式注记(同源分化/异源独立/收养追认/堕变造物), 至少使用两种打破"万物同源"平庸;
- [ ] 适应辐射有前提: 祖种+空生态位(大灭绝/魔潮之后)+环境梯度+特征对应生态位而非装饰;
- [ ] 混血规则服从生殖隔离梯度(同源且隔离不完整才可育), 非全有全无;
- [ ] 退化返祖写成机制: 衰落=多罗法则不可逆, 返祖=休眠基因重新表达, 非常识性"变强";
- [ ] 谱系表自带政治性(被追认的收养祖先/被抹除的旁支/神话与考古祖先错位), 家谱可伪造可焚毁;
- [ ] 智慧坐标(个体-集体/内嵌-抽象/技术-非技术/文化累积四轴)各族互不相同且与寿命/社会结构耦合;
- [ ] 群智慧有机制说明书(正反馈+负反馈+法定人数阈值), 非"心灵感应魔咒";
- [ ] 意识判定法明确(IIT/GWT 等选一)并用指标而非人形特征判定"谁有意识", 设意识税。

**文化层**(第 4-5 步):
- [ ] 三轴正交(表型/文化/政治): 主动构造同族多国/一国多族/跨族共享文化, 无"一民族一国家"未解释;
- [ ] 每族≥2–3 个互异文化+内部张力轴, 至少一个张力轴可由生态卡推导;
- [ ] 种族分类法出自政权/法典/户口并有可见后果(纳税/通婚/兵役/选举), 非作者旁白;
- [ ] 承袭规则有冲突引擎(不同法域规则冲突, 同一角色跨法域身份改变);
- [ ] 混血身份政治: 杂合性/克里奥尔化视角, 混血角色有可选与强加双重身份;
- [ ] 接触地带: 贸易港/皮钦语/混血社区, 不可译概念(时间/祖先/荣耀/罪)驱动剧情, 无万能翻译机;
- [ ] 歧视结构化: 居住区划/职业限制/法律定义等制度载体, 种族与阶级/性别/宗教交叉;
- [ ] 经典锚点句成立(每族 1–2 个可瞬间识别特征), "一次偏离+涟漪效应"有推导链记录;
- [ ] 内部多样性制度化(≥3 文化群/政治派系/历史分期+1 反类型亚文化);
- [ ] 人形度光谱定位明确(近人=共情/异形=认知刷新), 无"全员人穿皮套";
- [ ] 本质主义自检通过: 无全族单一价值观, 能力差异有环境/文化解释而非"天生"。

**生物层**(第 6-7 步):
- [ ] 生态位维度清单(8–12 维, 标基础位/实现位), 两个物种所有维度重叠者已写分化维度或合并;
- [ ] 能量预算硬约束怪物密度: 按约 10% 传递效率反推各营养级生物量, 顶级捕食者稀少(密度∝M^-0.75);
- [ ] 岛屿生物地理学设计多样性梯度(S=cA^z): 大陆/小岛/群岛物种数与特有种比例符合面积-隔离度;
- [ ] 营养级联与关键种有叙事用途(移除关键种引发可见连锁崩塌, 食物网箭头图已预演);
- [ ] 巨型生物过平方立方律(异速生长: 柱状腿/气骨化/散热器官), 或设为变温/巨温性;
- [ ] 飞行生物定飞行方式(拍翼≤20kg/翱翔数百kg), 魔法悬浮明确"魔法提供升力而非肌肉功率";
- [ ] 生物武器化=完整器官系统(喷火四件套: 燃料腺+氧化剂+点火器+热防护), 有冷却间隔与进食代价;
- [ ] 驯化写多代遗传账(神经嵴连锁性状同时出现, 世代数/退野化风险/改造硬代价明确);
- [ ] 魔力=生物能量学: 代谢代价/储存上限/废热排废/过载损伤, 无"无限魔力";
- [ ] 共生寄生有账本(互利点/成本/宿主免疫平衡/抗性个体军备竞赛);
- [ ] 异兽条目库用山海经公式(位置+状貌+声音+征兆), 征兆与叙事/机制后果直接挂钩;
- [ ] 复合兽 MCI 改动≤2 处且保留活物锚点, 拼装服从超捕食者逻辑;
- [ ] 每个神话原型有"买单者"(生存货币+法则更替点)或显式留白, "重新买单"已落地为机制;
- [ ] 阈限结构: 守卫者位于门槛(边界河/深井/山隘/季节/成年礼), 击败后"门槛另一侧"规则改变;
- [ ] 传说=生态记录可互证(物候/水文/灾害史以传说编码, 角色可从传说反推环境事实);
- [ ] 五大错误为零: 人类换皮/全族一帽/无推导链/生物无生态位/种族即国家;
- [ ] 孤儿设定清零, retcon 政策公开(重大改动以作者注声明);
- [ ] 与各篇衔接: 灵脉亲和↔法则篇, 雾裔雾水代谢↔地理篇白雾荒漠, 岩鳞云顶寺↔文明篇, 叶都↔文明篇, 雾盐蝶盐田↔经济篇盐本位, 灵纹↔技术/语言篇, 血月纪↔历史篇节拍器, 银泪生物灵魂神学争议↔宇宙篇, 禁咒公约↔军事篇。
