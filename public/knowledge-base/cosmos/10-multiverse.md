# 多元宇宙拓扑

> 目的: 为世界决定多元宇宙的"形状"——先选拓扑主轴,再配隔离机制,让拓扑决定权力结构与冲突类型,并把本体论声明写进设定书。
> 前置: 与位面旅行(08)、世界间旅行(11)、宇宙构建方法论(13)互相咬合;隔离机制与旅行代价必须统一解释。

## 核心理论: 多元宇宙的形状 = 拓扑 + 隔离 + 本体论

- **拓扑三轴说**: 多元宇宙的形状可归为三种基本拓扑,可混合嵌套——
  - **并列型**: 各世界是同一层级上的"相邻"实体,靠空间或介质隔开;代表结构: 晶壁系包裹太阳系+虚空介质、气泡宇宙群、邻接的平行世界;
  - **层级型**: 世界按高/低排列,存在上升/下降通道;代表结构: 世界树九界、飞升链(下界→上界→神界)。核心隐喻"位置即身份": 上层俯瞰下层,跨越需代价与资格;
  - **分支型**: 世界因选择/事件不断分岔,同源而异流;代表结构: 量子多世界、危机/假如式时间线。分支在分裂点之后**永不重聚**,除非引入元规则(时间缝合);
  - 三者不互斥: 层级型可嵌套在并列型之内,分支型可发生在某个并列世界内部——但每多一层就多一套规则,建议主用不超过两轴。
- **隔离机制五类**(回答"为何不同世界不互相吞噬"):
  1. **物理屏障**: 晶壁包裹世界,虚空介质内魔法/时间失效;
  2. **维度壁垒**: 高维与低维不存在共享截面,无法直接接触;
  3. **退相干**: 量子分支因与环境纠缠"冻结"为互不干涉的经典世界——多世界"看不见彼此"的物理原因;
  4. **界膜/空间拓扑**: 膜宇宙在额外维中相隔,仅在碰撞时产生信号;
  5. **神律禁令**: 世界自身法则禁止跨世界干扰(天道压制/监管实体)——最强的隔离是"规则本身不允许"。
- **本体论三派**(决定读者对穿越后果的预期):
  - **全实在论**: 所有可能世界同样真实,彼此时空隔离、无因果联系;"现实"只是索引词——每个世界的居民都认为自己是现实的;
  - **量子分支论**: 波函数整体为真实,分支是同一实在的相对态,无跨世界空间通道,分支间永久失联——隔离是本体论自带的;
  - **可打破的物理隔离**: 暴胀场不断成核气泡宇宙,泡间被暴胀空间隔开,碰撞罕见但理论上存在——隔离可被物理打破,需"守恒律/能标"兜底。
- **四级分类(分析工具)**: ①同暴胀泡内遥远区域 ②不同物理常数的气泡 ③量子分支 ④所有数学结构。四级彼此嵌套——先定层级,再定并列,再定分支。
- **拓扑决定权力结构与冲突类型**: 层级型产出"向上飞升、向下放逐"的权力叙事(资源与法则逐层升级);并列型产出贸易、殖民、战争与外交(跨世界组织);分支型产出身份与命运主题(另一个我、悔恨、时间缝合)。三个主题都想要?用嵌套让它们各占一层。

## 经典体系拆解

| 体系 | 拓扑主轴 | 隔离机制 | 合法渡桥 | 破口 |
|---|---|---|---|---|
| 晶壁系 | 并列 | 物理屏障(晶壁+虚空介质) | 魔法船穿越 | 星界冥想可抵达 |
| 世界树九界 | 层级 | 神律禁令(资格) | 彩虹桥(受控通道) | 树根暗路/坠落 |
| 飞升链 | 层级+神律 | 天道压制(向下禁止) | 渡劫飞升(向上单向) | 大能违规下界 |
| 多世界分支 | 分支 | 退相干(物理) | 无(本体论失联) | 元规则缝合/跳线 |
| 邻接平行世界 | 并列 | 自然屏障 | 薄弱处窗口(天象) | 破口神器(切任何表面) |

**破口=可讲的穿越故事的窗口数**: 建议全作限定2–4个破口,且每个破口有代价(寿命、记忆、身份);破口工具即最高级剧情道具。**元事件(隔离被打破→大事件→新拓扑)**是多元宇宙剧情闭环的标准范式: 合并/重启后,幸存者记忆成为新的矛盾源。

## 构建操作

1. 先写一句"拓扑宣言": "并列为主的世界群,每个世界内嵌三层位面(层级),时间线不分支"——单轴起步,确认必要后再加第二轴,每层规则单独成档;
2. 给每个隔离机制配一个"合法渡桥"(彩虹桥/魔法船/渡劫)和一个"破口"(薄弱点/禁术/神器),破口总数限定2–4个并各配代价;
3. 让拓扑决定冲突类型: 层级型写飞升与放逐,并列型写跨世界贸易与战争,分支型写身份与命运——先定冲突再补细节;
4. 写本体论声明三问: ①各世界是否同等真实; ②穿越是否守恒(记忆/能力/死亡/时间流速跨世界是否有效); ③谁认为自己是主世界——三问决定读者对穿越后果的预期;
5. 给"为何不互相吞噬"一个统一原理而非零散禁令: "晶壁即法则边界""维度差使接触面无界面积为零""天道即守恒律的拟人化"——统一原理让隔离显得必然而非人为;
6. 元事件必须解释"隔离如何被打破": 吞噬者/撕裂者/合并仪式+后果(重启/合并/幸存者记忆),否则事件显得廉价;
7. 控制可见范围: 展示3–7个有名字的世界,其余以传闻/图谱存在;每展示一个新世界回答"它为何重要、它与己方世界有何隔离差异";
8. 为穿越者立"跨世界法则小册子": 固定4–6条硬规则(传送必经渡桥/携物有限/异界魔力衰减/死者在异界无意义),让读者能预判穿越情节。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 单一拓扑到底,层次单薄 | 主用≤两轴,用嵌套让并列/层级/分支各占一层 |
| 隔离机制零散无原理 | 给"不互相吞噬"一个统一原理(法则边界/维度差/天道=守恒律) |
| 隔离无破口,故事无门 | 每隔离配渡桥+破口,破口2–4个且各配代价 |
| 破口无代价,穿越泛滥 | 破口收寿命/记忆/身份,破口数=可讲故事的窗口数 |
| 元事件无机制 | 解释"隔离如何被打破"与后果(重启/合并/幸存者记忆) |
| 世界无限堆砌 | 可见世界3–7个,其余以传闻/图谱存在 |
| 穿越规则混乱 | 立4–6条硬规则小册子,让读者能预判 |
| 本体论不声明 | 答三问: 是否同等真实/穿越是否守恒/谁是主世界 |

## 检查点/清单

- [ ] 拓扑与冲突类型匹配(层级→飞升/并列→贸易/分支→身份)?
- [ ] 本体论三问已答并写进设定书?
- [ ] "不互相吞噬"有统一原理?
- [ ] 元事件的破隔离机制与后果已定义?
- [ ] 可见世界3–7个,其余以传闻/图谱存在?
- [ ] 跨世界法则小册子4–6条硬规则,无自相矛盾?
