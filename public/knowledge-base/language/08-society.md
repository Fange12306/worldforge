# 语言与社会分层

> 目的: 让"谁说什么话、在什么场合说、为什么说"成为世界的社会制度与剧情引擎——语言不是背景噪音, 而是阶层、身份、权力与存亡的精确坐标。
> 前置: 语言档案(音系/词汇/谱系, 见方法论篇)与文明篇(阶级/族群/政体)双向咬合。

## 核心理论/机制要点

**有序异质与显/隐性声望**
- 语言并非均质: 同一言语社区内, 同一语言变量的发音随社会阶层与语体系统性变化——"有序异质"。
- 显性声望: 标准变体获学校、媒体、政府背书, 公开可谈, 是向上流动的语言资本; 隐性声望: 非标准变体在特定群体内部因"接地气、够硬核、有团结感"被暗中青睐, 标记本地身份与群体归属。

| 维度 | 显性声望 | 隐性声望 |
|---|---|---|
| 来源 | 机构背书(学校/媒体/政府) | 群体内部默契(团结感/硬核感) |
| 形态 | 标准变体 | 非标准变体、土话 |
| 功能 | 向上流动资本 | 本地身份标记 |
| 谈论方式 | 公开可谈 | 口是心非、暗中青睐 |

- 语体移动: 说话人随正式度在连续轴上滑动——随意谈话 < 正式谈话 < 朗读 < 词表 < 最小对立对; 越正式越趋标准。
- 变化方向: "自上而下"是有意识采纳上层标准形式; "自下而上"在意识阈下由隐性声望驱动, 是新音变的温床。
- 过度纠正: 中间阶层在正式语体中反而超出上层地滥用标准变体——社会流动焦虑的语言指纹。

**方言连续体与"语言还是方言"**
- 相邻方言逐村渐变、互相可懂, 相距越远差异越大; 连续体本身无天然分界, 分界是政治-教育裁决的产物。
- 双标准裁决: "距离型"语言靠与邻语互不可懂自成一体; "扩建型"语言靠标准化工程(统一拼写、文学传统、承担国家功能)人为拉开界限; 反之, 政治合一可以把独立语言降为"方言"。
- 屋顶语言: 一种标准语"罩住"多个低变体, 低变体在其下自生自灭。
- 定义权在政治与军队: "语言就是拥有陆军和海军的方言"。

**双言制与多言制**
- 同一社区内高变体 H 与低变体 L 并存且功能严格分工; 无人把 H 当作自然习得的母语。

| 特征 | 高变体 H | 低变体 L |
|---|---|---|
| 领域 | 书面/宗教/法律/教育/正式场合 | 口语/家庭/市场/日常 |
| 习得 | 靠学校(非母语习得) | 家庭自然习得 |
| 形态 | 高度标准化、语法更复杂 | 少标准化 |
| 声望 | 高 | 低 |

- 双言格局可稳定数百年; 典型配置: 标准书面语 vs 各方言、仿古书面语 vs 民话、外族书面语 vs 本地口语。
- 双言×双语四格: ①双言+双语(同一批人按域换码) ②双言无双语(两个单语群体分层, 各说各的) ③双语无双言(移民过渡态, 易发生语言更替) ④两者皆无。
- 多言制: 一个社会可同时有多个高变体(行政语/族内通用语/宗教语)与多个低变体(各地方言), 按族群与域分配——域表越复杂, 社会分层越精细。

**域分析与语码转换**
- 核心提问: 谁、在何时、对谁、说什么语言?
- 域: 家庭/友谊/宗教/教育/职场/政府/市场, 每个域默认绑定一种变体; 换域即换码, 构成"语码选择"制度。
- 语码转换是有意义的社会行为: 拉近距离、摆身份、表忠诚、翻脸。
- 域是语言更替的观测点: 当低变体的域逐一失守给高变体, 语言走向死亡。

**语言与身份认同**
- 族裔: 语言是族裔象征的"图腾", 认同与语言选择互为因果。
- 阶级: 阶层越高越趋标准变体; 男性自评常虚报"更土"——隐性声望的镜像证据。
- 性别悖论: 女性既更守标准(稳定变体), 又常领跑新音变(自下而上变化), 是变化的两面先锋。
- 身份即行为: 每次选词都是一次身份声明; 亚文化群体用音变标记归属(如"体制派 vs 反叛者")。

**语言灭绝与复兴**
- 死亡机制: 语言更替(域逐一失守)、语言屠杀(政策性消灭)、语言自杀(世代拒绝传承); 城市化与教育/媒体是最大杀手。
- 活力六级: 安全→脆弱→明确濒危→严重濒危→极危→灭绝。
- 八级梯度: 仅剩老人→家庭代际传承(关键临界点)→学校识字→职场→政府/高等教育/全国媒体; 复兴必须自下而上逐级爬。
- 复兴工具箱: 语言巢(祖辈对幼儿全程沉浸)、浸入式学校、成人"新说话人"、正字法与语料建设、媒体与教育立法。
- 经验知识: 全面复活的"死语"依赖极端社会动员; "语言巢+官方地位+媒体"三件套被反复验证有效。

## 构建操作

1. 先为每种语言/变体画"域表": 仿域分析, 为宫廷语、教会语、商路通用语、市井方言各列一张"域×场合"矩阵(宗教/法律/教育/家庭/市场), 写明哪些场合"绝对禁用"哪种话——双言社会最便宜的仪式感与权力感来源;
2. 再沿地形画方言连续体与等语线: 沿山脉、河流、古国边界布置渐变音变(如 r 化、元音央化), 让相邻村庄"听得懂但口音怪", 让政治边界把连续体一刀切成"语言", 地图上标出方言岛;
3. 设计"语言政治裁决"冲突: 帝国推广标准语、地方抵抗; 让一个民族用"我们有军队、有王"的逻辑为自己的话正名; 把标准化四步(选标准→定规范→扩功能→获接受)写成国策时间线, 制造改革与反改革剧情;
4. 用显/隐性声望刻画角色: 贵族说标准语, 下层用土话, 中间阶层正式场合"过度纠正"、私下又"降格"; 让角色的语体移动暴露其社会野心或乡愁;
5. 设计性别与代际音变: 让女性角色既守标准又领跑新音变; 让"身份音标"成为代际冲突点——父辈坚守土音, 子辈为进城而抛弃;
6. 为濒危语言标活力级数(还剩几代母语者?)与死因(禁语令/城市化/通婚/识字教育), 再写复兴运动(语言巢、浸入学校、文字改革、媒体节目), 让"救语言"成为故事引擎;
7. 把语码转换写成剧情信号: 谈判中角色从高变体切到低变体表示翻脸、拉拢或暴露出身; 让"谁先开口说哪种话"成为宫廷礼仪与外交信号;
8. 用身份冲突收尾: 混血/移民角色在族裔语与通用语间撕裂, 用"身份即行为"设计其每次选择的后果; "会说不会写"的学者、"只会读不会说"的祭司都是现成阶层细节。

## 检查点/清单

- [ ] 域表: 每种语言/变体都有"域×场合"矩阵? 哪些场合禁用哪种话已写明?
- [ ] 连续体: 方言差异沿地形渐变, 政治边界是"语言/方言"裁决的唯一理由?
- [ ] 声望: 每对高低变体标明了显性/隐性声望来源与受益群体?
- [ ] 语体移动: 至少一个场景用"正式度滑动"暴露角色阶层或野心?
- [ ] 过度纠正: 中间阶层/新贵在正式场合有可识别的过度标准行为?
- [ ] 双言/多言: H/L 分工明确, 无人以 H 为母语? 多高变体社会已按族群/域分配?
- [ ] 语码转换: "换码"被用作身份、情绪或权力信号, 而非随机混用?
- [ ] 濒危语言: 每门濒危语言标注了活力级数、死因与剩余代际数?
- [ ] 复兴路径: 复兴剧情遵循"自下而上"(家庭→学校→媒体→行政)而非空降?
- [ ] 身份一致: 角色语言选择与其阶级、族裔、代际立场自洽?
