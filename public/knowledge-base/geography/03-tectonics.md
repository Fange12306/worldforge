# 板块构造与宏观海陆分布

> "先画板块, 再长大陆"——大陆与海洋的宏观分布由板块构造决定。这是流程的第 4~5 步。

## 核心理论

- **大陆漂移说**: 泛大陆(Pangaea)裂解漂移。证据: 海岸线吻合、跨洋古生物化石、古气候标志。
- **海底扩张说**: 洋中脊生成新洋壳、对称扩张; 磁异常条带证实。
- **板块构造说**: 岩石圈分刚性板块在软流圈上运动; 边界三类——离散(洋中脊/裂谷)、汇聚(俯冲/碰撞)、转换(走滑)。大陆地壳厚(~35–40 km)且轻, 永不俯冲; 洋壳薄(~7 km)且重, 终将闭合。
- **威尔逊旋回**: 裂谷→幼年洋→成熟大洋→俯冲收缩→残余洋盆→碰撞造山→缝合线。完整旋回约 3–6 亿年。
- **超大陆循环**: 哥伦比亚/努纳(~18 亿年前)→罗迪尼亚(~10 亿年前)→泛大陆(~3 亿年前)→未来(~2–2.5 亿年后), 周期 4–7 亿年。

## 机制与参数

- **驱动力**: 俯冲板片拉力(slab pull)主导(~90%); 其次洋脊推力与地幔对流。俯冲带是构造的"引擎"。
- **板块运动速率**: 1–10 cm/yr(大西洋 2–4, 东太平洋海隆 6–16)。
- **洋中脊**: 全球连续约 65,000 km。
- **海沟**: 最深约 11 km(马里亚纳); 俯冲地震沿贝尼奥夫带深达 700 km。
- **火山弧**: 岛弧(洋-洋俯冲, 日本/印尼)与大陆边缘弧(洋-陆俯冲, 安第斯); 位于海沟后 90–300 km; 安山质爆发型。热点(夏威夷链)独立于板块边界, 记录板块运动方向。
- **碰撞造山**: 陆-陆碰撞地壳增厚至 ~70 km(喜马拉雅/青藏, 自 ~50 Ma 缩短 1500–2000 km)。
- **洋壳年龄—深度律**: 洋盆越老越深、越冷(深度 ≈ 2500 + 350·√年龄 m)。

## 构建操作

1. 画 **6~12 块板块**, 标注运动方向与边界类型; 边界必须构成连续网络, 三叉点要稳定。
2. 让大陆从板块中"长出来": 板块内部=克拉通(低平); 汇聚边界=造山带; 离散边界=裂谷或洋中脊; 转换边界=走滑断层谷。
3. 按运动史设计大陆形状: 碰撞处有缝合线与拼图海岸; 裂解处有年轻窄海(红海型); 漂远后为被动边缘宽大陆架。
4. 放置火山: 俯冲带(爆发型)+ 热点(溢流型, 年龄递变链)。
5. 魔法/灵脉资源(如有)挂到构造线上: 古缝合线、裂谷带、俯冲带。

## 边界类型 → 地貌长相

| 边界 | 地貌 | 实例型 |
|---|---|---|
| 碰撞(陆-陆) | 巨型高原+高峻褶皱山 | 喜马拉雅/青藏 |
| 俯冲(洋-陆) | 长条火山链+海沟+海岸山脉 | 安第斯 |
| 俯冲(洋-洋) | 岛弧+弧后盆地 | 日本/印尼 |
| 离散(陆内) | 裂谷: 陡崖+湖链+玄武岩高原 | 东非大裂谷 |
| 离散(洋底) | 洋中脊 | 大西洋中脊 |
| 转换 | 走滑断层谷地 | 圣安地列斯 |

## 海陆分布操作

1. 定海陆比: 70% 海洋≈地球; 50% → 大陆性强、荒漠广布; 85% → 大洋性、温和湿润。
2. 放海洋: 每个洋盆 = 洋中脊 + 两侧深海平原 + 大陆边缘(被动型宽大陆架 / 主动型窄大陆架+海沟)。
3. **用一次"海侵—海退"事件生成海岸细节**(最高效技巧): 设定海平面比现在高 ~100 m 再退去, 批量得到大陆岛、半岛、溺谷海湾、海峡、地峡——互相天然自洽。
4. 按冰期史补充: 高纬峡湾(冰川 U 谷被淹)、冰碛半岛; 低纬浅海珊瑚礁带(限 30° 内、暖水)。
5. 河口放三角洲(按海浪/潮汐强弱选形状)。

## 时间尺度管理

- 板块运动百万年内地貌几无变化, 千万年才显著;
- 剧情需要沧海桑田时, 以威尔逊旋回/超大陆循环为时间骨架, 配合生物隔离演化(裂解→独立演化; 碰撞→物种大交换);
- 熔岩高原(大火成岩省)可在 10⁵–10⁶ 年内快速形成——适合"神祇近古造地"设定。

## 检查点

- 板块边界构成连续网络、无悬空边界;
- 山脉/火山/地震带都在边界或缝合线上;
- 大陆形状与运动史相容;
- 洋盆有年龄梯度(越老越深);
- 每个岛屿可归入四成因(大陆/火山/珊瑚/冲积)。
