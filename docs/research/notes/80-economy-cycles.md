# 笔记 80: 经济周期与人口动态(economy-cycles)

> 研究主题: 经济周期与人口动态。

---


## 核心理论

**1. 马尔萨斯陷阱 (Malthusian Trap)**
人口按几何级数增长、食物按算术级数增长，人均收入总被人口增长拉回生存线 (subsistence equilibrium)。两类抑制:积极抑制 (positive checks:饥荒、瘟疫、战争) 与预防性抑制 (preventive checks:晚婚、独身、禁欲)。现代形式化:人口-技术正反馈 (Kremer) 与统一增长理论 (Unified Growth Theory) 认为 1800 年前人类长期困于陷阱,任何技术进步先被人口稀释。波斯坦 (Postan) 的"新马尔萨斯"中世纪模型:人口↑ → 耕地扩张至边际土地 → 人均产出↓ → 实际工资↓ → 死亡率↑,负反馈闭合成环。

**2. 丰歉-价格放大机制 (粮食需求弹性, Munro)**
谷物是生存必需品,短期需求价格弹性极低:歉收 10% 可致价格翻倍乃至数倍上涨,即供给小波动 → 价格大波动 (amplification)。这解释了中世纪"dearth"机制:危机未必是绝对短缺,而是低弹性把短缺放大为价格灾难。低弹性 + 存储不足 + 市场分割,导致丰年"谷贱伤农"、灾年"米贵如珠"的交替伤害。

**3. 价格革命与货币数量论 (Price Revolution, MV=PT)**
16 世纪新大陆白银 (波托西 1545、萨卡特卡斯 1546 开矿) 大量流入,欧洲物价百年涨 4~6 倍。萨拉曼卡学派阿兹皮尔库埃塔 (1556) 最早表述货币数量论;博丹 (Bodin, 1568) 在与马莱斯特罗伊特 (Malestroit) 的论战中把通胀归于白银流入而非铸币贬值。费雪方程 MV=PT 为其现代形式。反向案例:15 世纪"铸币荒" (bullion famine, Munro/John Day)——货币收缩导致长期通缩与商业危机。

**4. 康德拉季耶夫长波与熊彼特创新集群**
康德拉季耶夫 (1925) 用价格、利率等长序列识别 40~60 年长波;熊彼特 (1939《商业周期》) 将长波归因于创新集群 (swarming):基础创新出现后企业家蜂拥模仿,信贷扩张驱动繁荣,随后是过剩消化与清算,即创造性破坏。佩雷斯 (Perez) 补充"技术-经济范式":每次技术革命分安装期 (金融泡沫、基础设施狂热) 与部署期 (制度协同、全面扩散)。

**5. 铸币贬值螺旋与格雷欣法则 (Debasement Spiral, Gresham's Law)**
君主财政危机 → 降低铸币成色/重量套取铸币税 → 物价上涨、实际铸币税收入反而下降 → 再度贬值,形成螺旋。格雷欣法则:法定比价下"劣币驱逐良币"——成色足的旧币被窖藏、熔毁或出口,劣币充斥流通。循环终点是货币体系崩溃或"重铸" (recoinage) 改革。

**6. 人口冲击的经济结构改写 (Black Death)**
1348-1350 黑死病使欧洲人口减 30~50%。劳动力骤缺 → 实际工资上涨,工资-地租剪刀差反转 → 地主收入下降、谷物价相对工资下跌 → 农业转向畜牧与高附加值作物 → 西欧农奴制瓦解 (代役租化)、庄园制衰落 → 人均财富上升、城市工匠与消费需求扩张。国家机器反扑:1351 英国《劳工法令》试图冻结工资,最终失败。

## 机制与案例

- **1315-1317 大饥荒**:连续歉收叠加小冰期气候恶化,英格兰谷物价格涨至常年的 2~8 倍,爱德华二世政府限价、抑价失败——弹性机制与治理失效的典型。
- **黑死病后的英国**:实际工资 (Phelps Brown-Hopkins 序列) 在 1340s-1390s 近乎翻倍;领主转向租佃制;1381 农民起义 (人头税 + 劳工法令) 是人口-地租矛盾的政治爆发。
- **16 世纪价格革命**:白银流入 → 谷物价百年涨 4~6 倍 → 固定地租与封建义务实际缩水 → 商人、自耕农受益,靠固定收入的领主受损,财富再分配推动圈地与社会转型;博丹 1568 年成书即当代解释。
- **亨利八世"大贬值" (1544-1551)**:银币含银量从 92.5% 降至约 25%,铸币税暴利充作军费,物价短期大涨,1550s 重铸恢复成色。英法百年战争期间双方均反复以贬值筹资。
- **瑞典-芬兰 1350-1594 贬值周期**:北欧以长期贬值应付战争开支,证明贬值螺旋是前纸币时代常态化的财政工具。
- **五波康波**:①棉纺/铸铁/蒸汽 (1780s-1840s) ②铁路/钢铁 (1840s-1890s) ③电力/化工 (1890s-1940s) ④汽车/石油/大规模生产 (1940s-1990s) ⑤ICT (1990s-);每波含"狂热-清算-制度化"三阶段。
- **戈德斯通人口-结构模型 (Goldstone)**:人口超载 → 粮价涨、实际工资跌、城市移民、精英竞争加剧、国家财政危机 → 四要素叠加触发国家崩溃/革命,是前工业化政治动荡的统一解释。

## 对虚构世界构建的启示

1. **设定马尔萨斯上限与"逃生阀"**:确定世界的土地产出上限与人口承载力,并明确世界卡在陷阱里(周期性饥荒/瘟疫重置)还是已突破(某类技术革命);给突破设定明确触发条件,这决定整个文明史的基调与时间尺度。
2. **建立丰歉-粮价换算表**:按低需求弹性设计可复用的表格,如歉收 5%→价涨 20%、10%→60%、20%→200%、30%→粮价失控+饥荒;用它推演灾年的物价、租金与工资购买力,让"荒年"成为剧情确定性引擎。
3. **设计人口冲击后的制度反弹**:写一场减员 1/3 的大瘟疫,按真实历史推演:工资上涨 → 当局出台冻结工资法令 → 社会反抗(农民起义)→ 农奴制松动或强化;两种走向取决于统治精英议价能力,可衍生整条阶级冲突线。
4. **用铸币贬值螺旋做"王朝危机"叙事**:国库空虚 → 王室降成色 → 物价飞涨、旧币被窖藏/外流(格雷欣法则)→ 税基再缩 → 要么重铸(改革)要么崩溃(内战);这是可反复使用的政治-经济剧情循环。
5. **制作长波分期表**:把世界史切成 50~80 年的技术纪元,每纪元写明"核心创新-狂热资产(运河/铁路/魔晶反应堆)-清算崩溃-制度化扩散",使每个时代有标志性产业、贫富格局与世界观,读者凭"第几波"即可感知时代气质。
6. **设计"价格革命"式财富再分配**:当世界发现新矿脉/新贸易线,用 2~3 代人的渐进通胀改写社会结构:固定地租与年金缩水、商人崛起、旧贵族衰落——一个无需战争即可完成阶层洗牌的自然机制。
7. **引入戈德斯通四要素崩溃检测**:当一国同时出现"粮价高涨+人口过剩+精英竞争+财政危机"时,标记其进入革命倒计时,为地图提供可预测的政治动荡热区。
8. **把弹性原理写进贸易与存储设定**:市场分割(高运费、差存储)放大地区价差,丰收区"谷贱伤农"、歉收区饿殍遍野;设计跨区套利商队、官方粮仓与投机囤积者,让"粮食政治"成为地缘博弈抓手。
