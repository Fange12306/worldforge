# 死后世界与灵魂位面

> 目的: 为世界设计死后世界——先写价值观宣言,再画地图;把审判做成可玩机制,把灵魂做成经济学,把轮回做成记忆管理系统。
> 前置: 与宗教-合法性(文明篇)、灵魂与魔法(法则篇)、位面体系(08)互相咬合;死后世界的地图必须能倒推回价值判断。

## 核心理论: 死后世界是一份价值观宣言书

- **死后世界=道德宣言**: 死后世界的结构不是随机的"彼岸风景",而是世界观价值观的空间化投影——它回答"这个世界最厌恶什么、最奖赏什么"。地狱的恐怖程度=社会对恶的厌恶烈度,天堂的样貌=社会对至善的想象。**分流标准是一套价值排序的转译**: 称量式看"心的重量",死法式看"如何死",业力式看"因果累积",档案式看"功过记录"。设计死后世界,本质是替虚构世界写一份价值观宣言书。
- **审判是规则的具象化,而非口号**: 成熟体系都有可操作的审判流程——称量(天平)、档案核查(判官+功过簿)、竞技选拔(战死入选)、因果自动分流(业力)。且审判几乎都有**可被操作的空间**(咒语、贿赂、代偿、替身、作弊): 让心脏"不作证"的护符、赎罪券式交易——"死后法律"是戏剧冲突的富矿。
- **灵魂经济学**: 灵魂是稀缺资源——供给(自然死亡/献祭/战争收割)、需求(神国燃料/恶魔口粮/炼金原料)、货币化(赎罪券/纸钱/献祭品=灵魂转移支付)。灵魂被"消耗"的设定(吞噬/碾磨/奴役)决定死后世界的资源底色。
- **转世与记忆**: 轮回系统必须回答"记忆如何处置"。遗忘闸(忘川之水/孟婆汤/中阴投胎)是记忆过滤闸;记忆残留比例决定"觉醒者/天才/宿命通"的存在;灵魂磨损(转世次数越多灵魂越稀薄)为轮回添加熵与恐怖感。
- **宗教与位面互构**: 神国/地狱/炼狱不是孤立地图,而是教义的空间化。炼狱是"时间性中间态"的空间化(生与死之间、罪与赎之间)——"第三空间"的诞生直接催生了鬼魂叙事: 困于未了心愿的幽灵、等待审判的亡魂、代祷赎罪的任务线。
- **冥界镜像现世**: 官僚制地府(泰山→十殿→判官差役→功过簿→孟婆汤)几乎照抄帝国行政体系——死后世界是现世权力的天国翻版,"冥司"即"阴间县政府"。冥界的部门、晋升、贪腐可讽刺/对应/颠覆现世权力。

## 分流标准与审判流程对照

| 模型 | 分流标准 | 审判流程 | 可操作空间 |
|---|---|---|---|
| 称量式 | 心的重量对真理之羽 | 天平称量+记录+怪物吞噬罪重者 | 护符让心"不作证"、背负面告白 |
| 死法式 | 死亡方式而非品性 | 战死者入选英灵,病老者入冥国 | 求战死、改造死法 |
| 业力式 | 因果自动分流 | 无审判官,规则自动运转 | 修业、忏悔、代偿 |
| 档案式 | 功过簿记录 | 判官核查+刑期+投胎 | 贿赂判官、篡改档案、替身 |
| 选择式 | 灵魂自选来生 | 受审→游历→抽签→饮忘川→投胎 | "选择即责任",选错自负 |

**二次死亡是比地狱更深的恐惧**: 被彻底吞噬/湮灭意味着不再有转世、不再被记忆——"彻底湮灭"比永恒受苦更适合做终极威胁。**过渡态(中阴类)不是目的地,而是服务区**: 死后世界可以不是终点,而是通往下一站的中转。

## 构建操作

1. 先写价值观,再画地图: 列表——这个世界最尊崇的3种品质→分别对应哪座死后居所;最憎恶的3种罪→对应哪种惩罚;中庸者→中性滞留区;死后世界每块区域必须能倒推回一条价值判断;
2. 把审判做成可玩/可写的机制: 定流程(谁称量、用什么标准、有无豁免通道),再设计"规则漏洞"(作弊护符式、赎罪券式交易)——漏洞天然生成阴谋与反抗剧情;
3. 建立灵魂经济模型: 定灵魂单位与汇率(1魂=多少能量/货币)、生产者(自然死亡/献祭/战争)、消费者(神域/恶魔/法器)、中间商(祭司/死灵法师/勾魂使者);用"灵魂通胀/短缺"驱动冲突——如献祭维持神国运转的黑暗交易;
4. 设计记忆过滤闸与磨损曲线: 设"忘川/孟婆汤"关卡,规定何种灵魂可带多少记忆投胎(转世天才=残留记忆者);定义灵魂磨损(转世N次后劣化/失忆/疯狂/被回收);留一个漏洞——"漏网的记忆"制造觉醒者与寻回前世之谜;
5. 给中间态留叙事位: 设一个"非终点"空间(炼狱/中阴/滞留平原)——鬼魂故事与救赎弧线的天然温床;任务线: 代祷赎罪、未了心愿、等待审判;
6. 让冥界镜像现世结构: 给冥界设计部门、晋升、贪腐——死者故事即"阴间官场剧",可讽刺、对应或颠覆现世权力;
7. 为角色设计"灵魂故事线": 死亡不是剧情终点而是中转站——死后世界有目标(申诉错判/走私灵魂/赎回记忆/竞选冥王/逃出轮回);"灵魂弧线"(出生-磨损-审判-回归/湮灭)作为与主线并行的成长轨道。

## 记忆过滤闸三档

| 过滤档位 | 投胎记忆残留 | 后果 |
|---|---|---|
| 完全清洗 | 0% | 人人从零开始,前世不可考 |
| 部分残留 | 片段/梦/直觉 | 觉醒者、天才、宿命通、"似曾相识" |
| 完整保留 | 100% | 转世者带前世身份与债务,社会须立法处置 |

**记忆残留比例是全作"觉醒者/天才/宿命通"的生成器**: 残留率越高,社会越要回答"前世罪责是否清算、前世羁绊是否延续"——这是转世社会的核心法律与道德问题。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 先画地图后定价值观 | 先写"最尊崇3品质/最憎恶3罪"表,每块区域倒推价值判断 |
| 审判是口号无流程 | 定"谁称量、什么标准、有无豁免通道"完整流程 |
| 审判完美无漏洞 | 留作弊/交易空间,漏洞即阴谋与反抗剧情 |
| 灵魂无经济属性 | 建单位/汇率/生产者/消费者/中间商,用通胀短缺驱动冲突 |
| 轮回无记忆处理 | 设遗忘闸+磨损曲线,留"漏网记忆"制造觉醒者 |
| 死后世界是终点 | 设中间态(炼狱/中阴),死亡是中转站不是终点 |
| 冥界与现世无关 | 让冥界部门/晋升/贪腐对应或颠覆现世权力 |

## 检查点/清单

- [ ] 死后世界每块区域能倒推回一条价值判断?
- [ ] 审判有完整流程: 谁称量、什么标准、有无豁免通道?
- [ ] 审判存在"规则漏洞",且漏洞能生成剧情?
- [ ] 灵魂经济有单位/汇率/生产者/消费者/中间商?
- [ ] 记忆过滤闸与磨损曲线已定义,并留了"漏网记忆"漏洞?
- [ ] 中间态(炼狱/中阴类)空间存在且承载任务线?
- [ ] 冥界机构与现世权力结构有对应或反差?
- [ ] 每位关键角色有"灵魂故事线"起点(死后目标)?
