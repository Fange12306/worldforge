# 多语世界与语言生态

> 目的: 让整个世界的语言像生态系统一样自洽——语言随地形分布、随贸易扩散、随世代兴亡, 而不是孤立的标签。
> 前置: 地理篇(地形/水系/隔离带)与文明篇(贸易/殖民); 本文产出"语言版图"与"语言生命史"。

## 核心理论/机制要点

**多语社会三类型**

| 类型 | 结构 | 典型格局 |
|---|---|---|
| 并行多语 | 多种语言在统一领土内长期共存、各自独立 | 多语区联邦: 各语区边界稳定 |
| 分层多语 | 高变体 H 与低变体 L 按领域分工 | 书面/宗教/行政用 H, 家庭日常用 L |
| 语码混合 | 双语个体在句间/句内切换 | 双语社会的常态而非异常 |

- 个人双语(能力) vs 社会双语(制度): 有双语无分层 → 语言转用; 有分层无双语 → 稳定社会分层。
- 语码混合机制: 无标记转换遵循默认语言选择; 有标记转换用于表达身份、权威、疏离; 句法框架由"矩阵语言"提供, "嵌入语言"只插入词项; 混合可分插入/交替/融合三类。

**皮钦与克里奥尔**

| 阶段 | 特征 |
|---|---|
| 皮钦 | 无母语者的接触语; 词汇小(数百词)且主要来自强势语言; 语法极度简化(无屈折、固定语序、动词不定式化) |
| 克里奥尔 | 皮钦被下一代当母语习得后词汇与语法急速扩展, 成为完整语言 |

- 三代人可走完"接触→皮钦→克里奥尔→官方语"全程; 简化不是缺陷, 而是特定生态下的正常演化。
- 通用语: 跨族群交际的第二语言, 常见于贸易网络与宗教/行政领域; 不必然简化, 但海上贸易通用语多呈皮钦形态。

**语言生态学**
- 语言与其社会环境、心理环境互动, 类比生物生态; 语言演化是生态条件(接触、隔离、竞争)的函数。

**濒危语言评估**
- 代际破坏梯度: 官方领域使用→…→家庭代际传递(关键临界点)→仅剩几位老者; 复兴必须自下而上逐级爬。
- 评估六因素: 代际传递、使用者绝对数、使用领域、媒体/教育回应、政府态度、文献记录。
- 规模知识: 现存约七千种语言, 约半数濒危, 平均每两周消亡一种——灭绝不是抽象概念, 是有节奏的。

**机制速查表**

| 机制 | 内容 | 剧情用法 |
|---|---|---|
| 语言孤岛 | 地理阻隔(山/海/沼泽)使语言保留古层并独立演变 | 失落王国后裔、古语活化石 |
| 贸易语升级 | 贸易语→民族语→官方语(基础语法+可观比例外来借词) | 港口城市语言史 |
| 洋泾浜 | 强势词汇+本地语法, 词汇仅数百 | 通商口岸市井风味 |
| 海上皮钦 | 动词一律不定式、名词无性数变化 | 多民族港口通用语 |
| 生态-语言并行 | 生物多样性热点≈语言多样性热点(雨林/群岛/山区) | "砍一片森林带走一种语言" |

## 构建操作

1. 先画地形再画语言版图: 语系沿可航河流、海岸走廊扩散, 山脉/海峡/沙漠是天然语界; 平坦平原=低密度大语系, 山地/群岛=高密度小语种(可参考"一岛八百种语言"的密度模型); 每条语界配一个历史事件(战争/迁徙/贸易)使其可解释;
2. 再设计贸易通用语: 选最强势贸易民族的语言为词源基础, 按皮钦规则简化——固定语序、取消屈折、动词一律不定式、词汇量减半, 并设计借词来源比例(如基础语七成+周边语言三成); 让通用语成为"语法最简、词源最杂"的语言, 读者一眼可辨;
3. 用分层多语写权力结构: 给宗教/法律/学术一种高变体语(如教会书面语之于俗语), 家庭日常用低变体语——分工即阶级与社会制度的地图; 可设定"只有祭司能读写高变体语"作为剧情机关;
4. 用语码混合塑造角色: 让角色按场合切换语言——正式场合格律肃穆, 回家切回俗语; 让角色故意用对方语言(或故意不用)成为身份宣言; 双语个体不是例外, 而是常态角色设定;
5. 埋语言孤岛: 在山谷孤村保留一种古语(可作"失落王国后裔"伏笔); 注意隔离语言应比主流更保守、更古, 且受邻近语言词汇渗透;
6. 写濒危语言叙事: 设定 1~2 种仅剩几十位使用者的语言(山中孤村、群岛小岛), 用梯度自下而上设计复兴情节(语言巢→学校→媒体→行政); "最后一位母语者之死"是现成的高张力情节;
7. 给贸易港写语言演化时间线: 一个港口两百年语言史=接触一代造皮钦→下一代母语化变克里奥尔→国家独立后升格官方语; 三代人即可完成全程, 是极经济的背景设定;
8. 用生态-语言并行隐喻深化主题: 把语言多样性热点放在生物多样性热点(雨林/群岛/大裂谷), 用"每砍一片森林带走一种语言"作主题意象; 可设定守护语言的物种或"语言树"设定。

## 检查点/清单

- [ ] 版图: 语言分布与地形(河流扩散/山隔离)自洽, 每条语界有历史事件解释?
- [ ] 密度: 平原低密度/山地群岛高密度的分布与地理匹配?
- [ ] 通用语: 贸易语有词源基础与借词比例, 语法简化规则明确?
- [ ] 分层: 高/低变体分工即社会制度, "只有谁能读写高变体"已设定?
- [ ] 语码混合: 角色换码按场合/身份/情绪有规律, 非随机?
- [ ] 孤岛: 隔离语言更保守更古, 且带邻近语言渗透痕迹?
- [ ] 皮钦时间线: 港口/殖民地的"接触→皮钦→克里奥尔→官方语"各阶段时间戳清晰?
- [ ] 濒危评估: 濒危语言标注了使用者规模、代际传递状况与剩余领域?
- [ ] 生态并行: 语言热点与生物热点(雨林/群岛)重合, 主题意象已用?
- [ ] 生命史: 每门语言的兴衰(扩散/转用/复兴)有生态条件解释, 无无源之水?
