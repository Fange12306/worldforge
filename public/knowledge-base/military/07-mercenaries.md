# 雇佣军、私掠与私有武力

> 目的: 构建"合法暴力可买卖"的世界——军事劳动力市场、委托代理问题、兵变集体谈判、私掠者合法性光谱。

## 核心机制

**1. 暴力去私有化**
- 现代国家对暴力的垄断不是自然进化, 而是有意的政治工程: 近代早期雇佣军、私掠者、军事承包商是战争常态, 国家通过"授权"私人来扩张战争能力。
- 划时代法令把"境外暴力"定罪: 把公民受雇于外国军队、私掠、远征军定为非法, 逼私人武力收归国有。
- 关键洞见: 去私有化是**权威之争**而非效率考量——驱逐私人武力是为了让"谁能合法杀人"只有一个答案。

**2. 军事劳动力市场**
- 把军役视为在市场上买卖的劳动与职业: 士兵是劳动者, 团长是包工头/企业家, 国家是雇主。
- 近代早期没有"国家军队", 只有"军事企业": 君主与承包商签合同, 承包商自筹装备、招人、指挥并自负盈亏。
- 雇佣兵从"叛徒/恶棍"的道德叙事中解放, 还原为理性的职业选择与跨国劳动力流动。

**3. 委托-代理与承诺问题**
- 雇佣关系是一份不完全契约: 雇主付钱买武力却无法监督忠诚; 佣兵首领可诈败、勒索、倒戈甚至篡位。
- 双方都面对承诺问题: 雇主可能欠饷, 佣兵可能不战。缓解机制: 人质、定金、年金、封地、效忠宣誓、分期付款、把佣兵将帅编入本国贵族体系。

**4. 雇佣军两难**
- "佣兵首领若无能则必败, 若能干则必篡位"——雇主欠饷→佣兵首领攻城自立→新王朝是常规路径。
- 君主防御术: 扣押人质、分而治之、重金养闲、以封地与头衔把佣兵将帅"收编"进贵族体系。
- 每个佣兵首领都面对"太无能会被杀, 太能干会被猜忌"的两难——极好的人物弧光。

**5. 反佣兵规范**
- 反雇佣军不是经济学事实, 而是一支道德规范: 核心指控是"佣兵为钱而战、不与雇主同心, 故不配享有国家暴力特权"。
- 该规范划出"士兵"与"杀手"的边界, 也解释了私人军事公司为何总在法律灰区运营; "公民 vs 佣兵"的意识形态对线定义了此后数百年的征兵话语, 该叙事本身就是国家构建的工具。

**6. 兵变 = 集体谈判**
- 职业军"罢工"高度制度化: 欠饷时进入"兵变"状态——士兵选举代表, 占领要塞或城镇, 与雇主谈判补发欠饷与赦免, 谈成复工。
- 机制要点: 兵变=集体议价而非单纯叛乱; 士兵以"不战"为筹码, 国家以补饷+分化(处决首恶、重金收买)应对。
- **支付节奏是纪律的第一变量**: 兵变可能升级为洗劫城市的大惨案。

**7. 私掠者: 国家外包的海上战争**
- 私掠者持政府颁发的"缉拿特许状"攻击敌国商船; 捕获物须经海事法庭判定"合法捕获"后分配, 国王抽成, 船员按股分红。
- 武装商船介于商船与战舰之间; 私掠者与海盗只隔一张委任状——私掠者需合法委任状+法庭判例, 海盗被斥为"全人类的敌人", 二者构成"合法性光谱"。
- 废除私掠的政治运动(在主要大国间)是暴力去私有化的海上里程碑。

**8. 人力出口国模式**
- 山地小国把长枪方阵作为国家出口商品: 各州与外国君主签"服役协定"约定出兵数与军饷; 年金流入本国权贵以买通政治支持——"血钱"成为经济支柱, 也是腐败性制度。
- 制度精髓是**集体谈判**: 州=劳务出口国, 常带"本国人不打本国人""不得用于征服本国盟邦"的条款。
- 小国外交=劳动力定价谈判, 内政=年金分配斗争; 过度依赖佣金导致军事能力被外人购买、自身国家建构被延缓。

## 构建操作

1. 设定"暴力市场化"时代与"去私有化"事件: 世界先存在合法暴力可买卖的阶段(佣兵团、私掠团、军事承包商公开运营), 再设定一部"国家垄断武力"的划时代法令: 谁被定义成"非法暴力"、谁被收编为"国家军队", 将引爆政变、内战与佣兵大迁徙——现成的宏大剧情引擎;
2. 用契约细节构建佣兵团文化: 每份雇佣契约写明兵力、军饷、期限、装备自备、战利品分成与违约条款; 佣兵团是"公司", 有自己的纹章、招募站、后勤商、军需官与"品牌信誉"; 让主角团的每次任务都围绕契约条款的漏洞、履行与再谈判展开;
3. 把兵变写成"集体谈判"而非叛乱: 设计欠饷触发机制: 欠饷→士兵选代表→占领要塞/城市→谈判(补饷+赦免)→复工或转投他人; 兵变期间佣兵团进入"自治共和国"状态(选举、军法、议事会), 是塑造集团政治的绝佳素材; "支付节奏"应成为雇主决策的核心变量;
4. 创建"人力出口国": 设计一个山区小国: 国家垄断征兵、与外国君主签服役协定收年金, 年金同时贿赂本国权贵(腐败即制度); 条款可含"本国人不得互战""不得用于征服本国盟邦";
5. 让"篡位"成为雇佣军的结构性可能: 参考"雇主欠饷→佣兵首领攻城自立→新王朝"的路径; 给君主配成套防御术(扣押人质、分而治之、重金养闲、封地收编); 每个佣兵首领都面对"太无能会被杀, 太能干会被猜忌"的两难;
6. 铺开"武装商船-私掠者-海盗"合法性光谱: 委任状、战利品法庭、捕获分红、保险市场构成一套海上经济; "合法私掠"与"海盗"的边界由文书和法庭认定, 可被政治操纵(栽赃、吊销委任状); 设计一场"废除私掠"的政治运动, 逼旧私掠船队转型为海盗或国家海军;
7. 让军事劳动力市场塑造地理: 战争结束=雇佣军失业=溃兵成匪、移民垦殖或受雇新主; 地图上可出现"佣兵产地"(穷山地)、"佣兵集散市场"(自由市、边境镇)、战争外包的金融中心——劳动力流动本身就是世界观肌理;
8. 设计"忠诚"的多层结构: 佣兵的忠诚对象可拆解为对契约条款、对团长个人、对同袍/故乡、对国家/雇主——不同组合决定行为: 契约型忠诚可被转卖, 个人型忠诚可被篡位利用, 乡谊型忠诚能产生"佣兵不互战"的奇异外交规则。

## 检查点/清单

- [ ] 世界有"暴力市场化"阶段与"去私有化"法令, 其政治后果(政变/内战/佣兵迁徙)已推演;
- [ ] 佣兵团有完整契约文化(兵力/军饷/期限/装备/分成/违约条款);
- [ ] 兵变按集体谈判设计: 触发机制、选举代表、谈判筹码、处置手段俱全;
- [ ] 若有人力出口国, 服役协定+年金+腐败制度已落地;
- [ ] 篡位路径与君主防御术成对设计, 佣兵首领两难(无能必败/能干必篡)成立;
- [ ] 海上合法性光谱(武装商船/私掠者/海盗)有委任状、法庭与分红机制;
- [ ] 军事劳动力流动塑造了地理(佣兵产地/集散市场/金融中心);
- [ ] 忠诚多层结构(契约/个人/乡谊/国家)已拆解, 不同组合产生不同行为。
