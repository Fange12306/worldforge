# 历史体系: 从切片双向推演到完整历史构建 — 完整研究手册

> **目的**: 给定世界法则、地理底图、文明档案与一个"历史切片"(某时间点的世界状态快照), 按本手册合理**前推过去**(补充历史)与**后推未来**(推演历史), 并构建完整自洽的虚构历史体系。
> **范围**: 历史时间、方法论与叙事(与地理/文明篇衔接; 政治文化层在此展开为历史维度)。
> **用法**: 每部分有 [输入] → [操作] → [决策规则] → [输出产物] → [检查点]。12 个主题的详细研究笔记见 `docs/research/notes/`(27-38)。
> **贯穿示例**: 内嵌示例世界「米拉斯」历史篇——给定一个历史切片(血月大祭前 3 年), 双向推演完整历史。

---

# 第一部分: 双向推演执行流程

## 第 0 步: 解剖切片——三层归档

**[输入]** 历史切片 S₀: 某时间点的世界状态快照(人口/边界/制度/技术/文化/宗教/地理痕迹)。

**[操作]**
1. **三层归档**(布罗代尔三时段):
   - **长时段**(结构层): 地理/气候/生态/语言/技术底座——几乎不动, 百年千年计;
   - **中时段**(局势层): 制度/经济周期/人口趋势/王朝相位——数十年计;
   - **短时段**(事件层): 在场的关键事件与人物——数年计。
2. **痕迹层清单**: 切片中的"历史化石"——废墟、地名、习俗、禁忌、世代创伤、纪念建筑、法律条文、语言残留、神话传说。每项都是过去事件的线索。
3. **完整性管理**: 分三栏——已证实(硬事实)/推测(中间层)/空白(有意留白)。记录偏差是特性: 为不同文明设计不同的"史料生产制度"(帝国编年/神职记录/口传史诗/商业账簿)。

**[决策规则]**
- 切片 = "正在发掘的遗址 + 不完整档案"的双重对象;
- 作者所知 / 角色所知 / 记录所述 三者分开管理。

**[输出产物]** `切片解剖档案`(三层归档 + 痕迹层清单 + 完整性三栏)。

---

## 第 1 步: 前推过去(补充之前的历史)

**[输入]** 切片解剖档案。

**[操作]**
1. **痕迹取证**: 对每个痕迹做成因追问——这座废墟因何而毁? 这个地名是哪层语言的残留? 这条边界是战争线还是河川线? 这条禁忌在防什么? 逐层剥出事件, 构建证据链。
2. **倒溯法**(布洛赫): 对切片中每个特征(制度/技术/信仰/地名/人口)问"它需要多久形成": 制度革新与代际记忆约数十年; 技术从发明到普及约 1-3 世纪; 宗教与文明形态约数百年至千年; 地理气候为万年尺度。把所有特征所需时间叠加 = 该切片时代的最低历史深度。
3. **考古式反推**: 给每个重要场所画虚拟 Harris 矩阵(什么先建/什么切割了什么/哪里是重建前的拆除面); 用序列法反推器物风格的"祖先形态"; 用埋藏学反推"被埋的原因"(洪水/火山/战乱/有意平整——每种成因留下不同残迹形态, 让"被埋的原因"本身成为历史事件)。
4. **机制反推**: 沿六条驱动力线(技术/经济/人口/战争/制度文化/地理气候)各写一段"可证伪的过去", 直到触及一个可信的起源点(而非无中生有的创世神话)。
5. **反向链条纪律**: 至少推两级, 直到触及门槛或起源条件, 否则设定不可信。

**[决策规则]**
- 前推 = 解释(亨佩尔覆盖律: 解释与预测对称)——后推出的过去必须解释切片全部细节;
- 结构层面最稳健, 具体事件只能概率化——"结构确定、事件留白";
- 分层时间颗粒度: 越古越模糊(上古只有相对顺序, 中古"约某世纪", 近代才有精确年月)——颗粒度渐细本身是真实史感。

**[输出产物]** `过去证据链`(痕迹→事件→因果链→起源点)+ `前史年表`。

**[检查点]** 每个痕迹都有成因; 特征形成时间与切片深度匹配; 有多条独立证据链交叉"锚定"。

---

## 第 2 步: 后推未来(推演之后的历史)

**[输入]** 切片解剖档案 + 机制库(周期理论/驱动力/反事实)。

**[操作]**
1. **趋势外推**: 把切片中的长期结构(人口/技术/生态)沿时间轴延伸, **必须设定资源上限与饱和点**, 否则线性外推失真。
2. **机制推演**: 以微观机制(人口压力/精英竞争/宗教动员/贸易网络)生成宏观后果——强调"生成过程"而非简单规律套用。
3. **周期叠加**: 识别各周期相位——长波(50-60年)、霸权周期(100-120年)、王朝循环(200-300年)、世俗周期(150-300年)、长时段(百年千年)。**给每个周期标注"当前相位+剩余时长估计"**, 让各周期转折点在时间轴上错开或对齐; 对齐处(长波下降+霸权衰落+精英过剩高峰+王朝末期)是剧变与"史诗时刻"的最佳温床。
4. **反事实分支**: 在切片处做"最小改写"(只改最小因素集合、与已知规律相容), 观察时间线分叉——生成"主线 + 2-3 条支线"; 用反事实评估各因素因果权重(只删除该事件, 分别前推 1 代/5 代/50 代, 差异大→枢纽事件)。
5. **三钟同步**: 短时段(数年: 危机延续/政变/和约)、中时段(数十年: 经济周期/代际更替/王朝循环)、长时段(数百年: 人口结构/气候趋势/文明形态)。**事件层可以突变, 结构层只能渐变。**

**[决策规则]**
- 周期是概率性倾向而非铁律——每次循环被偶发冲击改写; 至少预留一个周期被外力打断的反例;
- 走廊模型: 关键节点后立即进入锁定走廊(短窗内自由度大=写"关键抉择"; 锁定期内惯性强=写"制度压迫与反叛");
- 远未来保留"模糊区": 用趋势+约束描述而非逐事指定(埃文斯克制要求)。

**[输出产物]** `未来候选集`(主线 + 支线 + 各周期相位表)+ `自由度曲线`(每时代)。

**[检查点]** 未来状态能反向"前推"回现在(未来的遗迹要在当前切片里埋下"种子"——双向校验闭环); 趋势外推有饱和点; 每步只改一个变量。

---

## 第 3 步: 对撞检查与缺口补写

**[输入]** 过去证据链 + 未来候选集。

**[操作]**
1. **对撞检查**: 前推出的未来必须能抵达既定后续切片; 后推出的过去必须解释 S₀ 的全部细节; 两端对不上的缺口 = 需要补写的"隐藏历史"。
2. **双向校验闭环**(亨佩尔解释—预测对称): 后推 500 年得到的未来状态, 必须能作为新切片反向"前推"回现在。
3. **周期相位定位**: 用五个问题定位切片——经济处于长波哪段? 世界体系结构如何(核心/边缘/现任霸权/挑战者)? 政权处于王朝第几代(asabiyyah 高低)? 人口结构位置(精英过剩/实际工资/财政健康)? 哪些要素属长时段结构?

**[输出产物]** `隐藏历史补丁` + `双向校验报告`。

**[检查点]** 因果闭合(无悬空事件); 比例感合理(千年无事一朝剧变, 不要每百年都天翻地覆)。

---

## 第 4 步: 分层历史输出(三层年表)

**[输入]** 补全后的历史。

**[操作]**
1. **宏观纪元层**: 用"门槛"(Threshold)切分而非单纯纪年——设定 5-8 个门槛(元素锻造→生命涌现→智慧出现→文字→工业魔法/科技奇点), 每个标注: 前提条件/跃迁内容/新能量流/遗留物。门槛之间是漫长渐变期。
2. **中观朝代层**: 用文明周期律生成朝代序列(赫勒敦四代论 + 图尔钦世俗周期)——开国一代尚武、二代大兴土木、三代奢靡、四代分裂, 新边缘集团入主循环重启。
3. **微观事件层**: 只记录"改变结构者"(休厄尔: 激起持久连锁反应的事件); 日常婚丧留给生活质感层——防止年表沦为流水账。
4. **三套钟标注**: 每层标注驱动机制与被解释现象; 上层快、下层慢; 用下层的慢变化解释上层的重复模式, 用上层的偶发扰动制造下层结构的突变点。

**[输出产物]** `三层年表`(纪元/朝代/事件, 每层标注驱动机制)+ `世界圣经·历史卷`。

**[检查点]** 纪元不随朝代频繁更替; 朝代不随事件而终结; 时间线无悬空。

---

## 第 5 步: 历史叙事与记忆设计

**[输入]** 三层年表。

**[操作]**
1. **叙事一致性而非整齐划一**: 世界内部的历史书写也有情节模式(怀特)——宫廷编年史是"浪漫剧"(英雄奠基), 反叛者秘史是"悲剧/反讽"。**让官方史与民间记忆产生落差**(官方说"大洪水是神罚", 民间歌谣暗示"洪水前有座被毁的城")——落差即叙事张力与探秘入口。
2. **安装记忆机制**(哈布瓦赫/诺拉): 设计记忆的社会框架——谁记住什么、纪念仪式如何框定回忆、孤儿事件(无纪念的事件)如何被遗忘; 设置"记忆之场"(纪念碑/圣物/节日/命名法)并标明其政治用途; 每次改朝换代后史书如何重写、被删者的对抗记忆如何在地下延续。
3. **事件与结构辩证**: 用"创造性事件"(勒华拉杜里)设计转折——选择短时段事件让它穿透长时段结构(杜比《布汶的星期天》模式: 一天之战剖析整个文化)。
4. **因果链质量检验**: 年表中每个重大事件须能回答"为何此时此地发生"(结构条件)与"谁做了什么决定"(行动者), 两者并置; 杜绝"因为神谕所以发生"的跳变——超自然力量本身也须遵守规则。

**[输出产物]** `叙事层档案`(官方史/民间记忆/记忆之场/被遗忘的历史)。

**[检查点]** 官方-民间落差制造张力; 记忆机制随政权更替动态演化; 因果链双层解释并置。

---

## 第 6 步: 一致性总检(历史篇)

**切片层**:
- [ ] 三层归档完整(结构/局势/事件); 痕迹层清单齐全;
- [ ] 完整性三栏明确; 记录偏差是特性(史料生产制度不同)。

**过去层**:
- [ ] 每个痕迹有成因; 特征形成时间与切片深度匹配;
- [ ] 反向链条至少两级; 起源点可信(非无中生有);
- [ ] 多条独立证据链交叉锚定; 时间颗粒度渐细。

**未来层**:
- [ ] 趋势外推有饱和点; 周期相位标注且可错开/对齐;
- [ ] 反事实最小改写; 每步只改一个变量;
- [ ] 三钟同步(事件突变/结构渐变); 远未来保留模糊区;
- [ ] 双向校验闭环(未来遗迹在当前切片埋下种子)。

**年表层**:
- [ ] 因果闭合无悬空事件; 比例感合理;
- [ ] 门槛切分纪元; 周期律生成朝代; 事件只记改变结构者;
- [ ] 三套钟速率正确(纪元不随朝代更替)。

**叙事层**:
- [ ] 官方史与民间记忆有落差; 记忆之场随政权演化;
- [ ] 创造性事件穿透结构; 因果链双层解释(结构+行动者);
- [ ] 超自然机制本身遵守规则。

**反设定病**:
- [ ] just-in-time 构建(只建故事需要的部分);
- [ ] 每段设定标注服务的故事功能;
- [ ] 定期"年表瘦身"(删除不解释任何现状的条目)。

# 第二部分: 贯穿示例(米拉斯历史篇)

> 地理篇: 龙骨山脉(灵脉)/苍原高原/丰饶平原/风语草原/白雾荒漠/北寒原/火链群岛/缝合地峡。
> 文明篇: 灵枢城(神权城邦)/潮邦(航海共和国)/云顶寺(隐修)/风语游牧/雾盐邦/北境遗民; 41 年血月周期。

## 第 0 步: 历史切片 S₀(血月大祭前 3 年)

**长时段**: 灵脉系统(地质结构, 万年尺度); 双月轨道(银月/血月, 血月蚀 41 年周期=天文结构); 龙骨山脉/银海裂谷(地理结构); 灵纹文字(语言底座)。

**中时段**: 灵枢城联盟处于王朝第 3 代(赫勒敦相位: 祭司寄生化、腐化中); 潮邦航运经济处于长波上升期; 风语游牧正因 41 年周期临近而聚集(血月蚀=灵脉爆发=草原丰盛→南下压力); 人口结构: 灵枢城精英过剩(灵脉学院毕业生 > 祭司职位)。

**短时段**: 上一次血月大祭的创伤记忆(41 年前"灵权革命"余波); 云顶寺预言"第三次血月审判"流传; 缝合地峡商路冲突升级。

**痕迹层**: 泪湖群底的沉没古城(传说"潮前之城"); 龙骨山脉的废弃灵脉矿井(禁地); 北寒原冰川下的"上古战场"(冻结兵器); 灵纹文字中的"禁忌音节"(不能拼写的古名); 雾盐湖岸的盐晶碑(已不可读的铭文)。

## 第 1 步: 前推过去(补充历史)

**痕迹取证**:
- 沉没古城 → 海侵事件(8000 年前"银海退却"前的高海面期, 与地理篇海侵事件衔接);
- 废弃灵脉矿井 → 三次"灵脉战争"(灵枢城 vs 云顶寺祖先)的遗迹, 矿井在"灵权革命"后被封印;
- 上古战场 → 冰期时代的文明冲突(与地理篇冰期史衔接), 北境遗民是其后裔;
- 禁忌音节 → 被除名的"第一王朝"之名(灵权革命中失败者的名字被系统性抹除——官方史的删除痕迹);
- 盐晶碑 → 前灵纹时代的原始纪年体系(用盐层记录年份, 已失传)。

**倒溯法时间深度**: 灵纹文字需 1-3 世纪普及 → 灵枢城至少 300 年; 神权城邦联盟形态需数百年 → 联盟起源约 800 年前; 灵脉崇拜需千年沉淀 → 灵教成型于 1000+ 年前; 沉没古城需万年尺度 → 高海面期 8000 年前。**叠加 = 米拉斯文明最低历史深度约 3000 年(从灵纹萌芽到切片)。**

**机制反推**: 灵权革命(800 年前, 卡里斯玛先知挑战祭司垄断→经典定形=**轴心时刻**); 三次灵脉战争(500-300 年前, 灵脉富集区争夺=资源战争); 银海退却(8000 年前, 海侵事件=地理门槛); 冰期上古战场(万年前, 深时历史)。

## 第 2 步: 后推未来(推演历史)

**周期定位**: 灵枢城=王朝第 3 代(腐化相位, asabiyyah 低); 潮邦=长波上升期; 血月蚀 41 年周期=3 年后到点(天文结构节拍器); 精英过剩=革命条件接近(图尔钦); 云顶寺预言=意识形态张力。

**主线推演(最小改写)**: 3 年后血月大祭——灵脉爆发 → 灵枢城祭司预言"审判"应验(或落空) → 分支: ①应验(灵脉异象)→ 祭司权力强化 → 但精英过剩压力仍在 → 10-30 年后"第二次灵权革命"(结构压力释放); ②落空 → 祭司合法性崩塌(神义论失灵)→ 世俗王权/商人势力抬头 → 城邦联盟重组。

**支线**: 潮邦趁灵枢城内乱控制缝合地峡商路(贸易扩张); 风语游牧在血月丰年后南下(赫勒敦边缘-中心动力学); 北境遗民在上古战场发现"前灵纹时代"技术(改变技术基线)。

**三钟同步**: 长时段(灵脉系统/双月轨道不动); 中时段(王朝循环/经济长波推进); 短时段(血月大祭事件)。

## 第 3 步: 对撞检查

- 前推 500 年的未来状态 → 反向前推必须回到切片: 未来的"血月审判纪念碑"要在当前切片埋下种子(云顶寺预言即种子);
- 后推的"灵权革命"解释切片的"禁忌音节"与"废弃矿井";
- 缺口补写: "第三次血月审判"的完整预言文本(隐藏历史)。

## 第 4 步: 分层年表(摘要)

- **纪元层**(门槛): ①元素之始(恒星成形)②生命之潮(第一生命)③灵脉觉醒(灵脉系统形成=世界法则门槛)④智人黎明(集体学习)⑤灵纹纪元(文字=轴心门槛)⑥血月纪元(历法纪年)。
- **朝代层**: 灵枢城六王朝(第一王朝→灵权革命→第二王朝……当前第三王朝末期); 潮邦四执政期; 北境遗民三守备时代。
- **事件层**: 血月蚀 41 年周期事件链; 三次灵脉战争; 灵权革命(轴心时刻); 银海退却(深时)。

## 第 5 步: 叙事与记忆

- **官方史**(灵枢城祭司): 历史=灵脉意志的展开(浪漫剧); 第一王朝被抹除(记忆政治);
- **民间记忆**(潮邦水手歌谣): 暗示"潮前之城"与"沉没的王国"(对抗记忆);
- **记忆之场**: 血月大祭(周期仪式=集体欢腾再激活)、盐晶碑(失传纪年)、禁忌音节(创伤);
- **创造性事件**: 血月大祭 = 让天文结构(41 年周期)穿透社会结构(王朝相位)——一次仪式同时是宗教审判、政治危机与历史转折。

## 第 6 步: 检查 — 全部通过; 历史体系与地理/文明篇完全衔接(海侵事件/冰期/灵脉法则/轴心时刻均复用)。
