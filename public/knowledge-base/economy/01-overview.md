# 经济构建总流程与接口

> 目的: 从 0 到 1 构建一个世界的经济体系——先定底账(粮食与能量), 再定流通(货币与信用), 最后接财政与政体。
> 前置: 地理篇产物(资源/气候/矿脉/河流)与文明篇产物(人口/政体/文化); 与法则篇(魔法)、历史篇(周期)双向咬合。

## 核心立场: 默认"嵌入", 反对"现代主义"

- **经济是社会关系的产物, 不是独立自足的市场**: 前现代经济行为被血缘、宗教、等级、权力塑造; 把"经济人理性最大化"当作普适默认是头号失真。分析任何非市场社会前, 先把它放回社会结构里。
- **三种整合模式是类型而非阶段, 真实社会多为混合**: 互惠(对称群体间礼物往来)、再分配(物品向中心聚敛再下发)、市场交换(价格撮合)。同一世界可并行——部落=互惠、帝国=再分配、商邦=市场。
- **前现代经济天然分三层, 各层"钱从哪来"不同**: 底层物质生活(自给村庄、实物税)、中层市场经济(市集、铸币、行会)、顶层远程贸易(汇票、银行、奢侈品)。三层混为一谈是"金币万能论"的病根。
- **贡赋制是前现代帝国的主流生产方式**: 领主/国家以地租、什一税、徭役、进贡榨取农业剩余, 再以战争、公共工程、宫廷消费再分配; 设计帝国的经济底层逻辑时, 先想贡赋, 再想市场。
- **前现代增长慢且易断**: 增长受人口上限、分工市场范围、能量阀门约束, 且会被战争瘟疫打断——经济危机即历史周期的引擎。

## 总体工作流(先做 X 再做 Y)

```
第 0 步: 地理输入——可耕地/矿脉/河流/气候带/能源(含魔法节点) → 定"资源底账"
   ↓
第 1 步: 粮食总阀门——农业产出与人口上限检验 → 定"能养多少人"
   ↓
第 2 步: 剩余与分工——剩余率 → 脱农人口 → 城市/军队/工匠/学者的规模上限
   ↓
第 3 步: 整合模式配方——给每个政权定主导模式(互惠/再分配/市场)+ 边缘模式
   ↓
第 4 步: 流通三件套——记账单位 / 铸币权 / 信用体系(分开设计, 不可混为一谈)
   ↓
第 5 步: 财政与政体——收入结构(地租/什一税/关税/专卖/徭役)→ 军力与官僚上限
   ↓
第 6 步: 历史与危机——通胀/饥荒/债务危机嵌入周期表, 作为政权更迭触发器
```

## 与其他大类的接口与依赖顺序

| 上游模块 | 接口内容 | 经济档案要写什么 |
|---|---|---|
| 地理(先定) | 可耕地/矿脉/河流/气候决定农业上限与矿源 | 资源地图、产区、运输成本(陆运≈水运5~20倍) |
| 法则(魔法) | 创造价值的魔法必须有成本锚点, 否则价格体系坍缩 | 法力节点=新"矿山"; 传送=重画运输地图 |
| 文明(并行) | 人口/政体/文化决定整合模式与财政结构 | 整合模式配方、政体-财政公式 |
| 历史(后定) | 经济危机嵌入长/中/短时段周期表 | 经济史年表(通胀、饥荒、债务危机) |

依赖纪律: 任何一步落定后, 前序模块不可再做推翻性改动; 档案应记录反向引用(如"此货币体系依赖北部银矿, 银矿枯竭则体系崩溃")。

## 经济档案应包含的清单

1. 资源地图与产区(农业区/矿脉/商路/能源);
2. 人口分布与密度(按生计模式分);
3. 主导整合模式 + 边缘模式(每政权);
4. 三层流通结构(村庄/城镇/顶层, 各层"钱从哪来"与层间通道);
5. 货币与信用制度(记账单位/铸币权/信用层);
6. 财政与税收(收入结构各占比);
7. 贸易路线与成本(水运/陆运费率);
8. 价格样本(谷物/盐/铁/布及波动范围);
9. 经济史年表(通胀、饥荒、债务危机、货币改革);
10. 与政体/宗教/魔法的接口说明。

## 构建操作

1. 先做能量检查再写任何设定: 计算食物热量、畜力、人力、魔法能量的总产出能否养活设定人口——前现代约 90% 人口务农, 城市人口占比≈农业剩余率, 账不平就调人口或调产出;
2. 再做运输检查: 陆运成本约为水运的 5~20 倍, 远程贸易只能是高价值低运量商品;"千里运粮"与"全境统一物价"必须重写;
3. 用整合模式配方给每个政权定调(互惠/再分配/市场主导), 再各配一个边缘模式(帝国边陲走私市场、部落间仪式交换), 不要把所有文明写成市场经济;
4. 按三层分别建账: 村庄层(自给自足、实物税)、城镇层(市集、铸币、行会)、顶层(远程贸易、银行、汇票), 并设计层间通道(商人、包税人、贵族投资);
5. 设计货币三件套: 贵金属来源与矿权归属、铸币权(谁铸/纯度/贬值史)、信用层(税册/赊账/钱庄/债务契约)——前现代以信用为主、铸币为辅;
6. 给每个政权算"收入结构"账: 地租/什一税/贡赋/关税/盐铁专卖/徭役各占多少; 可维持军队人数≈剩余提取率×农业产出−行政损耗; 财政危机(加税→起义)是最可靠的历史触发器;
7. 设计魔法/法则的成本锚点: 任何创造价值的魔法必须有法力/材料/时间/寿命/禁忌代价, 魔法资源稀缺性应与地理矿脉同等对待;
8. 最后把经济危机嵌入历史周期表: 地理气候=长时段, 制度与价格=中时段, 饥荒战争瘟疫=短时段——危机作为政权更迭导火索。

## 检查点/清单

- [ ] 能量检查通过: 粮食/热量总账能养活设定人口, 农业人口占比合理;
- [ ] 运输检查通过: 无"千里运粮"、无"全境统一物价"、远程贸易商品符合高价值低运量;
- [ ] 每个政权有明确的整合模式配方(主导+边缘), 不存在"无模式"的默认市场经济;
- [ ] 三层结构各回答"钱从哪来", 层间通道明确;
- [ ] 货币三件套(来源/铸币权/信用层)分开设计, 无"金币无来源";
- [ ] 财政账能支撑军队与官僚规模, 无"每边一万武装骑士"式失真;
- [ ] 魔法创造价值均有成本锚点, 价格体系未因魔法坍缩;
- [ ] 经济危机已嵌入历史周期表;
- [ ] 反现代主义自检: 金币有来源? 物价会波动? 有农业人口? 有运输成本? 非全市场社会?
