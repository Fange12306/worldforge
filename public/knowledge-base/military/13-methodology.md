# 军事构建方法论与一致性总检

> 从 0 到 1 构建可信军事体系——档案清单、规模校准、超自然改写与总检。

## 核心理论

**1. 战争的政治从属性与"三位一体"**
- 战争是政治通过其他手段的延续: 每次战争都应追问政治目的、可用手段与目标规模是否匹配。
- 战争由三股力量塑造: 民众的激情、军队的偶然性、政府的理性——任何政权若只呈现其中一极(只有将帅算谋、没有民意与前线混乱)即失真。
- 摩擦与战争迷雾: 现实战争充满迟到、误报、伤亡、天气与误解; 军事叙事让指挥官"全知全能"即违背原理。

**2. 重心与战略选择**
- 一方力量存在一个凝聚点(兵力集群、首都、民心、补给中枢或联盟); 战役设计围绕"打击对方重心、保护己方重心"展开。
- 战略二分: **歼灭战略**(追求决战)与**消耗战略**(资源与意志消耗); 政权能力决定适用性——小国强行歼灭战略往往破产。

**3. 战争的经济基础三公式**
- 军队规模 ≤ 人口 × 动员率; 军费 ≤ 财政 × 军费占比; 战役半径 ≤ 补给距离。
- 历史锚点: 前工业常备军约人口 0.5–2%; 战时动员 5–10%(峰值约 8–13%); 总力战可超 10–15% 但属社会崩溃级代价。
- 军费: 和平占财政 20–40%、战时 60–80%; 国家职能单一者军费可占 70–80%——军费占比本身反映政权性质。

**4. 后勤决定论**
- 战役上限由补给而非勇气决定; 军队形态是社会制度的产物——骑士需要土地分封、雇佣军需要金库、常备军需要户籍与税吏。

**5. 军事档案骨架(五事框架)**
- "道、天、地、将、法"可作军事档案骨架: "法"即编制、后勤、军法; "兵马未动、粮草先行"是后勤律; "知彼知己"是情报律——用于虚构军队的完整性检查。

**6. 军事档案完整清单(14 项)**
① 编制表(班→军团全链及人数); ② 军种划分(陆/海/空/超自然军种); ③ 兵源制度(征兵/募兵/雇佣/封建义务); ④ 军官来源与晋升(血统/军校/战功); ⑤ 军饷、福利与退役安置(缺则哗变); ⑥ 装备与兵工厂产能; ⑦ 训练与操典手册; ⑧ 后勤体系(粮秣/弹药/医药/马匹); ⑨ 情报体系(斥候/间谍/信号); ⑩ 交通线(道路/水路/铁路/传送门)与要塞; ⑪ 军法与战争法/会战礼仪; ⑫ 军事财政来源(税种/贡赋/掠夺); ⑬ 军事科技树(含魔法/超自然); ⑭ 战史档案与战争委员会决策链。

## 规模校准参考

- 前工业每兵需 3–5 个农民供养; 每匹马日耗 14–18kg 草料; 马车运输有效半径约 200–300km(再远则车马自耗殆尽); 水路效率为陆路数倍。
- 行军速度: 军团日行 25–30km; 大军团约 15–20km; 骑兵一兵 3–5 马可达日行 80km。
- 反面教材: 补给线长达 1500km+ 的远征, 就地征用遇上焦土政策, 60 万大军仅约 2 万生还——"战役半径≤补给距离"的具象化。若虚构世界出现 10 万级军队跨大陆作战, 必须给出对应补给机制(水路、传送、魔法粮仓), 否则即硬伤。

## 超自然/未来科技重写战争规则

不要"魔法=火炮"式贴皮, 应逐环节推演——生产、机动、侦察、防护、后勤、指挥、杀伤:

| 环节革命 | 示例 | 战争形态变化 |
|---|---|---|
| 侦察革命 | 魔法探知/卫星 | 消减迷雾→战争转向机动与欺骗 |
| 机动革命 | 传送/超光速 | 抹平战役纵深→重心转移到生产与政治中心 |
| 杀伤革命 | 核武/禁咒 | 相互威慑→代理人战争与军备竞赛 |
| 防护革命 | 护盾/屏蔽场 | 改变攻防均衡周期(远程失效→近战回归) |
| 后勤革命 | 空间袋/复制器 | 取消补给约束→上限转移到产能与政治意志 |

还要追问"谁垄断、谁付钱、谁受害"——垄断治疗术即垄断了兵源。

## 军事作为叙事引擎

- 战役结构: 动员铺垫→小规模接触试探→决战→战后清算四段; 决战应围绕重心设计。
- **胜利必须有代价**: 伤亡、政治债务、道德沦丧、盟友反目、财政破产、战后创伤——"完美胜利"是叙事毒药。
- **战后社会是最大富矿**: 复员军人失业与创伤("士兵心")、战债、胜利者联盟内讧、战败国的复仇记忆、纪念碑与记忆政治——战争在停火后继续。

## 常见错误对照表

| 错误 | 正确形态 |
|---|---|
| 军队规模与人口/财政脱节(动辄数十万) | 先用公式校准 |
| 补给凭空消失(跨大陆远征不吃饭) | 给出补给机制与时间表 |
| 攻城数日即破 | 历史围城常以月年计 |
| 伤亡比例不合理(每战团灭) | 参照历史伤亡率(会战损失 10–30% 已惨烈) |
| 单兵英雄无视阵型纪律 | 前工业战斗是纪律/队形数学 |
| 指挥官全知 | 保持情报迷雾与误判 |
| 军衔编制混乱(将军亲临每兵) | 建立指挥链 |
| 武器科技静止数百年 | 给军事技术演进时间线 |
| 战争总是"正义必胜且无代价" | 胜利必须付代价 |
| 敌人无战略、无后勤 | 反派也受同样约束 |
| 现代民族主义套前现代军队 | 士兵为饷银/义务/信仰/荣誉而战 |

## 构建操作

1. 先建军事档案再写作: 编制、预算、动员、装备、战史五张表, 所有数字可查、可对账, 避免"写到后面忘记前面";
2. 再用三公式强制校准: 军队≤人口 1–5%(战时 5–10%)、军费占财政 20–40%/战时 60–80%、战役半径≤补给距离——先算后写, 任何突破需给出机制理由(魔法粮仓、异界传送等);
3. 为每次战争写"成本清单": 人力、财政、政治、道德、时间五项代价, 胜利必须勾掉至少三项, 否则该战删改;
4. 把超自然/未来科技当基础设施而非特效: 逐环节(生产/机动/侦察/防护/后勤/指挥/杀伤)推演其改写效应, 并追问垄断权与受益/受害群体;
5. 用重心设计战役结构: 明确每方重心(兵力? 首都? 士气? 补给线?), 战役围绕攻防重心展开, 胜负逻辑可解释;
6. 让战后社会进入叙事: 复员、债务、纪念碑、老兵创伤、胜者内讧;
7. 给军队制度动机: 士兵为何而战、军官如何晋升、哗变如何触发, 制度与角色动机互锁;
8. 发布前过一遍十项一致性总检清单, 并用真实战争的规模与代价作锚点, 偏离必须能说出理由;
9. 用"战争观冲突"制造戏剧: 不同阵营对战争正当性的认知差异(圣战/荣誉/生存/正义)本身即情节引擎;
10. 借鉴军事史手册条目结构(编制、操典、后勤档案模板), 直接改造为虚构军队的档案格式。

## 一致性总检清单

- [ ] 三公式互证: 人口×动员率=军队上限, 财政×军费占比=军费, 军费÷人均成本=军队规模;
- [ ] 战役距离 vs 补给手段 vs 行军时间表自洽;
- [ ] 军事技术与政治制度匹配(常备军需官僚税收);
- [ ] 战争规模与政治目的匹配(有限战 vs 总力战);
- [ ] 战斗结果与战后统计(伤亡/俘虏/战利品)一致;
- [ ] 武器魔法系统规则统一(射程/装填/数量/能量源);
- [ ] 多场战争对人口财政的累积效应合理(连年征战仍繁荣=矛盾);
- [ ] 角色认知时序明确(谁知道什么、何时知道);
- [ ] 军事文化与战争法前后一致;
- [ ] 编制数与损失数全书各处对账;
- [ ] 军事档案 14 项清单已填齐;
- [ ] 每次胜利已勾掉至少三项代价。
