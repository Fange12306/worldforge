# 技术演化理论

> 目的: 让一个世界的技术"自己长出来"——理解组合进化、范式与轨道、知识类型、三阶段与加速/停滞机制,用于设计可信的技术史与剧情瓶颈。
> 前置: 法则篇的现象库(组合进化的原料);与 01-overview(总流程)、04-tree(树结构)配套使用。

## 核心理论/机制要点

### 1. 组合进化论

- **一切新技术 = 已有技术的组合 + 对现象的捕获**;技术是把自然现象"驯化成可控、可组合的效应"的手段,即对现象的编程。
- 进化速度取决于两件事: 已积累的技术池规模 × 已知现象的数量。组合空间随技术池扩大而爆炸式增长,这是技术"自动加速"的内生动力。
- **邻近可能**: 创新只能落在"现有技术一步之遥"的新组合处——解释"为什么现在才有 X"。
- 技术从技术中产生,递归地自我建构: 新技术以既有技术为零件,又反过来为更高级技术提供零件。

### 2. 技术范式与技术轨道

| 概念 | 含义 | 世界构建用法 |
|---|---|---|
| 技术范式 | 规定"要解决什么问题"+"用哪些搜索规则、哪些已有技术当模板" | 给每个时代写明问题集与搜索模板 |
| 技术轨道 | 范式内累积性局部搜索,渐进改进(如引擎百年提效) | 大多数创新是轨道内微发明(性能 +5%) |
| 范式更替 | 轨道逼近物理/经济极限、增量收益递减时才发生 | 只有范式更替才是历史转折点 |
| 选择环境 | 相对价格、需求、制度、军事需求约束范式确立 | 用需求与制度解释"为何走这条路" |
| 锁入 | 范式确立后排斥异质方案,可能"顽固地走弯路" | 旧势力守着成熟但见顶的范式抗拒新范式 |

### 3. 有用知识: 命题 vs 处方

- **命题知识**("是什么/为什么",近似科学)与**处方知识**("怎么做",配方=技术)是两类不同知识;技术进步 = 处方库扩张,而处方库扩张依赖命题库支撑。
- **宏发明**(开创全新范式,依赖洞察与运气)vs **微发明**(宏发明后的无数匿名小改进)——约 99% 的技术进步是微发明,构成大部分生产率增长。
- **知识基础设施比单项发明更重要**: 文字、印刷、学术网络、通信让两类知识双向流动,才引爆持续增长。

### 4. 发明—创新—扩散三阶段

| 阶段 | 内容 | 所需条件 |
|---|---|---|
| 发明 | 技术原型出现 | 知识存量 + 洞察 |
| 创新 | 首次商业/实际应用(企业家行为) | 企业家 + 资本 |
| 扩散 | 采用曲线(S 形: 早期缓慢→临界点后爆发→饱和) | 基础设施 + 标准 + 网络效应 + 制度适配 |

三阶段条件完全不同;许多技术"发明早、普及晚",正是后两环缺失。

### 5. 技术—科学互动

- 19 世纪前技术大体先于科学: 工匠凭经验试错积累配方,科学从技术中汲取素材;19 世纪后关系倒转,科学成为技术的前端(理论→工业)。
- "受应用启发的基础研究"打破纯基础/纯应用二分——科学进步常被技术需求牵引。
- 两者靠仪器、组织(大学、实验室、期刊)耦合;科学本身也常是技术的产物(仪器即高技术)。

### 6. 演化加速与停滞

- **加速的前提**: 知识可编码、可复制、可检索(文字/印刷/期刊/专利)+ 存在把知识转化为技术的组织循环;更好的技术被用来造更好的技术 → 指数式进步。
- **停滞的原因**: 范式饱和后曲线上端放缓;物理极限(材料、能量密度);组织瓶颈(制度僵化、知识产权反噬);社会阻力。
- **知识断裂可致真实倒退**: 知识若不编码、不复制、不制度化,会随一代人消亡(灾难后技术失传)——倒退用知识断裂解释,而非纯政治衰落。
- 两条力量同时起作用: 技术塑造社会,社会也塑造技术;不取单向决定。

## 构建操作

1. 先为每个关键科技列出"父技术零件 + 所需现象",强制组合来源,禁止凭空出现——主角造出 X 前必须先"解锁"全部前置,直接当作任务链/文明成长线;
2. 再建"现象库"统一魔法与技术: 魔法=可被认知和编程的现象,魔法师=命题知识持有者,炼金术师/符文工匠=处方知识持有者,"魔法工程"=现象+零件+系统的组合;
3. 为每个文明/时代设定"范式与轨道": 写明问题集、搜索模板、代表性器件;大多数创新是轨道内微发明,只有"范式更替"才是历史转折点;
4. 用"范式锁入"制造冲突: 旧势力守着成熟但见顶的范式,抗拒新范式;让锁入的代价可见(性能停滞、替代方案被压制);
5. 回答"为何现在才有 X": 列前提检查清单——材料、命题知识、组织(学会/大学/专利)、需求(相对价格/战争/贸易)、邻近可能;让发明"提前出现但无后继"(如汽转球只是玩具)是很强的现实感设定;
6. 用发明-创新-扩散三段驱动剧情: 造出原型≠改变世界;设计"发明成功但扩散失败"的悲剧(秘传配方、专利垄断、标准战失败)与"扩散引爆社会"的高潮(铁路、电网、印刷术);
7. 用知识基础设施解释加速与停滞: 谁建立大学/图书馆/专利局/学会,谁触发正循环;焚书、秘传制度、低识字率让文明停滞;黑暗时代用知识断裂解释倒退;
8. 设计两类角色及其耦合: 工匠(处方知识,经验试错)与学者(命题知识,理论解释),耦合方式(仪器共享/学徒制/科学院)决定技术速度;可设定"重理论轻工艺"与"重工艺轻理论"的文明分化。

## 检查点/清单

- [ ] 每项技术都能回溯到"现象+既有技术组合",无凭空发明?
- [ ] 每个文明/时代有明确的范式描述(问题集/搜索模板/代表性器件)?
- [ ] 发明-创新-扩散三阶段时间戳分离,无"发明即普及"?
- [ ] 每个"迟到技术"有前提检查(材料/知识/组织/需求/邻近可能)支撑?
- [ ] 至少一个"发明超前却无后继"的案例(玩具/珍玩)?
- [ ] 知识基础设施已设计(文字/印刷/学术网络/资助),并用以解释加速与停滞?
- [ ] 工匠-学者双角色及其耦合方式已设定,技术路径分化有据?
- [ ] 停滞与倒退有机制解释(范式饱和/物理极限/组织瓶颈/知识断裂)?
