# 经典种族与原创种族: 认知捷径与超越经典

> 目的: 解释经典种族为何"有效", 提供原创种族的方法论(一次偏离+涟漪效应)与超越经典的三个路径。
> 前置: 与生态位篇(形态由生态推导)、神话篇(原型)互相补充; 输出(锚点、推导链、谱系)是种族档案的基础。

## 核心理论: 六个机制

1. **种族即"压缩包"与认知捷径(属级位阶)**: 在"智慧生物"这一超位与"某个具体个体"这一低位之间, 基本层范畴(如"精灵")是识别成本最低、信息量最大的层级——读者一看到标签, 身体/人格/文化/价值观全部自动加载。幻想种族本质上是把一整套语义预设打包进一个词。

2. **心理本质主义**: 人类默认"种类成员共享不可见的共同本质", 这让"精灵=长寿+优雅+魔法亲和"看起来是内在必然而非约定。这是种族设计"自明感"的来源, 也是其风险根源: 本质主义把**物种、文化、人格、道德倾向四合一**, 形成生物决定论式的种族观。

3. **类原型机制**: 幻想种族是心理功能/原型(人格面具、阿尼玛、阴影等)的外化人格, 每族承载一种单一心理姿态。这解释了为何极端化的种族反而"有味道"——它们是冲突与欲望的具象化。

4. **人形度光谱与恐怖谷**: 近人/异人/异形连续谱。越近人→读者越易投射共情, 适合承担"人性议题的变奏"; 越异形→产生"认知刷新", 适合制造惊奇与世界观冲击; 介于中间、似人非人的设计反而触发排斥。叙事分工: 近人负责共情, 异形负责惊奇。

5. **原创方法论——"一次偏离+涟漪效应"**: 从现实生态/人类学/经典原型取**一个**可辩护的关键差异(繁殖方式、感官、代谢、社会结构、时间感知), 再像思想实验一样系统性推导连锁后果: 营养→身体→社会→语言→价值观→冲突。推导链每步可辩护, "合理"就替代了"魔法设定"。

6. **超越经典的三条路径**: ①保留捷径——每族仍留 1~2 个可瞬间识别的锚点; ②内部多样性——文化群、政治派系、历史分期、反类型亚文化; ③谱系深度——书写演化史(与人类谱系的分叉点、适应、兴衰)。捷径负责可读性, 多样性+谱系负责深度, 二者不冲突。

## 范本机制对照

| 范本 | 核心机制 | 可学教训 |
|---|---|---|
| 中土精灵式 | 主题对立: 不朽与死亡构成道德-神学主轴; 精灵=人类"失去/渴望成为的镜像"而非"更好的种族"; 始终留在近人区使共情成立 | 种族承载主题而非优越性 |
| 游戏阵营式 | 认知捷径游戏化: 阵营+种族天赋+子种族; 用内部派系与衰败叙事制造族内张力 | 捷径可制度化, 但"全族皆此"会破 |
| 极端本质主义式 | 每族=单一执念的化身; 无善阵营的冲突机器, 任何两族相遇即有戏; 经典原型+重新定位可工业化复活 | 极端化有味道, 代价是全族扁平 |
| 规则书式 | 种族-职业-阵营捆绑的制度化属级位阶, 半个世纪持久; 近年规则层已开始移除种族属性调整 | 本质主义可被规则层修正 |
| 一点偏差式(科幻) | 从人类基线取单一差异(逻辑主义、寄生繁殖、另类感知)并推到底, 不叠加第二个差异 | 一差异即一世界, 克制是深度 |

## 人形度光谱定位表

| 定位 | 叙事职能 | 设计要点 |
|---|---|---|
| 近人 | 人性议题的变奏 | 留在共情区, 用主题对立承载深度 |
| 异人(似人非人) | 慎用 | 只在有意制造不安时使用, 否则触发排斥 |
| 异形 | 认知刷新与惊奇 | 单点偏离推到底, 不补第二处差异 |

## 构建操作

1. 先立锚点, 后加深度: 每个种族先用一句话说清"它是什么"(1~2 个核心特征), 保证立即可读; 之后的所有扩展都不得稀释这个锚点;
2. 再执行"一次偏离+涟漪效应"并留推导记录: 选定单一关键差异后, 从生态→社会→文化→冲突逐层推导, 写一张"理由链"表; 任何读者质疑都应能被推导链回答, 而非"因为它魔法";
3. 把内部多样性写成制度而非点缀: 为每族设至少 3 个互斥的文化群/政治派系/历史分期, 再加一个"反类型"亚文化(精灵中的务实商人、矮人中的诗人); 族内冲突与族间冲突并存;
4. 补谱系深度: 为每族写演化史——与人类(或其他种族)的分叉点、关键适应、兴衰节点, 回答"为什么它现在长这样"; 这是"合理感"的主要来源;
5. 明确人形度定位与叙事分工: 在近人/异人/异形光谱上给每族定位; 近人族负责人性议题的变奏, 异形族负责认知刷新与惊奇, 杜绝全员"人穿皮套";
6. 本质主义自检: 每次设计完成后自查——该族是否有内部争议? 是否所有成员共享同一价值观? 能力差异是否有环境/文化解释而非"天生"? 若全是"天生", 即已滑入生物决定论;
7. 用语言与命名做低成本高回报的深度工具: 方言差异、命名规则、未翻译词汇能瞬间制造"文化厚度"与谱系感, 成本远低于设定文档。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 皮套综合征: 贴图式差异(尖耳/蓝皮)无推导链 | 单一关键差异 + 全链推导 |
| 锚点漂移: 扩展稀释核心特征 | 锚点一句话固定, 扩展不得稀释 |
| 全族同质: 无内部争议 | 变体≥3 + 反类型亚文化 |
| 本质主义帽子: 能力全"天生" | 能力给出环境/文化解释 |
| 全员近人/全员异形 | 按叙事分工定位人形度 |

## 检查点/清单

- [ ] 每族有 1–2 个稳定锚点且未稀释?
- [ ] 关键差异单一, 理由链表完整可回溯?
- [ ] 内部变体≥3 + 至少一个反类型亚文化?
- [ ] 演化史含分叉点/关键适应/兴衰节点?
- [ ] 人形度定位明确, 无全员"人穿皮套"?
- [ ] 本质主义自检通过(能力有环境/文化解释)?
- [ ] 有语言/命名层面的低成本深度工具?
