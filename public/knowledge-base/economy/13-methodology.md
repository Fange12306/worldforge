# 经济构建方法论与超自然经济

> 法术供给曲线、魔法货币锚定、传送术冲击、外生货币冲击、神力经济与一致性总检——让超自然元素也服从经济学。

## 核心机制

### 1. 给法术画供给曲线(超自然生产函数)

任何超自然产出都服从稀缺性: **供给量 = 施法者人数 × 人均产出**。四条供给约束, 价格由最紧的一条决定:

| 约束 | 含义 | 供给曲线形态 |
|---|---|---|
| 人力资本 | 施法者由学徒制/学院/血统决定, 长期缓慢增加 | 长期缓慢右移 |
| 容量 | 每日法术位/法力池有限 | 短期近乎垂直(价格暴涨也难增产) |
| 材料成本 | 昂贵施法材料推高边际成本 | 向上倾斜(卷轴/物品定价依据) |
| 管制 | 行会、神殿、帝国特许=进入壁垒 | 产生租金与黑市 |

**魔法服务是"双重用途商品"**: 既是消费(治疗/享乐)又是生产投入(传送/造物), 其价格像石油一样渗入所有下游成本。若施法者总数固定, 高阶法术=垂直供给+配额制, 价格由需求与关系决定, 黑市与"法术黄牛"必然出现。

### 2. 魔法货币的复合锚定

货币三职能(记账单位/交换媒介/价值储藏)中, 超自然货币的麻烦是**货币本身有使用价值**: 灵石/法力结晶既是钱又是修炼燃料, "花掉=消耗"→结构性通缩与囤积理性(富者吸收快速升级=加速折旧, 贫者囤积求突破=流动性偏好)。格雷欣法则: 内在价值高于面值的币被熔毁或吸走——若金币本身是施法材料, 市面上流通的只会是"坏钱"。

**复合锚定** = 货币同时锚定金、法力额度、神殿信用、地城产出等多重标的(类似货币篮子): 锚越多币值越稳, 但任何一锚的供给变化都是冲击源; 锚之间可套利(熔法力结晶铸币、再熔回去)。

### 3. 传送术对空间经济的冲击

运输成本→0 时, 中心地金字塔**扁平化为点对点网络**: 港口/十字路口型"天生枢纽"失去优势, 转为"法阵枢纽-辐条"结构。但传送受重量/载量/安全性限制, 于是出现**分级运输**:

- 大宗笨重商品仍走水路(成本);
- 只有高价值低重量货物(宝石、药材、密卷)值得传送 → 传送货物变成奢侈品与金融资产;
- 地租圈层被折叠: 郊区与远乡获得同等地租。

"距离之死"的实质: **对空间距离的租金(港口费、关税、中间商)被重新分配, 而非消失**——谁是新枢纽、谁衰败、关税与法阵税落在哪里, 都是重排后的结果。

### 4. 外生货币冲击(地城金币/龙宝藏)

货币数量论(MV=PT)框架: 冒险者倾入地城金币≈货币供给外生扩张 → 价格水平上升、存量财富重新分配、借贷契约实际价值被侵蚀。若流入的是可消耗资源(魔力结晶), 则是"直升机撒油"。反过来: 龙藏金、宝库封存=货币紧缩(通缩); 龙吃掉生产性矮人=供给侧冲击(产出骤降)。

**外生冲击必须走传导链**, 而非"凭空多了一堆钱":

```
金币 → 金价 → 粮价 → 地租 → 税收 → 政治动荡
```

同一个事件常有两套传导: 货币面(价格与债务)+ 实体面(资源与产能), 分别推演。

### 5. 神力经济(信仰即货币)

- **神是信用发行人**: 赐福=负债, 祈祷/香火=收入, 信徒的信仰活动是"信仰GDP";
- **救赎信用可超发**: 当神职机构像印钞一样发放救赎额度(赎罪券式), 信用扩张到信徒质疑可兑换性(死后兑现)→挤兑→制度危机(宗教改革式);
- **声誉-信用循环**: 神赐福→信徒增多→香火旺→神更强大, 自我强化正反馈→护国神教垄断, 或信徒预期贬值时集体背弃(信仰通胀);
- **神死亡=资产清算**: 神性被法律清算为债务资产, 信仰合同、神力债券成为金融工具——极佳的设定钩子。

### 6. 经济作为叙事引擎

- **三问检视**: 谁获益? 谁付费、成本由谁承担? 外部性是什么? 答案进入剧情, 经济就不是背景板;
- **稀缺-丰裕光谱**: 所有幻想故事都是"稀缺与丰裕"的思想实验——丰裕侧(复制器/量产魔法)回答"没有匮乏人类会做什么", 稀缺侧回答"极端匮乏下人性如何排序"。**光谱位置决定世界的类型基调。**

## 构建操作

1. 先画供给曲线再定价格: 为每种魔法服务写明"人数限制、容量限制、材料、管制"四项, 价格由最紧约束决定; 高阶服务用配额与关系定价, 不要按成本定价;
2. 给货币立"锚档案": 发行者(神殿/帝国/宗门)、锚定物(金/法力/信仰/地城产出)及可消耗性; 若货币可被消费, 主动设计通缩与囤积情节; 用格雷欣法则检查"为什么劣币还在流通";
3. 传送术只折叠一部分成本: 规定传送的载量、重量、生命体与安全性限制, 自然形成"高价值小件走传送、大宗走船"的分级运输; 据此重排城市层级并写明谁收法阵税;
4. 外生冲击必须走传导链: 每次"灌入地城金币/龙宝藏/遗迹科技"都列三步——货币面(价格与债务)、实体面(资源与产能)、制度面(谁被洗牌、谁造反);
5. 神力经济用信用模型: 把神当信用发行人, 设计"信仰资产负债"(赐福=负债, 香火=收入); 赎罪券/圣物/神力债券的"超发-贬值-挤兑"是一条现成剧情曲线; 神死之后的资产清算是设定钩子;
6. 用三问检视每个经济情节: 谁获益? 谁付费? 外部性?(如"魔法纺织机"外部性=织工失业→暴动;"复活术"外部性=人口结构与继承法崩溃);
7. 按稀缺-丰裕光谱定调: 复制器/量产魔法世界回答"丰裕之后钱变成什么"(注意力、地位、寿命成为新货币); 资源枯竭世界回答"极端稀缺下的产权与暴力"; 选好光谱位置再设计制度;
8. 跑一致性总检清单(见下), 全部通过经济层才"焊死"在世界里。

## 检查点/清单

- [ ] 每种魔法服务有四项供给约束, 定价由最紧约束决定
- [ ] 货币有锚档案, 可消耗性、发行者、通缩/囤积情节齐备
- [ ] 传送/瞬移有载量重量限制, 分级运输与新枢纽已重排
- [ ] 每次外生货币冲击都有货币面+实体面+制度面三步传导
- [ ] 神力经济有信用模型: 负债/收入/超发/挤兑/清算曲线完整
- [ ] 每个经济情节都过了一遍三问(获益/付费/外部性)
- [ ] 世界的稀缺-丰裕光谱位置明确, 制度与其一致
- [ ] 一致性总检: 货币从哪来、谁发行、可消耗吗; 魔法资源是存量还是流量、会枯竭吗; 谁垄断供给; 价格如何传导到粮价/地租/军费; 有哪些套利者与黑市; 短期冲击与长期均衡分别是什么; 每个设定与世界观时间线自洽(如帝国财政能否支撑常备军)
