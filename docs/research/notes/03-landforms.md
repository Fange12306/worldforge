# 笔记 03: 地形地貌的形成与分布(landforms)

> 研究主题: 山脉(褶皱/断块/火山/穹窿造山)、高原(碰撞/俯冲/熔岩)、平原(冲积/三角洲/湖海积/冰川)、草原(温带/热带稀树)、沙漠(副热带高压/雨影/寒流/内陆四大成因)。

---

## 核心理论

1. **内营力 vs 外营力**: 地貌是构造/岩浆作用(内营力)与流水、风、冰川、海(外营力)对抗的产物——内营力建立高差, 外力削高填低。虚构世界的宏观地形必须先由构造格局决定, 再由气候塑造细节。
2. **板块构造是第一因**: 山脉与高原绝大多数位于板块边界或古缝合线, 大陆内部平原位于克拉通或沉降盆地。造山带按边界类型分: 洋-陆俯冲(安第斯型)、陆-陆碰撞(喜马拉雅型)、洋-洋俯冲(岛弧型, 如日本)。
3. **地壳均衡(Isostasy)**: Airy 均衡下山脉有"山根", 地壳厚度约为地表高度的 5~8 倍(珠峰 8848 m, 下方地壳厚约 70 km), 由此设定陆地高度的物理上限(约 9 km)。想让世界有更高山, 必须同时调整地壳密度/厚度与岩石圈强度——这是"合理性自检"的锚点。
4. **侵蚀循环与动态平衡**: Davis 的"地理循环"(幼年-壮年-老年, 准平原 peneplain)、Penck 的坡面平行后退、King 的山麓夷平(pedimentation)共同解释高原顶面与平原的"平坦"来源; Hack 的动态平衡认为地形是抬升速率与侵蚀速率的平衡态。高差越大、降水越强, 侵蚀越快。
5. **气候分带控制植被与荒漠**: 哈德莱环流下沉支制造 20~30° 副热带干旱带; 大陆性、雨影、寒流可把沙漠推向更内陆或更靠岸的位置; 草原出现在"水分不足以支撑森林、又足以支撑草本"的区间, 且热带稀树草原依赖火维持。

---

## 形成与分布机制

### 山脉(四类)
- **褶皱山**: 水平挤压使沉积岩层弯曲(背斜/向斜), 常见于陆-陆碰撞(喜马拉雅、阿尔卑斯)与俯冲增生(安第斯); 山系长、平行缝合线延伸, 常伴逆冲断层。
- **断块山**: 正断层活动形成地垒/地堑(盆地-山脉省、泰山/华山); 坡度陡, 山脚有断层崖与坡积裙, 常与裂谷伴生。
- **火山山**: 盾状火山(玄武岩、低缓, 夏威夷)、成层火山(安山岩、高陡, 富士山)、火山渣锥; 分布于俯冲带(环太平洋火环)、裂谷带与地幔柱热点(热点链可反推板块运动方向)。
- **穹窿山**: 岩浆(岩基/岩盖)上侵使盖层隆起成穹(黑山 Black Hills), 侵蚀后中央出露深成岩、外围呈环形山脊; 盐穹窿同理。
- **分布规律**: 山脉连线即板块边界, 走向垂直于主压应力方向; 高度受均衡与侵蚀双重限制(高降水热带造山带被侵蚀更快, 如喜马拉雅南坡)。

### 高原(三类)
- **碰撞高原**: 陆-陆碰撞使地壳增厚一倍, 青藏高原平均约 4500 m、地壳厚 60~75 km; 顶面平坦来自河流夷平与内流盆地充填, 周缘为陡崖与逆冲带; 后期挤压引发侧向逃逸(Molnar & Tapponnier 的逃逸构造)。
- **俯冲高原**: 安第斯 Altiplano(约 3700 m)由平板俯冲(flat slab)+地壳缩短增厚形成。
- **熔岩高原**: 地幔柱/大火成岩省(LIP)溢流玄武岩层层堆叠(德干、哥伦比亚河、西伯利亚暗色岩); 单层熔岩厚 10~100 m, 总厚可达数千米, 顶面近乎水平, 伴柱状节理与暗色陡崖; 可在 10^5~10^6 年内快速形成——适合"神祇近古造地"的设定。
- **残余高原**: 古老克拉通夷平面被抬升切割(巴西高原、喀斯特化的云贵高原)。

### 平原(四类)
- **冲积平原**: 河流中下游泛滥堆积, 具自然堤、泛滥盆地、牛轭湖(华北平原、恒河平原); 沉积速率毫米-厘米/年, 分布于大河下游与构造沉降盆地。
- **三角洲平原**: 河口输沙大于海浪/潮汐搬运时堆积; 按主导营力分鸟足状(河流主导, 密西西比)、扇形(波浪主导, 尼罗河)、尖头状(潮汐主导, 恒河-布拉马普特拉); 分流河道(distributary)是标志性地貌。
- **湖积/海积平原**: 古湖干涸或海退露出(里海低地、美国大西洋海岸平原), 地势极平, 有古岸线与湖成阶地。
- **冰川平原**: 冰碛平原(终碛、鼓丘)与冰水外冲平原(outwash, 蛇形丘), 分布于中高纬被大陆冰盖扫过的地区(北欧、北美五大湖周边)。
- **分布规律**: 平原 = 沉降/低洼 + 充足沉积物供给, 常与造山带伴生(造山带剥蚀物在前陆盆地堆积)。

### 草原(两类)
- **温带草原**(Steppe/Prairie/Pampas): 中纬度约 30~55° 大陆内部, 年降水 250~750 mm, 半干旱-半湿润, 降水集中于夏季或春秋, 冬季寒冷干燥、年温差大(大陆性气候); 水分限制深根、高蒸腾的树木(欧亚草原、北美大平原、潘帕斯)。
- **热带稀树草原**(Savanna): 低纬约 5~20° 干湿季气候(Köppen Aw), 年降水 500~1500 mm 但 80% 以上集中于 4~8 个月湿季, 干季长达数月, 全年高温(>18°C); 维持关键为**季节性干旱 + 火 + 食草动物**——火清除木本幼苗, 无火则向森林演替(Bond 等 2005)。
- **分布规律**: 草原沿降水梯度位于森林(湿润侧)与荒漠(干旱侧)之间; 山地的海拔降温可局部制造"凉型稀树草原"(如东非高原)。

### 沙漠(四大成因)
- **副热带高压**: 哈德莱环流下沉支在 25~30°N/S 全年下沉, 晴空少云、抑制对流, 形成撒哈拉、阿拉伯、澳大利亚内陆等行星沙漠带; 大陆西岸更干燥(叠加寒流)。
- **雨影效应**: 盛行风翻山时水汽在迎风坡凝结降水, 背风坡下沉增温绝热变干(内华达山脉以东的大盆地、安第斯以东的巴塔哥尼亚、青藏高原北侧的塔克拉玛干); 山脉走向垂直盛行风时效应最强。
- **寒流**: 大陆西岸 20~30° 的冷洋流(加那利、本格拉、洪堡、加利福尼亚)冷却低层空气形成逆温、抑制降水, 造成阿塔卡马(年降水 <15 mm)、纳米布等"雾漠"(fog desert), 生命依赖雾与露水。
- **内陆/大陆性**: 远离海洋水汽来源 + 周围高山阻挡 + 盆地封闭(塔克拉玛干、戈壁、北美大盆地), 常与雨影叠加。
- **判定阈值**: 年降水 <250 mm 或干旱指数 P/PET < 0.2; 沙漠范围随轨道尺度气候波动大幅迁移(撒哈拉在全新世早期曾是绿洲), 可为世界留下古湖盆与干河床遗存。
- **沙漠地貌**: 沙质沙漠(erg/沙海)、石漠/砾漠(reg/serir)、岩漠(hamada)、盐漠(playa/salar); 沙丘形态(新月形 barchan、纵向 seif、抛物线形、星形)取决于风向稳定性与沙源(Bagnold 1941 风沙搬运理论)。

### 三大地带性规律(总纲)
- **纬向地带性**: 赤道雨林 → 热带稀树草原 → 副热带沙漠 → 地中海/硬叶林 → 温带森林 → 温带草原 → 寒带针叶林 → 苔原 → 冰原。
- **经向地带性(海陆位置)**: 大陆内部由沿海向内陆: 森林 → 草原 → 荒漠(欧亚大陆双向递变)。
- **垂直地带性**: 山地随海拔出现类似从赤道到两极的垂直带谱(基带决定带谱类型)。
- 三条地带性 + 非地带性因素(地形、洋流、季风)共同构成"任何一片大陆都可以据此推演"的气候—植被—地貌体系。

### 柯本 B 类(干旱)阈值公式(Peel et al. 2007)
- 干燥度阈值 P_th(mm) = 20×T(年均温 °C) + 280(≥70% 降水在暖半年)/ + 140(≥70% 在冷半年)/ + 210(均匀)。
- P < P_th → B 类; P < P_th/2 → 沙漠 BW(年均温≥18°C 为 BWh, <18°C 为 BWk); 其余 B 类 → 草原 BS。
- **这一公式让世界构建者可以用"年均温+年降水"两个数字直接推算某地是森林、草原还是沙漠。**

## 对虚构世界构建的启示

1. **先画板块, 再画地貌**: 用 4~6 块板块拼世界; 汇聚边界放高山/碰撞高原, 离散边界放裂谷+断块山, 热点放火山与熔岩高原, 转换断层放错断山脉; 山脉走向垂直于汇聚方向。
2. **用高度上限约束想象力**: 陆地最高点不超过约 9 km 且应有山根; 高原顶面必须平坦——要么熔岩盖、要么古夷平面, 边缘给陡崖。
3. **降水格局反推气候带**: 先在 25~30° 放行星沙漠、5~20° 干湿季区放稀树草原; 山脉走向垂直盛行风, 迎风坡森林、背风坡雨影荒漠; 大陆西岸 20~30° 设计冷洋流 → 沿岸雾漠。
4. **草原夹在森林与沙漠之间**: 温带草原给 250~750 mm 降水+冬冷夏热; 热带稀树草原给干湿季+火。把"火灾季节"设计为生态-文化事件(游牧迁徙、控火管理)会显著增加世界真实感。
5. **平原放在沉降盆地与大河下游**: 大河注入构造沉降带 → 冲积平原; 河口按波浪/潮汐强弱选三角洲形状; 若世界有冰期史, 中高纬留冰碛与冰水地貌。
6. **时间尺度与古气候遗存**: 造山需千万年以上, 熔岩高原可快速形成; 沙漠边缘留古绿洲湖盆、干涸河道, 暗示气候摆动。
7. **善用反馈循环**: 高原抬升改变季风(青藏-季风耦合), 沙漠反照率正反馈(Charney 机制)自我强化干旱——让"气候带错位"表现为长期演化的结果而非随意设定。
8. **七步法**: ①定板块骨架 ②定行星参数 ③用"理想大陆"模板铺气候带(纬度套行星风系)④叠加地形修正(雨影)⑤画洋流找寒流 ⑥用柯本阈值公式推植被带 ⑦反向一致性检查。
