# 种族与文明的关系: 种族是社会建构

> 目的: 把"种族"从生物学事实降格为世界内的社会分类, 拆解种族/文化/国家三轴, 为种族与文明的关系提供去本质主义的设计方法。
> 前置: 与物种篇(经典/原创种族、生态位)互相定义; 输出(承袭规则、族群边界、种族-国家关系)是历史篇与文明篇政体的输入。

## 核心理论: 九个去本质主义要点

1. **种族是社会建构, 不是生物学事实**: 基因差异绝大多数存在于种群内部, 种族间差异仅占极小份额; 肤色等表型沿地理连续渐变, 划不出清晰边界。种族分类随政权、法律、话语而变——所谓"种族"是**种族化过程**的产物: 由"种族方案"同时解释并组织人群, 可被政治争夺与重写。虚构世界同理: 世界的种族划分应来自世界内的分类权力(法典、户口、身份登记), 而非作者的天赋真理。

2. **生物决定论与文化决定论是同一枚硬币**: 前者宣称智力/德性/文明能力由血统决定; 后者把差异全归于"本质文化", 用文化本质替代生物本质, 同样制造封闭边界。正确基线: 表型、语言、习俗、制度各自独立演化, 不可互相化约——"尖耳朵→必然优雅"与"文化A→必然好战"是同一错误的两面。

3. **种族≠文化≠国家**: 民族是"想象的共同体"(共享叙事与归属感的集体), 国家是政治行政单元。同一种族可散居多国多文化(离散人群); 一国可容多族多文化; 一种文化可跨多族(宗教、职业、都市亚文化)。把国家说成种族的自然延伸, 是"发明传统"式的政治工程而非事实——"矮人王国"只能是矮人世界的一角。

| 轴 | 定义 | 档案输出 |
|---|---|---|
| 生物学表型 | 形态/生理/感官, 可完全没有"种族"概念 | 生理卡(见方法论篇) |
| 文化 | 语言/习俗/制度/价值观, 内部有变体与争议 | 文化卡(内部变体) |
| 政治 | 国家/帝国/联盟/教会, 与族裔无必然绑定 | 政体档案 |

4. **族群性是边界过程, 不是内容清单**: 族群认同由"我们/他们"的**边界维持**与内外**归属判定**决定, 文化内容随边界流动; 族群常源于共同政治命运的记忆(共同敌人、共同苦难)。设计族群=设计边界与归属规则, 而非设计特征清单。

5. **血统承袭的两条主轴**: 父系/母系承袭(按单线传递身份)与"一滴血"原则(混血后代自动归入从属/弱势种族); 反向工具是血统份额(按比例计算公民权, 用于原住民权利)。这些规则从不中立描述混血, 而是**维系等级的手段**。虚构用途: 让不同法域的承袭规则冲突——同一角色在甲国是"纯血"、在乙国是"混血", 是天然情节引擎。

6. **混血身份政治**: 混杂身份可成为颠覆二元对立的"第三空间"; 相遇中的融合本身是创造性过程而非污染; 接触中各方互相取用、再生产。分类层面, "勾选所有适用项"vs"只选一项"之争本身即政治战场——分类权=定义权。

7. **歧视是结构, 不是偏见集合**: 靠反通婚法、种族登记、居住隔离、职业分工与日常污名再生产, 并与阶级、性别、宗教**交叉运作**。写歧视=写制度(区划、限额、隔离、登记), 而非只写角色偏见。

8. **跨种族交流与翻译**: 语言塑造世界观差异; 皮钦语/克里奥尔语是跨族接触的典型产物; 翻译是"接触地带"中的权力协商, "不可译性"本身标记世界观鸿沟。不要用万能翻译机消解差异。

9. **"种族即国家"是意识形态而非事实**: 从"民族魂"叙事到血统法、再到"外来统治者"神话, 这类话语服务统治; 虚构作品可写角色相信它, 但设定者应知道它是**世界内观念**。

## 构建操作

1. 先拆三轴再设计: 为每个文明分别定义生物学表型(可完全没有种族概念)、文化、政治, 三轴两两正交——主动构造"同族多国""一国多族""跨族共享文化"的交叉矩阵;
2. 再破解"单帽星球": 给每个物种至少 2–3 个彼此冲突的文化(定居/游牧/离散)与内部分歧; 一个文化内要有阶级、地域、世代、职业亚文化; 外部"帽子"只作他者印象, 内部必须制造例外与争议;
3. 然后把种族分类写进世界内观念层: 设定分类法出自某政权、法典、户口或身份证(血统比例? 母系? 外貌? 宗教?), 展示其后果(纳税、通婚限制、兵役、选举权), 读者会自然读出"种族即国家"是意识形态;
4. 用承袭规则制造冲突: 定义世界的承袭规则(父系/母系/双系/按社会接受度), 并让不同法域规则冲突——同一角色跨境的"纯血/混血"身份翻转即剧情引擎;
5. 跨族交流不要只写翻译器: 设计接触地带(贸易港、边境市镇、克里奥尔语、宗教融合、混血社区); 让误译、不可译概念(时间、祖先、荣耀、罪)成为剧情驱动;
6. 歧视要结构化: 写居住区划、职业限制、法律定义、教育隔离等制度而非角色偏见; 并让种族与阶级、性别、宗教交叉;
7. 让"他者如何看他者"替代单一视角: 多族角色互相描述对方, 展示不对称成见(强势族眼中的"野蛮"vs 弱势族眼中的"不洁");
8. 写身份政治: 让混血角色同时拥有可选与强加的身份, 展示分类斗争(有人争"算我们族", 有人拒绝标签);
9. 机制可迁移、表型不可映射: 不让虚构种族一一对应现实种族, 但殖民、奴役、登记、隔离的权力结构可以迁移——那才是可学的教训;
10. 给种族-文明绑定留时间轴: 设计历史中的同化、融合、复兴与重新分类事件, 说明文化边界可变、分类可被推翻。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 全族一帽: 精灵=优雅、矮人=贪婪 | 每族 ≥2–3 个冲突文化 + 内部例外 |
| 种族=国家: 一民族一王国 | 一族多国/一国多族, 绑定需世界史理由 |
| 万能翻译机 | 接触地带 + 不可译概念成为剧情 |
| 种族分类无出处 | 分类法出自法典/政权/身份证并带后果 |
| 歧视=角色偏见 | 歧视写入制度结构 |

## 检查点/清单

- [ ] 三轴(表型/文化/政治)已拆解且两两正交?
- [ ] 每物种至少 2–3 个冲突文化?
- [ ] 种族分类法有世界内出处(法典/政权)与后果?
- [ ] 承袭规则明确, 跨法域冲突已设计?
- [ ] 接触地带与翻译张力存在, 无万能翻译机?
- [ ] 歧视有制度载体(区划/限额/登记/隔离)?
- [ ] 无现实种族一一映射(机制可迁移)?
- [ ] 种族-国家绑定有时间轴与例外?
