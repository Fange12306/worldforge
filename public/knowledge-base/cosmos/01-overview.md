# 宇宙总流程与接口

> 目的: 从 0 到 1 构建一个世界的宇宙体系——先立最高法则,再按依赖链逐层推导恒星/行星/位面,写全档案,最后与地理、法则、种族、历史接口咬合。
> 前置: 与法则篇(最高法则/魔法规则)互相定义;宇宙输出(恒星参数/行星轨道/位面结构)是地理篇气候与种族篇生存环境的输入;历史篇时间轴须与宇宙时间线(恒星寿命/深时事件)对齐。

## 核心立场: 宇宙体系的自洽高于科学精确

- **次级创造原理**: 作者是"次级创造者",虚构世界靠"现实的内在一致性"赢得读者信任——可信度不来自与现实相同,而来自内部法则彼此不矛盾。宇宙体系的首要目标是**自洽可回溯**,其次才是科学精确。
- **法则层—事实层二分**: 先立少量最高法则(物理常数、魔法终极规则、空间拓扑),再由法则推导海量事实。法则少而硬、事实多而软;每个事实必须能沿"法则→事实"链回溯,回溯失败即"参数不自洽"。改动法则成本极高,改动事实成本低——档案必须区分"法则条目"与"事实条目"。
- **模块依赖链单向传递**: 宇宙学(尺度/结构/时间起点)→ 恒星系统(恒星类型/行星轨道)→ 行星(质量/大气/卫星)→ 地理气候 → 生命/种族 → 文明 → 历史。上一层是下一层的"输入参数源";反向改写只允许以显式"世界观例外声明"出现(如"此星因创世者意志而特殊")。
- **魔法三定律同样约束宇宙**: 用超自然力量解决冲突的能力须与读者对它的理解成正比;限制(代价、条件)比能力更重要;先扩展已有设定,再新增设定。位面与多元宇宙本质是"宏观魔法",三定律全量适用。
- **多元宇宙必须有"为何存在多世界"的理由**: 量子分支(退相干天然隔离)、模态实在论(可能世界靠"可达关系"连接)、永恒暴胀/气泡宇宙(时空不可达隔离)——选择即锁定隔离机制形态。
- **代价经济学**: 任何跨尺度行为(跨位面、跨宇宙、超光速、复活)都必须有可量化代价与失败模式。无代价旅行取消空间稀缺性,会连锁瓦解地理、贸易、战争、侦查等全部下游模块。
- **深时视角**: 用宇宙级时间线(恒星主序、红巨星、热寂)而非仅文明史来编排历史;文明事件与恒星事件对齐可获得天然的"情节钟"。

## 模块依赖链

| 层 | 关键参数(输出给下一层) | 接口对象 |
|---|---|---|
| 宇宙学 | 宇宙年龄、星系结构、空间拓扑、时间流速 | 历史篇时间轴、位面篇 |
| 恒星系统 | 恒星光谱/质量/光度/寿命、宜居带内外缘、雪线、行星轨道 | 行星篇、地理篇天文参数 |
| 行星 | 质量/半径/大气/自转/卫星/磁场 | 地理篇气候与地形 |
| 位面/多元宇宙 | 位面法则清单、关系图、旅行代价 | 法则篇魔法、种族篇异界种族 |

## 宇宙档案清单

| # | 档案件 | 内容要点 |
|---|---|---|
| 1 | 最高法则页 | 1–3 条物理/魔法终极规则,每条标注升格理由 |
| 2 | 宇宙时间线 | 大爆炸/创世→恒星世代→文明纪元→终局时刻表 |
| 3 | 恒星系统参数表 | 每颗恒星: 光谱型/质量/光度/年龄/寿命/宜居带 |
| 4 | 行星参数表 | 轨道/偏心率/质量/大气/自转/卫星,附所依据公式 |
| 5 | 位面档案 | 每位面法则清单(时间/重力/物质/魔法/生死) |
| 6 | 位面关系图 | 层级/派生/镜像/相邻四类关系,附旅行路径与代价 |
| 7 | 世界观例外声明 | 所有"故意违反物理"的显式条目(反向改写集中登记) |
| 8 | 接口对照表 | 宇宙参数→地理/种族/历史引用点逐条核对 |

## 构建操作

1. 先写 1–3 条最高法则并记录"升格理由"——任何新设定先过回溯测试(能否由法则推出),失败则改事实;必须改法则时,在档案登记理由(每升格一次都应心痛);
2. 再按依赖链逐层推进: 宇宙→恒星→行星→地理→生命→文明→历史,层间只传参数表(恒星质量/光度/寿命、行星轨道/自转/倾角/卫星),禁止下层静默改写上层参数;
3. 为每颗恒星行星建参数表并跑回溯测试: 能否由质量/光度推出轨道、寿命、气候?历法能否由轨道与自转推出?
4. 为每位面写三钩子: ①2–3 条可感知法则差异; ②一处资源或禁忌; ③一个周期性或事件性接口(如位面相合期改写地表法则)——凑不齐钩子的位面直接删除;
5. 动笔多元宇宙前先答"隔离、导航、代价"三问,再选模型(门+钥匙+中继结构,或距离/海拔递增难度);
6. 为每种跨尺度旅行写代价条目(能量/时间/生命/危险/失败模式),并检查它是否真被故事使用——写了不用的代价等于没有;
7. 把文明史放在恒星寿命坐标上("主序还剩 5 亿年"),让宇宙事件充当倒计时,防止"永恒静止宇宙";
8. 设定分级: 作者知识(bulk)与角色知识(tip)分层,正文只露 tip,完整版进设定集;定期做"删掉是否损失"审计,无损失即删。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 巨星配久远文明、轨道在宜居带外却有液态水 | 用参数表跑回溯测试,一切由恒星质量/光度推出 |
| 位面只是"换个风景",无法则差异 | 每位面写法则清单: 时间/重力/物质/魔法/生死 |
| 平行世界互相渗透无理由 | 先答隔离三问: 为何 A 世界的事件不污染 B 世界 |
| 传送免费,空间失去稀缺性 | 每种旅行明码标价: 能量/时间/生命/失败模式 |
| 历法与公转自转周期矛盾 | 历法由轨道参数推导并交叉验证 |
| 下层静默改写上层参数 | 反向改写必须以显式"世界观例外声明"登记 |
| 设定删掉无损失仍保留 | 用"读者视角"四步检查,无损失即删 |

## 检查点/清单

- [ ] 最高法则 ≤3 条,每条有升格理由记录?
- [ ] 恒星/行星参数表齐全,回溯测试通过?
- [ ] 模块按依赖链单向推进,层间只传参数表?
- [ ] 每位面有法则清单+资源/禁忌+周期接口三钩子?
- [ ] 多元宇宙三问(隔离/导航/代价)已答并有机制?
- [ ] 每种跨尺度旅行有代价条目且被故事实际使用?
- [ ] 宇宙时间线对文明有可见压力(情节钟)?
- [ ] 世界观例外声明集中登记,无静默例外?
- [ ] 接口对照表与地理/种族/历史逐条核对?
