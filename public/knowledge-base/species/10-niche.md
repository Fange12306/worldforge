# 生态位设计与生物多样性

> 目的: 用群落生态学硬约束为物种/种族分配"生存坐标", 使多样性与怪物密度可计算、可审查。
> 前置: 与地理篇(气候/生物群系)、物种方法论(五卡档案)互相引用; 输出(生态位维度、营养级、多样性梯度)是地图与文明布局的输入。

## 核心理论: 六个机制

1. **生态位=n维超体积**: 把影响物种存活的每个环境变量(温度、湿度、食物粒径、盐度、光照、竞争者)视为一个维度; **基础生态位**=使种群净增长率≥0的全部点集; 受竞争、捕食等生物作用压缩后, 物种实际占有的**实现生态位**是其子集。生物多样性=生态位空间被填充与分割的方式——生态位不再是抽象角色, 而是可作图、可比较、可建模的坐标盒。

2. **竞争排斥原理**: 若两个物种在同一有限资源上竞争且生态位完全重叠, 则不能无限共存, 竞争力弱者被排斥; 稳定共存要求物种在多种资源间存在**权衡**。推论: 群落中每个物种必须占据不同的生态位维度——"生态位分化"是维持生物多样性的前提。

3. **营养级金字塔与能量预算**: 能量每经一个营养级约损失 90%、传递仅约 10%; 因此营养级数有限(通常 4~5 级), 顶级捕食者获得的总能量极小——个体大、数量少、所需领地极大, 形成"**顶级捕食者必然稀少**"的铁律。种群密度约正比于体型^(-0.75): 体重×10, 密度约÷5.6。

| 营养级 | 能量(kcal, 初级生产=100,000) |
|---|---|
| 初级生产者 | 100,000 |
| 草食动物 | ~10,000 |
| 一级肉食者 | ~1,000 |
| 顶级捕食者 | ~100 |

4. **生态位分化与同域共存**: 同一区域物种按不同取食高度/方式分配资源(如五种林莺同林错层觅食); 共存物种体型比约≥1.3; 竞争可驱动**特征位移**——同域近缘种在形态上拉开差距。

| 共存机制 | 做法 |
|---|---|
| 资源分配 | 不同食物粒径/取食高度/生境微区 |
| 时间隔离 | 昼夜、季节错峰 |
| 捕食者介导共存 | 捕食偏爱优势种, 频率依赖 |
| 存储效应 | 成体长寿+种子库/卵库跨越不利期 |
| 权衡 | 繁殖快 vs 竞争强 |
| 中间干扰 | 中等频率/强度干扰下多样性最高 |

5. **岛屿生物地理学**: 物种数 S≈cA^z(面积↑→物种数↑); 岛屿物种数是**迁入速率**与**灭绝速率**的动态平衡点——面积↑→灭绝率↓; 距源区(大陆)越远→迁入率↓。推论: 面积与隔离度共同决定物种丰富度; 岛屿特有种比例高、物种更替率高、对干扰更脆弱。

6. **生物入侵与灭绝**: 岛屿与隔离系统缺乏共同演化防线——进化史无捕食者的"天真"物种易被入侵者捕食或竞争排除, 特有种灭绝风险最高; 少数广布"赢家"取代大量特有"输家"(生物同质化); 入侵种彼此促进可形成失控的"入侵性融毁"。

## 构建操作

1. 给每个物种/种族开"生态位维度清单": 列出 8~12 个维度(食物粒径、水分、温度、盐度、活动时段、繁殖场所、天敌、共生者), 分别标注基础位与实现位; 若两个种族在所有维度重叠, 按竞争排斥原理必须"写死一个或写分一个"——这本身就是现成的剧情资源;
2. 用能量预算硬约束"怪物密度": 设定世界初级生产力后, 按每级 ~10% 传递效率反推各营养级总生物量; 顶级捕食者(龙、巨兽)数量应稀少, 给它们超大领地与极低繁殖率, 避免"遍地巨龙"破坏可信度;
3. 同域共存要有"分割轴": 让同一区域的物种/种族至少错开一个资源轴(昼伏夜出、不同取食层、不同猎物、错峰繁殖); 用体型比≥1.3 或特征位移写"竞争导致形态分化"的背景故事(两个近亲种族在接触带发展出不同獠牙/喙/食性);
4. 用岛屿生物地理学设计地图: 按物种-面积关系规划物种数——大陆腹地物种多、竞争激烈; 小岛物种少但特有种比例高、易灭绝; 离大陆越远迁入越少, 区系越贫乏或越特化; 群岛=进化实验室与"脆弱文明"设定; 碎片化大陆可用保护区政策冲突制造剧情;
5. 把营养级联与关键种写成叙事引擎: "猎杀最后一只关键种"必须引发可见的连锁崩塌(除狼→鹿泛滥→森林退化→河流改道); 先画食物网箭头图, 预演任意物种移除后的级联, 使生态灾难剧情自洽;
6. 让文明依赖可见的生态系统服务: 传粉生物、水源林、净化水体、防洪湿地成为文明的"基础设施", 其丧失直接导致饥荒、疫病、战争; 单一作物/单一猎物的文明更易崩溃;
7. 设计入侵与灭绝事件: 殖民、贸易或魔法传送引入外来种(鼠、蛇、杂草)→岛屿特有种灭绝→生物同质化; 用"入侵性融毁"制造多种入侵种互相促进的失控灾难; 背景灭绝+局部大灭绝可作世界史的时间锚点与"上古遗种"设定;
8. 布置生物多样性梯度: 低纬度、低海拔、高生产力区多样性最高(雨林、珊瑚礁), 高纬度、高山、沙漠、极地递减; 用梯度塑造文化差异——赤道"万族竞存"、北方"单一而坚韧", 让商路与迁徙路线沿梯度分布。

## 常见错误对照

| 常见错误 | 正确做法 |
|---|---|
| 遍地巨龙/顶级捕食者成群 | 按 ~10% 能量传递反推密度, 顶级捕食者必然稀少 |
| 两族生态位完全重叠却共存 | 写清分化维度, 写不出则合并为一族 |
| 岛屿物种数与大陆相同 | 按面积-隔离度预算, 小岛少而特化 |
| 猎杀关键种无后果 | 先画食物网, 预演移除后的级联 |
| 文明不依赖生态 | 列明文明依赖的生态系统服务清单 |

## 检查点/清单

- [ ] 每物种生态位维度清单完整(基础位/实现位)?
- [ ] 竞争排斥审查通过(无全维重叠的共存)?
- [ ] 能量预算闭合(怪物密度与营养级匹配)?
- [ ] 同域物种至少错开一个资源轴?
- [ ] 岛屿/大陆物种数与面积-隔离度匹配?
- [ ] 关键种移除有可见级联后果?
- [ ] 文明依赖的生态系统服务已列出?
- [ ] 入侵/灭绝事件有生态后果与时间锚点?
