# 笔记 32: 反事实历史与分岔点(counterfactual)

> 研究主题: 反事实历史方法论、最小改写原则、路径依赖与锁定、可能世界语义、反事实评估因果权重。

---

## 核心理论

1. **反事实历史与"混沌史学"**: 反事实历史追问"如果……会怎样", 在保持真实历史绝大部分不变的前提下构造替代过去。弗格森《虚拟的历史》(1997): 历史不是铁律预先写成的单线进程, 每时每刻都敞开多种可能的未来; 借用混沌理论"对初始条件的敏感依赖"——微小事件可放大为截然不同的宏观结果。合法性标准: 反事实须基于当时人可得的证据、落在历史行动者合理选择范围内。

2. **最小改写原则(minimal departure / minimal rewrite)**: 源自瑞安(1980)叙事可能世界理论: 除非明确指示, 默认虚构世界与熟知世界在所有未言明处一致。反事实同构于此——分岔只改动必要的最小事件, 其余由历史惯性原样延续。**改动越多越像纯想象而非分析。**

3. **可能世界语义(刘易斯, 1973)**: "若 A 则 B"为真, 当且仅当在所有"最接近现实世界的 A-世界"里 B 为真。接近度由相似性排序: (i) 不允许大面积违反自然法则的"奇迹"; (ii) 分岔点之前的历史与现实完全一致; (iii) 分岔后共享尽可能多的事实。1979 年"小奇迹"模型: 分岔仅在一个点引入微小偏离, 之后世界按法则重新展开。

4. **反事实因果理论(刘易斯)**: C 导致 E, 当且仅当若 C 不发生则 E 不发生; 2000 年转向"作为影响的因果"。现代形式化(Halpern-Pearl 结构因果模型)。史学应用逻辑即密尔"差异法": 只改动候选事件, 结果差异大则其权重大。

5. **路径依赖与锁定**: 大卫(QWERTY, 1985)与阿瑟(收益递增, 1989): 自增强机制(学习效应/网络外部性/协调效应/适应性预期)使早期微小事件被放大, 推入某均衡并锁定。诺斯引入制度, 皮尔森引入政治学(正反馈、关键节点)。**反事实与路径依赖互为表里: 分岔点即关键节点, 其后果进入"锁定的走廊"。**

6. **分岔点类型学**: 结构性分岔(技术/制度/生态/人口——约束强、变化慢)vs 偶然性分岔(个人决策/战役/巧合——约束弱、变化快)。二者比例决定历史系统的"自由度曲线"。

## 机制与案例

- **"英国中立, 1914"**(弗格森): 只改一个决策, 德国大概率陆上战胜俄法, 一战缩短, 十月革命与纳粹上台或可避免——示范最小改写驱动多重后果链;
- **"没有希特勒的纳粹德国"**(Burleigh): 共和国的结构性危机仍可能让激进右翼掌权——结构约束 vs 偶然事件的分层;
- **考利《What If?》**: "枢纽点"(hinge points)遴选战役级分岔;
- **铁路的社会节约**(Fogel, 1964): 反事实构造"无铁路的美国经济", 估算国民收入仅损失几个百分点——反事实计量史学为宏观因素"称重"的典范;
- **埃文斯《Altered Pasts》(2014)**: 多数反事实缺乏证据基础、混淆"可能"与"可辩护"——反事实的价值在于揭示结构而非预测(最重要的方法约束)。

## 对虚构世界构建的启示

1. **切片双向推演总原则**: 切片 = "锁定产物+未决开放面"复合体。前推未来: 识别路径依赖机制沿自增强方向外推, 只在未锁定的"开放面"引入新分岔; 后推过去: 从每个显著特征反推其成因(由哪次分岔锁定而成), 在时间线上铺设 2-3 个关键节点让过去呈现"沉积层";
2. **用反事实给事件称重**: 对每个候选事件做最小改写实验(只删除/改变该事件), 分别前推 1 代/5 代/50 代; 差异大→枢纽事件(驱动主线), 差异迅速被吸收→普通事件(可作背景)。这同时是设定的"增删审稿": 删掉不改变世界的设定;
3. **用相似度排序界定"合法反事实"**: 分岔点之前一字不改; 分岔后尊重已锁定的法则与制度; 只允许"小奇迹"; 给每个分支标注与正史的"距离";
4. **分岔点类型学用于节奏控制**: 结构性分岔(制度/宗教改革/技术革命)改变世界轨道→时代边界; 偶然性分岔(一役/一决/一疫)制造张力→叙事钩子;
5. **走廊模型(自由度-时间曲线)**: 关键节点后立即进入锁定走廊——短窗内自由度大(写"关键抉择"), 锁定期内惯性强(写"制度压迫与反叛"); 绘制每时代自由度曲线指导剧情密度;
6. **长期推演的诚实性**: 短期后果直接因果链推出; 中期受制度反应调制; 长期高度不可预测——远未来保留"模糊区", 用趋势+约束描述;
7. **防两种病**: 过度蝴蝶效应(一切皆变)与过度决定论(一切皆不变)——最小改写是平衡器; 收尾用"逆推验证": 最终世界必须能由切片+有限分岔+已知机制推出, 不依赖隐藏奇迹。
