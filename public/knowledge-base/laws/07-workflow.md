# 法则设计工作流

> 从用户指令→法则草稿→一致性审查→下游推导的完整流程、法则卡片写法、设定圣经维护。

## 核心方法

**公设-演绎法则论**(Campbell): SF 只取"一个或极少数新公设", 再"严格推导这些有限公设的逻辑后果"。**法则化世界构建: 世界 = 公设集 + 演绎闭包, 法则是世界唯一的"输入", 地理/文明/历史都应是导出项。**

**法则优先于天文/地理/文明的论证**: ①**可推导性**: 法则集是唯一需要"发明"的层, 其余一切可演绎生成; ②**变更成本**: 改一条法则连锁污染数百条派生设定, 改地图改文化代价极小——把高成本决策前置; ③**最小差异面**: 3-5 条硬法则即可定义"与地球不同的世界"; ④**读者契约**: 法则=读者理解与推理的锚点, 也是"作者不耍赖"的承诺书。

## 工作流四段

1. **指令解析**: 从用户意图提取题材公设(what-if premise), 写成可检验的命题句——拒绝空泛表述("魔法存在"不合格, "施法须燃烧金属、金属数量有限且单次用量固定"合格);
2. **法则草稿/卡片**: 压缩为 3-5 条硬约束, 每条五要素——规则陈述/限制(不能做什么)/代价(使用付什么)/可证伪表现/下游影响清单。用"否决式+成本式"表述强化硬度("施法者死后灵魂立刻消散, 无复活、无通灵"优于"灵魂存在"); 数量纪律: 超过 5 条即砍(第三定律+法则冲突随数量平方增长+细节守恒定律: 故事用不到的不进卡片);
3. **一致性审查**: ①矛盾扫描——对每两条法则做合取检验(同真推出悖论→修改其一); ②推演测试——把每条法则"跑一遍"看是否导出矛盾(若传送须"清晰想象目的地", 则无人能去从未见过的地方, 与"发现新大陆"冲突); ③读者视角测试——读者默认世界遵循现实物理, 凡偏离之处必须是法则显式声明的偏差("Guy at the Gym"谬误);
4. **下游推导**: 按"法则→天文→地理→气候→生物→文明→历史"依赖序逐层推导, 每层只允许使用上层已定事实。

## 法则卡片写法(3-5 条硬约束)

| 要素 | 说明 | 示例 |
|---|---|---|
| 规则陈述 | 这条法则是什么 | 世界能量以"灵脉"形式存在, 沿古板块缝合线分布 |
| 限制 | 不能做什么(否决式) | 灵脉不能凭空创造, 只能引导与积累 |
| 代价 | 使用付什么(成本式) | 施法消耗灵脉能量, 过度开采导致枯竭 |
| 可证伪表现 | 读者可检验的现象 | 灵脉富集区植物异常生长、动物异变 |
| 下游影响清单 | 预期连锁 | 地理(灵脉地貌)/文明(灵脉学院)/历史(灵脉战争) |

## 设定圣经(setting bible)维护

- **三层分层**: 核心法则层(卡片, 恒定)/推导层(地理文明, 可演进但标注上游法则)/细节层(随时扩充);
- **依赖图**: 每条派生条目挂"上游法则引用"——依赖图=变更影响评估的数据结构;
- **变更纪律**: 变更即入圣经(不等完稿)+交叉引用同步更新+保留变更日志;
- **审查制度化**: 类比 CI——每次法则变更触发一轮"推演回归测试"(把 3-5 条法则重跑所有已派生事实), 圣经即测试套件;
- **retcon 分级**: 小澄清(读者"本来不知道"→无痕吸收)vs 大矛盾(必须显式承认, "透明优于偷偷 retcon"); **法则层必须恒定, 改动只允许发生在导出层**;
- **冰山原则**: 作者掌握 90% 设定沉在水下, 文本只露叙事需要的一角。

## 变更影响评估(改一条法则连锁改变什么)

①遍历依赖图(直接依赖+二级传播); ②区分可变层(政治/态度/技术/局部地理)与恒定层(基础法则/历史事实); ③对每条法则问三问——推到极限会发生什么? 失效会发生什么? 被恶意利用会发生什么?; ④反事实测试: 把魔法从世界删除, 社会还能成立吗? 不能→魔法已渗入日常肌理; 毫无变化→魔法是装饰品。

## 从 0 到 1 完整流程

用户指令 → 提炼 what-if 公设 → 写成 3-5 条法则卡片 → 一致性审查(矛盾扫描+推演测试+读者视角测试) → 按依赖序下游推导(天文→地理→气候→生物→文明→历史) → 结果回填圣经并挂上游引用 → 此后一切变更走"影响评估→分级处理(澄清/矛盾)→更新圣经"闭环。
