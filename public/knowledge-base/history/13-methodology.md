# 历史构建方法论

> 从世界法则+地理+文明推导历史、历史切片双向推演操作流程、一致性检查清单、避免"历史设定病"。

## 核心原则

1. **历史 = 世界法则 + 初始条件的确定性展开**: 虚构历史不是任意年表, 而是法则层(物理/魔法/神学)、地理约束与文明参数共同决定的演化轨迹。法则层是"社会的物理学", 一切历史事件都应是它的可推导结果; 魔法/神祇不是装饰, 而是改写人口-技术-能量方程的自变量。
2. **分层时间观**: 长时段结构(百千年计)/中时段局势(十年百年计)/短时段事件(日年计)——三层须并存且变化速率不同(纪元不随朝代更替, 朝代不随事件终结)。
3. **文明周期律**: 赫勒敦 asabiyyah(王朝四代兴衰)+图尔钦世俗周期(精英过剩, 200-300年)+汤因比挑战-应战——合成"从文明参数推导朝代序列"的机制库。
4. **反事实推演纪律(弗格森)**: 改动须"最小化"——只改变一个前提, 其余约束保持一致。**历史切片=系统状态, 推演=在法则约束下解演化方程, 而非自由联想。**
5. **反设定病**: just-in-time 构建; 设定服务故事; 定期"年表瘦身"。

## 双向推演操作流程

1. **输入**: 历史切片 S₀(人口/边界/制度/技术/文化 + "痕迹层": 废墟/地名/习俗/禁忌/世代创伤);
2. **前推(推演未来)**: 以 S₀ 为初值, 用机制库(人口学/技术扩散/气候冲击/制度变迁/周期律)逐段模拟演化, 生成候选未来 S₁…Sₙ; 每步只注入一个外生冲击, 其余由内生机理驱动;
3. **后推(推演过去)**: 对 S₀ 的每个痕迹做成因追问(这座废墟因何而毁? 这个地名是哪层语言的残留? 这条边界是战争线还是河川线?), 逐层剥出事件, 构建证据链;
4. **对撞检查**: 前推出的未来必须能抵达既定后续切片; 后推出的过去必须解释 S₀ 全部细节; 对不上的缺口=需要补写的"隐藏历史";
5. **输出**: 三层年表(纪元/朝代/事件), 每层标注驱动机制与被解释现象;
6. **检查点**: ①因果闭合(无悬空事件)②比例感(千年无事一朝剧变, 不要每百年都天翻地覆)③机制守恒(魔法/神祇不能随剧情临时加码)④可证伪(设定须能被故事内证据检验)。

## 构建顺序

**法则→地理→文明→历史→故事**: 法则层定长时段约束(魔法能量潮汐=气候周期; 神祇是否直接干预=神学边界; 死后续存与否=人口压力泄压阀); 地理层是"第一因"(直接从地图读出文明摇篮/贸易线/战争咽喉/"历史伤疤": 被攻破的山口/沉没的陆桥/改道的河流); 文明层给参数(人口基数/技术树/制度类型/宗教观/地缘压力), 周期律据此自动生成朝代序列。

## 一致性检查清单

- [ ] 每个历史事实都有前因(无凭空事件);
- [ ] 人口/资源/技术数字闭合(战争伤亡与人口基数匹配, 大军团需要粮道与后勤);
- [ ] 制度与地理匹配(山地民族不轻易中央集权, 岛国重海权);
- [ ] 时间线无悬空;
- [ ] 层间速率正确(纪元不随朝代频繁更替);
- [ ] 魔法/神祇机制守恒;
- [ ] 历史伤疤有交代(当前世界的创伤/禁忌/未解之谜都有历史成因);
- [ ] 双向校验闭环(未来的遗迹在当前切片埋下种子)。

## 比例感

长时段写"结构", 中时段写"趋势", 短时段写"人"。让个人事件成为结构压力的表面表达(一场宫廷政变=精英过剩周期的触发器)——三层互相咬合; 反之若所有大事件都源于个人意志, 历史就退化为剧情串。

## 案例模板

- **周期律驱动朝代序列**: 赫勒敦四代论+图尔钦周期预写"王朝时钟"(开国尚武→二代大兴土木→三代奢靡→四代分裂→新边缘集团入主);
- **反事实重构整个世界**(《米盐年代》式): 只做一处改动(如黑死病消灭欧洲人口), 其余按真实规律演化;
- **深时地层作为历史档案**(《破碎的星球》式): 周期性灾变毁灭文明, 地貌断层全是前代文明活化石;
- **托尔金范式与陷阱**: "先有神话历史再有故事"成就了中土, 也是设定病最大病源——健康做法是"冰山原则": 作者拥有全部历史, 文本只露叙事需要的一角。

## 反设定病纪律

- just-in-time 构建(只构建故事当下需要的部分);
- 每段设定标注服务的故事功能;
- 与叙事无关的设定降级为"隐藏设定"(作者知道即可, 文本不展示);
- 定期"年表瘦身"——删除不解释任何现状的条目。
**历史的价值不在体量, 而在它解释了什么、埋下了什么。**
